### 6.2 异常被吞成业务错误（高风险）

```js
// useCanvasAgentTools.js:1397-1402
catch (e) {
  return { ok: false, error: ... }   // ← 无任何 logger
}
```

- 工具层异常被**统一转成 `{ok:false, error}` 返回给 LLM**
- **无任何 logger 输出**
- `callTool` 分发前仅有 debug 级日志

**影响**：画布写入异常在 debug 关闭时**全链路不可见**，排查只能靠复现。

## 九、问题清单

### 🔴 高

#### #1 AI 撤销栈无上限，`MAX_AI_UNDO` 定义但从未使用

- **位置**：`useCanvasAgentTools.js:274`（定义）vs `:1395`（`pushActiveAiUndo` 未引用）
- **证据**：

```js
// :274
const MAX_AI_UNDO = 20          // 定义
// :1395
pushActiveAiUndo(...)           // 无上限校验，未引用 MAX_AI_UNDO
```

- **影响**：AI 撤销栈**无界增长**，长会话内存膨胀；且**注释与实现矛盾**，误导后续维护者
- **建议**：在 `pushActiveAiUndo`（`conversationAiState.js:103`）内加截断，并补测试锁定

#### #2 工具层异常被吞成业务错误，全链路无日志

- **位置**：`useCanvasAgentTools.js:1397-1402`
- **证据**：`catch` 仅 `return { ok:false, error }`，**无任何 logger**
- **影响**：画布写入异常在 debug 关闭时完全不可见，线上排查只能靠复现
- **建议**：catch 内补 `logger.error`，保留原始堆栈

#### #3 Skill 全链路静默失败（6 处 catch 无日志无提示）

- **位置**：`skillStore.js:116, 125, 169, 178, 192, 197`
- **影响**：用户自定义 Skill **静默消失**，UI 不报错，数据直接丢
- **建议**：逐处补 `logger.warn` + toast

#### #4 `toolRegistry` 全局单例返回 live 引用，可被任意模块 mutate

- **位置**：`src/components/base/toolRegistry.js:20`（`const tools=[]`）、`:29`（`getTools`）
- **证据**：`getTools()` 返回**引用**而非副本
- **影响**：任何持有返回值的模块都能外部 mutate 全局工具表；`resetTools()`（`:34`）生产误调即清空全部工具
- **建议**：`getTools()` 改为返回 `[...tools]` 冻结副本；补独立单测

### 🟡 中

#### #5 端点与存储键硬编码，无编译期拦截

- **位置**：`agentRuntime.js:141`（`/api/proxy`）、`:162`（`/api/agent/{key}/chat`）、`useAgentChat.js:363`、`useCanvasAgentTools.js:43`（`canvasAgentGenParams`）
- **证据**：端点仅在 `contracts.js:558/562` 的 apiRegistry 出现，**不在 `API_ENDPOINTS` 常量表**；存储键登记了但代码用本地字面量
- **影响**：端点改名/键迁移无编译期拦截，**运行时 404 才暴露**
- **建议**：提取到常量表并 import 引用

#### #6 `agent:credit-gate` 登记表滞后

- **位置**：`contracts.js:69-74` 登记 `from:[] to:[]`，实测双向存在
- **证据**：发布 `useCanvasAgentTools.js:1046/:1101`；订阅 `AgentPanel.jsx:242`
- **影响**：`npm run check:events` 双向校验形同虚设；**可能被误判为死事件而删除发布逻辑**
- **建议**：更新为 `from:['useCanvasAgentTools.js:1046,1101'] to:['AgentPanel.jsx:242']`

#### #7 积分门禁零观测

- **位置**：`useCanvasAgentTools.js:1046/:1101`（发布）、`AgentPanel.jsx:242`（订阅）
- **影响**：**烧钱分支无任何日志**，门禁置位/清除/失败全不可见
- **建议**：补 logger

#### #8 creditSwitch 双读无同步

- **位置**：`useCanvasAgentTools.js:70`（工具层读）vs `AgentPanel.jsx:230`（面板读）
- **证据**：注释称"判定收敛在 executePlanTool 一处"，实际两处各读一次，**无订阅同步**
- **影响**：面板开关状态与工具判定可能瞬时不一（切窗口/多标签）
- **建议**：收敛为单一读取点 + 订阅

#### #9 两条发送链路超时重试配置不一致

- **位置**：链路 A `agentRuntime.js:141`（`timeoutMs:0 / retries:0`）vs 链路 B `:162`（裸 fetch 无超时）
- **影响**：**长请求可能永久挂起**，用户无感知、无取消手段
- **建议**：统一超时策略并暴露取消能力

#### #10 `accountsStore` 裸 localStorage 绕过登记表

- **位置**：`accountsStore.js:272`、`:304`
- **影响**：云同步导出/导入路径绕过 `STORAGE_KEYS` 契约，`check:keys` 静态校验失效
- **建议**：改走 `storageAdapter` 或显式登记 `backend:'native'`

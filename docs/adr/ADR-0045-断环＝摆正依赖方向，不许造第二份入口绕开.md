# ADR-0045 · 断环＝摆正依赖方向，不许造第二份入口绕开

- **状态**：生效
- **结论**：修结构环只有一条合法路径——消除依赖倒置（让依赖指向更稳定的叶子）。**禁止**新增中转模块 / 裁剪门面出口来绕开环。判据：环上每条边的两端，稳定者在下。
- **日期**：2026-09-20
- **裁定人**：架构师
- **触发**：TD-22-68（engine/core↔命令类结构环 26 组拆除）

## 背景

`check-arch` 的 `no-circular` 判据（2026-09-19 收窄到「会 TDZ 的环」）会逐条列出**无 TDZ 实害的结构环**，登记为结构债。

处理这批环时出现了一条**错的默认做法**（本节即其留档，防重提）：**把环上某侧要用的函数抠到新文件，让那一侧改连新文件**。
- 环确实断了，但**依赖倒置原封不动**（发起方仍 import 那个含 UI/大实现的门面）；
- 凭空造出**第二份导出面**，还得按当前消费者**裁剪**转发范围才不被死代码闸报 ⇒ **假收口**；
- 真实收益 = 0：正确性未变，只是让闸的数字变好看。

⇒ 这是「**改闸不改问题**」：绕开环的闭合边，而非消除产生环的依赖倒置（同 ADR-0016）。

## 判据（它凭什么成立）

**环的燃料永远是依赖倒置，不是"文件放错"。** 两种形态：

| 形态 | 典型 | 稳定者应在下 |
| --- | --- | --- |
| **大模块兼两职** | 一个文件**既定义实现、又当 barrel**，而被环上其他文件顶层 import | 实现件 / 访问点在下，聚合 barrel 在上 |
| **跨层倒置** | 逻辑层 import 了含 UI 组件的域门面；或纯逻辑 import 了 DOM 工具层 | 纯逻辑在下，UI / DOM 在上 |

**判别式「绕开 vs 消除」= 依赖倒置改没改。**
绕开只换访问路径（倒置仍在 ⇒ 换个新需求就以别的形态复发）；消除让依赖指向更稳定的层（形态不再可能）。
**两者的区别无法从闸的绿灯看出来** ⇒ 闸绿不构成证据（ADR-0041）。

## 决议

**1. 修环三选一（按优先序，取能做的最前一个）**

| # | 手段 | 何时用 | 做法 |
| --- | --- | --- | --- |
| ① | **给大模块开叶子** | 环的闭合边指向"既定义实现又当 barrel"的文件 | 把**访问点**（单例/实例的 getter）剥到零依赖叶子；实现件构造期向叶子注册；环上其他文件改连叶子 |
| ② | **逻辑层直连纯逻辑** | 环的闭合边由"逻辑层 → 含 UI 的门面"构成 | 改直连那个纯逻辑模块，不经域门面（门面继续只露 UI 入口） |
| ③ | **契约下沉到零依赖叶子** | 多方共用一个"格式/协议"常量，而它现住在某层的实现文件里 | 把该常量下沉为**零 import** 的叶子，各层向下依赖它 |

**2. 禁止**
- ❌ 新增中转模块承接环上一侧函数的转发（＝第二份导出面，见 §背景）；
- ❌ 裁剪门面出口以迎合闸（闸报"无消费者死导出"时**改问题**，不是裁出口 —— ADR-0016）；
- ❌ 为断环改动环外消费者（只改**环上**的边）。

**3. 完成后必须验证**
- `npm run check:arch`：**结构环归零且不新增 TDZ 环**；
- 探针（ADR-0041）：把修法**改回旧写法** ⇒ 该环必须**重新出现**（仍绿 = 闸失明）。

**落点（本条首次落实，可作范本）**：`videoEditor/engine/core/editorInstance.ts`（手段①）·
`hooks/useNodeData.ts` · `agent/canvas/agentCanvasHost.ts`（手段②）·
`canvas/shell/promptChipFormat.ts`（手段③）。

## 后果

- ✅ **收益**：结构环 26 → 0；依赖方向回正（逻辑→逻辑、DOM→格式契约）；门面语义保住（消费者零改动）。
- ⚠️ **代价 / 回潮风险**：手段① 会新增一个叶子文件 —— 它的合法性**只在于"零运行时依赖"**；若把有依赖的东西塞进叶子，本判据即被架空。手段③ 可能使某常量离开"原属地"，需在文件头写明为何在此。
- 📌 **违反时的判据（怎么发现"又回去了"）**：
  1. **又出现结构环** ⇒ `npm run check:arch` 的「结构环」段非 0；
  2. **造了第二份入口** ⇒ `npm run check:dead-code` 报「无消费者的死导出 `+ <门面>::<导出>`」（此时**应改问题，不是裁出口**）；
  3. **逻辑层 import 到含 UI 的门面** ⇒ 对目标文件跑 `node scripts/mv-sync-refs.mjs refs <file>`：`src/hooks/` 或 `base/store/` 的消费者出现在"引用含 `.tsx` 的域门面"即违规；
  4. **探针**：改回旧写法 ⇒ `check:arch` 必须重新报出该环。

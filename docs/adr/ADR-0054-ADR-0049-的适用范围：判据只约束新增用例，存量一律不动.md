## 背景

**旧约定**：`ADR-0049`（2026-09-20 裁定）禁两类用例 —— ① 文档测试；② UI 面板存在性测试。其决议第 1 条明写「**禁两类用例（新增与存量同此判据）**」，并把「存量 `tests/unit/*.test.tsx` 里的 UI 存在性用例待清点」列为**待办②**。

**它当初为什么这么定**：这两类断言（"某个图标／元素渲染出来了"）恒绿或恒假红，属自证式装饰 —— 判据本身是对的，问题出在**它要不要溯及存量**。

**触发这次修订的实测**（2026-09-21 清点，落账见 `daily/架构日志/25-跨区-ADR-0049存量用例清点-2026-09-21.md`）：

| 形态 | grep 命中 | 其中真断言 | 其余是 |
| --- | --- | --- | --- |
| `toBeTruthy` | 297 行 / 35 文件 | 297 | — |
| `querySelector` | 172 行 / 28 文件 | 62 | 110 行是**定位/取值** |
| `getAttribute` + `className` | 78 行 / 19 文件 | 70 | 8 行是**注释／类型定义／字符串模板** |

## 判据（它凭什么成立 / 为什么不成立）

1. **形态口径在存量上失效**（与 `ADR-0019` 的净减口径同款硬伤，见 `scripts/m1-count.mjs` 头部）：grep 把注释（`Comet.test.tsx:7`）、类型定义（`NodeTitle.test.tsx:23`）、字符串模板（`veMissingMediaIndicator.test.tsx:64`）、定位取值一并计入 ⇒ **"按形态数删"= 按噪声删**。
2. **真违规数机器给不出**：唯一判据是「把被测实现改坏，断言还绿不绿」（7 步法 §7.2），这需要**逐条人读** 297 + 62 + 70 处 ⇒ 成本高。
3. **误删后果不可逆，且方向与既有红线相反**：存量里混着**真契约断言**（`getAttribute('src')` 断的是"图片取错没取错"、`aria-*` 断的是可访问性状态），与 `NodeTitle` 那条纯样式断言同文件同形态 ⇒ 按形态批量删必伤真契约，直接对撞 `ADR-0053` 第 2 关「用户能做的事不许变少」。
4. **新增侧没有这个问题**：新写用例的作者**知道自己在断言什么**，判据当场可判、成本为零 ⇒ 判据的价值全在新增侧，溯及存量只产生风险。
5. **能不能不用 ADR 守**：不能。这是**判据的适用范围**问题 —— 结构／类型层／唯一入口都表达不了"只约束新增"；对账测试更表达不了（存量断言正是它要放过的对象）。⇒ 手段优先级 5，必须落 ADR。
6. **防线级别**（`ADR-0052`）：机器判不了（"存量 vs 新增"的边界靠回读 git 历史）⇒ 落**第 6 级：诚实声明 + 人工判据**，**不硬凑假 grep**。

## 决议

> ⛔ **以下 5 条为历史文本，已作废，不承载判据** —— 现行判据见 `ADR-0049`「决议 · ★适用范围」+「判据 5/6」。
> **不在此处重写**（重写 = 又造一份真相）；保留原文只为留痕：让后人看见**"一律不动 / 不改"这种缺射程的措辞是怎么产生的**。

1. **适用范围**：`ADR-0049` 的两类禁令**只约束新增用例** —— 本 ADR 生效日（2026-09-21）起**新写或新改**的断言。
2. **存量豁免**：生效日之前已存在的 `tests/unit/**` 用例**一律不动** —— 不删、不改、不因本判据判违规。**理由是避免误删**。（⚠️ "不改"措辞已废，见 0049 §判据 5）
3. **`TD-25-43` 随之失效**：其解法「按 ADR-0049 逐处判存在性即删」不再执行 ⇒ 改判**非债**（存量不再进入"清点—删除"流程）。
4. **投入方向**：新增用例按 `ADR-0049` 判；存量**不做专项清点**，**改到哪个文件顺手更新它的测试**。
5. ~~**落点**：判据唯一真源 = 本 ADR~~ ⇒ **已修正**：**判据唯一真源 = `ADR-0049`**；`spec/TEST-GUIDE.md` §〇 只留指针，不复述。

## 后果

- ✅ **收益**：消除大面积误删风险；不必为 ~430 处存量命中做逐条人判；判据回到"新增侧可当场判"这个成本为零的位置。
- ⚠️ **代价 / 回潮风险**：存量里的**真装饰断言**（如已被类型层拦住的图标样式断言）**留在库里**，测试集仍被稀释，"红"的信息量不因此提高；且"存量 vs 新增"靠回读 git 历史判，**非机器可判** —— 后人若图省事，可能把一条存量断言改一改就宣称"新写的"。
- 📌 **违反时的判据（怎么发现"又回去了"）**：**新写／新改**的用例里出现 ① 断文档文件／文本；② 断某 UI 元素／图标**存在**而非交互行为 ⇒ **违规，删**。**判存量不算违规** —— 若有人拿本 ADR 的存量豁免去为**新写**的存在性断言开脱，即违反本条。

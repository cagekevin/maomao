# ADR-0019 · 兜底六形态与净减口径：验收看数量净减，不看症状消失

- **状态**：生效
- **结论**：兜底只有六种形态（静默catch／失败归一null／占位对象+事后补／默认值兜底／UI层提前宣告成功／只在某入口补的补偿步骤）；验收口径是数量净减，不是症状消失。
- **日期**：2026-09-18
- **裁定人**：架构师
- **触发**：架构师改码7步法 Step 4 拆兜底 · 交付四闸「减一」（2026-09-17 立）

## 背景

**被推翻的旧验收口径：「症状消失了 = 修好了」。**

旧口径下，最省力的"修复"是**在报错处加一层接住**：症状立刻消失、测试变绿、用户体验"变好了"。真实代价被推迟到三个月后 —— 报错的位置不变，但**再也看不见**。

本仓实证（`daily/架构师日志/` 2026-09-17 系列）：13 条兜底里 **5 条**是地基缺陷的影子（附 A6）—— 症状消失时，真正的地基缺陷（id 重铸无根因 / 断链三件套掩盖地基缺位）**一个都没修**。

## 判据（它凭什么成立）

1. **因果不可逆**：兜底让症状消失 → 你会以为修好了 → 错误被埋得更深 → **真正的问题再也排查不出来**。且这个损失**不可逆**（信息已丢）。
2. **可数**：兜底是**代码实体**，可枚举、可清点、可比对改前改后 ⇒ 口径能落到**数字**上，不靠感觉（`CLAUDE.md §5.1`「复杂度实减」同款要求）。
3. **封闭枚举**：六形态是**封闭集**（下方决议）—— 因为"接住失败"的手段在 JS/TS 里只有这些位置：catch、返回值、对象构造、默认参数、UI 状态、补偿步骤。**答不出形态 ⇒ 你还没理解它**（不是发现了第 7 种）。
4. **与 ADR-0002 / ADR-0003 的边界**：那两条管**失败怎么表达**；本 ADR 管**不许把失败表达成"没事"**。

## 决议

**兜底的六种形态（看到自己在写这些 → 停，问"我在掩盖什么"）：**

| # | 形态 | 说明 |
| --- | --- | --- |
| ① | **静默 catch** | `.catch(() => {})` 零日志（ADR-0011 已确立无标记豁免） |
| ② | **失败归一 `null`** | 把各种失败全压成一个 `null` / `[]` / `{}`，调用方无从判别 |
| ③ | **占位对象 + 事后打补丁** | 先塞个假对象让它跑通，再在别处补 |
| ④ | **默认值兜底** | 拿不到就给个默认值，假装成功 |
| ⑤ | **UI 层提前宣告成功** | 上层先显示"成功"，下层其实还没落盘（违 CLAUDE §5.1「成功必须为真」） |
| ⑥ | **只在某一入口补的"补偿步骤"** | 哪里报错补哪里，而不是改结构 |

**强制动作**：每发现一处兜底，**逐个问「它在掩盖哪条地基缺陷？」** —— **答得出 → 改地基、删兜底**；**答不出 → 你还没理解它，不许加到第 7 种形态**。

**验收口径（唯一）：「兜底数量净减」** —— 不是"症状消失了"（症状可能只是被兜底埋了）。

**落点**：`.codebuddy/commands/架构师改码7步法.md` Step 4「🔒 拆兜底」+ 交付四闸「**减一 · 兜底净减**」。红线原文在 `CLAUDE.md §5.1`。

## 后果

- ✅ 验收从"看起来好了"改为**可数**（兜底总数净减），并把"加一层接住"从"修复"重新定义为**新债**。
- ✅ 与「确定性五种滑法/四种滑法」互补：滑法描述**过程**（改一版试一次），本 ADR 描述**产物**（六形态）—— 过程看不到，产物数得出。
- ⚠️ **代价 / 回潮风险**：删兜底期间**用户可见报错会变多**（失败不再被藏住）—— 这会被误报为"你改坏了"。回潮动因 = "上线要紧，先接住"。故落账必须**同时给度量**（兜底数改前/改后）。
- ⚠️ **反滥用**：不许拿"这是兜底"当借口**删除正常的防御性校验** —— 判据是"**它是不是在掩盖一条地基缺陷**"，不是"它长得像 catch"。类型守卫（`if (!x) throw`）不是兜底，是**fail-fast**。
- 📌 **违反时的判据**（怎么发现"又回去了"）：
  1. 改动的 diff 里**新增**了六形态之一，而落账未说明"它掩盖了哪条地基缺陷"；
  2. 报一个 bug 被"修复"后，**兜底总数未降**（改前/改后度量答不出）；
  3. 出现第 7 种"接住失败"的写法且无法归入六形态（= 理解不足就动手）；
  4. 测试为让新增兜底通过而**新增适配分支**（同款违 **减一** 闸）。

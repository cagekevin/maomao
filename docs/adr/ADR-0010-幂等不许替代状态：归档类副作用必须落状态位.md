# ADR-0010 · 幂等不许替代状态：归档类副作用必须落状态位

- **状态**：已取代
- **结论**：有可判状态就不许用「反正幂等、再补一次」替代判断；归档类副作用完成必须落唯一状态位，由所有产生方写入，判据只认它。幂等是后端实现细节，不是前端正确性依据。
- **日期**：2026-09-18
- **裁定人**：架构师（取证后自定）
- **触发**：TD-01-25

## 背景

剧本盒「生成完自动归类进素材库」这一步，旧设计的判据是**本会话内存 ref**（`recoveredAssetsRef`，只保证每个资产在本会话只补一次），
其**正确性论证**写在注释里：「幂等：后端按 sha1 去重，重复调用不会产生第二份；并记 ref 防同一资产重复触发」。

于是链路变成：生成路径（契约 `localize`）归档一次 → `taskStore.done()` **总会**广播 `agent:task-completed`
→ 同一会话里 recover handler 再**盲补**一次 ⇒ 同一资产归档两遍，靠后端 sha1 幂等兜住。

## 判据（它凭什么成立 / 为什么不成立）

**「既然幂等，重复补一次无害」凭什么成立？答不出**（铁律 6 / ADR-0001）：

- **幂等只承诺"不产生第二份"，不承诺"没多做"** —— 重复调用照付网络往返、落盘、`rescanUploads`、`relocateToFolder`、`emitResourceSent` 的成本；
- **它掩盖"谁是归档真相"**：排查「素材库里少了一张」时，要看生成路径、recover 补库、手动上传三条路，而三条路都不记状态；
- **幂等是后端实现细节**：把"sha1 去重"当**前端正确性判据**，是拿未契约化的跨层行为当依据（换后端/换存储即失效）；
- 且 `imageStatus === 'uploaded'` 这个**状态位本来就存在**，另两条归档路径（手动上传、从素材库选图）**都在写它** ——
  生成路径与 recover 补库不写 = 同族已写、本处漏改的**部分收口**。

## 决议

1. **「已归档素材库」的唯一状态位 = `ScriptBoxAsset.imageStatus === 'uploaded'`**，由**所有**归档路径写入：
   生成 `settle`（**仅当**本地化真的发生）/ 手动上传（`onRetryAssetImageUpload`、`onUploadAssetImage`）/ recover 补库。
2. **补库的判据只认该状态位**（`imageStatus !== 'uploaded'` 才补）；内存 ref 降级为**同会话在途去重**
   （补库是 fire-and-forget，状态位写入前可能再来一条广播）—— 两把锁管两件事，不是同一真相两份。
3. **生产者给全**：`generationContract.settle` 新增第 4 参 `ctx: { localized: boolean }` ——
   「本地化是否真的发生」由契约如实交出；`localize` 抛错/返空必须报 `localized:false`（消费方据此**不**标已归档，禁谎报）。
4. 落点：`src/components/base/store/generationContract.ts`（`settle` 签名 + `localized` 计算）·
   `src/components/scriptbox/scriptBoxEngine.ts`（asset `settle` 写状态位）· `src/hooks/useScriptBoxEngine.ts`（recover 判据）。

## 后果

- ✅ 收益：同一会话的**冗余归档归零**；「已归档」在三条路上**判据唯一**（状态位）；降级（localize 失败）不再被误标为已归档。
- ⚠️ 代价 / 回潮风险：后端 sha1 去重**仍保留**（层内合理，继续兜住并发/重放）——本约定约束的是**前端的正确性判据**，不是禁止幂等。
  最可能的回潮：有人图省事写回「反正幂等，补一次也没事」。
- 📌 违反时的判据（怎么发现"又回去了"）：
  · 出现「**先调用、再判断要不要做**」的补偿式代码（本处 `needsArchive` 判据被删或绕过）；
  · 某条归档路径**不写** `imageStatus`（三条路必须一致）；
  · `settle` 拿到 `ctx.localized` 却恒报 `true`（`generationContract.test.ts` 已锁：降级必须 `localized:false`）。
- **被取代于**：ADR-0026
- **毕业去向**：合并入 ADR-0026：幂等两面的完整判据在同一条

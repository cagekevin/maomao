# ADR-0028 · 拉取动作只由视图意图驱动，拉取结果不得反流

- **状态**：生效
- **结论**：拉取只由视图意图（来源／分类／下钻／项目）驱动，结果只进渲染不得反流；意图状态须自足——选中分类存对象含其 query 而非 key，默认分类取自 provider 静态声明而非已拉到的数据。
- **日期**：2026-09-18
- **裁定人**：架构师
- **触发**：TD-03-20 导入弹窗无限自拉卡死

## 背景

**旧形态（不是明文约定，是"没人觉得有问题"的写法）**：把「拉取结果」直接挂进「拉取动作」的依赖上游。

导入弹窗原实现里，视图只存分类 **key**（`catKey: string`），而 key → query 只能回查一张
**派生自已拉到的 `items`** 的表（`provider.categories(items)`）。于是：

```
items → categories → queryFor → navigate → 切 tab 的 useEffect → load → setItems(新数组) → …
```

`setItems` 每次给的都是**新数组**（即便内容相同）⇒ `items` 身份必变 ⇒ 环**必闭合**。
用户实测：弹窗内文件夹/图片疯狂刷新直到卡死（探针注入旧实现时输出 **14956 行**，即自拉了上千圈）。

**为什么同域两个兄弟面板是对的**（`ResourceLibrary.tsx:197-257`、`GeneratedView.tsx:144-207`）：
它们的 loader 只依赖 `currentFolder` / `typeFilter` / `projectId`（纯意图），
分类/目录清单**从不喂回**拉取触发 —— 差异只在**依赖方向**，不在功能。

## 判据（它凭什么成立 / 为什么不成立）

- **它凭什么成立（三条支撑，缺一不可）**：
  1. **物理层**：`setState(新数组)` 必然改变引用 ⇒ 只要"结果"在"动作"的依赖链上，环**在结构上必然闭合**，
     不是"可能出 bug"，是**必然**。⇒ 这是一条结构性判据，不是风格偏好。
  2. **职责层**：`items` 的**所有方是渲染**（pills / 网格），不是拉取动作。
     让消费者（渲染数据）去驱动生产者（拉取）＝越权（同 CLAUDE.md §5.1 / 7 步法 Step 4 三铁律）。
  3. **契约层**：`MediaRefProvider.categories` 契约明文要求「无数据上下文时必须返回**静态部分**」
     且「首个分类 = 默认分类」⇒ 默认分类**本来就取得到**，根本不需要依赖 `items`。
- **"把 effect 依赖收成 `[tab]`、内部再取默认 key" 为什么不成立**（曾作为偿还计划，已证伪）：
  ① 默认 key 仍派生自 `items`，只是把回边藏进 effect 内部；② `setTab` 异步，effect/onClick 首帧读到的是
  **未提交的旧 `tab`** ⇒ 会拿旧来源去拉（拉错 tab）。**藏回边 ≠ 断回边。**

## 决议

1. **意图状态必须自足**：视图意图里凡是"需要查表才能变成参数"的，**在选中那一刻就把结果带上**
   —— 分类存**对象**（含其 `query`），不存 key。落点：`src/components/base/panels/ImportMediaModal.tsx:168`、`:237-245`。
2. **默认值只取自「声明」，不取自「已拉到的数据」**：默认分类 = `provider.categories()[0]`
   （无 `entries`），落点 `:226`；**禁止**写 `categories(items)[0]`。
3. **拉取收敛为唯一一条 effect，只依赖意图**：落点 `:317-320`；
   `navigate` 退化为**纯状态写入**（`:286-293`），不再自己 `load`（否则"谁在拉"有两个真相）。
4. **切 tab 的 effect 只重置视图状态、不拉取**：落点 `:302-312`，依赖只剩 `[source]`。
5. **同域先例即正确形状**：新写"列表 + 过滤/分类"的面板，照抄 `ResourceLibrary` / `GeneratedView` 的依赖形状。

## 后果

- ✅ 收益：触发链 **5 环 → 2 环**（含回边 → 无回边）；`queryFor` 依赖 3 → 2 且不再派生自 `items`；
  「默认分类」判据 2 份 → 1 份；「谁在拉」2 处 → 1 处；每次意图变化**恰好 1 次**请求（原先自环）；
  顺带删掉一处「key 查不到就悄悄换默认分类」的默认值兜底（兜底 1 → 0）。
- ⚠️ 代价 / 回潮风险：**"存对象而非 key"这个选择看着比存 key 啰嗦**，后来者很容易"顺手简化成 key"
  —— 一简化，回边立刻回来。且分类对象会随 provider 声明的新实例而"看着变了"（但只在选中时落一次，无害）。
- 📌 违反时的判据：
  - **机器**：`tests/unit/ImportMediaModal.no-loop.test.tsx` 变红（断言"挂载/切 tab/点分类/进目录各只拉 1 次"）；
  - **人工（新面板）**：审查 `useEffect` 依赖里有没有**派生自拉取结果**的值（`items`/`rows`/`list` 的 `useMemo`）；
    以及"意图状态里有没有需要查表才能变成参数的 key"。

# ADR-0051 · 给用户选项的形态：结论+代价，或代价等价的真备选

- **状态**：生效
- **结论**：请用户拍板只有两种合法形态：① 给结论 + 我为此放弃了什么；② 给代价等价的真备选。禁把单一结论包装成 A/B/C（「推荐／能接受／别做」是同一答案的三张脸）—— 那既没给选择，又占用了用户的判断位置。
- **日期**：2026-09-21
- **裁定人**：用户
- **触发**：2026-09-21 用户指正：AI 把「治本(推荐)／只止损／只改号」当三选一摆出，实为单一答案的三张脸

## 背景

"请用户拍板"在仓里高频出现（`Step 5`）。既往做法只要求"摆成带成本的 A/B/C 选项 + 推荐项"—— 于是**单一路径被包装成三个选项**也能合规。

## 判据（它凭什么成立）

- **「推荐／能接受／别做」不是三个选项**，是同一答案按接受度排的三张脸 —— 选任何一个，结果都指向推荐项。（用户原话：「把结论包装成三选一 …… 等于用选项的外形掩护单一答案，还占了你判断的位置」）
- **同时违反两条既有判据**：① `Step 5`「反滥用：把该自己判的结构问题退化成『这个要问用户』= **偷懒**」；② 拍板动作的唯一价值 = 用户行使判断，而假选项让这次拍板**没有可判断的内容**。
- **只能人判**：等价性要理解"每条路放弃了什么"，无类型 / 结构可承载（`ADR-0052` 要求写明"不能"）。

## 决议

**请用户拍板时只有两种合法形态（本条为判据本体）：**

| 形态 | 长什么样 | 何时用 |
| --- | --- | --- |
| **① 结论 + 代价** | 「我判为 X —— 为此**放弃了** Y（代价 / 机会成本）」 | 架构师**能自判**且路径唯一时（`Step 5`「结构自裁」） |
| **② 代价等价的真备选** | 每条路**放弃了不同的东西**；代价须是**同类量**、可并排比较 | 真有多条路，且代价**不可通约**时 |

- **禁**：把单一结论包成 A/B/C · 用"推荐"标注代替论证 · 把一条路写成"次优"来凑数。
- **落点**：`.codebuddy/commands/架构师改码7步法.md` Step 5 —— 删旧模板 `方案 A（推荐）：…`（它本身就是"推荐 + 陪衬"的诱导形态），改为上述两形态。
- **与 `Step 5` 三关 + 留痕的关系（正交，不冲突）**：那条管"**该不该交用户 / 代价算清没**"；本条管"**交出去的东西是选择还是伪装**"。

## 后果

- ✅ 拍板恢复它唯一的价值：用户行使判断；架构师该自判的不再披三选一的外衣。
- ⚠️ **代价**：真备选要求每条路给出**同类量**的代价 ⇒ 摆选项变贵；摆不出 ⇒ 必须自己判（这正是想要的压力方向）。
- ⚠️ **回潮风险**：把"结论 + 代价"退化成"我推荐 X + 两个陪衬"。
- 📌 **违反时的判据**：① 把"推荐项"拿掉后，剩下的选项**只是更差**（而非放弃了不同东西）⇒ 违规；② 选项的"成本"列不是同类量（一条写工期、一条写能力损失）⇒ 不可比 ⇒ 违规。**两条都靠人判**（`ADR-0052`）。

# ADR-0006 · canvas 产出必走唯一出口

- **状态**：生效
- **结论**：canvas 产出（同步 toDataURL／异步 toBlob）必走唯一出口；产物不是真图像即根部抛出，判据与文案各一份
- **日期**：2026-09-18
- **裁定人**：架构师（取证后自定）
- **触发**：TD-06-14（异步族 toBlob 6 处各写判据：1 处静默失败、1 处重分类）

## 背景

canvas 产出有两个族，**失败语义完全不同**：

| 族 | API | 失败表现 | 何时收口 |
| --- | --- | --- | --- |
| 同步 | `toDataURL()` | 返回 `"data:,"`（规范允许，**是真值不是 null**） | 2026-09-17 → 唯一出口 `canvasToImageDataUrl`（21 处改调） |
| 异步 | `toBlob(cb, …)` | **回调收到 `null`**（不抛错） | **2026-09-18（本 ADR）→ 唯一出口 `canvasToBlob`** |

异步族长期无出口的后果（6 处实测）：**各写一份判据 + 各自编文案** ——
其中 1 处 `if (!blob) return;` = **静默失败**（用户点了"导出当前帧"，什么都没发生、零提示零留痕）；
1 处把 `null` **重分类**成「canvas 可能被跨域污染」（**无证据的因果结论**，CLAUDE.md §5.1 禁）。

## 判据（它凭什么成立）

1. **同一能力一种实现**（CLAUDE.md §5.4(9)）：判据散在 6 处 = SSOT 第二份的典型形态。
2. **失败必须诚实**（一诚实闸）：`"data:,"` / `null` / 0 字节都**不是真图像**，但都不是异常 ——
   调用方若只判 `!dataUrl` / `!blob`，**空白图会被写回节点 / 送给模型 / 下载成功**，用户看到"成功"。
   ⇒ 「产出」与「校验」必须是**同一个不可分动作**，产物不是真图像就**在根部抛出**。
3. **禁重分类**：同步抛（如 `format` 非法）是**编程错误**，不是"设备画不出来" ⇒ 原样透传，不伪装成环境问题。

## 决议

- 同步族：`canvasToImageDataUrl(canvas, format?, quality?) → string`（`core/utils.ts`）
- 异步族：`canvasToBlob(canvas, format?, quality?) → Promise<Blob>`（`core/utils.ts`）
- **判据同源**：产物为空 / 0 字节 / `type` 非 `image/*` ⇒ 抛**同一句**用户可读文案。
- **消费方禁止**再写第二份 `startsWith('data:image/')` / `!blob` 判据，也**禁止**把非环境错误重分类成"跨域污染"。
- 落点：`src/components/base/core/utils.ts`（两个出口）；消费点 6 处改委托（`captureFrame` / `clipboard`×2 / `director3d` / `videoEditor`×2）。

## 后果

- ✅ 判据 6 → 1；文案 4 种（含英文）+ 1 处无文案 → **1 份**；`src/**` 裸 `.toBlob(` 6 → **1**（仅实现处）。
- ✅ 静默失败 1 → 0；重分类 1 → 0。
- ⚠️ **回潮风险（重要）**：**这条约束没有机器守卫** —— 2026-09-17 曾加 `check-canvas-to-dataurl` 反向判据闸，
  **同日按用户裁定删除**（当时闸漏了 `toBlob` 族，而"改覆盖声明让闸继续绿"是绕过而非守卫）。
  故本约束**只靠纪律**：新写画布产出**自觉**经唯一出口。
- 📌 **违反时的判据**：
  1. 全仓 grep `toDataURL(` / `toBlob(` 出现在 `core/utils.ts` **之外**；
  2. 消费点出现 `startsWith('data:image/')` 或 `if (!blob)` 判据（第二份）；
  3. 失败文案里出现**因果断言**（"跨域污染"等）而非统一文案。
- ⚠️ **诚实边界（2026-09-21 实测）**：`tests/unit/utils.test.ts:69` 测的是 **canvasToBlob 的失败语义**（null / 0 字节 / 非 `image/*` 抛统一文案），
  **不上列第 1 条**（别处直接调 `toDataURL` / `toBlob`）—— 那正是本条要守的"唯一出口"，而它**没有闸**（原 `check-canvas-exit` 已按用户裁定删除）。
  ⇒ 本条**未毕业、不许判毕业**（毕业口径见已毕业的 `ADR-0027`/`0035`/`0036`：载体须是**闸或类型层**）。
  按 `ADR-0052` 第 6 级：**不能机器判定**，本约束**只靠纪律 + review**。

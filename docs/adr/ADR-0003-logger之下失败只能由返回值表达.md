# ADR-0003 · logger 之下：失败只能由返回值表达

- **状态**：生效
- **结论**：底层（logger 之下）不得依赖留痕（成环）；真空与非法必须分离
- **日期**：2026-09-18
- **裁定人**：架构师（取证后自定）
- **触发**：TD-18-8（`formatBytes` / `formatTime` 把非法输入伪装成正常值）· 上承 TD-16-49 §8.2 的归位

## 背景

本仓铁律是「**降级必留痕**」（`degrade.ts` 注释原文）。但**这条铁律在底层物理上做不到**：

```
logger.ts:25  →  core/utils.ts（logger 依赖 formatTime）
core/utils.ts →  asyncGuard.ts（依赖 tryParse）
```

⇒ `core/utils.ts` 与 `asyncGuard.ts` **位于 logger 之下** —— 在这两个文件里 import logger 或 `degrade` 会**成环**。

## 判据（它凭什么成立）

1. **依赖环实测**（`logger.ts:25`；`asyncGuard.ts:256-260` 已自述该约束）。
2. **契约收窄也不可用**：fan-in 实测 `toAbsoluteFileUrl` **48** · `formatBytes` **21** · `formatTime` 6
   ⇒ 命中 Step 3「动 ≥10 消费方 → **退回重选**」。
3. ⇒ 「补留痕」与「收窄契约」**两条常规手段都不可用**，只剩「在返回值上表达失败」。

## 决议

**底层（logger 之下）的失败只能由返回值表达，且「真空」与「非法」必须分离：**

| 函数 | 真空（合法真实值） | 非法（无可用值） |
| --- | --- | --- |
| `formatBytesParts(n)` | `{ value, unit }`（含 `0` → `{value:'0',unit:'B'}`） | **`null`** |
| `formatBytes(n)` | `'0 B'` | 哨兵 `'—'` |
| `formatTime(ts)` | 正常格式化 | 哨兵 `'—'` |

**⚠️ 不得把「降级必留痕」机械套到 logger 之下的层。** 判定顺序：先看**依赖方向**，再看 **fan-in**，最后才选手段。

### 与 ADR-0002 的边界（2026-09-19 补 · TD-18-16 证伪留痕）

**两条 ADR 不冲突，因适用范围不重叠** —— 误判一次（TD-18-16），故在此钉死：

| | ADR-0002（压平必须留痕） | 本条 ADR-0003（失败只能由返回值表达） |
| --- | --- | --- |
| **管哪一层** | **logger 之上**（有依赖 logger 的能力） | **logger 之下**（`core/utils.ts` · `asyncGuard.ts`，import logger 即成环） |
| **管谁** | **消费者**（拿到判别联合后压平） | **生产者**（底层原语如何表达失败） |
| **要求** | 压平**必须留痕**（否则静默） | **禁止留痕**（物理成环）⇒ 只靠返回值/哨兵表达 |

**判据（一句话）**：**先看依赖方向** —— 该文件能不能 import `logger`？
- 能（logger 之上）→ 走 ADR-0002，压平必须留痕；
- 不能（logger 之下）→ 走本条，失败只能由返回值表达。

**⇒ 在 logger 之下看到「`r.ok ? v : fallback` 无留痕」是合规的**，不是缺陷
（它在 `core/utils.ts` / `asyncGuard.ts` 内，physically 不能留痕）。
**但"真空 vs 非法"仍必须分离**（见上表）：探测语义返 `''`/`null` 是对的；
把 **非法**（NaN/负值）返成**看起来正常**的值（`'0 B'`）才是违规。

## 后果

- ✅ 「非法 → 伪装成正常值」出口 **2 → 0**；消费方 **0 改动**（签名未变）。
- ⚠️ **代价**：底层失败只能靠**显示**可见，开发者侧**无日志** —— 这是物理约束下的取舍，不是遗漏。
- ⚠️ **回潮风险**：有人"顺手"在 `core/utils.ts` 里 import logger 求留痕 → **成环**（构建/运行期炸）。
- 📌 **违反时的判据**：
  1. `core/utils.ts` / `asyncGuard.ts` 出现 `logger` 或 `degrade` 的 import；
  2. 格式化函数对 `NaN` / 负值返回**看起来正常**的值（如 `'0 B'`）。

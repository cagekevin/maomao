# ADR-0039 · 域前缀与门面：命名规范的判据与边界

- **状态**：生效
- **结论**：域专用导出**撞名时**才带域前缀（域名原词、禁缩写；判据=撞名，同名≥2处且分属不同域）；跨域只走门面（见 ADR-0044 §9）；*Store 仅状态真源、Contract 专属 contracts.ts；横切层不加前缀。
- **日期**：2026-09-19
- **裁定人**：架构师（取证后自定）
- **触发**：域模块化命名阶段；`docs/DOMAIN-MODULES.md §6` 需判据归属（审计 A6）

## 背景

**旧约定「命名规范」散在 4 处，且都是"目录轴时代"的产物**：
`docs/ARCHITECTURE.md §六` 只有两条（禁混淆短名 / 数据字段全名），整篇基于 `.jsx` 4 层结构，其引用的 `PromptNode.jsx`·`TextNode.jsx`·`DiscountVideoNode.jsx` **均已改名**（`spec/DATAFLOW.md §十六`）；
`docs/DOMAIN-MODULES.md §6` 本轮才写，旧前缀表仍是目录轴（**无 `image`/`video`/`text`**）；
落点"就近写"的 `spec/CONTEXT.md` / `BASE-CAPABILITIES §八` 属落点问题（ADR-0025）。

**漂移实证**：导出符号级前缀**基本不存在** —— `node` · `edge` · `editor` · `image` · `scriptBox` · `creative` · `setting` · `cloud` **实测全为 0**；
19 处跨域撞名由此而来（`logger`/`ChatMessage`/`MediaType`/`Timeline`/`Conversation`/`subscribe`/`uid`/`PanelState`…）。

⇒ 三条默认导致漂移：① 命名规范**没有唯一归属**；② **"前缀"被当可选风格**而非判据；③ 前缀词表**沿目录而非沿域**。

## 判据（它凭什么成立）

1. **撞名是物理事实、可机器发现**：同名导出 ≥2 域 ⇒ 调用方 `import { x }` 出现两个来源、误引难查（19 例实证）。
2. **"域名原词"是唯一可推导的词源**：域清单真源 = `spec/DATAFLOW.md` 的链路（其 §十七 原文把"链路"当"域"用）⇒ 前缀**不另起词表**（`scriptBox` ✅ / `ve` ❌）。
3. **门面机制实测有效**：域外直连内部文件 —— `agent` **0 处** · `videoEditor` **1 处**（装配点）⇒ 补门面风险低，有 3 个范本（`agent/`·`videoEditor/`·`base/media/`）。
4. **边界：不得与 ADR-0031 冲突** —— 域外副本属**判据重复 ⇒ 禁合并**；本 ADR **不授权**以"统一命名"为名合并域外副本。
5. **边界：运行时字符串冻结**（ADR-0038）—— 本 ADR 的改名只动「符号名 + 文件路径」。
6. **反证（"一律加前缀"不成立）**：域内已唯一的名（`formatTimeCode` 实测 10 处全在域内）加前缀 ⇒ **信息增量 0 + churn** ⇒ 违减二闸。⇒ **判据是撞名**。

## 决议

| # | 规则 | 判据 / 反例 |
| --- | --- | --- |
| **N1** | 域专用导出**撞名时**才带域前缀（camelCase，**域名原词不缩写**）；**域内已唯一者不加** | **判据 = 撞名**（同名 ≥2 处且分属不同域）；给已唯一者加前缀 = 误读（§判据 6） |
| **N2** | 文件名 = 主导出名；纯类型文件 `<域>Types.ts` | `videoEditor/types/assets.ts` vs `src/types/asset.ts` |
| **N3** | `*Store.ts` **仅状态真源** | `base/store` 15 个里 6 个非 `*Store`（TD-18-41） |
| **N4** | `Contract` 一词**专属** `core/contracts.ts` | `store/generationContract.ts`（TD-18-40） |
| **N5** | 域目录**必须有 `index.ts` 门面**；跨域**只准**走门面 | ⛔ **已过期（2026-09-20）** —— 用户裁定「门面不要随意乱建，都是转发的，让架构变的更复杂，并没有真的变成深模块，都是假的」＋「目标是**深模块 / 窄接口**」。**新判据见 `ADR-0044` §3-b / §7 / §8**（门面按**用例**建、导出面按用例定义、判据是**接口宽度**而非"有没有门面"）。**不要再据本行补建门面或判人违规。** |
| **N6** | 横切层**不放域专用物**；通用物**不装进域** | `base/utils` 9 图片物；`cn` 唯一却住 videoEditor |
| **N7** | 前缀用**域名原词**（`videoEditor` ✅ / `ve` ❌） | `ve-tailwind-colors.ts` · `ve-theme.css` |
| **N8** | 改名只保证「**符号名 + 文件路径**」一致；**运行时字符串默认不改** | → **ADR-0038** |
| **N9** | 前缀**只取「域」级**；同域内子域撞名余者加子域段 | `base/editors` 与 `cameraParams` 的 `CameraLens` |

**例外（禁重审）**：`director3d`（V2 日志 §七）· 可编辑判据（ADR-0031 · TD-18-10~13）· 提示词域三件（TD-18-39）· `filesApi` 落盘域（TD-02-66）。

**落点**：判据本体=**本条** · 前缀表=`DOMAIN-MODULES §6.1` · 撞名→新名=`§6.2` · **域清单真源=`spec/DATAFLOW.md`** · 字符串边界=ADR-0038 · 旧→新=`DATAFLOW §十六`。

## 后果

- ✅ **收益**：命名有**唯一判据**（撞名）+ **唯一词源**（域名原词）；各域不再各判一次；撞名**可机器发现**；门面有 3 个现成范本。
- ⚠️ **代价 / 回潮风险**：**"一律加前缀"是误读**（判据 6）；符号名与键名长期不一致 ⇒ 须在 `contracts.ts` 登记行注明「键名冻结（ADR-0038）」；**建门面会暴露既有环**（闸盲区 D13 教训：`check:arch` 绿**不算证据**，须带负例探针证它**真会红**）。
- ⛔ **N5 已于 2026-09-20 判过期**（门面新判据 = 按**用例**建 + **接口宽度**，见 `ADR-0044` §3-b / §7 / §8）⇒ 下方机器判据 **②③ 随之作废**；照它们登记违规 = **假债**（域清单 `nodes`/`edges`/`panels` 已不存在，且 0044 §7 要求的「能力片门面」会被 ③ 误判成"绕过门面"）。
- 📌 **违反时的判据**：

```bash
# ① 跨域撞名（≥2 域）⇒ 违规
grep -rnoE "^export (async )?(function|const|type|interface|class) [A-Za-z0-9_]+" src --include='*.ts' --include='*.tsx'
# ⛔ ② 已作废（2026-09-20 · N5 过期）：原为「域目录缺门面 ⇒ 违规」。
#    作废理由：域清单是过期的（nodes/edges/panels 目录已不存在 ⇒ 一直在报幽灵违规）；
#    且门面新判据是「按用例建 + 接口宽度」，不是「有没有门面」。新判据见 ADR-0044 §3-b / §7 / §8。
# ⛔ ③ 已作废（2026-09-20 · N5 过期）：原为「跨域绕过门面 ⇒ 违规」。
#    作废理由：ADR-0044 §7 要求横切消费者只依赖**能力片门面**（如 settings/store/index.ts），
#    而本 grep 会把「能力片门面」判成"绕过门面" ⇒ 它把**正确形态**判成违规。新判据同上。
# ④ store/ 内非真源（N3）⇒ 违规
ls src/components/base/store | grep -vE "Store\.ts$|index\.ts$"
```

- **人工**：① 给**域内已唯一**的名字加前缀 ⇒ 违反（误读 N1）；② **删除域外副本**以求命名统一 ⇒ 违反 **ADR-0031**；③ 引用 `docs/ARCHITECTURE.md §六` 当命名依据 ⇒ 违反（该处已 stale）。

# ADR-0058 · 非债裁定须给可复算理由（落到 DATAFLOW 行）

- **状态**：生效
- **结论**：裁非债只能从固定角度择一，并写出该角度的依据；「低息／价值低／边缘」单独不成立
- **日期**：2026-09-22（2026-09-23 改为「角度表」形态）
- **裁定人**：用户
- **触发**：04 区清偿时发现「改判非债」的理由混用了不可复算的价值判断

## 背景

非债裁定**没有产物** —— 没有 diff、没有测试、没有探针，只剩一句 `--note`；
而它是唯一能让线索**永久离开主表**的决策（进归档后不再被审）。

所以理由必须经得起复算。**但理由不必宏大** —— 从下面这张表里择一条站得住的写清即可。

## 判据（逐角度过表；命中哪条，就把那条的依据写进 `--note` 与轮次日志 §九）

| # | 角度 | 成立的判据（必须可查） | 依据怎么写 |
| - | - | - | - |
| ① | **链路位置** | 该判据**不参与任何链路的数据流**（边缘/旁支，改它不影响任何链） | `spec/DATAFLOW.md` **行号** +「不经过哪条链」 |
| ② | **判据性质** | 它**不是「同一判据 N 份」**，而是「两个不同判据 / 有意分缝」 | 指出两侧**各自的真相方与关注点** |
| ③ | **有机器守** | 真源**明文声明**了该处分缝，**且**有可复现对账闸 | 闸名 + 跑一次的输出结论 |
| ④ | **代价倒挂** | 收口会**削掉某层必要能力**，或改动半径 ≫ 收益（且收益可测） | 改动半径（文件/消费方数）× 收益量级 |
| ⑤ | **运行不可达** | 零消费 / 幽灵预留 / 物理不可收口 | `refs` 或 `grep` 的**零命中**输出 |

**三条硬约束**：

1. **说不出上表任一角度的依据 ⇒ 不许裁非债**，留在 `[待还]`（唯一的硬约束）。
2. **角度必须实际走过**：④ 的「收益」要带量级、① 要打开 DATAFLOW 落到行 —— 凭记忆/印象 = 未取证。
3. **「低息／价值低／边缘／不重要」不是任一角度**：它们是**结论的复述**（≡「所以不修」），
   同义反复、零信息、不可证伪 ⇒ 单独出现即视为**未裁定**。（「觉得不重要」可以作为**线索**去查上面五条，
   但查不出来就是查不出来。）

**不适用**：若它其实是「为旧版本/旧数据而存在」，那不是非债而是**待删**（项目约定：不为存量兼容），走删除流程。

## 决议

- 裁「非债／不修」时，`--note` 与轮次日志 §九**必须**写明命中的**角度编号 + 该角度依据**。
- **可复算 = 第三方拿依据能独立得出同一结论**（DATAFLOW 行 / 闸输出 / refs 零命中…）。
- 同一判据**只许一处结论**：发现两处相反（非债 vs 待还）⇒ 先按本表重判，再改掉错的那处；
  真源备注同步 `spec/判据登记表.md`（就地改，不追加）。

## 后果

- ✅ **收益**：非债裁定有固定路可走、结论可复算；消灭不可逆的假非债与「同判据两处矛盾」。
- ⚠️ **代价**：裁非债前多走一遍表；说不清的项**留在待办堆积** —— 这是**有意的**（堆积可见，假非债不可见）。
  回潮风险：把本表当格式要求、随手勾一个角度，依据仍是形容词。
- 📌 **违反时的判据**：`--note` 里只有「低息／价值低／边缘」，或写了角度却**给不出该角度要求的依据**
  （无 DATAFLOW 行 / 无闸输出 / 无零命中证据 / 无改动半径）。

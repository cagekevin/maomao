# ADR-0037 · 工具不得凭硬编码映射替调用方决定 import 后缀：默认继承既有写法

- **状态**：生效
- **结论**：改写 import 的工具，默认必须继承既有写法（原 .ts 保 .ts、原 .js 保 .js），禁凭硬编码映射推断；当仓内两种约定各自都对时，'按项目类型推断'的前提即被证伪。
- **日期**：2026-09-19
- **裁定人**：架构师（取证后自定；用户判据「正确性优先，别等确认」）
- **触发**：TD-17-20（`mv-sync-refs.mjs` 默认 `--suffix auto` 把 `src/` 的 `.ts` 说明符改写成 `.js`）

## 背景

**旧约定**：`scripts/mv-sync-refs.mjs` 的 `--suffix` 默认 `auto` = "按目标源码推断运行后缀"，
硬编码映射写在 `runtimeSuffixForSource()`：

```js
if (e === '.ts')  return '.js';    // tsx/esbuild 会把 .js 解析回 .ts 源
if (e === '.tsx') return '.jsx';
```

它当初这么定是有道理的：**Node-ESM 项目**确实惯用 `.js` 指向 `.ts` 源（tsx/esbuild 会解析回去）。
接口注释也写明了这一理由。

**但它被写成了"全局规则"** —— 于是 `src/`（bundler 域）也一并被套上了。

## 判据（它凭什么成立 / 为什么不成立）

**旧默认不成立。** 判据（铁律 6：引用任何既有约定之前，先问「它凭什么成立？」）：

| 默认 | 凭什么成立 | 判定 |
| --- | --- | --- |
| `auto` | 前提 = "**所有**项目都用 Node-ESM 后缀" | ❌ **前提在本仓不成立** ⇒ 答不出 ⇒ 待消灭对象 |
| `keep` | 前提 = "**不猜**，各域既有写法自己作数" | ✅ 无可被推翻的前提 |

**实证（本仓两种约定相反、且各自都对）**：

| 域 | import 后缀约定 | 实测 |
| --- | --- | --- |
| `src/**`（bundler，`allowImportingTsExtensions:true`） | 显式源码后缀 | **1322 处 `.ts`/`.tsx`，`.js` 0 处** |
| `localTool/**`（`"type":"module"`，Node-ESM） | 运行时后缀 | **262 处 `.js`** |

`auto` 拿**一条映射**套两个域 ⇒ **对后端对、对前端错**，且 `moduleResolution:bundler` 下
`.ts` 与 `.js` **都能解析** ⇒ 改完**不报错、静默**、单方面破坏 `src/` 的 1322 处一致性。

**同形判据**：ADR-0027「两个根类别共用一条规则，**必然错一半**」——
本条是"两个后缀约定共用一条规则"，实测正好错在前端这一半。

**为什么不是"偏好"而是"正确性"**：`auto` 的默认**污染了 fan-in 之外的第二类判据** ——
它让"工具静默改了代码"与"代码本来就是那样"**无法区分**。错的东西不该因"向后兼容"留作默认
（兼容性恒排最末）。想用旧行为 → **显式** `--suffix auto`。

## 决议

**改写 import 的工具，默认必须继承既有写法；"按项目类型推断"只能显式开启。**

1. `--suffix` **默认由 `auto` 改为 `keep`**（原样保留：原 `.ts` 保 `.ts`、原 `.js` 保 `.js`、原裸写保裸写）；
   落点 `scripts/mv-sync-refs.mjs`（CLI 默认值 + `applySpecSuffix` 的 `keep` 分支）。
2. **非法取值回落 `keep`**（不是 `auto`）—— 安全侧：宁可"不改"也不"凭映射猜"。
3. `auto` / `ts` / `js` 保留为**显式**选项（决定权交还调用方，工具不替它决定）。
4. **`convert` 同样默认 `keep`**：说明符后缀属"调用方写法/域约定"，文件扩展名属"文件本体"，
   两者是**不同维度**，不联动；要连后缀一起转 → 显式 `--suffix ts`。

## 后果

- ✅ **收益**：搬 `src/` 的文件不再静默改写 import 风格（1322 处一致性保住）；搬 `localTool/` 的仍保 `.js`。
  **同一选项两域都对** —— 因为它不猜，**无映射表可漏登记**（优于"按目录分两套规则"）。
- ⚠️ **代价 / 回潮风险**：
  - 想要旧行为的人须**显式** `--suffix auto`（多打几个字，但"改不改"变成**有意识的选择**）；
  - 回潮形态：有人为了"省事/向后兼容"把默认改回 `auto` —— 那是**把被证伪的前提重新设成默认**。
- 📌 **违反时的判据（怎么发现"又回去了"）**：
  - `mv-sync-refs.mjs` 的 `--suffix` 默认值不是 `keep` ⇒ 违规；
  - 出现"按目录/项目类型映射后缀"的表（`src → .ts`、`localTool → .js` 之类）⇒ 违规
    （那是把 `auto` 换个形状带回来 —— 该表**必然漏登记新目录**）；
  - 任何工具**默认**改写调用方既有写法（而非显式要求）⇒ 违规。

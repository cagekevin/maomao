# ADR-0049 · 测试只锁用户可感知的契约：禁文档测试与 UI 存在性测试

- **状态**：生效
- **结论**：测试只写能捕获真实回归的用例：禁给文档做测试（文件／文本存在性、引用对账）、禁给 UI 面板做存在性测试（有这个图标／这个元素渲染出来了）。这类断言恒绿或恒假红，属自证式装饰；文档写错就改文档，UI 靠手测，投入落纯逻辑层。
- **日期**：2026-09-20
- **裁定人**：用户
- **触发**：2026-09-20 用户裁定（原话：文档不需要任何测试，UI 不需要测试；给文档做测试、给 UI 面板做测试这种自证式的不要做）。触发：health-check.cjs「决策渠道门禁」断言 docs/adr 为空，而该约定已被 ADR-0017 推翻 ⇒ 恒假红；先被翻正成 grep CLAUDE.md 文本，再被用户判定无意义 ⇒ 删闸。

## 背景

**旧做法**：把「文档内容」与「UI 面板渲染结果」也纳入测试与机器闸 ——

- `scripts/health-check.cjs` §6「决策渠道门禁」：断言 `docs/adr/` 目录**必须为空**（读目录 + grep CLAUDE.md 文本）；
- `scripts/check-doc-refs.mjs`（push 层闸）：对账文档里引用的债号是否存在；
- `tests/unit/*.test.tsx`：一批「某图标／某元素渲染出来了」的存在性用例。

**它当初为什么这么定**：把「规范一致性」当红线守 —— 图省事：文档用 grep 断言、UI 用挂载断言，成本低、写起来快。

**它为什么错**：这两类断言**都不锁用户可感知的契约**，只会恒绿或恒假红 ——

- 文档内容改了**不会让用户拿到错误结果**；`docs/adr/` 该不该为空更是**一条已被推翻的旧约定**（ADR-0017）⇒ 判据没了、断言还在 ⇒ 在**健康态**上判红（恒假红）。
- UI 上「有哪个图标」**不是契约**：图标换了、挪了，用户不会拿到错误结果 ⇒ 断言既抓不到真实回归，又会在重构 UI 时批量变红。

## 判据（它凭什么成立 / 为什么不成立）

1. **测试的价值 = 能否捕获真实回归**（`spec/TEST-GUIDE.md` §〇「核心原则」）—— 文档测试与 UI 存在性测试两条都答「不能」。
2. **它们就是 §7.2 认定的自证式断言**（形态⑤「断源码文本／文件存在」、形态②「断实现细节而非行为」）：把实现改坏它可能仍绿（图标还在、逻辑已坏），改个措辞／换个图标就红（真实行为没坏）⇒ **恒绿与恒假红同源，都不构成证据**。
3. **实证（2026-09-20 本轮）**：`health-check.cjs` 的「`docs/adr/` 必须为空」在依据被 ADR-0017 推翻后**恒假红**；把它「翻正」成 grep `CLAUDE.md` 文本后，又变成**恒绿装饰**（文档写错时只红一条 grep，拦不住任何真实损失）。**两个方向都失败 ⇒ 结论是「文档不进测试／闸」，而不是「换个断言继续守」。**
4. **能不能不用 ADR 守**：这是「这个用例值不值得写」的**语义判断，不可机器验证**（判断者须理解「用户会不会拿到错误结果」）⇒ 按「建闸前置评审」第 6 问**不上闸**，只留人工判据。

## 决议

**禁两类用例（新增与存量同此判据）**：

1. **文档测试**：断言文档文件存在、文本内容含某串、文档间引用对账；
2. **UI 面板存在性测试**：断言「有这个图标／这个按钮／这个元素渲染出来了」。**交互行为不在此列** —— 点击触发真实副作用属 TEST-GUIDE §〇 的「行为测试」，仍可写。

**该做什么**：文档写错 → **改文档**；UI 对不对 → **手测**；测试投入落**纯逻辑层**（store／api／工具函数／引擎），那里契约最稳、最值得锁。

**落点**：

- 判据唯一真源 = 本 ADR；价值分级 = `spec/TEST-GUIDE.md` §〇（**不在此复述，避免第二份真相**）；
- `scripts/health-check.cjs`：§6「决策渠道门禁」整节已于 2026-09-20 删除，文件头留痕说明。

## 后果

- ✅ 测试集不再被装饰用例稀释；闸不再恒红／恒绿，「红」重新有信息量。
- ⚠️ 代价：文档漂移失去机器拦截 ⇒ 靠 A7「修正必须回改原文」+ 人回读（本轮即因 `CLAUDE.md` 未回改而吃亏）。
- ⚠️ 回潮风险：新功能顺手加一条「渲染出来了」的冒烟用例当验收。
- 📌 违反时的判据（人工）：新写的用例若 ① 断言对象是**文档文件／文本**；② 断言**某 UI 元素／图标存在**而非交互行为 ⇒ 违规，删。

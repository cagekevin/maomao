# ADR-0049 · 测试只锁用户可感知的契约：禁文档测试与 UI 存在性测试

- **状态**：生效
- **结论**：测试只锁用户可感知契约：禁文档测试（文件／文本／引用对账）、禁 UI 存在性测试（有这个图标／元素）—— 恒绿或恒假红，自证式。**只约束新增用例**；2026-09-21 前的存量 `tests/unit` 用例一律不动（避免误删）。
- **日期**：2026-09-20
- **裁定人**：用户
- **触发**：2026-09-20 用户裁定「文档不需要任何测试，UI 不需要测试；自证式的不要做」（触发事件：`health-check.cjs`「决策渠道门禁」断言 `docs/adr` 为空，而该约定已被 `ADR-0017` 推翻 ⇒ 恒假红）。2026-09-21 用户再裁定：适用范围收窄为「只约束新增」，存量一律不动（避免误删）。

## 背景

**旧做法**：把「文档内容」与「UI 面板渲染结果」也纳入测试与机器闸 ——

- `scripts/health-check.cjs` §6「决策渠道门禁」：断言 `docs/adr/` 必须为空（读目录 + grep `CLAUDE.md` 文本）；
- `scripts/check-doc-refs.mjs`（push 层闸）：对账文档引用的债号是否存在；
- `tests/unit/*.test.tsx`：一批「某图标／某元素渲染出来了」的存在性用例。

**它当初为什么这么定**：把「规范一致性」当红线守 —— 图省事：文档用 grep 断言、UI 用挂载断言，成本低、写起来快。

**它为什么错**：这两类断言**都不锁用户可感知的契约**，只会恒绿或恒假红 ——

- 文档内容改了**不会让用户拿到错误结果**；`docs/adr/` 该不该为空更是**已被推翻的旧约定**（`ADR-0017`）⇒ 判据没了、断言还在 ⇒ 在**健康态**上判红。
- UI 上「有哪个图标」**不是契约**：图标换了、挪了，用户不会拿到错误结果 ⇒ 既抓不到真实回归，又会在重构 UI 时批量变红。

## 判据（它凭什么成立 / 为什么不成立）

1. **测试的价值 = 能否捕获真实回归**（`spec/TEST-GUIDE.md` §〇）—— 文档测试与 UI 存在性测试两条都答「不能」。
2. **它们就是 §7.2 认定的自证式断言**（形态⑤「断源码文本／文件存在」、形态②「断实现细节而非行为」）：把实现改坏它可能仍绿（图标还在、逻辑已坏），改个措辞／换个图标就红（真实行为没坏）⇒ **恒绿与恒假红同源，都不构成证据**。
3. **实证（2026-09-20）**：「`docs/adr/` 必须为空」在依据被 `ADR-0017` 推翻后**恒假红**；「翻正」成 grep `CLAUDE.md` 文本后又变成**恒绿装饰**。两个方向都失败 ⇒ 结论是「文档不进测试／闸」，不是「换个断言继续守」。
4. **能不能不用 ADR 守**：这是「这个用例值不值得写」的**语义判断，不可机器验证**（须理解「用户会不会拿到错误结果」）⇒ 按「建闸前置评审」第 6 问**不上闸**，只留人工判据。

## 决议

**禁两类用例（适用范围见下）**：

1. **文档测试**：断言文档文件存在、文本内容含某串、文档间引用对账；
2. **UI 面板存在性测试**：断言「有这个图标／这个按钮／这个元素渲染出来了」。**交互行为不在此列** —— 点击触发真实副作用属「行为测试」，仍可写。

**★ 适用范围（2026-09-21 用户裁定 · 收窄；原「新增与存量同此判据」作废）**

| | 处置 |
| --- | --- |
| **新增／新改**的用例（2026-09-21 起） | 按上面两类禁令判，**违规即删** |
| **存量** `tests/unit/**`（生效日之前已存在） | **一律不动** —— 不删、不改、不判违规（理由：避免误删） |

**为什么存量豁免**（2026-09-21 实测，落账 `daily/架构日志/25-跨区-ADR-0049存量用例清点-2026-09-21.md`）：

| 形态 | grep 命中 | 其中真断言 | 其余是 |
| --- | --- | --- | --- |
| `toBeTruthy` | 297 行 / 35 文件 | 297 | — |
| `querySelector` | 172 行 / 28 文件 | 62 | 110 行是**定位／取值** |
| `getAttribute` + `className` | 78 行 / 19 文件 | 70 | 8 行是**注释／类型定义／字符串模板** |

- **形态口径在存量上失效**（同 `ADR-0019` 净减口径的硬伤）：grep 把注释、类型定义、字符串模板、定位取值一并计入 ⇒ **"按形态数删" = 按噪声删**。
- **真违规数机器给不出**：唯一判据是「把被测实现改坏，断言还绿不绿」（§7.2），须**逐条人读** ~430 处。
- **误删不可逆且对撞红线**：存量里混着**真契约断言**（`getAttribute('src')` 断图片取错没取错、`aria-*` 断可访问性状态），与纯样式断言同文件同形态 ⇒ 按形态删必伤真契约，直接对撞 `ADR-0053` 能力关「用户能做的事不许变少」。
- **新增侧没有这个问题**：新写用例的作者**知道自己在断言什么**，判据当场可判、成本为零 ⇒ 判据的价值全在新增侧。

**该做什么**：文档写错 → **改文档**；UI 对不对 → **手测**；测试投入落**纯逻辑层**（store／api／工具函数／引擎）。
**存量方向**：不做专项清点，靠**人读**（改到哪个文件顺手看一眼）。`TD-25-43`（「按 ADR-0049 逐处判存在性即删」）**改判非债**。

**落点**：判据唯一真源 = 本 ADR；价值分级 = `spec/TEST-GUIDE.md` §〇（**不在此复述**，避免第二份真相）；`scripts/health-check.cjs` §6 已于 2026-09-20 删除，文件头留痕。

## 后果

- ✅ 测试集不再被装饰用例稀释；闸不再恒红／恒绿；**消除大面积误删风险**，不必为 ~430 处存量做逐条人判。
- ⚠️ 代价：文档漂移失去机器拦截 ⇒ 靠 A7「修正必须回改原文」+ 人回读。存量里的**真装饰断言**（如已被类型层拦住的图标样式）**留在库里**，测试集仍被稀释。
- ⚠️ 回潮风险：① 新功能顺手加一条「渲染出来了」的冒烟用例当验收；②「存量 vs 新增」靠**回读 git 历史**判，**非机器可判** ⇒ 后人可能把存量断言改一改就宣称"新写的"（`ADR-0052` 第 6 级：诚实声明，不硬凑 grep）。
- 📌 **违反时的判据（人工）**：**新写／新改**的用例若 ① 断言对象是**文档文件／文本**；② 断言**某 UI 元素／图标存在**而非交互行为 ⇒ 违规，删。
  **判存量不算违规** —— 但拿存量豁免为**新写**的存在性断言开脱 ⇒ 违反本条。
- ⏳ **待办①（2026-09-20 已裁定：删）**：`scripts/check-doc-refs.mjs`（push 层闸）。判据不变，本条只记结果，见 `daily/架构日志/17-跨区-决策渠道旧约定未回改与恒假红闸-2026-09-20.md`。待办②「存量待清点」**已于 2026-09-21 作废**。

## Lessons Learned

- **判据对了，不等于适用范围对了。** 本条判据从第一天就成立；翻车在决议写了「新增与存量同此判据」—— **正确的判据溯及存量，就变成大面积误删的授权书**。⇒ **立判据默认只约束新增**；要溯及存量须单独举证（真违规数可数 + 误删可逆）。
- **「形态命中数」在存量上不等于违规数。** grep 297 行里混着注释、类型定义、字符串模板、定位取值 ——
  与 `ADR-0019` 净减口径同款硬伤。⇒ 看见大数字先问「这个口径在存量上还成立吗」，别拿它当工作量或收益的证据。
- **批量删除的方向性代价**：存量里**真契约断言**（`getAttribute('src')` 断图片取错没取错、`aria-*` 断可访问性）
  与纯样式断言同文件同形态 ⇒ 按形态删必伤真契约。⇒ **凡批量删除，先证明它不误伤真契约**（`ADR-0053` 能力关）。

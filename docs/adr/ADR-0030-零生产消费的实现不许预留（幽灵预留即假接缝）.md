# ADR-0030 · 零生产消费的实现不许预留（幽灵预留即假接缝）

- **状态**：生效
- **结论**：fan-in=0 的生产消费＝假接缝（幽灵预留）：处置是删，既不许为将来铺路、也不许补消费方；死代码基线是待清偿清单，--update-baseline 只能在确认「基线外无新增」之后跑，否则等于给回潮发合法证。
- **日期**：2026-09-18
- **裁定人**：架构师
- **触发**：TD-02-50／TD-16-30／TD-22-65（区域 02 第 50 轮）

## 背景

三笔债（TD-02-50／TD-16-30／TD-22-65）同日取证，暴露同一条既有做法：**「先把地基建好，等上层来接」**。
它当初的理由是"一次把接口想全，免得将来改签名"——而这个理由已被反复证伪：

- 20 区「幽灵预留清偿轮」（2026-09-13）：4 债同为"为设想的消费方预留 API"，处置全是删；
- TD-21-4（用户拍板）：共用层必须「**建层与存量迁入同批做**」，不许先建层；
- 本轮三笔：`parseMediaRef`／`searchMediaRefs`／`subscribeCanvasNodes`（"成对／三件套"的对侧）、
  `audioPeaks.ts`（波形地基；UI 侧后来另走 wavesurfer 内联）、`rulerTicks.ts`（G1 建层时多建的一套刻度）。

## 判据（它凭什么成立 / 为什么不成立）

**判据：看 fan-in（生产消费方数量），不看它写得多完整。** 三条硬证据：

1. **物理证据**：本轮 5 处被删对象 fan-in **全为 0** —— 全仓 grep 只命中定义处与**它自己的单测**；
   `base/media/index.ts`（barrel）**从未导出**其中三个函数；`tsc --noEmit` 删后 **0 错**（有引用必红）。
2. **代价证据**：正因如此，同一件事长出了**两份实现**（波形峰值 `audioPeaks` vs 内联 `extractPeaks`；
   刻度 `rulerTicks` vs 引擎 `ruler-utils`）—— 就是"复杂度不会消失，只会被藏起来"的同款。
3. **机器可见性**：`check:dead-code`（knip `--production`，TD-16-28 修正后）**能报出**这类零生产消费的导出与文件。
   故它不必靠人记 —— **基线是待清偿清单，不是豁免名单**。

**被否决的反方案**：「先建着，将来一定会用」。本仓已三次被这句话带回同一笔债；且"将来会用"不可证伪，进不了验收。

## 决议

1. **零生产消费的实现 = 假接缝（幽灵预留），处置是删**：不许为将来铺路，也不许补消费方（补 = 制造新需求）。
   真要用时，**按当时的真实消费方重建**。
2. **同一件事已有一份在用的实现时**，收口方向 = **保留在用的那份**、删掉没接上的那份（本轮两处都按此处理）。
3. **落点**：`base/media/mediaRefTypes.ts`（`makeMediaRef` 头部"目前只写不读"）· `mediaRefRegistry.ts`（失败语义段）·
   `canvasNodesBridge.ts`（`setCanvasNodesSnapshot`）· `docs/plan/125-…`（B2 更新条）· `spec/DATAFLOW.md`（media 段 / 视频段）。
4. **`--update-baseline` 红线**：闸报「基线外新增」时**不许**直接 `--update-baseline`（= 把回潮塞进基线、发合法证）；
   必须先判「这份零消费实现该不该存在」，不得则删。

## 后果

- ✅ 收益：死代码基线 88→83；`src` −2 文件；两处"同一件事两份"各收为 1 份；**消费方 0 改动**。
- ⚠️ 代价 / 回潮风险：`audioPeaks`（波形算法）与 `rulerTicks`（刻度抽稀）将来要用时**要重写**；
  且 `base/utils/` 里还有其它零消费导出（`timeScale.dropIndexAt／fitZoom／rectsIntersect`、`refToken` 双函数）——
  它们在本判据下同属待清偿，**不是豁免**。
- 📌 违反时的判据（怎么发现"又回去了"）：`npm run check:dead-code` 报「基线外新增」即命中；
  也可 `grep -rn` 复核「某导出是否只被 `tests/**` 引用」—— knip `--production` 的口径就是它。
  （全仓扫时补 `--exclude-dir=node_modules --exclude-dir=dist`：**grep 既不默认递归、也不自动跳过 .gitignore**
  —— 漏 `-r` 只查当前层、不排除则扎进 node_modules；两者都会产出「空结果」而非报错，形同假绿。）

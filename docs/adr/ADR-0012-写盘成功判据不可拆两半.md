# ADR-0012 · 写盘成功判据不可拆两半

- **状态**：生效
- **结论**：产物落地的成功判据只有一份：字节写盘＋内容寻址登记＋磁盘存在性必须同源同次成立；任一半各自成立即假成功。
- **日期**：2026-09-18
- **裁定人**：架构师
- **触发**：TD-08-31（后端成功响应与磁盘DB脱钩·四子项同母体）

## 背景

旧形态：`/files/` 落盘的「成功」被拆成两半各自成立，各自只看自己那一半：

- `writeUploadDedup` 命中去重即返回，**不校验磁盘上那份是否还在** → 复用了一个已 404 的死 url；
- `recordUploadedFileRow` 登记失败**静默不登记**；
- `rescan` 漏扫不可读目录**静默 return**；
- `subfolder` 非法时**静默回退** `canvas`。

结果：接口返回成功，磁盘/DB 却是脱钩的 —— 正是「成功必须为真」（`CLAUDE.md §5.1`）要禁的假成功。

## 判据（它凭什么成立 / 为什么不成立）

**旧形态不成立。** 四子项同母体，母体一句话：**「写盘成功」的判据被拆成两半，各自成立**（附 A6：兜底数量 = 地基的体温计）。

- 「成功」的**唯一物理判据**是产物**真的可被再次读到** —— 字节在磁盘上 + 它被登记为可寻址。只有一半成立 ⇒ 用户/后续请求会拿到 404，而接口说成功。
- 这四个半判据全都是**兜底形态**（静默 return / 静默不登记 / 静默回退）= 掩盖地基缺陷，不是修地基。
- 判据可由物理事实裁定（磁盘存在性 + 行存在性），**不属业务问题** ⇒ 架构师直接定（7 步法铁律④）。

## 决议

**成功判据收口为一份、同源同次成立**（落点 `localTool/src/routes/files.ts` 等）：

1. 非法 `subfolder` 由静默回退 `canvas` 改为 **throw + 入口 400**；并补登记真实在用的后端产物根 `local-patch`（**真源缺项才是静默回退的成因** —— 修地基而非留兜底）。
2. `writeUploadDedup` 命中去重时**补磁盘存在性校验**，不在则留痕并重落盘（替代复用死 url）。
3. `recordUploadedFileRow`：`rel` 取不到即 **500**；**登记失败与下载失败分开归因**；读文件失败必须留痕。
4. `rescan` 目录不可读由静默 `return` 改为**留痕 + `errors` 回传**。

## 后果

- ✅ 收益：接口「成功」与磁盘真相不再可能脱钩；四类静默兜底净删；排除故障时不再出现「说成功但 404」的分裂。
- ⚠️ 代价 / 回潮风险：`subfolder` 非法由「静默兜住」变「400」——**向上游暴露了原先被吞的调用错误**，若某调用方一直依赖那个默认值，它会开始报错（这是正确行为，但需按真实产物根补齐）。新增产物根必须同步登记，否则又会走回静默回退。
- 📌 违反时的判据（怎么发现「又回去了」）：
  - 见「命中去重即返回」而不校验磁盘存在性 → 违规；
  - 见 `subfolder` 非法静默回退 / `rescan` 静默 return / 登记失败静默吞 → 违规；
  - `test:localtool` 中「去重返回死 url」「非法 subfolder 回退 canvas」类断言复活 → 违规。

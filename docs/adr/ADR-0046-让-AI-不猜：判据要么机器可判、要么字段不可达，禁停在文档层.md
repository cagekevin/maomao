# ADR-0046 · 让 AI 不猜：判据必须可判定或不可误用，禁停在文档层

- **状态**：已取代
- **结论**：一句话判据「AI 会猜吗」——判据里出现须读者自行推断的措辞（「视场景」「必要时」「AI 侧/人工侧」）即违规。落点四选一：目录 / 类型层 / 唯一入口 / 删。**禁止**以「把文档写详细」结案。
- **日期**：2026-09-20
- **裁定人**：架构师
- **触发**：C4 类形态普查 —— 判据只在文档、误用仍能写出来（同族：ADR-0030 幽灵预留、ADR-0035 timeoutMs）

## 背景

本仓判据的**唯一失败形态**：判据说得对，但**违背它的代码照样能写出来**。于是判据沦为"读完点点头，写码时照旧"——注释拦不住任何人（母体 M2）。

同族已收口两例（本次沿用其手法）：ADR-0030（零消费的实现 → 删）、ADR-0035（`timeoutMs` 必填 → 类型层）。

## 判据（它凭什么成立）

**核心反问：违背这条的代码，写得出来吗？**
写得出来 ⇒ 判据只在文档层 ⇒ **等于没守**（AI 会在某个时刻写出来）。写不出来 ⇒ 已守住。

**四个信号 = 该判据要改造**（命中任一）：

| # | 信号 | 读者被迫猜什么 |
| --- | --- | --- |
| ① | 两条路看起来都对 | 「该走 A 还是 B」 |
| ② | 量词模糊（必要时 / 视场景 / 通常 / 原则上） | 「什么时候触发」 |
| ③ | 只写禁止、不写替代（「禁止 X」但没说该写什么） | 「那我写什么」 |
| ④ | 可选开关零生产调用方显式传值 | 「我这场景该不该传」 |

## 决议

**1. 改造落点（按成本从低到高，取能做的最前一个）**

| 落点 | 手段 | 判定 |
| --- | --- | --- |
| **删** | 该能力/开关零生产消费 ⇒ 删掉（ADR-0030） | 结构上不可能用 |
| **类型层** | 必填参数 / 字段移出类型 / 判别联合 | 写不出来（`tsc` 即探针） |
| **唯一入口** | 收口成一个函数，外部拿不到底层 | 绕不过去 |
| **目录** | 判据若本就是「文件在哪」，直接写出目录名，别写"AI 侧/人工侧" | 可机械判定 |

**2. 文档只写「判据本身」，不写「我如何发现它」**
- §决议必须是**可照做的表/条款**；取证、试错、探针输出一律归区域日志，不进 ADR 正文。
- 判据若涉及"该走哪条路"，**写可判定的事实**（目录名 / 函数名 / 参数名），不写需要理解语义的类别（"AI 侧""业务层"）。

**3. 判据写在读者一定会打开的那个文件头**
例：判断"画布写走哪条"的人会打开 `agentCanvasHost.ts` ⇒ 判据表就放那里，不藏在 DATAFLOW。

**4. 每个子判据必须给出一条 grep / tsc / 闸 级别的检查方式**（写在 §后果），否则它没有防线（ADR-0041）。

**落点（本条首次落实）**：`agent/canvas/agentCanvasHost.ts`（画布写判据＝目录）·
`generate/lib/generationOrchestration.ts`（删零消费开关 `saveToTasks`，落盘转无条件一步）·
`base/utils/genErrors.ts`（`retryable` 移出 `ClassifiedError`）。

## 后果

- ✅ **收益**：违背判据的代码**写不出来**（类型层/目录），而非"写了但被劝"。文档从"要读懂"变"照表做"。
- ⚠️ **代价 / 回潮风险**：类型层改造会**破坏调用方签名**（如 `timeoutMs` 必填需逐个补齐，本次 43 处）。若为避免改动而保留可选参数，本条即被架空。
- 📌 **违反时的判据（怎么发现"又回去了"）**：
  1. **新增可选开关零生产调用方传值** ⇒ `grep -rn "<参数名>" src` 命中只有定义处（+ 自己的测试）即违规（处置：删，见 ADR-0030）；
  2. **字段本应观测却可读** ⇒ 该字段若不在类型上，误用 `tsc` 即报「属性不存在」；能通过 ⇒ 失守（本次探针：`cls.retryable` 报属性不存在 = 已守）；
  3. **本该机器可判的判据却写成需推断的说法**（如"AI 侧/人工侧"而非目录名）⇒ 人工 review 判；**无机器判据**（"须推断"不可机器验证，与"该不该写 ADR"同属语义判断，见 README §6.4）。
- ⚠️ **诚实边界**：本条第 3 项**没有机器防线** —— 它靠 review + 落点示例（`agentCanvasHost.ts` 的目录判据表）示范。
  不假装有闸：硬凑的 grep 会把"说这条规矩的句子"自己也抓进去（假防线比无防线更坏）。
- **被取代于**：ADR-0052
- **毕业去向**：合并入 ADR-0052（判据的防线形态）；其落点四选一已扩为六级，第 6 级即它原先缺失的合法出口

# ADR-0056 · 新增一类用户数据的四问：根归属 · 真相源 · 稳定身份 · 上云与加密

- **状态**：生效
- **结论**：新用户数据先答四问：会不会被当素材（是→uploads，否→getDataDir 另开根）；真相源在哪；跨设备身份是否稳定 id；上云按意愿、加密按通道是否即凭据（同通道不做单类加密）
- **日期**：2026-09-21
- **裁定人**：用户
- **触发**：Skill 系统落地时暴露「新数据的根 / 真相源 / 身份 / 上云口径」无据可依。用户裁定本条须写成**通用**判据（skill 只是首个实例，换个项目、换件事还会遇到）

## 背景

隐性习惯（从未立条）：新数据一律塞 `uploads/`；默认只活在 localStorage；上云靠顺手标 `sync:true`；加密靠"敏感不敏感"的直觉。
实证代价：① uploads 顶层白名单仍漏出 `canvas/cleaned`、`canvas/template` 等**全仓零引用**的孤儿目录（`fileStore.ts:56` · ADR-0027）；
② 素材库 rescan **递归收录 uploads 每个顶层目录** ⇒ 非素材数据进去就变"素材"（`routes/resources.ts`）；
③ `cloudSync` 的进云清单曾手抄两份、必然漂移，后收口为登记表字段 `sync`；
④ Skill（121 方案）按"敏感直觉"判出"正文不得明文上云"，与**同通道已载的账号 / API key** 自相矛盾（双标）。

## 判据（它凭什么成立）

- **Q1 根归属** —— 凭**三条物理事实**，不凭习惯：会不会 ① 被 `/files/**` 静态服务暴露 ② 被素材库 rescan 收录 ③ 受 uploads 白名单 / 孤儿 GC 管。三条全"是" ⇒ 素材 / 产物；**任一"否" ⇒ 它是有自己语义的用户数据**。
- **Q2 真相源** —— 判据是「**改哪一处才算改了**」能否一句话答；真相源在磁盘 ⇒ 内存 / localStorage 只能是缓存，"缓存里有就算成功"是把失败伪装成成功。
  **Q2 补充（2026-09-21）**：真相源同样是**引用**的唯一来源 —— 消费者只许把「**指谁**」（id）传给它，**不许把真相的字段镜像成参数**（镜像必漏子集：Skill P4 漏 `category`／`slug` ⇒「按需读资料」对**全部** skill 恒失败，且单测自己造 binding ⇒ 测不出来）。
  同理，**「谁存在 / 属于谁」只能由真相源派生**：副本（缓存）不得参与存在性判定，否则删掉真相之后界面仍会显示它（Skill 组清单实证：成员 `category` 与磁盘目录并集 ⇒ 删掉组目录后侧栏仍显示该组）。
- **Q3 稳定身份** —— 凭"实体要不要跨**改名 / 换目录 / 换设备**存活"判；要 ⇒ 必须有 UUID 且**禁路径兜底**（`id = 分类/名称` 一旦改名就断绑定：启用态、收藏、绑定全失联）。
- **Q4 上云与加密** —— 两问分开，**不要用"敏感不敏感"合并**：进云 = 「**换了设备也希望跟着走**吗」；加密 = 「**通道本身是否即凭据**」（capability secret 且同通道已载更高敏感数据 ⇒ 不做单类加密，那是双标 + 假安全感；公开 / 多租户通道 ⇒ 必须 per-user 鉴权 + 加密）。**附加**：高频变动数据不进云（判据是"变动频率 × 同步收益"，不是重要性）。

## 决议

| # | 问题 | 合格形态 | 反例（禁） |
| --- | --- | --- | --- |
| Q1 | 会不会被当素材 | 三条全"是" ⇒ `uploads/<已登记子目录>/`；**任一"否" ⇒ `getDataDir()` 下另开兄弟根** | 往 uploads 塞非素材；往 `UPLOAD_ROOT_ALLOW` 加特例"让它能放进去" |
| Q2 | 真相源在哪 | 唯一可写处即真相源，其余是缓存 / 副本；写路径 = **真相源成功才算成功**；消费者只传「指谁」（id），「存在／归属」只由真相源派生 | 两个可写真相源并存；"缓存里有就算成功"；**把真相字段镜像成参数**（在真相源之外再造一份子集）；**让副本参与存在性／归属判定** |
| Q3 | 身份怎么定 | 需跨改名 / 换设备存活 ⇒ **UUID 写进数据本身、与路径解耦、无路径兜底** | `id = 分类/名称` 式路径兜底 |
| Q4 | 进云？加密？ | 进云 = 换设备也希望跟着走；加密 = 通道是否即凭据；高频变动**不进云** | 凭"敏感直觉"单类加密 / 隔离；把高频计数类丢进云 |

**同族引用（不重复其判据）**：`ADR-0027`（uploads 子目录分域）——本条是它的**上一层**（先判该不该进 uploads，再谈进去后怎么分域）· `ADR-0042` / `ADR-0044`（能力片与门面形态）· `ADR-0053`（零生产消费不许预留：别为"以后可能"预建根与目录）。

**首批实例**：素材 / 产物（三问全中 ⇒ uploads · 路径身份 · 不进云）｜工程数据（非素材 ⇒ KV / `getDataDir()` 自有根 · 工程 id · 不进云同步，各有跨端真通道）｜设置 `app_settings`（非素材 · 键身份 · **不进云**）｜**Skill（本条首个落地实例）**：非素材 ⇒ `getSkillsDir()`；**磁盘 `SKILL.md` 为真相源**；**UUID 写 frontmatter**；**进云但不加密**（落点 `docs/plan/140` · `localTool/src/routes/skills.ts` · `src/components/agent/skill/`）。

## 后果

- ✅ **收益**：以后任何新数据域**四问一答就有落点**，不必重新论证（Skill 一条已在库内论证三轮：114 → 116 → 121）。
- ⚠️ **代价 / 回潮风险**：`getDataDir()` 下会出现**多个兄弟根**（uploads / skills / backups …），新人会觉得"不统一" ⇒ 本条即答案，**不要用"方便统一管理"为由合并**；四问必须**逐条答**，不能"看着像素材"就塞 uploads。
- 📌 **违反时的判据**：
  1. `ls ~/.maomao-localtool/uploads` 逐项对 Q1（除 tasks/web/canvas/migrated/director3d/local-patch/sounds 外都不该在）
  2. `grep -rln "KEY_AGENT_SKILLS" src` —— 写者应只剩 `agent/skill/skillRepository.ts`（有两个 = 违反 Q2）
  3. `grep -rnE "id *= *\`\\\$\{.*\}/\\\$\{.*\}\`" src` 命中 ⇒ 违反 Q3
  4. `grep -rn "SYNC_EXCLUDE\|encrypt(" src localTool/src` 命中 ⇒ 先答 Q4 的"这条通道是否即凭据"
  5. **消费者镜像真相字段当参数** ⇒ 在该装配点 grep 这些字段名，应**只命中注释**：
     `grep -n "category\|slug" src/components/agent/panels/AgentPanel.tsx`（Skill P4 实证：装配处 0 处实现命中 + 1 行注释 = 合格）；命中实现行 ⇒ 有人又在真相源之外造子集

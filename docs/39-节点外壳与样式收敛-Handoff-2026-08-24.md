## 二、逐节点明细

### 1. Director3DNode（3D 导演台）

**外壳收敛（对齐 NodeShell）：**
- 主显示框：`bg-surface-muted rounded-xl border shadow-xl` → 模板标准 `relative flex flex-col w-full flex-1 min-h-0`（背景/圆角/边框/阴影交给 NodeShell 主容器，消除双重外框）。
- 删掉手写左右 `CustomHandle`，改用 NodeShell `handleVariant="small"` 默认渲染。
- 全屏 portal：`z-[9999]` → `z-modal`（模板索引认可全景/Director3D 用 `z-modal`）。
- 悬浮按钮裸色 `bg-black/70 text-white border-white/15` → token `bg-overlay text-primary border-edge-strong shadow-popover`。
- 清理未使用 import（`CustomHandle` / `Camera` / `X`）。

**背景一致性修复（关键）：**
- 空态占位补 `bg-surface-muted`。此前去掉手写背景后空态透明露出 NodeShell `bg-surface-raised`（#1d1d1c），与生图/模板/特惠视频的空态 `bg-surface-muted`（#161615）不一致。

**图标更换：**
- `Box` → `Clapperboard` → **`Orbit`**（最终）：避免与特惠视频的 `Clapperboard`（场记板）撞图标。`Orbit` 贴合 3D 摄像机轨道语义。
- 标题小图标 `size={11}`；背景大图标 `size={64}`（原 48 太小、80 在矮节点里太大，取 64）。

### 2. VideoProcessNode（视频处理）

**手写外壳 → NodeShell 重构（最大改动）：**
- 删除手写根 div（`w-full h-full`）、`NodeResizer`、`NodeTitle`、手写主框背景（`bg-surface-panel-2`）。
- 改为 `<NodeShell defaultHeight={620} minWidth={520} minHeight={620} showHandles={false} syncSize={false}>`。
- **`showHandles={false}`**：本节点有自定义端口，手写保留左 `default` + 右 `main-output`（`main-output` 是下游视频输出契约，不能丢）。
- **`syncSize={false}`**：禁用 NodeShell 的 `useSizeSync`（改比例同步尺寸），避免它强制把节点高度设回 `defaultHeight` 覆盖 NodeResizer 拖拽/原有尺寸行为。
- 主框圆角 `rounded-lg` → `rounded-xl`（与其他节点统一）。

**移除 `useContentHeightSync`：**
- 本节点内容区是 `overflow-y-auto` 内部滚动，内容不撑高节点，高度自适应本就不适用。
- 且 NodeShell 标题在主框外占高度后，该 hook 会把 node 高度"吸回" `minHeight`（写回 `node.height = contentRef高`，丢了标题行），与 NodeResizer 冲突。
- 移除后 node 尺寸完全由 NodeShell 的 NodeResizer + `nodeDefaults` 控制，更正确。

### 3. PanoramaNode（全景图）

外壳已合规（NodeShell + `keepAspect` + `aspectRatio="16:9"` 比例同步）。仅清理内部裸样式：
- `z-[9999]` → `z-modal`（全屏球体层）
- `shadow-lg` / `shadow-2xl` → `shadow-popover`（3 处）
- `text-[10px]` → `text-caption-sm`（截图比例选择器 3 处）
- `text-xs` → `text-caption-sm`（2 处）
- `z-[5]` → `z-dropdown`（比例虚线遮罩）

> 保留：全屏球体场景层深色背景（`bg-black/60` 等）—— 3D 场景视觉需要，未强行 token 化。主显示框用 `nodeSize`（`useStore` 订阅）给 Canvas 明确尺寸，有注释说明原因。

### 5. TextNode（文本节点）

外壳已合规（模板"最简"范例：文本区用 `flex-1` 替代 `h-full`，这是模板强调的正确做法）。清理裸样式：

## 三、背景色一致性结论

项目背景色层级（`src/index.css`）：
- `surface-raised: #1d1d1c`（NodeShell 主容器，最浅）
- `surface: #1b1b1a`（文本承载）
- `surface-muted: #161615`（空态/占位，较深）

**各节点空态背景标准 = `bg-surface-muted`**（模板、生图、全景、特惠视频、3D 导演台一致）。
**主内容区有内容时**：生图/导演台/特惠视频透明露出 NodeShell `bg-surface-raised`；文本内容区常驻 `bg-surface`。

本次修复了 3D 导演台空态背景缺失（露 surface-raised）导致的不一致。

## 五、给后续 AI 的注意点

1. **`VideoProcessNode` 是 `syncSize={false}` + `showHandles={false}` + 手写 `main-output` 端口**——这是它作为"内容内部滚动 + 自定义输出端口"节点的合理收敛，别改成默认。`main-output` 是下游视频产出契约，不能删。
2. **`useContentHeightSync` 不适合"内容内部滚动"节点**（VideoProcess/Prompt 这类 `overflow-y-auto`），它只适用于"内容自然撑高"的节点（ScriptBox/GridSplit 等）。新增节点时按内容形态选择。
3. **空态背景统一用 `bg-surface-muted`**，别手写 `bg-surface`/`bg-surface-strong`/裸色。
4. **全屏浮层用 `z-modal`**，`z-[9999]` 禁止；下拉菜单用 `shadow-popover` + `z-dropdown`。
5. **图标语义**：每个节点图标需唯一，避免撞车。当前分配：生图 `ImageIcon`、文本 `FileText`、特惠视频 `Clapperboard`、全景 `Globe`、编组 `Folder`、循环 `Repeat`、3D 导演台 `Orbit`、视频处理/视频抽帧 `Clapperboard`（视频类）。
6. 规范源头见：`spec/NEW-NODE-GUIDE.md`（权威流程）、`src/components/nodes/TemplateNode.jsx`（权威蓝本）、`docs/NODE-DESIGN-SPEC.md`、`docs/CODING-STANDARD.md`、`docs/38-配色统一与一键改色-MasterPlan-2026-08-24.md`。

# 节点重命名安全操作手册（符号 + 字符串标识 + 文件名）

> 日期：2026-09-08
> 适用：本仓库所有画布节点（DiscountVideoNode / PromptNode / ImageNode / TextNode …）的改名
> 状态：视频节点 `DiscountVideoNode → VideoGenerate` 已落地并通过单测

---

## 0. 一句话结论

节点有**两套身份**，且互相独立：

| 身份 | 例子（视频节点） | 作用 |
|---|---|---|
| **符号（TS）** | `DiscountVideoNode`（组件）、`DiscountVideoNodeData` / `DiscountVideoNodeProps`（接口） | 编译期类型与引用 |
| **字符串标识（运行时）** | `'discountVideoNode'`（小写） | 节点的**真实运行时身份**，驱动 `contracts.ts`、`nodePrefs.ts`、`ALLOWED_TYPES`、各 `enum` 数组、`setup.mjs` 等 |

只改符号、不改字符串标识，会让节点在运行时断链（`useNodePrefs('videoGenerateNode')` 在注册表里查不到 `discountVideoNode` 键、枚举不匹配）。**两者必须一起改。**

> 注：本仓库没有任何工具能"自动知道"符号和字符串是绑定的——这是代码约定，不是语言事实。任何工具都要分两步：改名符号 + 另写一条规则/替换改字符串。

---

## 1. 工具选择

| 场景 | 工具 | 说明 |
|---|---|---|
| 精确整词改名（标识符 exact match；或"字符串值恰好等于该 token"） | **ast-grep (`sg`)** | 快、跨 `.ts/.tsx/.js/.mjs/.json`，规则可同时命中标识符与字符串 |
| 字符串 / 注释**内部子串**替换（import 路径、`describe`、枚举描述、注释） | **标准查找替换**（sed / perl / node） | ast-grep 做不了"长字符串里换子串"，见 §3.3 |
| 改文件名并同步引用 | `git mv` + 子串替换同步路径 | ast-grep 不改文件名 |

二者组合使用，**每步改动都可由 `git diff` 审查**。

---

## 2. ast-grep 规则写法（已验证可用）

调用形式（`sg` 已被标记为 deprecated，但 `ast-grep` 等价）：

```powershell
# 预览（只读，不落盘）
npx --yes -p @ast-grep/cli sg scan -r <rule>.yml src tests

# 应用改写（本版本参数是 --update-all，不是 --rewrite）
npx --yes -p @ast-grep/cli sg scan -r <rule>.yml src tests --update-all
```

一条规则文件的模板（**单条规则一个文件**，`scan -r` 不接受 `rules:` 列表或顶层数组）：

```yaml
id: xxx
message: "DiscountVideoNode -> VideoGenerate"
severity: info
language: Tsx          # Ts / Tsx / Jsx / JavaScript / Json 必须分开写
rule:
  kind: identifier
  regex: "^DiscountVideoNode$"   # 精确整词，务必加 ^...$
fix: VideoGenerate
```

- `kind: identifier` 改符号；`kind: string_fragment` 改**值恰好等于该 token**的字符串；
- `kind: property_identifier` 改**对象键**（见 §3.2，极易漏）。

## 3. 踩坑记录（必读，都是真踩过的）

### 3.1 单文件单规则 + 必须带 language
- `scan -r` **只接受单个规则对象**，不支持 `rules:` 列表，也不接受顶层 YAML 数组（会报 `expected struct` / `expected sequence`）。每种语言一个文件。
- 每条规则**必须带 `language`**，且 `.ts` 与 `.tsx` 是不同 grammar，要分别写。

### 3.2 对象键是 property_identifier，不是 identifier / string_fragment
`contracts.ts` 里：

```ts
discountVideoNode: 'videoGenerateNode',   // 键是 property_identifier，值才是 string_fragment
```

若只用 `identifier` + `string_fragment` 规则，键 `discountVideoNode:` 不会被改，导致**值与键错位、prefs 直接失效**。
修正规则：

```yaml
language: Ts
rule:
  kind: property_identifier
  regex: "^discountVideoNode$"
fix: videoGenerateNode
```

### 3.3 string_fragment 的 fix 替换的是"整个字符串节点"，不是子串
非锚定地写 `regex: "DiscountVideoNode"` + `fix: VideoGenerate` 会发生灾难性替换：

```ts
import X from '../../nodes/DiscountVideoNode.tsx';
//   └─ 变成 ─→  import X from 'VideoGenerate';   （整条路径没了！）

describe('DiscountVideoNode 上游合并', () => { /* … */ });
//   └─ 变成 ─→  describe('VideoGenerate', () => { /* … */ });  （描述文字全没了）
```

**结论**：`string_fragment` + `fix` 只能用于"字符串值恰好等于该 token"的精确情形（如本次视频节点里 `type: 'discountVideoNode'`）。凡是"长字符串里换子串"（路径、`describe`、枚举描述、注释），一律用 §4 的子串替换。

### 3.4 捕获组 fix 的元变量后不能紧跟字母
想在 fix 里写 `$1VideoGenerate$2`（保留前后文、中间替换），ast-grep 会把 `$1V` 误当成元变量名 `1V` 报错；`${1}` 在本版本不被识别。
**结论**：ast-grep 无法干净地做"注释内子串替换"，注释交给标准查找替换。

### 3.5 文件名 ast-grep 不改
`DiscountVideoNode.tsx` 这类文件名要靠 `git mv`，再用子串替换把 `'../../nodes/DiscountVideoNode(.tsx)'` 这类 import 路径同步。

## 4. 子串替换（字符串/注释内部）的标准做法

用一把**范围限定、编码安全（utf8 无 BOM）、可由 git diff 审查**的替换即可（等价于 `sed -i`）。关键约束：

- **大小写敏感**替换：`DiscountVideoNode → VideoGenerate` 与 `discountVideoNode → videoGenerateNode` 必须分开两条，否则小写串会误吞大写。
- 仅作用于 `src` / `tests` 源码文件，不碰 `docs` / `scripts` 历史快照与规则文件自身。
- Node `fs` 以 utf8 读写默认**不带 BOM**，不会污染编码。

```js
// 范围：src / tests；utf8 无 BOM；仅做子串替换
import { readFileSync, writeFileSync } from 'node:fs';
import { execSync } from 'node:child_process';
const out = execSync('git grep -l -E "DiscountVideoNode|discountVideoNode" -- src tests', { encoding: 'utf8' });
for (const f of out.split(/\r?\n/).filter(Boolean)) {
  const s = readFileSync(f, 'utf8');
  const n = s.replace(/DiscountVideoNode/g, 'VideoGenerate').replace(/discountVideoNode/g, 'videoGenerateNode');
  if (n !== s) writeFileSync(f, n);
}
```

## 5. 视频节点实操（已落地，可当模板）

四步，每步都能单独 `git diff` 审查：

1. **符号 exact**：`DiscountVideoNode → VideoGenerate`；接口 `DiscountVideoNodeData/Props → VideoGenerateData/Props`（ast-grep `identifier`）。
2. **字符串 exact + 子串**：`'discountVideoNode' → 'videoGenerateNode'`（ast-grep `string_fragment` 精确值 + §4 子串替换覆盖路径/枚举描述）。
3. **对象键**：`discountVideoNode: → videoGenerateNode:`（`property_identifier`，否则 prefs 失效）。
4. **文件名**：`git mv DiscountVideoNode.tsx VideoGenerate.tsx`（含两个测试文件），再用 §4 子串替换同步 `'.../DiscountVideoNode(.tsx)'` 引用。

验证：`npm run test:unit` —— **179 文件 / 2322 用例全绿**。

> 实测：漏掉第 3 步时，`useNodePrefs('videoGenerateNode')` 在注册表查不到旧键 `discountVideoNode`，prefs 直接失效；补上 `property_identifier` 规则后恢复。

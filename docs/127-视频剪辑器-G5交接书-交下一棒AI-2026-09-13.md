### 3.0 ⏱ 第一件：**时间轴标尺**（用户点名"时间轴还没有"）

**现状**：`base/utils/timeline/rulerTicks.ts` 的 `pickTickStep(pps)` / `formatTickLabel(t, step)` / `buildTicks(duration, step)` 在 G1 就已实现并有 16 例单测，**但基座从未渲染过标尺**——轨道区里只有片段盒子、播放头线和一条常驻信息，**没有任何刻度/时间参照**。目前唯一的"时间感"来自工带里的时间码文字。

**怎么做（照 mockup）**：
1. `mockup/video-editor-dock-mockup.html:251-258 / :408-413` 有 `.ve-ruler` / `.ve-ruler-sp` 的形态参考（左列对齐轨道头宽度 `w-28`，右侧是刻度带）。
2. 在轨道区**上方**加一行标尺（与轨道区同宽、同横向滚动容器，否则刻度和片段会错位）：
   - `pickTickStep(pps)` 定步长 → `buildTicks(totalDuration, step)` 取刻度 → 每个刻度 `timeToX(t, pps, scrollLeft)` 定位 + `formatTickLabel(t, step)`。
   - **吸附联动**：播放头落点已吸附 `clipEdges`（`VideoEditorDock` 轨道区 `onPointerDown`）；标尺出现后，拖播放头也应走同一条 `snapTime` 判据（**判据单点**，别抄第二份）。
3. 标尺必须**跟随横向滚动**（与片段同容器或同步 `scrollLeft`），否则就是"看起来有刻度、实际对不上"。

**验收点**：刻度与片段左缘对齐（把一个片段拖到某刻度上，刻度读数 = 该片段 `timelineStart`）；缩放时刻度步长自动变疏/密；横向滚动时刻度跟着走。

**⚠️ 顺手要处理的债**：`pickTickStep` / `buildTicks` 目前**只有测试消费**（knip 把 tests 当 entry，所以 `check:dead-code` 没红）——**接上 UI 后这道"隐性豁免"就消失了**，别以为是闸在纵容你。

- [ ] 播放头：点轨道区落点并吸附到片段边界
- [ ] 胶片条/波形：视频片段显示胶片条且**裁剪即所见**（裁过的片段显示对应段）；音频片段显示真实波形；同素材多片段只抽一次（Network 面板看请求数）
- [ ] 编辑：分割/裁左/裁右/定格/复制/删除（留洞/波纹）/撤销重做，全部与预期一致且**不可用时置灰 + tooltip**
- [ ] 导出：纯直通工程 → 走直通（常驻信息正确）；含图片/叠加/尺寸不一致 → 走合成；取消真中断（再导不撞残留）；导出后画布出现新 assetNode 且可播放；**音频去向有提示**
- [ ] 断链：删掉源文件 → 片段红标 + 预检条；导出跳过断链片段
- [ ] 冲突：两个窗口同开 → 一边改动另一边出现冲突条且**本地改动保留**
- [ ] 键盘：基座展开时 Delete/⌘Z/⌘⇧Z/⌘Y 归剪辑器，**其余画布快捷键照旧**；画布仍可点选/拖节点

# 测试体系契约化审计 —— 测 UI 而非契约的现状与待办

> 日期：2026-08-26
> 性质：调研报告 / 待办清单（已调研、未实施）
> 状态：⏸ 待用户有空后处理

## 〇、背景与结论

近期提交时发现部分测试在测"UI 的改变"而非"契约的改变"：功能（契约）不变、只改样式/文案/class，测试就误红；而真正会因逻辑变更失败的契约反而没锁住。

对照 `spec/TEST-GUIDE.md` 的核心判定标准——"测试的价值 = 能否捕获真实回归"，本次用三个子代理（code-explorer）对 `tests/unit/` 做了全面审计。**结论与用户的判断一致**：

1. 组件层（`.test.jsx`）存在大量**自证式断言**（存在即通过）和 **UI 细节断言**（class/文本/结构字面量），测的是 UI 不是契约。
2. 逻辑层（`.test.js`)存在 **~62 处垃圾边界防御**（测不可能发生的异常输入"不崩"）和 **同一契约多文件重复**。
3. **真正的契约缺口**集中在三步子组件（StepShots/StepAssets/StepPrompt）——它们在 `ScriptBoxNode.test.jsx` 里被整体 mock 掉，内联业务逻辑完全无契约守护。

## 一、问题一：组件层自证式 / UI 细节断言

按 `TEST-GUIDE` 判定标准，`tests/unit/*.test.jsx`（约 40 个文件）中命中约 **40 个低价值用例**。典型类型：

| 类型 | 例子 | 问题 |
|------|------|------|
| **UI 细节断言** | `TaskCenter.test.jsx` 断言 `60%` 文本、`.animate-spin` class；`ScriptBoxNode` 断言 `bg-surface-hover` class | 改 UI 就红，契约没变 |
| **自证式断言** | `ScriptBoxNode` 三步渲染 `getByTestId('step-shots').toBeTruthy()`；`TaskCenter` 缩略图"存在即通过" | 存在即通过，改逻辑不红 |
| **mock 被调用式** | `TaskCenter` 复制提示词 `showToast.toHaveBeenCalled()` 不校验参数 | 测自己写的 mock |

**需要说明**：这批里**很多其实是"合理的组件行为测试"**（如 `AgentPanel` 发送消息、`DiscountVideoNode` prefs 记忆都校验了真实副作用参数），**不应一刀切全删**。真正该删/降级的是纯 class、文本字面量、无参数校验的断言。

### 逐文件命中清单（节选）

- **TaskCenter.test.jsx**（22 用例，~13 处 UI/自证）：`暂无任务`、计数 `0 生成中 · 0 失败`、`.animate-spin` class、`img[src]` 存在即通过、`showToast` 无参数调用等。有契约价值保留：搜索过滤、状态/类型下拉、重试、删除、预览关闭（校验真实副作用）。
- **AgentPanel.test.jsx**（22 用例，~9 处 UI/自证）：`hidden` class、`AI 助手` 文本、`思考中...` 文本、`msg-user` 存在即通过。有契约价值保留：回车发送、sendImageMode 参数、Skill 应用 markSkillUsed('s1')、对话新建等。
- **ScriptBoxNode.test.jsx**（16 用例，~8 处 UI/自证）：三步 `getByTestId` 存在即通过、`bg-surface-hover` class。**但注意：三步子组件被整体 mock 掉，见问题三**。
- **DiscountVideoNode.test.jsx**（17 用例，~7 处 UI/自证）：空态占位文本、摘要 `16:9·1080p·10s` 字面量、`video-thumb` 存在即通过。有契约价值保留：prefs 记忆、prompt 落盘、@素材追加、断线 setEdges、下载补 .mp4。

## 四、建议行动路线（待用户确认后执行）

**原则**（对齐 TEST-GUIDE）：**宁可只写 5 条真契约，也不凑 50 条假边界。**

1. **删垃圾边界 + 去重**：删 Top 10 用例 + `filesTasksApi.test.js` 重复部分 + 多余 `API_BASE` 断言（纯删除，不动逻辑）。
2. **抽函数补契约**：把问题三的 10 项内联逻辑抽成纯函数（`scriptBoxPrompts.js` / `utils.js` / `clipboard.js`），补 `.test.js` 契约测试。
3. **组件测试瘦身**：把 `.test.jsx` 里的 class/文本字面量断言改为"副作用参数"断言或删除，只保留真实行为测试。
4. **低成本即补**：`stripAtRef`、`textToDlg` 两个已存在纯函数零测试，成本最低、收益最直接，可先行。

**注意事项**：
- 删除测试前先确认该契约是否在别处已覆盖（避免删了真的守护）。
- 抽函数是"重构 + 补测"，改 `src` 需跑 `test:unit:logic` 回归；纯删测试文件只跑受影响文件确认。
- 组件测试里的"合理行为测试"（校验副作用参数）**保留**，不要一刀切。
- 涉及 `src` 改动时，新逻辑要满足 TEST-GUIDE §六 SOP（node 层 `.test.js` 优先）。

# 28-R2 · 生成节点接入 useNodeGeneration 收口（可执行）

> 配套售后计划：`docs/27-API中转层售后收口计划-2026-08-22.md`（R2）。
> 数据一致性红线：CONTEXT §五「生成链路真相源契约」——任务中心为结果权威源，node.data 为渲染缓存副本；写只走 `useNodeGeneration`，刷新后任务中心→节点回填，节点不回写。

---

## 1. 现状

`src/components/nodes/` 共 **17 个节点**，仅 **4 个**接入生成链路（`useNodeGeneration`/`onRecover`）：

| 已接入 ✅ | 未接入 ⚠️ |
|---|---|
| TextNode / PromptNode / DiscountVideoNode / TemplateNode | VideoExtractNode / VideoProcessNode / ImageNode / ImageBoxNode / GridSplitNode / GridMergeNode / PanoramaNode / FaceMosaicNode / LoopNode / GhostTargetNode / Director3DNode / ScriptBoxNode / GroupNode |

> ⚠️ **代码审计补遗（2026-08-22，code-explorer 实测）**：§1 未接入表漏列 `ImageBoxNode`（磁盘 17 个节点之一，§3 L39 已与 ImageNode 并列提及豁免）。节点总数 17、接入 4 / 未接入 13 的数量结构正确；`VideoExtractNode` 未接入且刷新丢结果风险**属实**（结果仅存 React state `extractedImages`，无 `patchData`/`saveResultToTasks`、不订阅 `agent:task-completed`）——确认 P1 优先收口无误。

未接入的后果（见 CONTEXT §五）：
- **刷新丢结果**：`VideoExtractNode` 等异步结果不随刷新恢复
- **异步完成不恢复**：无 `onRecover`，`agent:task-completed` 广播不回填
- **新节点会效仿**：新节点看到"不走 useNodeGeneration"的样板会照抄，放大问题

---

## 2. 目标

把「有生成/异步结果」的节点逐个接入 `useNodeGeneration`，使刷新不丢、异步完成恢复。**无生成语义的节点豁免**。

---

## 3. 节点分类与处理

> ⚠️ **先分类，不盲目全收口**。按 CONTEXT §〇 重构边界：特定功能模块不主动收口，除非有明确 bug。

| 节点 | 是否有生成/异步结果 | 处理 |
|---|---|---|
| **VideoExtractNode** | ✅ 抽帧异步 | **收口**（明确刷新丢结果，P1） |
| **VideoProcessNode** | ✅ 视频处理异步 | **收口**（若频繁用） |
| **GridSplit/GridMerge** | ⚠️ 生成结果 | 评估（明确 bug 才收口） |
| **LoopNode** | ⚠️ 循环生成 | 评估 |
| **ImageNode/ImageBoxNode** | ⚠️ 图片展示/上传 | ImageNode 已澄清豁免（不走生成 Seam，是落盘 URL）；ImageBoxNode 同理豁免 |
| **Panorama/FaceMosaic** | ⚠️ | 评估（特定功能，倾向豁免） |
| **GhostTarget/Director3D/ScriptBox/Group** | ❌ 无生成语义 | **豁免**（不接入） |

---

## 4. 执行步骤

### 4.1 样板对齐
参照已接入节点（PromptNode 是最完整样板）：
- `useNodeGeneration(节点数据, 回调)` 统一入口
- `onSuccess` 写回 `node.data.imageUrl/videoUrl/text`（字段名统一，禁双字段冗余）
- 异步节点传 `onRecover`（收到 `agent:task-completed` 回填）
- 参考 `src/components/base/useNodeGeneration.js` 文件头

### 4.2 逐个节点接入（按优先级）
```
1. VideoExtractNode  ← P1，先做（明确刷新丢结果）
2. VideoProcessNode  ← 评估后做
3. GridSplit/GridMerge/Loop ← 评估
4. 其余评估豁免
```

### 4.3 每个节点完成即验证
- 刷新页面 → 结果保留（不丢）
- 异步任务完成 → 自动恢复
- `npm run test:unit` + 该节点相关测试

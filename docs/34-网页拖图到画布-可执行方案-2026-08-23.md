## 一、目标

解决"从网页拖图片到画布"的两个问题：
1. 加号出现但图片没放进来（URL 在 `text/uri-list` 未被读取）。
2. 图片放进来但破图（防盗链/跨域）。

**最终采用方案**：网页图直接显示原 URL，能显示就显示，不做本地化下载（避免延迟和副作用）。**保持简单、不引入回归。**

## 三、改动点明细

### 1. `useAssetDropPaste.js` — `onDrop`

**现状**（问题 1 根因）：只读 `text/plain`，不读 `text/uri-list`。

**改为**：`onDrop` 里 `files` 为空时，同时读 `text/uri-list` 和 `text/plain`，取第一个非空 URL 候选（uri-list 可能多行，取首行）。

```js
const uriList = e.dataTransfer?.getData('text/uri-list') || ''
const text = e.dataTransfer?.getData('text/plain') || ''
const candidate = (uriList.trim() || text.trim()).split(/\r?\n/)[0]?.trim() || ''
if (candidate) {
  if (isAssetUrl(candidate)) {
    addImageNodeFromUrl(pos, candidate)   // 图片 URL
  } else {
    addNode('textNode', pos, { text: candidate, expanded: false })
    showToast('已导入文本')
  }
}
return
```

### 2. `useAssetDropPaste.js` — 新增 `addImageNodeFromUrl`

直接同步用原 URL 建节点，**不做下载/本地化**：

```js
const addImageNodeFromUrl = useCallback((pos, url) => {
  if (!url) return
  addNode('imageNode', pos, { imageUrl: url })
}, [addNode])
```

> 注意：**不要加 label**（保持与原来一致，避免改变节点 data）；**不要做本地化下载**（跨域会失败且引入延迟/副作用）。

### 3. `ScriptBoxAssetPicker.jsx`

第 34 行 `const { rescanResources } = await import('../base/localToolApi.js')` → 改为顶部静态导入：
```js
import { fetchResources, rescanResources } from '../base/localToolApi.js'
```
函数内直接 `await rescanResources()`。

## 四、测试

在 `tests/unit/useAssetDropPaste.test.js` 补 `onDrop` 测试（文件末尾新增 describe）：

| 用例 | 输入 | 期望 |
|------|------|------|
| 拖入图片（uri-list 图片 URL） | `files: []`，`getData('text/uri-list') = 'https://x/cat.png'` | `addNode('imageNode', pos, { imageUrl: 'https://x/cat.png' })` |
| 拖入文本（uri-list 纯文本） | `getData('text/uri-list') = 'hello'` | `addNode('textNode', pos, { text: 'hello', expanded: false })` |
| 拖入链接（plain 图片 URL，uri-list 空） | `getData('text/plain') = 'https://x/1.jpg'` | `addNode('imageNode', pos, { imageUrl: 'https://x/1.jpg' })` |
| 拖入空内容 | `files: []`，`getData = ''` | 不建节点、不报错 |

**测试注意**：`addImageNodeFromUrl` 是同步的，断言用 `result.current.onDrop(e)` 后同步 `expect(opts.addNode).toHaveBeenCalledWith(...)`。**不要 mock `httpClient`/`assetStore`**（已不用）。

1. 从网页拖图片 → 图片能进画布（加号出现且节点建成功）。

3. 本地文件拖入、素材库拖入、文本拖入、粘贴，行为**不变**。
4. 缩略图显示正常（ImageNode 未改）。
5. `npm run build` 无 `localToolApi` 动态导入警告。
6. `npx vitest run tests/unit/useAssetDropPaste.test.js` 全绿。

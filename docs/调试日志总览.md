# 全链路调试日志总览

> **排查任何 bug（不回复/出图失败/视频卡住/不落盘/点了没反应）先开 debug，不要猜。**
> 本文是前端 `logger.debug` 全链路埋点清单。A 层（info/warn/error）与 B 层（debug）均已落地，区分「常态价值」与「排查噪音」。
> 权威定义在 `spec/CONTEXT.md` §二「debug 开关」+ `CLAUDE.md` §3.2（改 bug 先加日志）。**改这里必同步本文**。

---

## 一、开关（通用 DEBUG，模块位）

- `logger.debug(cat, act, det, { module })` 默认安静，仅对应模块位开启时 console 输出、**不上报后端**。
- 开启（任一）：`.env` 加 `VITE_DEBUG_ALL=1`（全开）或 `VITE_DEBUG_<MODULE>=1`（单模块）；运行时 `window.__DEBUG_ALL=true` / `window.__DEBUG_<MODULE>=true`。
- 模块位集中在 `config.js` 的 `DEBUG_MODULES`：**`asset`（素材库）/ `agent`（AI 助手）/ `image`（生图+视频）**。新增模块直接在 `DEBUG_MODULES` 登记，禁止再起散开关。
- `DEBUG_ASSET` 保留为 asset 模块位别名（旧引用不破）。
- **修复完确认开关已关**（默认即关，勿在 `.env` 留 `VITE_DEBUG_*`，运行时设的 `window.__DEBUG_*` 排查完清掉）。

## 二、素材库链路（模块位 = asset，分类 `assetStore`/`filesApi`）

**链路**：`节点/面板发送 → assetStore.persistUrlToBackend → filesApi.uploadFileToLocal → /api/resources`（素材统一存 `migrated`）。

| 文件 | B 层 debug | 定位什么 |
|---|---|---|
| `assetStore.js` | `[SEND]` 进入/准备落盘 | 发送入口、url 形态、目标 folder |
| `assetStore.js` | `[PERSIST]` 开始 / data / blob / http 分支 / 落盘成功 / rescan | 各分支下载与落盘成败、rescan |
| `filesApi.js` | `[UPLOAD]` 准备/完成 | multipart 上传参数与结果 |

> **A 层**：落盘失败 `toastError` 已透出；无 `materials` 目录（统一 `migrated`）。开 `VITE_DEBUG_ASSET=1` 复现一次，看 `[SEND] → [PERSIST] → [UPLOAD] → 落盘` 全链路。
> 排查历史见 `docs/10-发送到素材库不落盘-排查-2026-08-19.md`。

## 三、AI 助手链路（模块位 = agent）

**链路**：`AgentPanel → useAgentChat(send/sendImageMode) → agentCore.buildRequestMessages → agentRuntime.roundTrip(LLM) / runToolCalls(工具) → useCanvasAgentTools → canvasPlanExecutor.executePlan(批量) → 生成`。

### A 层（始终 info/warn/error，进后端全链路）

| 文件 | 日志 | 用途 |
|---|---|---|
| `useAgentChat.js` | `发送` / `图像发送`（入口摘要） | 定位一次发送的入参（文本/附件数） |
| `useAgentChat.js` | `图像模式结果`（ok/entries/error） | 图像直连链路成败 |
| `agentRuntime.js` | `请求` / `响应` / `流式结果` / `非流式结果` | LLM 通信（via proxy\|agent、消息数、内容长、工具数） |
| `agentRuntime.js` | `请求失败` / `非流式解析失败(可能截断)` | 通信异常与内容截断 |
| `agentRuntime.js` | `工具` / `工具失败` | 每个工具执行成败 |
| `useCanvasAgentTools.js` | `未知工具`（warn） | 模型幻觉调不存在的工具 |
| `canvasPlanExecutor.js` | `执行计划` / `执行计划完成` | 批量出图发起与终态（步数/完成/失败） |

### B 层（debug 开关控制，逐跳排查）

| 文件 | 日志 | 定位什么 |
|---|---|---|
| `useAgentChat.js` | `[发送] 入口` / `[发送] 终态` / `[图像] 拆分判定` | send 入参、终态（rounds/status/steer）、分别改图拆分 |
| `agentCore.js` | `[消息组装]` | 发 LLM 的 messages：总数/丢弃孤儿 tool 数/historyTurns/roles |
| `agentRuntime.js` | `[请求] messages` / `[流式] 完成` / `[工具] 入参` | 发的内容摘要、流式字节数、工具参数 |
| `useCanvasAgentTools.js` | `[工具] 分发` | 每个工具名 + 参数摘要（截断防刷屏） |
| `canvasPlanExecutor.js` | `[执行计划] 分批/建节点` | 独立/依赖批、每步建节点与参考图挂载 |

> **排障**：开 `VITE_DEBUG_AGENT=1`，看 `[发送] 入口 → [消息组装] → [请求] → [流式] → [工具] → [执行计划]`；A 层 `info` 已在后端 `/api/logs` 留存可 grep。

## 四、生图节点链路（模块位 = image，分类 `生图`）

**链路**：`PromptNode → useNodeGeneration(start/run) → imageApi.generateImage(组 genBody) → proxyGenerate.imageProxy(SSE/轮询) → /api/proxy`。

| 文件 | B 层 debug | 定位什么 |
|---|---|---|
| `useNodeGeneration.js` | `[节点] start` / `run返回` / `落盘` / `用户停止`（分类 `生成`，通用） | 哪个节点发的什么 prompt、run 是否拿到 url、落盘、是否被停 |
| `imageApi.js` | `[参数] genBody`（分类 `生图`） | 发给网关的参数：尺寸/resolution/参考图数/refFormat 是否正确拼装 |
| `proxyGenerate.js` | `[请求] 发出` / `[请求] HTTP失败`（分类 `生图`） | 请求是否发出、发到哪、网关是否拒绝 |
| `proxyGenerate.js` | `[SSE] 完成`（分类 `生图`，同步） | 流式字节数 + 是否拿到图片 url（定位断流/未返回） |
| `proxyGenerate.js` | `[异步] 提交 / 拿到结果 / 上游失败 / 轮询超时`（分类 `生成`，通用） | 异步轮询：task_id、轮询次数、耗时、成败 |

> **A 层**：`taskStore.js`（gen 分类：`concurrency-limit-skip`/`run-trigger-fail`/`run-callback-missing`）+ `useNodeGeneration.js`（`生成 start/success/fail/异常`）覆盖生成发起与成败，进后端全链路可 grep。
> **排障**：开 `VITE_DEBUG_IMAGE=1`，看 `[节点] start → [参数] genBody → [请求] 发出 → [SSE]/[异步] → [节点] 落盘`；A 层 `生成 fail` 会在后端 `/api/logs` 留存。

## 五、视频节点链路（模块位 = image，分类 `视频`）

**链路**：`DiscountVideoNode → useNodeGeneration → videoApi.generateVideo(组 body) → proxyGenerate.videoProxy → pollUntilDone(轮询) → /api/proxy`。
与生图共用 `image` 模块位（同属媒体生成链路），分类标签 `视频`/`生成` 区分。

| 文件 | B 层 debug | 定位什么 |
|---|---|---|
| `useNodeGeneration.js` | `[节点] start / run返回 / 落盘 / 用户停止`（分类 `生成`，通用） | 哪个节点发的什么 prompt、run 是否拿到 url、落盘、是否被停 |
| `videoApi.js` | `[参数] genBody`（分类 `视频`） | 发给网关的视频参数：尺寸/清晰度/时长/参考图是否正确拼装 |
| `proxyGenerate.js` | `[视频] 开始`（分类 `视频`） | 视频提交是否进入轮询 |
| `proxyGenerate.js` | `[异步] 提交 / 拿到结果 / 上游失败 / 轮询超时`（分类 `生成`，通用） | 异步轮询：task_id、轮询次数、耗时、成败（视频/生图共用） |

> **A 层**：视频节点走 `useNodeGeneration`（`生成 start/success/fail/异常`）+ `taskStore.js`（gen 分类），已在后端全链路留存可 grep。
> **排障**：开 `VITE_DEBUG_IMAGE=1`，看 `[节点] start → [参数] genBody(视频) → [视频] 开始 → [异步] 提交/拿到结果 → [节点] 落盘`；A 层 `生成 fail` 会在后端 `/api/logs` 留存。

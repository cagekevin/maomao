## 三、你要做的主体：Dock 拆分

### 3.0 目标与原则

- 目标：`VideoEditorDock.tsx` 从 **~1600 行**收敛到 **~400 行纯编排**（状态声明 + hook 调用 + 组件组装 + 回调绑定）。
- 原则（克制，别一拆到底）：**带副作用 / 自有生命周期的逻辑抽 hook**；**低耦合的 JSX 段抽渲染组件**；纯编排留在 Dock。
- 红线（机器守卫，已有）：`dockContract.test.ts`（基座非 portal / 不登记 modalLayer / 不直调 `exportLossless`/`exportComposite`/`needsCompositing`）· `dockEnqueue.test.tsx`（入轨幂等，复现过"点一次出两条"）——**这两个必须一直绿**。

### 3.1 抽 hook（放 `panels/dock/`，与 `useEditorProject` 同目录）

| hook | 内容 | 关键依赖 |
| --- | --- | --- |
| `useEditorExport` | `exportRequest`/`plan`/`letterbox`/`kindByUrl` + `exporting/stage/progress/abortRef` + `spawnAssetNode` + `onExport` | `flow`(ReactFlow)·`history`(canvas edges)·`project`·`allClips`·`sources.byClipId`·`aliveRef` → 用 `runExport`/`uploadResult`/`spawnAndCommit` |
| `useTimelineDrag` | `beginClipDrag`(move/trimLeft/trimRight) + pointermove 拖拽 effect + `applyMain` + `duplicateSelected` + 键盘(und/redo/delete) + `canSplit/canTrimLeft/canTrimRight/canDelete` | `store`·`pps`·`project`·`selectedClipId`·`setPlayhead`·`mainClips` |
| `useEditorTransport` | `playInfo`(播放钟) + `displayHead` + `onTogglePlay` + `stepToBoundary`(上/下一边界) + `setPlayhead` | 播放钟用 rAF，`useEditorPlayback` 的 `PlaybackSink` 接 `displayHead` |
| `useEditorIngest` | `enqueue`(点选入轨) + `selectedSig`/`handledRef` effect(幂等入轨) | `flow`·`store`·`open` · 签名逆运算在 `base/canvas/nodeMedia.ts` `selectedNodeIdsOfSig` |

> 抽这些时注意：**把"上一个签名"的入轨判据、拖拽的 origin 增量、播放钟的节流(CAS 写放大)原样搬，别顺手改逻辑**。它们各自的坑见 §五。

### 3.2 抽渲染件（`panels/dock/` 下独立 .tsx）

| 组件 | 内容 | 备注 |
| --- | --- | --- |
| `DockToolbar` | 工带 header：收起/走带/时间码/撤销重做/分割裁剪定格/删除复制/缩放/导出按钮+阶段进度/设置(Cog) | **最大的一段 JSX**，props 较多（走带+编辑+导出回调+缩放）可接受 |
| `DockStatusBar` | C5.6 常驻信息条 + 断链 banner + 冲突条 + 加载/失败 + 设置条(宽/高/fps/行高) | 拆出后 Dock 更清爽 |
| `RulerStrip` / `PlayheadLine` | 标尺刻度、播放头 + 顶部抓手 | 小件，可留 Dock 也可独立，看剩余行数 |

> 组装回调仍由 Dock 提供（经 props 传入组件），**组件本身不持有领域逻辑**。

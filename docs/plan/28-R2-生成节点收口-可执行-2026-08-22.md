---

## 2. 目标

把「有生成/异步结果」的节点逐个接入 `useNodeGeneration`，使刷新不丢、异步完成恢复。**无生成语义的节点豁免**。

> **✅ 审计结论（2026-08-22）**：13 个未接入节点逐节点核对后，**仅 `VideoExtractNode` 存在真实"刷新丢结果"**（结果仅存 `extractedImages` state）。其余 12 个结果均已落盘（写 `node.data`）或以子节点交付（`spawnAndCommit`），刷新不丢，属 §0 豁免或非生成语义，**无需改造**。R2 收口 = VideoExtractNode 落地 + 全量审计 + 清单同步（CONTEXT §五 ⑥）。

## 3. 节点分类与处理

> ⚠️ **先分类，不盲目全收口**。按 CONTEXT §〇 重构边界：特定功能模块不主动收口，除非有明确 bug。

| 节点 | 是否有生成/异步结果 | 处理 |
|---|---|---|
| **VideoExtractNode** | ✅ 抽帧异步 | ✅ **已收口**（唯一真实刷新丢结果：结果仅存 state；本地处理不走 useNodeGeneration，改 useNodeData.patchData 写 `data.extractedImages` 落盘） |
| **VideoProcessNode** | ✅ 视频处理异步 | ✅ **豁免**（`gifResult`/`outputInfo` 经 setNodes 落盘 + spawn 子节点交付，刷新不丢） |
| **GridSplit/GridMerge** | ⚠️ 生成结果 | ✅ **豁免**（GridSplit spawn 子节点；GridMerge 写 `data.imageUrl`） |
| **LoopNode** | ⚠️ 循环生成 | ✅ **豁免**（patchData + spawnAndCommit，已落盘） |
| **ImageNode/ImageBoxNode** | ⚠️ 图片展示/上传 | ✅ **豁免**（非生成节点，落盘 URL 持久） |
| **Panorama/FaceMosaic** | ⚠️ | ✅ **豁免**（Panorama 写 `data.imageUrl`+spawn；FaceMosaic outputResults 生成子节点） |
| **GhostTarget/Director3D/ScriptBox/Group** | ❌ 无生成语义 | ✅ **豁免**（不接入） |

## 4. 执行步骤

### 4.1 样板对齐
参照已接入节点（PromptNode 是最完整样板）：
- `useNodeGeneration(节点数据, 回调)` 统一入口
- `onSuccess` 写回 `node.data.imageUrl/videoUrl/text`（字段名统一，禁双字段冗余）
- 异步节点传 `onRecover`（收到 `agent:task-completed` 回填）
- 参考 `src/components/base/useNodeGeneration.js` 文件头

### 4.2 逐个节点接入（按优先级）
```
1. VideoExtractNode  ← P1，已收口（结果落盘 node.data + 原子防重入）✅
2. VideoProcessNode  ← 已审计豁免（结果已落盘）✅
3. GridSplit/GridMerge/Loop ← 已审计豁免（结果已落盘/子节点交付）✅
4. 其余已审计豁免（无生成语义或非生成节点）✅
```

### 4.3 每个节点完成即验证
- 刷新页面 → 结果保留（不丢）
- 异步任务完成 → 自动恢复
- `npm run test:unit` + 该节点相关测试

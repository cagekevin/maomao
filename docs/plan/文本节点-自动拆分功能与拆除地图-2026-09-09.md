# 文本节点「自动拆分」功能说明与拆除地图

> 日期：2026-09-09
> 状态：**功能保留**，本文只是功能说明 + 将来删除时的「拆除清单」（用户暂未要求删）。
> 范围：仅 text node（`src/components/nodes/TextGenerate.tsx`）里的「自动拆分」复选框及其连带逻辑。

---

## 〇、一句话定位

文本生成节点底部有一个「自动拆分」复选框（`autoSplit`）。勾选后，点生成时不再走普通助手，
而是让 AI 当「智能内容拆分助手」，返回严格 JSON `{items:[{title,content}]}`，前端把每个 item
**新建一个子文本节点并自动连线**；解析失败则降级为正文文本。

---

## 一、功能交互链

1. **入口**：底部工具栏左侧复选框「自动拆分」（`TextGenerate.tsx` 面板底部）。
2. **落盘**：勾选状态写回 `node.data.autoSplit`（即时写回，非防抖）。
3. **生成时**（`useGenerateNode` 的 `run`）：
   - 勾选 → `system` 换成「智能内容拆分助手」，要求返回严格 JSON `{items:[{title,content}]}`。
   - 未勾选 → `system = 'You are a helpful assistant.'`（普通助手，无 JSON 指令）。
4. **成功后**（`onSuccess`）：
   - 勾选且 `r.content` 为字符串 → 先 `strip ```json` → `JSON.parse` → 取 `items`（或整个解析结果）。
   - `items` 是数组且非空 → 以父节点为源，纵向每隔 250px 排一个 `textGenerateNode` 子节点
     （`data.text = it.content`、`data.label = it.title`、`expanded:false`），经 `buildSpawnNodes` + `spawnAndCommit` 原子提交 + 自动连线（源 handle `main-output`）。
   - 解析异常 → `logger.warn` 降级为普通文本，不阻断。
   - 未勾选（或解析失败）→ 正常把 `r.content` 写回本节点 `text`，并落盘成 txt 进文本 tab。

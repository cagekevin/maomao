## 一、任务目标与边界

**目标**：把 director3d 改造成"专业 3D 软件式"的动画编辑器，能力清单：
1. **布局统一**：右栏**只有一个动画面板**，把普通属性面板（Scene/Character/Prop/Camera）全部整合进动画面板内，按选中对象动态显示。
2. **视图模式简化**：去掉顶栏 3 个视图按钮（导演视角/机位视角/动画），动画模块默认常驻、成为主模块；移动/旋转/缩放工具栏**一直出现**。
3. **摄像机模式**：左栏对象树点摄像机按钮 → 进入该摄像机视口；再点退出（C4D 式）。
4. **C4D 式打帧触点**：位置/旋转 X/Y/Z 每轴独立打帧点（灰=无帧、亮=有帧、点击记录），并支持角色/道具/摄像机等可动画对象。
5. **摄像机打帧 + 目标约束**：位置 XYZ/注视 XYZ/FOV 可打帧；近远裁剪不打帧；注视点支持"跟随目标对象"（C4D Target）或手动可打帧。
6. **Auto Key 自动关键帧** + **F9 一键记录 PSR**。
7. **路径并入关键帧**：删掉路径 tab 的表单，"从 A 走到 B" 用 K 帧（起点帧+终点帧）。
8. **曲线编辑器弹窗**：右键对象 → 弹出窗口（选对象 → 编辑曲线）。

**边界（不做）**：
- 不改既有截图/导出/资产导入等与本次无关的核心逻辑（仅必要的布局迁移）。
- 曲线编辑器只做基础版（线性/缓入缓出/台阶 三种插值 + 简单曲线显示），不做贝塞尔手柄精调。
- 不引入新的 3D 引擎/库。

**硬性约束**：
- `director3d/` 是外部集成目录（CLAUDE.md：不做主动重构、只做最小集成）→ 但本次是作者明确要求的重构，可在既有代码上合理改造，改动既有逻辑前先确认影响面。
- 状态走既有 `commitMutation/commitUiMutation`（`directorStore.ts`），不裸改 state。
- 每完成一阶段跑 `npx tsc --noEmit` 确认无类型错误。

## 二、依赖顺序与优先级（务必按此实施）

```
阶段1 布局统一(属性并入动画面板) → 阶段2 视图模式简化 → 阶段3 对象管理与动画打通
  → 阶段4 摄像机模式打通 → 阶段5 打帧触点+摄像机打帧 → 阶段6 Auto Key+F9
  → 阶段7 路径并入关键帧 → 阶段8 曲线编辑器弹窗
```

**为什么这个顺序**：
- 阶段1 是地基：布局统一后，属性面板进入动画面板，后续打帧触点/摄像机打帧都在统一面板里做。
- 阶段2 简化视图后，动画模块常驻，避免"动画/属性"两个面板反复切换的复杂度。
- 阶段3 打通对象管理（场景树选中→面板/时间轴联动）后，阶段4/5 才能准确作用到选中对象。
- 阶段6/7/8 是增强，依赖前 5 阶段的稳定。

## 三、分阶段实施（每阶段含验证标准）

### 阶段1 · 布局统一：属性面板并入动画面板

**目标**：右栏只有动画面板，属性编辑整合进去。

**子步骤**：
- **1.1** 读 `RightPanel.tsx`，确认 `animationModuleOpen` 时整栏切动画面板的逻辑（L14）。
- **1.2** 设计动画面板内部结构：新增一个"属性"区域，按选中对象类型动态渲染对应属性编辑：
  - 选中角色 → 角色属性（复用 `CharacterPanel` 的属性部分）
  - 选中道具/模型 → 道具属性（`PropPanel`）
  - 选中摄像机 → 摄像机属性 + 打帧触点（`CameraPanel` 的 properties 部分）
  - 未选中/场景 → 场景属性（`ScenePanel`）
- **1.3** 把 Scene/Character/Prop/Camera 面板组件（或其内容）以**子组件**形式并入动画面板，不单独整栏切换。
- **1.4** 处理 `RightPanel`：动画模块常驻后，不再需要 `animationModuleOpen ? <AnimationPanel/> : <属性面板>` 的分派。右栏直接渲染统一的动画面板。

**验证**：
- `npx tsc --noEmit` 零错误。
- 进入导演台：右栏是动画面板；选中角色/摄像机/场景，动画面板内能看到对应属性编辑；属性改动生效。

### 阶段2 · 视图模式简化

**子步骤**：

- **2.2** store：`DEFAULT_UI_STATE.animationModuleOpen` 默认 `true`（store L281）；简化 `setViewMode`/`toggleAnimationModule` 逻辑，动画模块常驻。
- **2.3** 确认 `DirectorDeskShell` 底部动画模块（时间轴 + PlaybackTicker）始终渲染（L69-74 不再依赖 animationModuleOpen）。
- **2.4** 确认移动/旋转/缩放工具栏（`ViewportToolbar`）**一直出现**，不随模式隐藏。

**验证**：
- 进入导演台：无顶栏视图切换按钮；底部时间轴、右栏动画面板始终显示；移动/旋转/缩放工具栏始终可用。
- 选中对象在视口拖动：仍能写关键帧（动画态路径不受影响）。

### 阶段3 · 对象管理与动画打通

**目标**：场景树选中对象 → 动画面板/时间轴自动定位到该对象。

**子步骤**：
- **3.1** 确认 `ObjectTreePanel` 选中对象调用 `selectObject`（已更新 store `selectedObjectId`）。
- **3.2** 动画面板读取 `selectedObjectId`，打帧/属性编辑作用到选中对象（已部分支持，补齐摄像机 `linkedCameraId` 映射）。
- **3.3** 时间轴：选中对象 → 高亮其轨道行（`AnimationTimelineBar` 已有 `isActiveRow`，补齐跨类型 key 映射：对象 id vs 相机 linkedCameraId）。

**验证**：
- 场景树点对象 → 时间轴高亮该对象轨道、动画面板显示该对象属性与打帧触点。
- 摄像机：场景树点摄像机对象 → 联动到其 linkedCameraId 轨道。

### 阶段4 · 摄像机模式打通

**目标**：对象树点摄像机按钮 → 进入该摄像机视口；再点退出。

**子步骤**：
- **4.1** 读 `ObjectTreePanel` 摄像机分组交互，给每个摄像机加"进入视口"按钮。
- **4.2** 点按钮 → `setAnimationViewportMode("camera")` + 设 `activeCameraId` 为该摄像机 → 视口从该摄像机视角渲染（复用 `DirectorCanvas` 相机视角驱动）。
- **4.3** 再点按钮 → 退出回导演漫游（`setAnimationViewportMode("director")`）。
- **4.4** 移除顶栏/时间轴里残留的"导演视角/相机视角"切换入口（已被阶段2去掉）。

**验证**：
- 对象树点摄像机按钮 → 视口切到该摄像机视角；再点退出回漫游。
- 相机视角下播放：画面按时间轴驱动（复用 cameraAnims）。

### 阶段5 · C4D 式打帧触点 + 摄像机打帧 + 目标约束

**目标**：位置/旋转 X/Y/Z 每轴独立打帧触点（灰/亮、点击记录）；摄像机参数打帧 + 目标约束。

**子步骤**：
- **5.1** 新建/复用打帧触点组件（`anim-ed` 风格，参考现有 `.anim-ed-attr-diamond`）：一个属性一个触点，状态灰（当前播放头无该属性关键帧）/亮（有）。
- **5.2** 在动画面板"关键帧"区，把位置/旋转改成 **X/Y/Z 每轴独立触点**：点击某轴 → 当前播放头写该轴关键帧（其他轴保留，做"按轴合并"）。
- **5.3** 摄像机打帧（属性区）：位置 X/Y/Z、注视 X/Y/Z（仅手动模式）、FOV 各一个触点；近/远裁剪不打帧。
- **5.4** 目标约束：摄像机"注视目标"开关（复用 `targetMode: "object"`）→ 选目标对象，相机注视点自动跟随该对象（需补实时跟随：目标对象移动 → camera.target 更新）；关 → 手动坐标可打帧。
- **5.5** 打帧统一走 `setKeyframeGroupAtPlayhead(cameraId/objectId, { position/target/fov })`（track 用相机 id / 对象 id）。

**验证**：
- 选中对象/摄像机：属性参数前有打帧触点，灰→点击记录→亮；播放时按帧运动。
- 摄像机勾选"注视目标"后选一个人 → 相机自动看向并跟随；不勾选 → 注视 XYZ 可打帧。

- **6.3** 开启 Auto Key 后，属性/视口改参数自动写当前播放头关键帧（复用动画态拖动写帧逻辑）。
- **6.4** 快捷键 F9：一键记录选中对象 PSR（`addKeyframeForSelection`）。

**验证**：
- 开 Auto Key 后拖动/改参数自动打帧；关后需手动点触点。
- 按 F9 记录选中对象 PSR。

## 四、翻车点与规避

| # | 翻车点 | 规避 |
|---|---|---|
| C1 | 阶段1 属性面板并入动画面板后，属性改动不生效/丢失 | 复用原面板的 store action，不裸改；逐面板验证 |
| C2 | 去掉顶栏 3 档后，`animationModuleOpen` 常驻导致属性面板完全无法访问 | 属性已并入动画面板，动画面板内部按选中对象显示属性 |
| C3 | 摄像机 `linkedCameraId` vs `id` 轨道 key 不一致 | 统一：相机打帧 track 用相机 id；对象树摄像机对象映射到 linkedCameraId |
| C4 | 摄像机"跟随目标"实时跟随未实现 | 阶段5 需补：目标对象 transform 变化 → 重算 camera.target |
| C5 | 打帧触点"按轴合并"破坏整体 position | 点某轴时读当前帧已有值合并，缺省取对象当前值 |
| C6 | 大重构引入类型错误/回归 | 每阶段跑 `tsc --noEmit`；保留原功能最小改动 |
| C7 | Auto Key 误打大量多余帧 | 默认关闭；用完提醒关闭（C4D 惯例） |

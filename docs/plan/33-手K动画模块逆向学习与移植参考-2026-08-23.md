## 一、契约（数据结构与状态）

### 1.1 timeline（挂在 `project.timeline` 上）

```
timeline: {
  duration: 5,        // 默认总时长(秒)，常量 kF=5
  fps: 30,            // 默认帧率，常量 DF=30
  tracks: {
    // key = 对象 id 或相机 id（相机用 linkedCameraId）
    [objectIdOrCameraId]: Keyframe[]
  }
}
```

### 1.2 Keyframe（关键帧）

一个关键帧可以混合携带「位移/旋转/姿态/相机参数」任意子集（缺啥就不覆盖该维度）：

```ts
interface Keyframe {
  id: string;                 // crypto.randomUUID()
  time: number;               // 播放头时间(秒)
  position?: [x, y, z];       // 世界位置
  rotation?: [x, y, z];       // 欧拉角（y 可能是朝向角，见 mC）
  target?: [x, y, z];         // 相机看向点
  fov?: number; near?: number; far?: number;  // 相机参数
  posePresetId?: string | null; // 姿态预设 id（内置或自定义）
  controls?: Record<string, number>; // 骨骼控制值（覆盖/插值用）
  easing?: "linear" | "hold" | "ease";  // 插值方式，默认 linear；姿态默认 ease
}
```

> 关键设计：**一帧 = 各维度可选**。同一轨道里，位移帧和姿态帧可以分开打；
> 插值时按维度各自在「有该值的帧」间插值，互不干扰。

### 1.3 自定义姿势资产（`project.customPosePresets`）

```ts
interface CustomPosePreset {
  id: string;              // crypto.randomUUID()
  name: string;            // 缺省「自定义姿势 N」
  controls: Record<string, number>;  // 骨骼控制值快照
}
```

### 1.4 store 动画相关 state + actions（Zustand）

**state**：
- `project.timeline`（§1.1）
- `project.customPosePresets`（§1.3）
- `currentTime: number`（播放头，秒）
- `isPlaying: boolean`
- `animationModuleOpen: boolean`（动画模块是否打开 → 右栏切动画面板）
- `animationViewportMode: "director" | "camera"`（动画时视口视角）
- `poseHandlesEnabled: boolean`（视口 IK 摆姿势开关）
- `pathDraft`（路径生成草稿）

**actions（核心）**：

| action | 作用 |
|---|---|
| `addKeyframeForSelection()` | 对当前选中对象/相机，在播放头打一帧（位置/旋转/姿态快照） |
| `setPoseKeyframeAtPlayhead(objId, poseId)` | 把指定姿态写成当前播放头的关键帧 |
| `upsertTransformKeyframeAtPlayhead(id, transform)` | 播放头处更新/插入位移关键帧（视口拖动时用） |

| `applyPosePreset` / `applyCrowdPosePreset` | 已有姿势预设（含关键帧感知：若该对象有姿态关键帧则同步写帧） |

## 二、数据流（手K闭环）

### 2.1 打关键帧 → 存储

```
视口选中角色/机位 → 拖到某个时间点(播放头 currentTime) → 点「打关键帧」
  addKeyframeForSelection()
    ├─ 角色：Il(transform, 轨道, time) 取当前位置插值 → 存 { position, rotation, posePresetId, controls, easing }
    ├─ 相机：Il(transform) 取位置 + Cy(target) 取看向 → 存 { position, target }
    └─ 写回：f0(state, trackId, [kf])   // 追加并 sort 按 time，duration 自动扩到 max(time)+0.001
```

**关键纯函数**：
- `f0(state, trackId, kfs, mode="append")`：把关键帧追加/替换进轨道，按 time 排序，扩 duration。
- `h0(timeline, trackId, obj, time, poseId, controls)`：在播放头处**更新或插入**姿态关键帧（time 容差 0.0001 视为同帧 → 覆盖）。

### 2.2 播放 → 插值 → 驱动视口

```
播放(play) → 每帧(C5 组件用 R3F useFrame)：
  currentTime += delta，到 duration 自动 pause
  └─ 视口对象渲染(ObjectSceneNode) 每帧：
       position/rotation = Il(object.transform, 轨道, currentTime)   // 位移/旋转插值
       rigState          = N0(characterRig, 轨道, currentTime, customPosePresets)  // 姿势插值
       相机视角模式(R5)：
       camera.position/lookAt/fov/near/far 由 Il/Cy/gC/FF/UF 按当前时间插值驱动
```

**插值引擎**：
- `f1(base, keyframes, t, field)`：三维向量插值。`field∈{position,rotation,target}`。
  - 边界：t≤首帧 → 首帧值；t≥末帧 → 末帧值。
  - 中间：找区间 `[c[d], c[d+1]]`，`tRatio=(t-c[d])/(c[d+1]-c[d])`。
  - easing：`hold`→前帧值；`ease`→`t^2*(3-2t)`（smoothstep）；`linear`→t。
  - 返回 `lerp(o[d], o[d+1], t)` 逐分量。
- `_w(base, kfs, t, field)`：**标量**插值（fov/near/far），逻辑同上。
- `BF(a, b, t)`：骨骼 controls 对象逐 key `lerp`。
- `N0(rig, kfs, t, customPoses)`：**姿势插值**。
  - 只取有 `posePresetId/controls` 的帧；每帧 `controls` 优先于 `posePresetId` 解析（posePresetId → 查内置 `ia`/自定义 presets 得 controls）。
  - 区间内：`ease` 用 `BF(controls_a, controls_b, smooth(t))` 混合，`hold` 用前帧；返回 `l0(poseId, controls)`。
- `Il(transform, kfs, t, isCharacterFace)`：封装 position/rotation 插值 + **可选朝向**（`mC` 用 XZ 平面两帧位置差算 `atan2` 得朝向角，覆写到 rotation.y，用于角色面向移动方向）。
- `Cy(target, kfs, t)`：相机看向点插值。

### 2.3 视口拖动 → 写回关键帧（IK/位移手K）

视口对象被拖动结束（`ee()`）：
- **动画模块打开时**：
  - 相机 → `updateCamera(linkedCameraId, transform)` + `upsertTransformKeyframeAtPlayhead(linkedCameraId, F)`
  - 其它 → `upsertTransformKeyframeAtPlayhead(id, F)`（播放头处更新/插帧）
- **动画模块关闭时**：若 currentTime 附近(±0.06s)已有关键帧 → `updateKeyframe`；否则直接改对象 transform。

> 这就是"手K"的精髓：**播放头指到哪，拖物体就写到那帧**；播放时按帧插值丝滑过渡。

## 三、功能（UI 与能力）

### 3.1 右栏动画面板（`animationModuleOpen` 时整栏切换）

Tab：**轨道 / 关键帧 / 运镜 / 路径**

- **轨道**：列出所有 `tracks`（角色 kind=角色、相机 kind=camera，显示帧数），可「选中/清除」。
- **关键帧**：当前轨道关键帧表格（时间/类型/插值/操作：定位·删除），「打关键帧」「保留首尾」「删除全部」。
  - 类型判定：`ne(kf)` → 有 posePresetId/controls → `姿态·X`；有 target → `运镜`；否则 `位移动画`。
- **姿势调节（关键帧感知）**：选姿态预设 / 拖骨骼滑块 / 开「画面摆姿势(IK)」，都会**记录到当前播放头关键帧**（`updatePoseControl` 在 `animationModuleOpen && character` 时写帧）。
- **运镜**（选中相机时）：8 种预设（`dollyIn/Out`推拉、`truck`移、`pan`摇、`orbit`环绕、`crane`升降、`pedestal`俯仰、`handheld`手持）+ 起点/时长/幅度/角度/手持种子参数 →「生成运镜」(`applyCameraShotPreset`)。
- **路径**（选中角色时）：起点/终点/时长/姿态/插值/追加或替换 →「生成匀速路径」(`applyCharacterPath`)。

### 3.2 底部动画模块条（`_4` 组件，动画模块打开时显示）

- 回到开头 / 播放暂停 / 跳到结尾 / 当前时间输入 / `duration s · fps`。
- 时间轴 scrubber（range，拖动即 `setCurrentTime`）。
- 总时长 / 帧率设置。
- 导出视频：选录制视角（导演/相机）+ 分辨率 + 帧率 → `MediaRecorder + captureStream` 逐帧推进 currentTime 录制 → 优先 MP4(H.264)，不支持回退 WebM。
- 视口视角切换：导演视角（自由漫游）/ 相机视角（按时间轴渲染）。

### 3.3 视口/工具栏

- 工具栏新增 **「视口存为关键帧」**：需先在相机视角激活一台相机，把当前视口捕获为它的关键帧。
- **IK 摆姿势**（`poseHandlesEnabled`）：视口拖绿色手脚(IK)/蓝球调头躯干，自动记录到播放头关键帧。
- **姿势保存**：右栏可把当前骨骼姿态存为自定义姿势（`saveCustomPose`），存进 `customPosePresets`，之后可复用/应用。

# 手K动画模块 · PRD（第 1 层全局骨架）

> 本 PRD 与上方「契约/数据流/功能」同源同文（同一份移植工程）。上文是**实现原理学习**，本节是**移植需求级契约基线**（写码3步法 State1 的锚）。后续第 2 层模块细化将追加到本节。

## P0 · 项目定位

- **做什么**：为 3D 导演台（`src/components/director3d/`）新增**关键帧手K动画系统**：时间轴/播放头、关键帧轨道（位移/旋转/姿态/相机参数）、线性插值播放引擎、8 种运镜预设生成、角色匀速路径、IK 视口摆姿势、自定义姿势保存与复用、动画视频导出（MP4/WebM）。
- **给谁用**：分镜/预演创作者——用画布式交互做角色动作与镜头运动的预演动画。
- **核心价值**：把「摆姿势 → 拍机位 → 出预演」从**静态分镜**升级为**可播放、可导出的动态预演**；与现有角色骨骼（mannequin）和机位系统（DirectorCameraShot）无缝衔接，零 3D 软件门槛。
- **边界（本次不做）**：模型库/素材；改动既有角色/相机/截图的**既有逻辑**；1:1 复刻外部便携版（只移植实现思路）。

## P1 · 模块拆解（5 个，互不重叠）

| 编号 | 模块 | 一句话职责 |
|---|---|---|
| M1 | 数据层（schema+store） | 定义 timeline/customPosePresets 类型与动画全部 state/actions，状态唯一真相 |
| M2 | 插值引擎（纯函数） | f1/_w/BF/N0/Il/Cy/mC/f0/h0/jF/VF，纯计算、无副作用、可单测 |
| M3 | 播放与视口驱动（runtime） | useFrame 推进 currentTime；对象/相机按时间插值驱动；视口拖动写回关键帧 |
| M4 | 动画面板 UI | 右栏动画编辑面板（轨道/关键帧/运镜/路径）+ 底部时间轴条 + 工具栏入口 |
| M5 | 视频导出 | captureStream+MediaRecorder 逐帧录制，MP4(H.264) 优先、WebM 回退 |

**依赖链（单向无环）**：M1 → M2 → M3 → { M4, M5 }
**重叠检查**：M1 存 / M2 算 / M3 驱动 / M4 交互 / M5 录制，职责边界清晰，无重叠。

## P2 · 翻车点（3 个）

1. **播放循环性能与时序**：useFrame 每帧对带轨道对象插值，无差别计算会卡；currentTime 推进与插值读取存在同帧竞态 → 抖动/跳帧。→ 只算带轨对象 + currentTime 单一 store 源。
2. **时间容差不一致**：打帧/改帧/拖动写回的时间对齐容差若不统一，会出现重复帧或覆盖错乱。→ 统一「时间对齐」容差常量。
3. **动画态与普通态冲突**：`animationModuleOpen` 打开后右栏/拖动/相机语义改变，未隔离会回归（拖不动物体/误改 transform/截图失效）。→ 显式分支隔离。

## P3 · 约束清单

**模块级约束：**

| 模块 | 核心约束 |
|---|---|
| M1 | 关键帧结构支持"各维度可选"（位移/姿态/相机参数子集）；读写走既有 `commitMutation/commitUiMutation` |
| M2 | 全部纯函数、无副作用、脱离 React 可单测；easing 支持 linear/hold/ease；插值签名统一 `(base, keyframes, t, field)` |
| M3 | 播放只对"带轨道对象"计算；currentTime 单一来源；动画态与普通态显式分支隔离 |
| M4 | 复用既有面板组件风格；4 个 tab + 底部时间轴条；不重复造轮子 |
| M5 | captureStream+MediaRecorder，MP4 优先 WebM 回退；导出进度可感知 |

**跨模块约束：**
- **C1 时间单源**：currentTime 只在 store，插值/播放/UI/导出全读它，杜绝分叉。
- **C2 状态单源**：所有动画状态（轨道/播放头/开关/IK）只进 store，组件零私有动画 state。
- **C3 最小集成**：不改既有角色/相机/截图逻辑，新增模块独立，符合外部目录边界。
- **C4 可测试**：插值引擎与数据层纯函数必须可单测（vitest 体系）。

**约束支撑关系**：M2 纯函数 → C1/C4；M1 状态单源 → C2；M3 隔离分支 → C3；M4/M5 消费单源 → C1/C2。

## M2 插值引擎（纯函数层）

### M2 边界对齐
`f1/_w/BF/N0/Il/Cy/mC/f0/h0/jF/VF` 纯计算函数，输入 keyframes+time → 输出插值结果/新轨道，无副作用、无 React 依赖。✅ 支撑 C1（时间作为入参）/C4（纯函数可单测）。

### M2 子结构
- **M2.1 向量/标量插值**：`f1`(position/rotation/target 三维)、`_w`(fov/near/far 标量)、`Wp`(lerp)、`BF`(骨骼 controls 逐 key lerp)。
- **M2.2 姿势插值**：`N0`(rig, kfs, t, customPoses) → 解析 posePresetId/controls，ease 混合、hold 取前帧。
- **M2.3 对象/相机插值封装**：`Il`(transform+朝向mC)、`Cy`(target)。
- **M2.4 写轨纯函数**：`f0`(追加/替换+排序+扩 duration)、`h0`(播放头覆盖/插入姿态帧)。
- **M2.5 生成类**：`jF`(8 种运镜)、`vC`(orbit 环绕多点)、`VF`(角色匀速路径)。

### M2 翻车点
1. **easing 计算顺序**：`tRatio` 先算区间比例再 smoothstep，写反会非平滑。
2. **除零**：`c[d+1]-c[d] || 1` 区间长度为 0 时必须兜底，否则 NaN。
3. **姿态 controls 的 key 集不一致**：两帧 controls 的 key 不同，`BF` 需并集补 0，否则丢骨骼。

### M2 详细约束 + 验证标准
| # | 约束 | 验证标准 | 支撑 |
|---|---|---|---|
| M2-1 | 插值签名统一 `(base, keyframes, t, field)`；边界 t≤首帧取首帧、t≥末帧取末帧 | 单测：t=0/末尾/区间中/越界四类 | C1/C4 |
| M2-2 | easing 三态：hold=前帧值，ease=smoothstep `t²(3-2t)`，linear=原比例；区间长 0 兜底 | 单测：三态输出；0 长区间不 NaN | C4 |
| M2-3 | `N0` 姿势：controls 优先于 posePresetId；`BF` 并集补 0 混合 | 单测：混两 pose 中间帧各 key 在两者值之间 | C4 |
| M2-4 | `f0/h0` 纯函数不触 store；`h0` 用 TIME_EPSILON 覆盖同帧 | 单测：f0 返回新对象不改入参；h0 同帧覆盖 | C2 |
| M2-5 | `jF` 8 种运镜 + orbit 多点 + `VF` 路径，输出 keyframe 数组含 position/target | 单测：每种预设生成 ≥2 帧、time 递增 | C4 |

## M3 播放与视口驱动（runtime）

### M3 边界对齐
用 useFrame 推进 currentTime；对象/相机渲染按时间插值驱动；视口拖动写回关键帧。✅ 支撑 C1（读 store currentTime）/C3（动画态与普通态分支隔离）。

### M3 子结构
- **M3.1 播放循环**：`PlayheadDriver` 组件 useFrame `currentTime += delta`，到 duration 自动 pause。
- **M3.2 对象渲染驱动**：ObjectSceneNode 里 `Il(transform, tracks, t)` 驱动 position/rotation、`N0(rig, tracks, t)` 驱动骨骼。
- **M3.3 相机视图驱动**：相机视角下 `Il/Cy/gC/FF/UF` 按时间驱动 position/lookAt/fov/near/far。
- **M3.4 拖动写回**：对象拖动结束，动画态→`upsertTransformKeyframeAtPlayhead`，普通态→既有 transform 逻辑。

### M3 翻车点
1. **useFrame 全场景计算**：只对"该对象有轨道"才算插值，否则用原 transform，避免每帧全量算。
2. **同帧竞态**：currentTime 只从 store 读、由 PlayheadDriver 唯一推进，禁止组件私有时间。
3. **动画态与普通态拖动冲突**：用 `animationModuleOpen` 显式分支，普通态路径完全保留。

### M3 详细约束 + 验证标准
| # | 约束 | 验证标准 | 支撑 |
|---|---|---|---|
| M3-1 | 播放只对"带轨道对象"插值；无轨道对象保持原 transform | 审阅/冒烟：无轨道时渲染不变 | C1/C3 |
| M3-2 | currentTime 唯一由 PlayheadDriver 经 store 推进；到 duration 自动 pause | 单测/冒烟：播放到末尾 isPlaying=false | C1 |
| M3-3 | 动画态拖动→写关键帧，普通态→改 transform，显式分支 | 冒烟：开/关动画模块拖动语义不同且均不崩 | C3 |
| M3-4 | 相机视角下 R5 式按时间驱动相机参数；导演视角不受影响 | 冒烟：相机视角播放时画面随帧变化 | C1 |
| M3-5 | 不新增组件私有动画 state | 审阅：动画相关仅读 store | C2 |

# 第 2 层 · 深挖补充细节（二次扫描新增，2026-08-23）

> 对 `deobfuscated.js` 二次深挖（顶栏/视图联动/关键帧精修表单/工程序列化/路径运镜参数）后补充的契约与交互细节。这些在首次 PRD 中缺失，移植时**必须**纳入。

## S1 · 动画模式是「顶栏第三档 viewMode」（不是纯布尔）

- 顶栏三档切换：**导演视角 / 机位视角 / 动画**。动画是独立 `viewMode === "animation"`。
- `viewMode` 与 `animationModuleOpen` **强绑定**：
  - `setViewMode("animation")` → `animationModuleOpen = true`，且 timeline 缺失时初始化 `Cl()`。
  - `setViewMode("director"/"camera")` → `animationModuleOpen = false`。
  - `toggleAnimationModule` → 同步翻转 viewMode（开→"animation"，关→"director"）。
- 进入动画模式时若 `project.timeline` 不存在 → 自动 `?? Cl()`（duration:5/fps:30/tracks:{}）。

## S2 · 动画视角模式（animationViewportMode）

- 动画模式下视口渲染视角由 `animationViewportMode`（"director"|"camera"）决定，而非 viewMode 本身：
  `O = viewMode === "animation" ? animationViewportMode : viewMode`
- `setAnimationViewportMode("camera")` → 自动把 `activeCameraId` 设为当前或第一台相机。
- `O === "director"` → OrbitControls（可自由漫游）；`O === "camera"` → 相机视角（按时间轴驱动，播放中禁用 OrbitControls 拖动 `enabled={!isPlaying}`）。

## S3 · 关键帧精修表单（选中帧后编辑，补 M4 契约）

选中某帧后显示 `kf-editor`：
- **通用**：时间(s)、引出段插值（linear/hold/ease）。
- **角色/物体帧**：位置 XYZ、旋转 XYZ（弧度）。
- **相机帧**：位置 XYZ、看向 XYZ、视野 FOV°(5-160)、近裁剪、远裁剪；按钮「看向原点」「匹配当前机位」（用当前机位配置覆盖本帧）。
- **角色帧**：姿态预设（本帧，可设 null）。

## S4 · 自定义姿势随工程序列化（补 M1 契约）

- `project.customPosePresets` **随工程导出/导入 JSON 一起持久化**（`saveCustomPose` 存进 project，导出 JSON 包含它）。
- 「清空场景」只保留角色01 + **保留 customPosePresets**。
- `applyCustomPose`/`applyCrowdCustomPose` 与内置 `applyPosePreset` 同语义（含关键帧感知：有姿态关键帧则同步写帧）。

## S5 · 路径生成（VF）只产 2 帧

- `VF(start, end, startTime, duration, poseId, easing)` → **仅首尾两帧**（各带朝向角 `rotation.y = atan2(dx, dz)`），靠播放插值自动补间。
- UI 参数：起点 XYZ（留空=角色当前坐标）、终点 XYZ（含 Y 高度）、起点时间、时长、行走姿态、插值、生成模式（append/replace）。

## S6 · 运镜参数（补 M4 契约）

- 8 预设 + 参数：起点(s)、时长(s)、幅度、角度(°)、手持种子(handheld)。
- `orbit` 特殊：`角度`=总环绕度数（90/180/270/360），`vC` 按度数分 `max(2, round(|deg|/15))` 点采样生成多点关键帧。
- 其他预设：`dollyIn/Out`(沿视线推拉)、`truck`(横向)、`crane`(升降)、`pedestal`(俯仰 target 升降)、`pan`(视角转动)、`handheld`(手持抖动) → 多为 2 帧（起点/终点）。

## S7 · 姿势保存入口（补 M4 契约）

- 右栏（动画 & 角色面板）均有「保存为自定义姿势」：输入名称 + 当前 `characterRig.controls` 快照 → `saveCustomPose(name, controls)`。
- 骨骼分组展示（`UU`：头/手/脚等），每骨骼滑块有 min/max 范围（`hd`）。

## S8 · 动画模块快捷键

- **G**：切换视口 transform gizmo（输入框/textarea 忽略）——动画模式下常用。
- Ctrl/Cmd+C / V / Z：复制/粘贴/撤销（全局，动画态同样生效）。

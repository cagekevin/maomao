# 专业 3D 软件关键帧与对象管理标准 · 学习笔记 + director3d 对照

> 日期：2026-08-23
> 目的：了解 C4D / Blender / Maya 等专业 3D 软件最基础的**关键帧（K帧）** 与 **对象管理** 交互标准，
> 作为 director3d 动画模块改造（C4D 式每轴打帧、曲线编辑、Auto Key、路径并入关键帧）的设计依据。
> 参考资料：Maxon C4D 官方文档、Blender 官方手册、C4D 核心基础笔记、Blender 关键帧教程等。

## 一、打关键帧（Keyframing）的三种方式

| 方式 | 操作 | 说明 |
|---|---|---|
| **① 属性触点（小圈）** | 点击参数旁的小圆圈 | 空心=当前时间**无关键帧**；实心红/黄=当前时间**已有关键帧**；黄=数值改了但未记录。点击即在当前播放头记录/更新该属性关键帧 |
| **② 快捷键 F9 / I** | 选中对象按 `F9`(C4D) / `I`(Blender) | 一次性记录当前对象的 **PSR**：位置(Position)、缩放(Scale)、旋转(Rotation) |
| **③ 自动关键帧 Auto Key** | 点击时间轴红色 `●` 录制按钮 | 开启后，**修改任何参数/变换对象都会自动在当前时间记录关键帧**，无需手动点。**用完务必关闭**，否则产生大量多余关键帧 |

> 核心：**几乎任何参数（位置/旋转/缩放/颜色/开关）都能打关键帧**，本质是「当前时间 + 当前值 → 存为关键帧」。

## 二、时间线 / 时间轴（Timeline）

- **轨道（Track）**：每个对象的一个属性（位置/旋转/缩放…）一条轨道；每个轨道含**任意数量关键帧（Key）**。
- **关键帧**：拖动可改出现时间，可缩放改动画时长；最少两个关键帧即可产生一段动画，中间自动插值。
- **播放头（蓝色竖线）**：点击/拖动定位；`←`/`→` 单帧移动；空格播放/暂停。
- **模式切换（C4D 按 Tab）**：
  - **Dope Sheet（动画表）**：以表格/条状形式总览所有对象的关键帧，可批量移动/缩放/删除。
  - **F-Curve（函数曲线）**：以曲线形式精细编辑插值，控制运动节奏。
  - **Motion**：运动编辑。
- **迷你函数曲线**：轨道关键帧下方可展开，做有限编辑。

## 三、曲线编辑器 / 插值类型（Graph Editor）

- **作用**：自然界物体很少瞬间加速/停止，曲线编辑是让动画自然的关键。
- **三种基本插值类型**：
  1. **线性 Linear**：匀速，直线，机械感，适合传送带/循环。
  2. **缓入缓出 Spline / Easy Ease**：S 形曲线，「慢→快→慢」，最自然，符合现实物理。
  3. **台阶 Step**：瞬间跳变，阶梯状，适合定格/开关。
- **手柄（Handle）**：拖曲线控制点的手柄，精细调加速/减速时间点。

## 四、对象管理（场景树 Outliner）与动画联动

- **Outliner** 列出场景所有对象，可选中/隐藏/锁定/删除。
- **选中对象 → 联动动画编辑器**：在 Dope Sheet / Graph Editor / 属性面板中查看、编辑该对象的动画数据。
- **父子/集合**：父对象动画可传递给子对象；集合可统一管理多个对象的动画。
- **空物体/控制器**：作为动画控制手柄，通过约束驱动其他对象。

## 五、专业软件的"移动/路径"做法

- **没有"填表单生成路径"**。从 A 走到 B 就是：
  1. 播放头到起点时间 → 记录起点关键帧
  2. 播放头到终点时间 → 移动对象到终点 → 记录终点关键帧
  3. 播放时自动插值走位
- 这正是 **Auto Key + 手动打帧** 的自然结果，路径 = 两帧的位移。

# 对照 director3d 现状与差距

## 现状（已有）
| 功能 | 现状 |
|---|---|
| 播放/暂停/跳头尾/时间输入 | ✅ 底部时间轴条 |
| 多轨时间轴 | ✅ 每个对象/相机一行，拖关键帧/选中/删除/清轨道 |
| 关键帧插值（linear/hold/ease） | ✅ 纯函数已实现 |
| 关键帧精修（位置/旋转/FOV等） | ✅ 关键帧 tab 内 |
| 运镜预设（8种） | ✅ 运镜 tab |
| 视口拖动写关键帧（动画态） | ✅ 类似 Auto Key 的效果 |
| 走路循环动画 | ✅ 走路开关 |

## 差距（待按专业标准改造）

### 1. 打帧交互 —— 未到 C4D 标准
- ❌ **没有"属性触点"（每轴/每属性独立小圈）**：现在位置 XYZ 是**一个整体**打帧点，不是 C4D 式 **X/Y/Z 每轴独立一个点**（灰=无帧、亮=有帧、点击记录该轴）。
- ❌ **没有 Auto Key 开关按钮**：现在动画态拖动会自动写帧，但没有"自动关键帧"总开关（开启才自动，关闭则需手动打帧）。
- ❌ **没有 F9/I 快捷键**：一键记录选中对象 PSR。

### 2. 曲线编辑器 —— 缺失
- ❌ **没有 F-Curve / Graph Editor**：无法看到/调整插值曲线，无法拖手柄控制运动节奏（缓入缓出）。
- ❌ **插值类型切换不够直观**：现在精修里能改 linear/hold/ease，但没有曲线可视化。

### 3. 对象管理与动画 —— 脱节
- ❌ **场景树选中对象与动画模块联动不完整**：用户反映"左边就有一个对象，但动画跟他产生不了关系"。
  - 问题：场景树选中对象后，动画面板/时间轴应该自动定位到该对象的轨道；不同类型（角色/机位/模型/几何体）的轨道 key 映射（对象 id vs 相机 linkedCameraId）需要统一。
  - 目标：**在场景树点对象 → 时间轴高亮该对象轨道、动画面板打帧作用于该对象**，与 Blender Outliner 一致。

### 4. 路径 —— 应并入关键帧
- ❌ **路径 tab 是"填表单生成"**，不符合专业软件"记录起点帧+终点帧"的做法。
- 目标：删掉路径 tab 的表单，"从 A 走到 B" 直接用 K 帧（起点播放头打帧 + 移动对象打终点帧）。可以并入关键帧 tab 并加操作引导。

### 5. 每轴独立打帧 —— 数据模型需支持
- 现状 `DirectorKeyframe.position` 是整体 `[x,y,z]`。C4D 式每轴打帧需要：点击某轴 → 当前帧该轴记录，其他轴保留/取当前对象值。需在打帧时做"按轴合并"。

### 6. 摄像机模式 —— 与对象树 / 动画脱节
- **进入方式**：专业 3D 软件（Blender `Num0` 从摄像机视图 / C4D 摄像机）是**在对象树选中摄像机 → 进入该摄像机视角**；现在机位视角是顶栏/工具栏切换（`animationViewportMode`），跟"对象树里点摄像机"没打通。
- **期望**：对象树里点摄像机图标 → 进入该摄像机视角模式；从摄像机视角里能看到/操作/打关键帧。
- **机位视角与动画脱节**：
  - 相机视角（`animationViewportMode === "camera"`）按时间轴驱动相机（`cameraAnims` 已实现），但**操作（移动/旋转相机）跟动画打帧没有直接联动**（视口拖相机写帧只有动画态有效，且与"导演视角"语义不统一）。
  - 相机关键帧（`captureViewportToCameraKeyframe`）需"相机视角 + activeCamera"才可用，入口不够直接。
- **目标**：对象树选中摄像机即进入其视角；相机视角下操作相机 = 打该机位的动画关键帧（Auto Key），与 Blender 摄像机动画一致。

### 7. 摄像机打帧 + 目标约束（C4D Target）设计
> 用户确认：摄像机可打帧参数 = **位置 XYZ、注视 XYZ（手动模式）、FOV**；**近远裁剪不打帧**。
> 注视点采用 **C4D 目标约束**：要么跟随目标对象，要么手动可打帧。

**可打帧参数与触点**：
| 参数 | 数据 | 打帧触点 | 说明 |
|---|---|---|---|
| 位置 X / Y / Z | `transform.position` | 3 触点（每轴独立） | 始终可打帧 |
| 注视点 X / Y / Z | `target` | 3 触点（每轴独立） | **仅手动模式**可打帧 |
| FOV | `fov` | 1 触点 | 始终可打帧 |
| 近裁剪 / 远裁剪 | `near`/`far` | ❌ 不打帧 | 排除 |

**目标约束（C4D Target）**：
- 一个"注视目标"开关（复选框）：
  - **开**：选择目标对象（画面中的人）→ 相机自动看向并**跟随该目标**（注视点被对象绑定，XYZ 不可打帧）
  - **关**：注视点 XYZ 为手动坐标，可自己打关键帧
- 现状已有基础：`DirectorCameraShot.targetMode`（"manual"|"object"）+ `targetObjectId` + `CameraPanel` 的"注视目标"下拉。需补**实时跟随**（目标对象移动 → 相机注视点跟随）。

**打帧触点交互（C4D 式）**：
- 触点状态：**灰**（当前播放头该参数无关键帧）→ **亮**（有）
- 点击触点 → 在 `currentTime` 给该参数记录关键帧（track 用 camera.id）
- 打帧走 `setKeyframeGroupAtPlayhead(cameraId, { position/target/fov })`

### 8. 视图模式简化 + 曲线编辑器弹窗（用户最终方案）
- **去掉顶栏 3 个视图按钮**（导演视角/机位视角/动画），默认就是动画模式，不需要 3 个视图切换。
- **移动/旋转/缩放工具栏一直出现**（不随模式隐藏）。
- **摄像机模式**：左侧对象栏（场景树）点摄像机的按钮 → 进入该摄像机视口；再点退出（C4D 式）。
- **曲线编辑器用弹窗**：右键对象 → 弹出窗口（选对象 → 编辑曲线弹窗）。
- **摄像机参数全部挪到关键帧**（见 §7 打帧触点 + 目标约束）。

### 9. 布局统一：属性面板全部并入动画面板（用户最终方案）
> 动画模块本来就是主模块、默认存在。普通属性面板（角色/摄像机/场景/道具）**全部合并进动画面板**，不再单独切换。

**新布局**：
| 区域 | 内容 |
|---|---|
| 顶栏 | 去掉 3 个视图按钮；保留标题 + 截图/返回 |
| 左栏 | 对象树（场景树）——点摄像机按钮进入其视口 |
| 右栏 | **唯一动画面板**（动画编辑 + 属性编辑合一） |
| 底部 | 时间轴条（transport + 多轨时间轴） |
| 视口 | 默认漫游；点左栏摄像机按钮进入该摄像机视口 |

**动画面板需整合的普通属性面板**（原 RightPanel 分支）：
- `ScenePanel`（场景属性：背景色/网格/地面等）
- `CharacterPanel`（角色：位置/旋转/缩放/颜色 + 姿势）
- `PropPanel`（道具/几何体属性）
- `CameraPanel`（摄像机参数 + 打帧触点 + 目标约束）
- 统一进入方式：动画面板内按选中对象类型显示对应属性编辑（角色→角色属性、摄像机→摄像机打帧等）

**关键改动**：
- `RightPanel` 不再按 `animationModuleOpen` 切面板，动画面板成为常驻主面板。
- `animationModuleOpen` 概念简化（动画模块默认常开）。
- 属性面板组件（Scene/Character/Prop/Camera）迁入动画面板内部，按选中对象动态展示。

## 改造优先级（建议）
1. **布局统一**：动画面板作为唯一右栏面板，整合属性面板（Scene/Character/Prop/Camera）
2. **视图模式简化**：去掉顶栏 3 档，动画模块默认常驻，移动/旋转工具栏常显
3. **对象管理与动画打通**：场景树选中对象 → 动画面板/时间轴联动
4. **摄像机模式打通**：对象树点摄像机进入其视口，机位视角与动画打帧联动
5. **C4D 式每轴打帧触点** + **摄像机打帧触点 + 目标约束**
6. **Auto Key 自动关键帧开关** + **F9 一键 PSR**
7. **路径并入关键帧**（删路径 tab 表单，引导用 K 帧）
8. **曲线编辑器弹窗**（右键对象 → 编辑曲线，最复杂）

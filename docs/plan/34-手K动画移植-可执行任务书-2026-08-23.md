## 一、任务目标与边界

**目标**：为 `src/components/director3d/` 新增关键帧手K动画系统，能力清单：
1. 时间轴/播放头（currentTime + isPlaying + duration/fps）
2. 关键帧轨道（对象位移/旋转/姿态、相机位置/看向/FOV/裁剪）
3. 插值播放引擎（linear/hold/ease，姿势骨骼混合）
4. 运镜预设生成（8 种）+ 角色匀速路径
5. IK 视口摆姿势 + 自定义姿势保存复用
6. 动画视频导出（MP4/WebM）
7. 动画模式（顶栏第三档，viewMode="animation"）
8. 角色「自动朝向运动方向」（`faceMovement`，M1 需给对象加该字段）

**边界（不做，审计后明确排除）**：
- 模型库/素材。
- 不改既有角色/相机/截图**既有逻辑**（新增分支可以）。
- **group 对象动画**：外部版有群组，但我们项目 director3d **不支持 group 对象类型**，故 group 动画不移植。
- **演示场景（loadDemoScene）**：非核心，可降级不做。
- 不 1:1 复刻外部代码（按本仓库习惯移植实现思路）。

**硬性约束**：
- `director3d/` 是外部集成目录（CLAUDE.md：不做主动重构、只做最小集成）→ **新增模块独立，改动既有文件只做"加分支"，不重构**。
- 状态走既有 `commitMutation/commitUiMutation`（`directorStore.ts`）。
- 纯函数（插值/写轨）放独立文件，可单测。

### M1.1 新增类型（`directorProject.ts`）

```ts
export type KeyframeEasing = "linear" | "hold" | "ease";

export interface DirectorKeyframe {
  id: string;
  time: number;
  // 各维度可选：位移/姿态/相机参数子集，缺啥就不覆盖该维度
  position?: [number, number, number];
  rotation?: [number, number, number];
  target?: [number, number, number];
  fov?: number;
  near?: number;
  far?: number;
  posePresetId?: string | null;
  controls?: Record<string, number>;
  easing?: KeyframeEasing;
}

export interface DirectorTimeline {
  duration: number;   // 默认 5
  fps: number;        // 默认 30
  tracks: Record<string, DirectorKeyframe[]>; // key=对象id 或 相机id
}

export interface CustomPosePreset {
  id: string;
  name: string;
  controls: Record<string, number>;
}
```

在 `DirectorProject` 接口加：
```ts
timeline: DirectorTimeline;
customPosePresets: CustomPosePreset[];
```

### M1.2 store 新增 state + 默认值

新增 state：`currentTime`(0)、`isPlaying`(false)、`animationModuleOpen`(false)、`animationViewportMode`("director"|"camera" → "director")、`poseHandlesEnabled`(false)、`pathDraft`(null)。
默认值放 `createDefaultDirectorProject` 里：`timeline: { duration: 5, fps: 30, tracks: {} }`、`customPosePresets: []`。
注意：**老工程加载时 timeline 可能缺失**，所有读写 timeline 前 `?? createDefaultTimeline()`（写个工厂函数）。

### M1.3 新增 actions（`directorStore.ts`）

| action | 签名 | 作用 |
|---|---|---|
| `setCurrentTime` | `(t:number)` | 夹到 [0,duration] |

| `updateKeyframe` | `(trackId, kfId, patch)` | 改单帧 |

| `saveCustomPose/deleteCustomPose/applyCustomPose` | — | 自定义姿势 |

| `setPoseHandlesEnabled/setPathDraft/toggleAnimationModule` | — | UI 开关 |

**关键语义**（从外部实现的还原，参考 `docs/33 §一/二`）：
- 关键帧写轨统一走纯函数 `f0/h0`（见 M2）。
- `addKeyframeForSelection`：
  - 相机对象 → `{ id, time: currentTime, position, target }`
  - 角色对象 → `{ id, time, position, rotation, posePresetId, controls, easing }`
  - 追加后 `duration = max(duration, 最新帧time) + 0.001`。
- `applyPosePreset`/`applyCustomPose` **补"关键帧感知"**：动画态下若该角色已有姿态关键帧（`track.some(k=>k.posePresetId!=null)`），用 `h0` 把当前播放头也写帧。普通态行为保持原样（C3）。

## 四、M2 插值纯函数（独立文件）

**新建**：`src/components/director3d/editor/runtime/timelineInterpolation.ts`

必须实现的纯函数（签名 + 语义），全部无副作用、可单测：

| 函数 | 签名 | 语义 |
|---|---|---|
| `lerpVec` | `(a,b,t):[n,n,n]` | 三维 lerp |
| `interpolateVec` | `(base, kfs, t, field:"position"\|"rotation"\|"target")` | 边界取首/末帧；区间内按 easing：hold=前帧值，ease=smoothstep `t²(3-2t)`，linear=原比例；区间长 0 兜底 |
| `interpolateScalar` | `(base, kfs, t, field:"fov"\|"near"\|"far")` | 同上但标量 |
| `blendControls` | `(a, b, t)` | 骨骼 controls 逐 key lerp（并集补 0） |
| `interpolatePose` | `(rig, kfs, t, customPoses)` | 姿势插值：只取有 posePresetId/controls 的帧；controls 优先；ease 用 blendControls 混合 |
| `applyTransformAt` | `(transform, kfs, t, isFace)` | 封装 position/rotation 插值 + 可选朝向角 |
| `interpolateTarget` | `(target, kfs, t)` | 相机看向插值 |
| `facingYaw` | `(kfs, t)` | XZ 平面朝向角 atan2(dx,dz) |
| `appendKeyframes` | `(timeline, trackId, kfs, mode:"append"\|"replace")` | 写轨+排序+扩 duration（对应 f0） |
| `upsertPoseKeyframe` | `(timeline, trackId, obj, time, poseId, controls)` | 播放头覆盖/插入姿态帧（对应 h0） |

**测试**：`tests/unit/director3dTimeline.test.ts`，覆盖：边界/区间中/越界三态；easing 三态；0 长区间不 NaN；姿势混合在两者值之间；f0 返回新对象不改入参；h0 同帧覆盖。

## 五、M3 播放与视口驱动

**对接文件**：
- `src/components/director3d/editor/canvas/DirectorCanvas.tsx`（视口主组件，接播放循环）
- `src/components/director3d/editor/canvas/SceneRoot.tsx`（对象渲染，`ObjectSceneNode`，约 446 行）
- `src/components/director3d/editor/runtime/CharacterModel.tsx`（角色骨骼驱动）

### M3.1 播放循环
新建组件（放 DirectorCanvas 内或独立）用 R3F `useFrame((_, delta) => {...})`：
- 读 store `isPlaying`；false → return。
- `currentTime += delta`；`>= duration` → `setCurrentTime(duration)` + `pause()`。
- 只推进 currentTime，不做其它（currentTime 是 store 单一来源）。

### M3.2 对象渲染驱动（SceneRoot.tsx 的 ObjectSceneNode）
对**每个对象**读其轨道，若存在则：
```ts
const track = timeline?.tracks?.[id];
const animatedTransform = track?.length ? applyTransformAt(object.transform, track, currentTime, isCharacterFace) : object.transform;
```
渲染 group 的 position/rotation 用 `animatedTransform`。无轨道对象直接用原 transform（C3，普通态零影响）。
角色姿势：`const rig = track?.length ? interpolatePose(characterRig, track, currentTime, customPosePresets) : characterRig;` 传给 `CharacterModel`。

### M3.3 相机视图驱动
动画模式 + `animationViewportMode === "camera"` 时，用 `useFrame` 每帧：
`camera.position/lookAt/fov/near/far` 由 `applyTransformAt`/`interpolateTarget`/`interpolateScalar` 按 currentTime 驱动相机对象。

### M3.4 视口拖动写回
`ObjectSceneNode` 的对象拖动结束回调里：
- `animationModuleOpen` 时 → `upsertTransformKeyframeAtPlayhead(id, transform)`（动画态写帧）。
- 否则 → 走既有 `updateObjectTransform`（普通态，原样保留）。

**验证**：`npm run dev` 打开导演台 → 顶栏切"动画" → 选中角色 → 拖到某时间打帧 → 播放 → 物体按帧动；开关动画模式拖动语义不同且不崩。

## 十、最终审计补充（翻车点细化 + 遗漏功能，2026-08-23 全量扫 713 条中文文案后）

> 对 `deobfuscated.js` 全量中文文案扫描 + 与本仓库 director3d 现状核对后的补充。**实现时必须纳入。**

### A · 必做补充（原任务书漏了，不做会功能缺失/崩）

**A1：`DirectorObject` 加 `faceMovement` 字段（角色自动朝向运动方向）**
- 外部版角色有 `faceMovement: boolean`，为 true 时播放中角色**自动转向运动方向**（`mC` 用 XZ 平面两帧位置差算 `atan2` 朝向角，覆写到 rotation.y）。
- 我们项目 `directorProject.ts` 的 `DirectorObject` **没有此字段** → 需新增 `faceMovement?: boolean`（默认 false）。
- 配套：`applyTransformAt(transform, kfs, t, isFace)` 的第 4 参 `isFace` 即来自 `object.faceMovement === true`。
- 动画面板姿势区加「自动朝向运动方向」开关（对应文案「关闭则保留手动设定的朝向」）。

**A2：非 humanoid 骨骼降级（防导入 FBX 后崩）**
- 外部版对**未识别到 humanoid 骨骼**的模型（如导入的 FBX）会禁用姿势编辑并提示「该模型未识别到标准 humanoid 骨骼」「暂不支持姿势编辑」。
- 我们项目 `CharacterModel` 已有 rig 类型判断（mannequin/ue4-mannequin），**在姿势面板/打帧前校验 rigType**，非 humanoid 只允许位移/旋转 K 帧、禁用姿态 K 帧与姿势滑块，避免对无骨骼对象写 `controls` 崩。

### B · 明确排除项（避免白做）

- **group 对象动画**：外部版支持群组 K 帧，但我们项目 director3d **无 group 对象类型** → 不做。若未来加 group 再补。
- **演示场景（loadDemoScene）**：外部版"加载演示场景"直接进动画模式，非核心 → 降级不做。
- **视口坐标切换（世界/本地）**：外部版有「视口原生坐标控件」，非动画专属、且我们项目坐标体系不同 → 不做。

### C · 翻车点细化（比 §1 更具体）

| # | 翻车点 | 规避 |
|---|---|---|
| C1 | `faceMovement` 未加 → 角色移动不自动转向，且 `applyTransformAt` 的 isFace 分支永 false | 照 A1 补字段 |
| C2 | 对无骨骼模型（导入 FBX）打姿态帧 → `controls` 写入崩 | 照 A2 校验 rigType |
| C3 | 老工程无 timeline → 进动画模式崩 | 进动画模式时 `?? createDefaultTimeline()`（M1 已含） |
| C4 | `applyPosePreset` 改姿势但不写帧 → 手K失效 | 关键帧感知分支（M1.3 已含） |
| C5 | 播放循环对全对象插值 → 卡 | M3 只对"带轨道对象"算 |
| C6 | 录制时用户手动拖 → 双驱动抖 | M5 录制期间接管播放 |

### D · 确认结论（对用户判断的回答）

全量扫描 713 条中文文案后确认：**外部版核心功能确实就是「手K（对角色/机位打关键帧）+ 运镜（相机关键帧/预设）+ 姿势保存」**，外加少量外围特性。没有其它独立的隐藏大模块。唯一值得补的是 **A1 faceMovement（角色自动朝向）** 和 **A2 非humanoid降级**，其余（group/演示场景/坐标切换）均明确排除。

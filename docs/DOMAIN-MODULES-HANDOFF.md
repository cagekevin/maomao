## 3 · 判据沉淀（本轮最值的方法产出，**接手者直接照用**）

```
L1 归属只看「界面位置 + 数据落点」              （ADR-0040）
L2 目录名/前缀/文档标签不作判据；引用前自证       （ADR-0001；本轮四次判错全因违此）
L3 真横切 = ≥3 域消费 + 零业务语义              （承 ADR-0039 N6）
L4 只被一域用的件，不许留横切
L5 同形态不拆（展开态/子部件/配套件跟主件走）
   —— FullscreenEditor 是 PromptInput 的展开态；ResourceStrip 是输入区的素材条
L6 跨域消费不改归属（走 A 的门面，不搬到 B）
L7 判据 1（界面位置）优先于「被 App 消费 ⇒ 横切」
M1 每条结构规则须可写成检查命令                  （ADR-0041）
M2 闸绿不算证据 → 负例探针证它真会红
M3 验收行禁止写「跑 X ✅」→ 须写判定命令 + 期望输出
```

**目标三词**：最正确（符合事实）· 最清晰（与界面一致）· 最简单（不发明，照产品与界面）。

## 5 · 🔴 硬坑清单（两轮合计，**接手必读**）

**第一轮遗留（仍有效）**

1. `rename-symbol` 不动 `vi.mock` 的对象键 ⇒ 改名后 mock 静默失效。每批改名后必查 `grep -rn "vi.mock.*<被改模块>" tests`。
2. `mv-sync-refs` 三处工具缺口（TD-17-22/23 未修）：`rename` 对 `.css` 丢扩展名；不改写无扩展名 import；**`move-dir` 不搬 CSS 且被搬文件的兄弟导入会写成指向旧目录的别名路径。
3. `check-arch` 规则 2 方向：`base/` 的件被业务域消费 = 正确单向。
4. 登记/计划里的数字与结论**不可照抄**（第一轮 6 处被推翻，其中 D7 照做 = 删掉素材库落盘调度（数据丢失级）。
5. N1 判据 = 撞名，不是"所有导出都加前缀"。
6. 闸分工：`pre-commit` = lint-staged + `test-affected.cjs`（**按源码→同名 stem 反查，会漏跨 stem 的测试）+ 3 个秒级 SSR 门禁；代码闸（tsc/arch/any…）**只在 pre-push** 跑一次。跨 stem 的 mock 测试要手工点名跑。

**本轮新踩（8 条，都是同类：**搬迁必改闸**）**

7. **`move-dir` 只搬源码、不搬 `.css`** ⇒ 残留随 `rm -rf` 被误删 ⇒ 用 `git show HEAD:<路径>` 恢复（27 行）。**move-dir 后必须手动补非源码文件**（css/json/data）。
8. **CSS 副作用 import 指向旧目录，`tsc` 查不出，只有 `vite build` 会炸** ⇒ 碰 CSS 的批次必跑 build。
9. **闸硬编码路径**（本轮四次）：
   - `check-arch.mjs` 的 `MEDIA_SSOT`（`skillStore` 是 Skill 白名单真源 TD-16-8）
   - `_smoke_checks.cjs` 的 nodeTypes 候选目录 + `canvas/NodePalette` · `canvas/lazyNode`
   - `scripts/dead-code-baseline.json` 的全量路径（本轮同步 11+ 处）
10. **测试硬编码目录** ⇒ `nodePrefsRegression.test.ts` 已**两次**因搬迁变红 ⇒ 改成 `NODE_DIRS` 多目录探测。**凡"测试自己写死目录"的写法一律改成多候选目录扫描。**
11. **`@public 跨边界消费者` 注释必须放进 JSDoc 块内**（插到 `*/` 外 ⇒ eslint 解析失败，commit 被钩子拦下）。
12. **本环境同一条命令会被执行两次** ⇒ 重复提交 / 「nothing to commit」是第二次运行的正常回显。提交后**必须 `git log` 核对 HEAD 内容。
13. **验证脚本自己也要先自检**（本会话验证脚本错 2 次：前缀漏配 / 扩展名漏配）。
14. **计数/清单断言须机器复算**，禁沿用旧数（本文件件数栽 3 次：563→564→491→504）。

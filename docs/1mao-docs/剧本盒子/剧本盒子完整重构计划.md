## 第3层：引擎重构（主线）

> 完整实现细节、行号、依赖参数化清单、端点契约 → 见 `docs/40`（§2 逐引擎 / §3 契约 / §4 文件拆分 / §5 决策 / §6 步骤 / §7 风险）。**本文只列执行清单与验收，不重复代码级细节。**

### 目标形态

```
src/bundle/httpClient-BknZwXjG_components/
├── scriptBox/
│   ├── scriptBoxPrompts.js   ← 纯模块：4类 system 模板 + Zg/Nr 拼装函数（零依赖，必抽）
│   ├── scriptBoxEngine.js    ← 顶部端点契约 + createScriptBoxEngine(deps) 返回 7 个生成回调
│   └── scriptBoxConnect.js   ← li/ui 连线的纯计算（di/ii 强耦合留 H_.jsx 薄封装）
└── H_.jsx                    ← 宿主：只 import + 注入（useRef 每次渲染重建引擎）
```

### 执行步骤（小步、每步可回退）

| 步 | 动作 | 风险 | 验证 |
|---|---|---|---|
| **Step 1** | 新建 `scriptBoxPrompts.js`：抽 `Ar` 编剧模板(L5204)、`Ir` 导演模板(L5843)、`Qg/Xg/Zg/Nr` 拼装为导出 | 🟢 纯搬移 | build + smoke + Chrome 跑通 3 步 |
| **Step 2** | 新建 `scriptBoxEngine.js`：`createScriptBoxEngine(deps)` 收口 `Ar/Pr/Fr/Ir/Mr/Nr/Un/oi/ai`（**不含 li/ui**）；`H_.jsx` 用 `useRef` 每次渲染重建，补传 `l/t/u/r/i/a` 与 `Mr/di/ii` | 🟡 依赖引用/漏传 | build + **contracts** + Chrome 全流程 + **切模型验证** |
| **Step 3** | `li/ui` 纯计算抽 `scriptBoxConnect.js`；`H_.jsx` 薄封装，保留 `di()` 注入 + ref 同步（机制 B） | 🟢 | build + contracts + 连线生图/视频验证 |
| **Step 4** | 沉淀 `docs/01`；删 `H_.jsx` 残余剧本盒子注释（用 `scripts/extract-range.cjs --delete` 按标记大段删，勿用 replace_in_file） | 🟢 | `npm run map` 复核符号索引无悬空 |

### 关键决策（来自 docs/40 §5，落地时遵守）

1. **`li/ui` 连线逻辑留 `H_.jsx`**：强依赖本地 `di`(建节点)/`ii`(视频上传)，只把纯计算抽 `scriptBoxConnect.js`。
2. **`H_.jsx` 用 `useRef` 每次渲染重建引擎**，不赌 `useMemo`（规避 stale closure / 依赖误判）。
3. **`Mr/di/ii` 是 `H_.jsx` 本地符号**（shared.js 同名是 `new Map()`），必须经 deps 参数化传入，**绝不** import shared.js。
4. **`H_.jsx` 宿主改动受「场景① 最小差异」约束**（diff ≤ 30 行/commit）：Step 2 拆成「先独立 commit 落 scriptBox 新文件」+「逐回调删除/薄封装」，每删 1 个 useCallback 单 commit。

### 验收（Step 完成后全过）

1. 三步 + 连线全通，与重构前行为一致。
2. `npm run test:smoke` / `npm run contracts` / `npm run build` / `npm run map` 全 PASS。
3. Chrome 切换文本/绘图模型后，新生成用上新模型（验证 useRef 重建生效）。
4. 视频上传重试(`oi`)/批量上传(`ai`)/停止(`Un`)/错误态回滚 loading 正常。
5. `c_.jsx` 零改动，`node.data` 回调完整。

### 风险与回退

| 风险 | 回退 |
|---|---|
| 独立文件反向 import 宿主 → 循环依赖 | **退路 B**：只 import shared.js 纯函数 + scriptBoxPrompts，`H_.jsx` 本地符号一律 deps 传入 |
| import graph 报错 / stale closure / contracts FAIL | **退路 C（原地重写）**：引擎留 H_.jsx 但顶部收口端点契约；`scriptBoxPrompts.js` 仍抽走（可维护性达 ~80%） |

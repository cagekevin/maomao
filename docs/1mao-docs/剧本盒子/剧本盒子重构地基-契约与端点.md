# 剧本盒子重构地基：契约 + 端点（接口定义书）

> **定位**：剧本盒子重构（第3层）开工前必须钉死的**地基**。分两半：
> - **内部契约**：`node.data` 字段、9 个回调端点、`createScriptBoxEngine(deps)` 签名 —— 重构拆分（`docs/40`）的接缝。
> - **外部端点**：剧本盒子调用的后端接口（代理/文本/图像/上传）的请求体与响应 —— 引擎请求的地基。
>
> **权威来源**：内部契约以 `docs/40` §3/§4 为准；外部端点以 `docs/33` §7.1 + `shared.js Bl/ci/si` + `H_.jsx Ar/Mr/Ir` 核实为准。**本文是执行地基，不重复重构步骤。**
> **地基铁律**：契约一旦钉死，重构过程中**不改接口、只改内部实现**；任何新增字段/回调先更新本文再动代码。

## 第一部分 · 内部契约

### A. `node.data` 字段契约（唯一数据源）

**读字段（组件读取、引擎可写回）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `step` | 1\|2\|3 | 当前步骤 |
| `story` | string | 用户剧情输入 |
| `globalStyle` | string | 全片统一风格 |
| `shots[]` | array | 分镜（字段见下） |
| `assets[]` | array | 资产（字段见下） |
| `projectName` | string | 生成的项目名 |

**shot 子字段**：`id,index,duration("Ns"),description(可含@资产),shotType,lighting,dialogue(双态: string|array, 读走at/写走ot),sound,motion,grid(0/4/9),prompt,videoPrompt,promptLoading,connImg,connVid`

**asset 子字段**：`id,category(character|scene|prop),name,description,prompt,imageUrl,thumbnailUrl,loading,videoStatus(uploading|failed|uploaded)`

**配置字段（设置弹窗读写）**：`aspectRatio,customAspectRatio,imageGlobalConstraint,videoGlobalConstraint,customGlobalConstraint,customScriptPrompt,customShotPrompt,customAssetTemplates{character,scene,prop},assetModelSettings{globalModel,globalAspectRatio,globalSize},shotCount(自动/10/20/30/50/自定义),customCount`

> ⚠️ 所有读写必须经 `setNodes(K)`/`updateNodeData(r)` 不可变更新写回（见 `剧本盒子职责划分.md`）。改字段→`{...data, shots:[...]}`；改配置→`{...data, key}`。

### B. 回调端点契约（挂到 `node.data` 的回调，9 个）

| # | data 字段 | 引擎 | 签名（调用方传入） | 触发点 |
|---|---|---|---|---|
| 1 | `onGenerateScript` | `Ar` | `(e, n)`：e=节点, n=触发者标识 | 步骤1 生成 |
| 2 | `onGenerateAssetImage` | `Pr` | `(e, n, a, o)`：a=资产, o=模型设置 | 步骤2 单资产 |
| 3 | `onGenerateAllAssetImages` | `Fr` | `(e)` | 步骤2 批量 |
| 4 | `onGenerateShotPrompts` | `Ir` | `(e)` | 步骤3 批量 |
| 5 | `onStopScriptItem` | `Un` | `(e, n)`：n=abortKey | 停止单项 |
| 6 | `onRetryVideoAssetUpload` | `oi` | `(e, a)`：a=资产 | 重试视频上传 |
| 7 | `onUploadAllVideoAssets` | `ai` | `(e)` | 批量上传视频 |
| 8 | `onConnectShot` | `li` | `(e, n, t)`：n=shot, t=类型 | 单镜连线 |
| 9 | `onConnectShots` | `ui` | `(e, n, t)` | 批量连线 |

**注入点**：节点创建（H_.jsx L8734）+ 运行时（H_.jsx L1149/L1170）`r.onXxx = Jn.current.onXxx`。

> ⚠️ 组件**只调** `d.onXxx?.(...)`，不 read 引擎内部；引擎写回只用 `K`（setNodes）。改回调签名=破坏契约，需三方同步（组件/引擎/注入）。

### C. `createScriptBoxEngine(deps)` 签名（重构拆分接缝）

```js
createScriptBoxEngine(deps) → 返回 9 个生成回调对象
deps 必须含（外部注入，引擎不自己造）：
  K          // setNodes setter —— 引擎写回 node.data 的唯一通道
  updateNodeData  // 编辑写回通道（He/J 用）
  Ar/Pr/Fr/Ir 端点契约引用 / 尺寸映射表 / 模型判定
  Mr         // 资产生图引擎
  oi/ai      // 视频上传
  li/ui/di   // 连线 + 建节点（di 是节点创建）
  l/t/u/r/i/a  // 请求环境注入（端口/模型/密钥等）
  zt         // AbortController 池（停止用）
```

**拆分边界**（呼应职责划分）：
- 纯函数（`Zg/Qg` 拼装、`scriptBoxPrompts`）→ `scriptBoxPrompts.js`，不依赖任何宿主符号。
- 需写回/依赖宿主（`Mr`/`di`/`ii`、`K`/`updateNodeData`）→ 经 deps 传入 `scriptBoxEngine.js`。
- `li/ui` 纯计算 → `scriptBoxConnect.js`；强耦合宿主的部分留 `H_.jsx` 薄封装。

## 第二部分 · 外部端点

### D. 代理请求地基（`Bl`，shared.js L6092）

所有外部请求统一经 `Bl` → `/api/proxy` → 网关/目标。

**`/api/proxy` 契约**
```
POST {baseUrl}/api/proxy
Headers:
  Content-Type: application/json
  Authorization: Bearer {targetKey}        // 目标服务密钥
  X-Proxy-Target: {targetUrl}               // 实际请求地址（如 https://api.lovart.ai/v1）
  X-Proxy-Mode: proxy | direct              // proxy=经网关, direct=直连本地(localPort)
  X-Proxy-Local-Port: {localPort}           // direct 模式（localTool 端口）
Body: 透传目标请求的 JSON body
```
**返回**：目标服务响应；`stream:true` 时返回 SSE 流（`data:` 行解析）。

**关键分支**：`g`（文本/图像）判定目标是否走 OpenAI 兼容接口；`localPort` 仅在 localTool 已连接时注入。

### E. 文本生成端点（`Ar` 剧本 / `Ir` 分镜提示词）

```
POST {baseUrl}/v1/chat/completions        // 经 D 代理
Body (Ar):
{ model, messages:[
    {role:"system", content: customScriptPrompt(或内置编剧模板)},
    {role:"user",   content: story}
  ], stream:true,
  response_format: 模型非 deepseek/claude ? {type:"json_object"} : undefined }
Body (Ir): 同构，system=customShotPrompt(或内置导演模板)，user=Nr(分镜,资产,风格)+各约束
返回: SSE 流，data: 行含 choices[0].delta.content；Ar 拼 JSON，Ir 拼 JSON
```
> 尺寸映射/尺寸约束见 `docs/33` §7.1；json_object 判定：模型含 deepseek/claude 则不用。

### F. 资产生图端点（`Mr`，H_.jsx L5414，双分支）

**OpenAI 分支**（`v/r?.[o]` 命中 → OpenAI 兼容）
```
POST {baseUrl}/v1/images/generations
Body: { model, prompt, n:1, image_size:"1K|2K|4K"(大写), size?:"1024x1024"(非auto时) }
```
**Gemini 分支**
```
POST {baseUrl}/v1beta/models/{model}:generateContent?key={apiKey}
Body: { contents:[{role:"user",parts:[{text:prompt}]}],
        generationConfig:{ responseModalities:["IMAGE"], imageConfig:{aspectRatio,imageSize} } }
```
**尺寸映射表**（`v`，H_.jsx L5456-5465）：`4:4→1K/2K/4K=1024/2048/4096…`（含 16:9/9:16/4:3/3:4/1:1 各级）。

### G. 文件上传端点（资产图本地化，`ci`/`si`，shared.js L1717/L1752）

**`ci`（fileUrl 模式，资产生成后本地化）**
```
POST {localToolBase}/api/files/upload
Body(FormData): fileUrl={imageUrl}, subfolder="canvas", filename?
返回: { url, thumbnailUrl, path }  → 存 asset.imageUrl/thumbnailUrl
```
**`si`（blob 模式）**：body 换 `file=blob+filename`。

### H. 视频素材上传端点（生视频连线，`wr`/`ii`）

连 discountVideoNode 前，把命中的资产图上传到视频网关换远程 URL，回填下游 `uploadedAssets`。协议见 `docs/33` §7.1「视频上传」。

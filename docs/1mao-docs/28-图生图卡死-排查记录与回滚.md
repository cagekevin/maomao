## 八、最终根因（已确认）

**根因不在 files 读取，而在 `resolve_attachments` 对"裸 base64"参考图的透传。**

### 关键证据（网关调试日志）

```
[submit:rawurl] traceId=- [0] /9j/4QAYRXhpZgAASUkqAAgAA...   ← JPEG 裸 base64（无 data: 前缀）
[submit:attach] traceId=- [0] /9j/4QAYRXhpZgAASUkqAAgAA...   ← 原样进 attachments
```

- 前端图生图把参考图以**裸 base64**（`/9j/...`，即 JPEG 文件头 `FF D8` 的 base64，**没有 `data:` 前缀**）发出。
- 旧 `resolve_attachments` 只认 `http://` 和 `data:` 两种开头。
- 裸 base64 两个都不匹配 → 走兜底 `else: out.append(u)` **原样透传给 Lovart**。
- Lovart 收到 `attachments=[裸base64]`，**无法识别** → 图生图一直 `running` 卡死（10 分钟超时 failed / items 空）。
- 文生图（不带图）不受影响，所以正常。

### 为什么"退 git"解决不了
- 前端裸 base64 不经过 `files` 字段（走 `urls`/`image_urls`），`f8d7884`/`64c9482` 回滚均无法解决，因为它一直在 `resolve_attachments` 里漏处理。

## 九、修复方案（已完成，实测通过）

在 `apimart-gateway/main.py` 的 `TaskService.resolve_attachments` 中，把参考素材统一"翻译"成 Lovart 可用的 CDN URL：

| 输入形式 | 处理 |
|---|---|
| `http(s)://` | 直接透传（Lovart 可自行下载） |
| `data:image/...;base64,...` | 解析 header 得扩展名 → base64 解码 → 上传 CDN |
| **裸 base64**（`/9j/` JPEG、`iVBOR` PNG、`R0lGOD` GIF、`UklGR` WebP、`SUQz` MP3、`AAAA` MP4…） | **识别魔数前缀 → base64 解码 → 上传 CDN**（核心修复） |
| `blob:` / 本地路径 / 无法识别 | 丢弃（不再透传，避免污染 Lovart），记 `[resolve:drop]` 日志 |

### 新增代码
- 模块级：`_B64_MEDIA_MAGIC`（魔数→扩展名映射）、`looks_like_base64_media()`、`_ext_from_b64_magic()`、`_ext_from_data_header()`
- `resolve_attachments` 重构，`raw_urls` 唯一收口（image_urls/images/attachments/reference_images/videos/audios/files + chat 的 vision_urls 都统一走它）

### 验证
- 实测任务 `task_3cad7140`（17:40:05）：`raw_urls=1 attachments=1` → 约 55s → `lovart_raw=done` → `POST /v1/draw/completions 200 OK` ✅
- **图生图恢复，约 1 分钟正常生成。**

脚本核心（简洁版）：
```python
import asyncio, os, sys
from lovart_client import LovartClient, LovartError
async def main():
    ak, sk = os.environ["LOVART_ACCESS_KEY"], os.environ["LOVART_SECRET_KEY"]
    c = LovartClient("https://lgw.lovart.ai", ak, sk, timeout=30)
    for tid in sys.argv[1:]:
        print(tid, "status:", await c.get_status(tid))
        try:
            r = await c.get_result(tid)
            print("  result keys:", list(r.keys()), "| items:", len(r.get("items") or []))
        except LovartError as e:
            print("  result ERROR:", e)
asyncio.run(main())
```

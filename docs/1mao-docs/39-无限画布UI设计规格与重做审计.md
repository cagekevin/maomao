# 第一部分：设计规范（重做照做）

## 1. 画布本体 = react-flow，不是自研

底层 react-flow（`@xyflow`）。网格与底色实测：

```11962:H_.jsx
<_Component128 ... className={`bg-[#0d0c0c] ${Yi ? `performance-large-canvas` : ``}`} ...>
```
```12100:H_.jsx
<Oe variant={E.Dots} gap={20} size={1} color={`#333`} />
```

- 点阵网格（`Dots`），`gap=20` / `size=1` / `color=#333`：远看空间感、近看有节奏、点几乎不抢内容。
- **画布底色实测为 `#0d0c0c`**（偏暖褐近黑），不是初探写的 `#0a0a0a`。重做令牌以 `#0d0c0c` 为 canvas-bg（见 §2.1）。
- 缩放范围 `minZoom=0.05` `maxZoom=4`，`connectionRadius=60`，`deleteKeyCode=[Backspace,Delete]`。

## 2. 配色系统：一套精密的"黑阶梯度"

全应用不是随便用黑，而是一套灰阶明度阶梯。从代码提取的真实色板：

| Token | 值 | 用途 |
|-------|-----|------|
| 画布底 | `#0d0c0c` | 无限画布背景、最底层容器（**实测值，初探误写为 #0a0a0a**） |
| 面板底 | `#101010` | 输入框、卡片、列表行 |
| 面板底2 | `#151515` | 次级输入、折叠区 |
| 卡片/弹窗 | `#1a1a1a` | 弹窗、下拉、卡片主色 |
| 悬停/高亮 | `#181818` `~` `#222` | hover 态、选中态 |
| 选中项 | `#252525` | 当前激活导航项 |
| 边框弱 | `#222` | 卡片描边 |
| 边框中 | `#2a2a2a` `~` `#333` | 输入框、网格点、通用描边 |

**规律（设计感来源）：**
- 背景永远比前景**深 1-2 阶**。层级靠"明度差"划分，不是靠阴影或颜色。
- 最小差是 `#101010` → `#181818`（hover），几乎察觉不到，但**有反馈**。
- 边框统一用 `#222`~`#333`，从不纯黑、从不亮色描边。描边是"结构线"，不是装饰线。

### 2.1 语义令牌表（重做时的唯一取色依据）

逆向出的散值必须收敛成**语义令牌**，重做 UI 时只许引用令牌、不许写死裸色值：

```
--canvas-bg        #0d0c0c   /* 最底层，永远是最深（实测修正） */
--surface-1        #101010   /* 输入框 / 卡片底 / 列表行 */
--surface-2        #151515   /* 次级输入 / 折叠区 / 卡片内分区 */
--surface-3        #1a1a1a   /* 弹窗 / 下拉 / 节点卡片主底 ★ */
--state-hover      #181818   /* hover 背景（比 surface-1 亮 1 阶，几乎不可见但存在） */
--state-active     #222222   /* 按下 / 选中态背景 */
--state-selected   #252525   /* 当前激活导航项 / 选中节点高亮底 */
--border-subtle    #222222   /* 弱描边：卡片与卡片之间 */
--border-default   #2a2a2a   /* 通用描边：输入框、面板外框 */
--border-strong    #333333   /* 强描边：网格点同色、强调分隔 */
--text-primary     #ededed   /* 主文字（近白不刺眼，非 #fff） */
--text-secondary   #a1a1a1   /* 次级文字：节点副标题、占位 */
--text-tertiary    #6b6b6b   /* 三级文字：表头、禁用、坐标标注 */
--text-disabled    #4d4d4d   /* 禁用态文字 */
```

**取色铁律（重做时强制）：**
1. 任何"容器底"只能从 `--canvas-bg / surface-1 / surface-2 / surface-3` 四选一，且**嵌套时逐层 +1 阶**。
2. 任何"描边"只能从 `--border-subtle / default / strong` 三选一。**禁止**纯黑 `#000` 描边、禁止彩色描边（状态色描边除外，见 §3）。
3. 文字只用三级 + 禁用四级灰度，**禁止**用纯白 `#fff` 作主文字。
4. 明度差守恒：相邻两层背景的明度差恒为 1 阶，这是"专业工具感"的物理来源。

### 2.2 节点卡片专用底色（§4 前置约定）

画布上的节点卡片**主底固定 `--surface-3 (#1a1a1a)`**，不允许节点用 surface-1/2 当主底（否则会"沉"进背景看不见边界）。卡片内部分区（如参数折叠区）才用 surface-2。卡片描边默认 `--border-default (#2a2a2a)`，选中时升级为蓝交互色描边（见 §3.1 + §5.3）。

## 3. 强调色：克制地只用蓝，状态色才出彩

### 主操作色 = 蓝（`blue-500` / `blue-600`）
- 输入框聚焦：`focus:border-blue-500`
- 主按钮：`bg-blue-600 hover:bg-blue-500`
- 选中态文字：`text-blue-500`
- 次级按钮（半透明）：`bg-blue-500/15 text-blue-200`

蓝只出现在**"你能操作的地方"**。这是刻意的：把"可交互"和"纯展示"在颜色上分开。

### 状态色 = 低饱和半透明（霓虹感但收敛）
状态用 `xxx-500/10` 背景 + `xxx-500/30` 边框 + `shadow-[0_0_20px_rgba(...)]` 柔光：

```31:Lt.jsx
from-green-500/10 to-emerald-500/10 border-green-500/30 shadow-[0_0_20px_rgba(34,197,94,0.15)]
from-red-500/10 to-rose-500/10   border-red-500/30   shadow-[0_0_20px_rgba(239,68,68,0.15)]
from-yellow-500/10 ...
from-blue-500/10 to-indigo-500/10 ...
```

- 绿=成功/可用，红=错误/额度满，黄/琥珀=警告，蓝=信息。
- 全部是 **`/10` 填充 + `/30` 描边 + 15% 透明度柔光**。像暗房里的荧光标签——亮但不刺眼。

### 来源判断
这套"近黑底 + 单一蓝交互色 + 低饱和霓虹状态色 + 柔光"是 **Vercel / Linear 风格暗色系统**的变体。设计感本质 = "专业工具感"：安静、密集、但每个状态都一眼可辨。

### 3.1 蓝交互色：精确的触发边界（重做时必须守住）

蓝（`blue-500 #3b82f6` / `blue-600 #2563eb`）**只许出现在"用户能操作"的元素上**：

| 元素 | 用法 | 精确写法 |
|------|------|----------|
| 主按钮 | 实底蓝 | `bg-blue-600 hover:bg-blue-500 text-white` |
| 次级按钮 | 半透明蓝 | `bg-blue-500/15 text-blue-200 hover:bg-blue-500/25` |
| 输入框聚焦 | 边框变蓝 | `focus:border-blue-500 focus:ring-1 focus:ring-blue-500/30` |
| 选中态文字 | 文字变蓝 | `text-blue-500`（选中节点标题、激活 tab） |
| 链接 / 可点击项 | 文字蓝 | `text-blue-400 hover:text-blue-300` |
| 节点选中描边 | 边框蓝 | `border-blue-500`（覆盖默认 `#2a2a2a`） |

**禁止**：蓝不得用于背景大色块（除按钮）、不得用于状态指示、不得用于装饰。一句话——**蓝 = "这里能点"**。

### 3.2 状态色柔光：可复用的 class 模板（直接抄）

```tsx
// 成功 / 可用（绿）
"from-green-500/10 to-emerald-500/10 border-green-500/30 shadow-[0_0_20px_rgba(34,197,94,0.15)] text-emerald-300"
// 错误 / 额度满（红）
"from-red-500/10 to-rose-500/10 border-red-500/30 shadow-[0_0_20px_rgba(239,68,68,0.15)] text-rose-300"
// 警告 / 注意（黄/琥珀）
"from-yellow-500/10 to-amber-500/10 border-yellow-500/30 shadow-[0_0_20px_rgba(234,179,8,0.15)] text-amber-300"
// 信息（蓝/靛）
"from-blue-500/10 to-indigo-500/10 border-blue-500/30 shadow-[0_0_20px_rgba(59,130,246,0.15)] text-blue-300"
```

**柔光参数铁律**：`shadow` blur 恒 `20px`，颜色 alpha 恒 `0.15`，填充 alpha 恒 `0.10`，描边 alpha 恒 `0.30`。状态标签（badge）复用同一套：`bg-{c}-500/15 text-{c}-300 border-{c}-500/30`，填充比卡片略高（0.15 vs 0.10）。

**状态语义映射（节点/任务通用）：**
- 绿 = 生成完成 / 可用 / 成功
- 红 = 生成失败 / 额度满 / 错误
- 黄 = 警告 / 等待中 / 配置不完整
- 蓝 = 信息 / 生成中（进行态也可用蓝脉冲）

## 4. 圆角 & 间距：统一的"软边界"语言

- 卡片/弹窗：`rounded-xl`（12px）为主，小元素 `rounded-lg`（8px）。
- 输入框：几乎都 `rounded-lg`。
- 间距：列表行 `px-4 py-3`、卡片 `gap-3`/`gap-4`，是 4px 栅格的倍数。

### 4.1 圆角令牌（强制三档）
| 令牌 | 值 | 适用范围 |
|------|-----|----------|
| `--radius-sm` | `rounded-lg` (8px) | 输入框、按钮、小徽标、句柄 |
| `--radius-md` | `rounded-xl` (12px) | 节点卡片、弹窗、面板主容器 ★ |
| `--radius-lg` | `rounded-2xl` (16px) | 大型模态、画布级浮层（命令面板） |

规则：画布节点卡片统一 `rounded-xl`。禁止卡片内混用多种半径。

### 4.2 间距栅格：4px 基线 + 语义间距
```
--sp-1 = 4px    --sp-2 = 8px    --sp-3 = 12px   --sp-4 = 16px
--sp-5 = 20px   --sp-6 = 24px   --sp-8 = 32px   --sp-10 = 40px
```
典型落点：列表行 `px-4 py-3`；卡片内边距 `p-4`；卡片内部 `gap-3`、区块间 `gap-4`；工具栏按钮 `gap-1`、留白 `p-2`。

### 4.3 字号阶梯（"工具密度 > 装饰密度"）
| 令牌 | 值 | 用途 |
|------|-----|------|
| `--text-xs` | 11px | 表头、坐标标注、句柄标签、禁用说明 |
| `--text-sm` | 12px | 列表行、节点副标题、badge 文字 |
| `--text-base` | 13px | 节点主标题、正文、按钮文字 |
| `--text-md` | 14px | 面板标题、分区标题 |
| `--text-lg` | 16px | 弹窗标题、画布级浮层标题（最大字号，禁止更大） |

规则：画布 UI 中**不允许 16px 以上文字**。层级靠灰度差表达，不靠放大字号。

### 4.4 节点卡片 UI 结构规格（★ 重做核心）
定义**统一节点卡片骨架**（所有节点 type 共用此骨架，仅内容区不同）：

```
┌─────────────────────────────────────────┐  ← 卡片外框：surface-3(#1a1a1a) + border-default(#2a2a2a) + rounded-xl
│ [图标] 节点标题                [状态badge] │  ← 头部：px-4 py-3，标题 text-base/text-primary，badge 用 §3.2
│─────────────────────────────────────────│  ← 分隔线：border-subtle(#222)
│ 内容区（按节点 type 不同）：              │  ← 内容区：surface-2(#151515) 底或透明，p-4，gap-3
│  · promptNode：提示词预览 + 模型标签      │
│  · imageNode：缩略图占位(虚线框或结果图)  │
│  · videoNode：视频帧占位 + 时长/比例标签   │
│  · textNode：文本预览 line-clamp-2         │
│  · 通用：config 字段用 §4.5 字段行渲染      │
│─────────────────────────────────────────│  ← 分隔线：border-subtle(#222)
│ [生成按钮·蓝]  [重试]      [· · · 菜单]   │  ← 底部操作条：px-4 py-2，按钮见 §3.1
└─────────────────────────────────────────┘
   ●                              ●           ← 句柄：cust-handle-dot，极小圆点，左右中
```

**卡片尺寸约束：**
- 默认宽 `w-64`(256px)，最小 `w-56`(224px)，最大 `w-80`(320px)；高自适应。
- 句柄（`cust-handle-dot`）：直径 `6px` 圆点，色 `border-strong(#333)`，hover 变 `blue-500`，连线态变 `blue-400`。左右各一个（输入/输出）。

### 4.5 字段行渲染规格（config 面板 / 卡片内通用）
```
[字段中文名]                   [值/输入控件]
  text-tertiary(11px)           text-secondary(12px) / 输入用 surface-1 底
```
- 字段名列固定宽 `w-20`(80px)，左对齐 `text-tertiary`。
- 值列：文本直接 `text-secondary`；可编辑用 `surface-1` 输入框 + `border-default` + `focus:border-blue-500`。
- 媒体类字段渲染为缩略图占位（虚线框 `border-dashed border-[#333]` + 居中图标）。
- 一行一字段，`gap-3` 纵向；虚线框专门标记"空状态/可拖入区"。

## 5. 信息密度：为"多端重活"设计

- 表格头 `text-[11px] font-medium text-gray-500`，行 `text-xs`。靠位置而非颜色区分层级。
- 节点用极小句柄圆点，深色卡片叠在画布上。
- 整体"工具密度 > 装饰密度"。对 ADHD 友好：背景足够"安静"，唯一彩色是"能点什么 / 出了什么状态"。

### 5.1 多端适配规则
| 端 | 画布底色 | 节点默认宽 | 字号 | 句柄 | 特殊 |
|----|---------|-----------|------|------|------|
| 桌面 | `#0d0c0c` | `w-64`(256) | 见 §4.3 | `6px` 圆点 | hover/选中靠鼠标，框选/连线拖拽 |
| 移动端 | `#0d0c0c` | `w-72`(288) | 同阶梯最小 12px | `8px` 圆点 | 无 hover；连线靠"长按句柄→拖到目标"；pinch 缩放、双指平移 |
| 分享/只读 | `#0d0c0c` | `w-64` | 同 | 隐藏句柄 | 无操作条按钮，仅展示 badge |

**铁律**：多端**共用同一套色板与令牌**，只调"尺寸与交互方式"，不调"颜色与风格"。禁止为移动端做亮色或不同色阶。

### 5.2 交互态视觉规范（★ 重做核心）
所有交互态都必须落在既有令牌上，不允许为状态新造颜色。

- **(a) hover**：卡片 `surface-3 → state-hover` 微亮；句柄 `#333→blue-500`；操作条按钮提亮到 `text-secondary`。禁止加阴影/放大/变色块。
- **(b) 选中**：描边 `border-default→border-blue-500` + `ring-1 ring-blue-500/30`；标题 `text-primary→text-blue-500`；多选框选矩形 `bg-blue-500/10 border-blue-500/40`。
- **(c) 拖拽中**：被拖节点 `opacity-80` + `shadow-[0_8px_24px_rgba(0,0,0,0.4)]`；落点 `border-dashed border-blue-500/60` 虚线框。
- **(d) 连线中**：临时连线 `stroke-blue-500` `stroke-width=2` `opacity-80`；合法落点句柄放大到 `10px` + `bg-blue-500` 实心。
- **(e) 空状态**：画布级中央 `border-dashed border-[#333] rounded-xl` 大虚线框（约 60% 视口），内文"从左侧拖入节点，或按 ⌘K 唤起命令面板"；节点内容空状态用小虚线框。
- **(f) 生成中**：badge 蓝信息模板 + "生成中"；底部 `h-0.5` 细进度条 `bg-blue-500`；可选 `animate-pulse` 呼吸描边。
- **(g) 完成/失败**：完成切绿模板显结果；失败切红模板 + `errorMsg`（text-rose-300, 11px, line-clamp-2），"重试"变蓝可点。
- **(h) 平移/缩放**：pan 光标 `grabbing` 且 `transition-none`；缩放以光标为锚点，`zoom<0.5` 网格变稀，`zoom>2` 节点字号不放大。

## 6. 一句话总结设计感来源
> **近黑阶梯度（#0d0c0c→#333）+ react-flow 点阵网格（#333/20px）+ 蓝做唯一交互色 + 低饱和霓虹状态色带柔光。**
> 它不"炫"，它"稳"——所有视觉重量都用来区分"层级"和"状态"，而不是"好看"。

## 2. 选中连线的「线条流动感」—— 自定义 Edge + Comet

这是你最喜欢的效果。实现由 **三层 path + 一个彗星流光组** 组成。

### 2.1 自定义 Edge 组件

**文件**：`src/bundle/httpClient-BknZwXjG_components/Mg.jsx`
**注册**：`shared.js:11477` → `var k_ = { default: Ng }`，`Ng = Z.memo(_cmp_Mg)`（`shared.js:11125`）。
**导入**：`Mg.jsx:1` → `import _cmp_Mg from "./Mg.jsx"`。

渲染结构（简化）：

```jsx
<Fragment>
  {/* 透明加宽命中层，扩大点击范围 */}
  <path d={m} className="cust-edge-hit" />

  {/* 选中/关联时显示的辉光层 */}
  {b && <path d={m} className="cust-edge-glow is-active" />}

  {/* 主线：选中时加亮 */}
  <path d={m} className={`cust-edge-base ${v ? 'is-active' : ''}`} markerEnd={...} />

  {/* 彗星流光：只有选中或关联时才渲染 */}

  {/* 删除按钮（选中时出现在中点） */}

```

路径用 `Mt(...)` 生成（`Mt` = React Flow 的 `getBezierPath`，见 `Mg.jsx:23`），固定 `sourcePosition: Right / targetPosition: Left`。
`b = v = selected || relatedToSelected` —— 即**选中**或**与选中节点关联的边**都会触发特效。

### 2.2 Comet（彗星流光）—— 流动感的本体

**文件**：`src/bundle/httpClient-BknZwXjG_components/_Component111.jsx`

完全用**纯 SVG `<animateMotion>` 沿 path 运动**，不需要 JS 动画循环，性能极好：

```jsx
// 16 个拖尾圆点，半径/透明度递减，沿同一 path 但 begin 错开 → 形成彗星拖尾
let i = [];
for (let e = 0; e < 16; e++) {
  let t = e / 15;
  let r = 4.6 - t * 4;        // 半径 4.6 → 0.6
  let op = Math.max(0.05, 1 - t * 1.05);  // 透明度 1 → 0.05
  let begin = e * 18;         // 每个错开 18ms
  i.push([r, op, begin]);
}

<g className={`cust-edge-comet ${n ? 'is-active' : ''}`}>
  <defs>
    <filter id={filterId} ...><feGaussianBlur stdDeviation="1.4"/></filter>
  </defs>
  <g filter={`url(#${filterId})`}>
    {i.map(([r, op, begin]) =>
      <circle r={r} fill="#fff" opacity={op}>
        <animateMotion dur="1.8s" repeatCount="indefinite" rotate="auto" begin={-begin+'ms'}>
          <mpath xlinkHref={`#${pathRef}`} />
        </animateMotion>
      </circle>
    )}
  </g>
  {/* 头部主光点，带白+蓝双 drop-shadow 发光（选中态半径 3.4） */}
  <circle r="3.4" fill="#fff" opacity="1"
    style={{ filter: 'drop-shadow(0 0 6px #fff) drop-shadow(0 0 14px rgba(180,210,255,0.7))' }}>
    <animateMotion dur="1.8s" repeatCount="indefinite" rotate="auto" begin="0s">
      <mpath xlinkHref={`#${pathRef}`} />
    </animateMotion>
  </circle>
</g>
```

**流动感 = `1.8s` 循环 + 16 点拖尾 + 高斯模糊辉光 + 蓝白 drop-shadow**。`pathRef` 指向上面 `_cmp_Mg` 里那条 `id="cust-edge-mpath-{edgeId}"` 的隐藏 path（`Mg.jsx:43,51,57`）。

→ **点变成环 + 十字**，这就是你要的「端点变大」。

**连接中**（`connectingto`/`connectingfrom`，`shared.js:616`）：

### 3.3 「端点跟随鼠标」—— 手感核心

`_Component12.jsx:22` 的 `mousemove` 监听，把鼠标偏移写进 CSS 变量 `--cust-shift-x/y`，子元素 `+` 号用 `translate(calc(-50% + var(--cust-shift-x)) ...)` 跟随（见 `shared.js:571,612,627`）：

```js
let l = Math.max(-14, Math.min(14, a * 0.35));  // 最大 ±14px
let u = Math.max(-14, Math.min(14, c * 0.35));
if (o) l = Math.min(0, l);       // 左 handle 只朝左外
else if (s) l = Math.max(0, l);  // 右 handle 只朝右外
e.style.setProperty('--cust-shift-x', `${l}px`);
e.style.setProperty('--cust-shift-y', `${u}px`);

// 性能保护：节点数 > handleFollowLimit(60) 直接不跟随
let f = u <= d;  // u = nodeCount, d = handleFollowLimit
if (!f) { setProperty('0px'); return; }
```

缓动用 `cubic-bezier(.34,1.56,.64,1)`（ring/plus 的 transition，`shared.js:562,573`）→ 带轻微回弹的「弹出」感。

## 7. 复刻这两套手感的要点（给以后自己）

1. **流动连线**：选中态给 edge 加 `is-active` → 渲染一个沿隐藏 path 运动的 `<animateMotion>` 彗星组（16 拖尾圆 + 1 发光头，dur 1.8s）。纯 SVG，不用 JS rAF。
2. **端点变大**：每个 handle 外层包一个 `cust-handle-wrap`，内含 ring/plus/dot 三层；用 CSS `:hover` / React Flow 自动加的 `.connectingto` 类切换 `scale` + 白光 shadow。mousemove 写 `--cust-shift-x/y` CSS 变量实现 + 号追鼠标，缓动用回弹 bezier。
3. **性能护栏**：`handleFollowLimit=60`（节点超 60 关跟随）、`edgeFxLimit`（控 comet 数量）、`onlyRenderVisibleElements`（>20 节点开）、`selectionOnDrag`（≤80 节点才框选）。这是大画布不卡的关键，也是 ADHD 友好的「不突然卡死」设计。

## 8. 画布通用交互（Pan / Zoom / 框选）

### 8.1 平移 / 缩放 / 框选的 ReactFlow 参数

`H_.jsx:11958` 的 `<_Component128>`（ReactFlow）显式传了：

```jsx
panOnDrag={true}                  // 左键拖空白处 = 平移（默认行为）
selectionOnDrag={De.length <= 80}// 节点 ≤80 时：拖拽=框选；>80 改回平移（防误触）
nodesDraggable nodesConnectable
onlyRenderVisibleElements={De.length > 20}
minZoom={0.05} maxZoom={4}
fitView fitViewOptions={{ padding:0.2, maxZoom:1, minZoom:0.05 }}
deleteKeyCode={['Backspace','Delete']}
elevateNodesOnSelect={false}     // 故意关「选中置顶」，保持层级稳定不乱跳
elevateEdgesOnSelect={false}
nodeOrigin={[0,0]}
```

**未显式覆盖、走 React Flow 默认的行为**（UX 推断，符合库默认）：
- **缩放锚点 = 光标位置**（库默认 `zoomOnScroll`，滚轮以指针为锚点）。
- **滚轮缩放** 开（`zoomOnScroll` 默认 true）；**触控板双指捏合** 开（`zoomOnPinch` 默认 true）。
- **中键拖拽平移**：React Flow 默认 `panOnDrag={true}` 只绑左键；中键/空格平移**未启用**（没传 `panOnScroll` / `panActivationKeyCode`）。
- **双击放大**：`zoomOnDoubleClick` 默认 true，但项目用 `onEdgeDoubleClick` 拦截了双击连线（见 §11.2）。双击空白处仍可能触发放大（库默认）。
- **缩放缓动/惯性**：React Flow 默认有平滑过渡（`zoomOnScroll` 带 easing），无物理惯性。

### 8.2 框选外观与选区操作

- 选区是 React Flow 默认的半透明蓝色矩形（`react-flow__selection`）。
- **Shift 加选 / 减选**：库默认 `multiSelectionKeyCode='Shift'`，配合点击节点/边加减选（代码未覆盖，走默认）。
- **框选后整体拖拽**：选中多个节点拖其中一个 → 整组跟随（React Flow 默认 `selectNodesOnDrag`）。
- **框选与平移的优先级**：`selectionOnDrag` 仅当节点 ≤80 为真；超 80 时拖拽变平移，框选需按住 Shift。这是个**性能 / 手感折中**。

### 8.3 右键 / 上下文菜单（三套独立菜单）

`H_.jsx` 绑定了三个不同的 contextmenu 回调，统一写入菜单状态 `Ie`：

| 触发对象 | 回调 | 行号 | `Ie.type` |
|---|---|---|---|
| 空白处 | `Zn` | `1324` | `canvas` |
| 节点 | `Qn` | `1341` | `node`（带 `nodeId`） |
| 选区（多选拖完） | `$n` / `er` | `1357` / `1372` | `selection` |

菜单本体（新建节点、删除、打组、整理等）由 `Ie` 驱动渲染在 `H_.jsx` 下方（约 `11993` 起的 `tt && <Component2922>` 弹层）。

## 9. 节点拖拽与多选交互

### 9.1 拖拽手感

- **无网格吸附**（`snapToGrid` / `snapGrid` 全代码 0 命中）→ 纯自由摆放，ADHD 友好（不强迫对齐）。
- **无对齐辅助线**（smart guide / helper line 0 命中）→ 拖拽时不显示与邻节点的对齐参考线。
- **无磁性吸附**其他节点边缘。

### 9.2 多选拖拽时连线跟随

- 框选多个节点整体拖动时，连线**实时跟随**（React Flow 默认，edge path 随 node position 重算）。
- 因为 comet 是 SVG `<animateMotion>` 沿当前 path 跑，path 变了光点**自动沿新线流动**，无需重算动画。

### 9.3 拖出画布边界 / 无限远

- 画布是**无限画布**（React Flow 坐标系无界），节点可被拖到任意远。
- 视口不强制跟随；需手动平移或 `fitView`。`onMoveStart`/`onMoveEnd`（`Wt`/`Kt`）只用于标记 `viewportMoving`（驱动 LOD 性能模式）。

## 10. 连接（Connection）全流程

### 10.1 拖拽中的连线预览 `connectionLineComponent={_cmp_Pg}`

**文件**：`Pg.jsx`（默认导入 `_cmp_Pg`）。视觉与选中 comet **同一套**：

- 用 `Mt`（= `getBezierPath`）生成曲线，固定 `sourcePosition:Right / targetPosition:Left`。

## 8. 交互层补全（原记录 §一~§七 之外扒出的行为）【已并入第二部分 §11.5 / §10 / §8.3，此重复章节删除】

### 8.1 撤销 / 重做 —— 自研栈，非 zustand-temporal

**位置**：`shared.js:7683` 起。`clipboard/undoStack/undoBatchDepth/undoBatchSnapshot` 都是 store 字段（不是独立中间件）。

- **栈结构（store 备用栈）**：`undoStack: []` 存整图快照（序列化对象），`Dd(r)`（`shared.js:7683`）从快照还原，还原时**保留 clipboard / undoStack / 粘贴计数**（不清空，避免撤销后粘贴状态错乱）。入栈长度由 `rf(e)`（`shared.js:8173`）截断到 `Qu=80` 步（`shared.js:7437`，**注意默认上限是 80，不是 15**）。
- **快照判定**：`nf(a, Cd(o))`（`shared.js:8170`）比对前后是否真的变化，没变化就不入栈。
- **批量事务**：`beginUndoBatch()` / `endUndoBatch()`（`shared.js:8223/8236`）用 `undoBatchDepth` 计数器包裹「一组应算一步」的操作（如脚本盒一次性连多条）。depth=0 时存 `undoBatchSnapshot`，结束时若 `undoBatchHasTrackedChanges` 且快照确有变化才 push 进 `undoStack`。
- **持久化耦合**：每次入栈/撤销/重做都调 `wd(r)`（`shared.js:7629`）写盘（localStorage / 云端）。
- **⚠️ 重要：这套 store 栈并未接入画布主流程**：在 `H_.jsx` 中搜索 `undo()/redo()/beginUndoBatch/endUndoBatch/saveLatestSnapshot` 均为 0 命中。画布实际使用的撤销机制是下面 §11.5 描述的**组件内 15 步本地栈**，与 store 栈是两套独立实现，不要混淆。

> ⚠️ 设计新画布时**必须**先定撤销粒度：画布实际生效的是「整图快照」级的 15 步本地栈，简单但内存占用随节点数上升。节点 >300 时快照成本需评估；store 里另有一套 80 步快照栈可供后续接入。

### 8.2 连接全流程（onConnect 的真实逻辑）

**位置**：`H_.jsx:1217` `Yn`（= `onConnect`）。

1. **同侧禁止**：若 `source` 与 `target` 的 handle 同侧（都 left / 都 right）→ `k('请连接节点的不同侧 (右侧输出 → 左侧输入)')`，直接 return。
2. **左右反接自动翻转**：若 `source` 在 left、`target` 在 right，自动 swap `source/target/handle`（让用户怎么拖都对）。
3. **特殊类型联动**：`scriptBoxNode` 的 `shot-*` 输出连到 `promptNode` / `discountVideoNode` 时，自动把画布比例/时长写入目标节点 `data`（§四 的跨节点联动）。
4. **多选批量连接**：若源节点 `selected` 且选区 >1 个节点，会把当前边**复制给选区里其他所有节点**（一次性连一片）。
5. 最终 `ue(edge, edges)`（React Flow 的 `addEdge`）入 store，`type: 'default'`（即走 §2 的 comet 自定义 edge）。

**拖拽中的临时连线** `_cmp_Pg` = `Pg.jsx`：
- 完全复用 comet 视觉（16 拖尾 + 发光头、dur 1.8s、高斯模糊），与选中态同一套审美。
- `lodLevel < 2` 才渲染 comet（`f = o < 2`），低缩放时只画 base 线省性能。
- 处理**父节点折叠**：若 `fromNode.parentId` 且父 `collapsed`，连线起点回退到父节点右下边缘（`Pg.jsx:21-30`）——这是子图/分组折叠的视觉补偿。

**连接落点校验**：无独立 `isValidConnection` prop，校验全部内联在 `Yn` 里（同侧/反接）。`connectionRadius={60}`（§1）控制 hover handle 的吸附半径。

### 8.3 右键上下文菜单（三套，按目标区分）

**位置**：`H_.jsx:1324/1341/1357`（`Zn`/`Qn`/`$n`），菜单状态存 `Ie({x,y,type,nodeId?})`，由 `it(false)` 关掉节点 hover 态。

| 触发 | handler | `type` | 携带 |
|---|---|---|---|
| 空白画布 | `onPaneContextMenu`=`Zn` | `canvas` | x,y |
| 单个节点 | `onNodeContextMenu`=`Qn` | `node` | x,y,`nodeId` |
| 选区（>1节点） | `onSelectionContextMenu`=`$n` 或 `onSelectionEnd`=`er`(延迟50ms判定多选) | `selection` | x,y |

- **输入框保护**：`Xn(e)` 判断 `target` 是 INPUT/TEXTAREA/contenteditable 时**不弹菜单**（直接 return），避免编辑文字时误触。
- 坐标用 `Le.current.getBoundingClientRect()` 转成画布内局部坐标，菜单组件应是 portal 渲染（参考 `Rg.jsx:748` 的 `Fn.createPortal(..., document.body)` 模式）。

### 8.4 拖放新建节点（onDrop）

**位置**：`H_.jsx:11958` `onDragOver={ki}` / `onDrop={Ai}`；落点计算在 `H_.jsx:11436` 附近的 `Ve()`（screenToFlowPosition 封装）。

- 支持拖入：**图片 / 视频 / 音频 / 文本文件**（`accept="image/*,video/*,audio/*,text/plain"`）。
- 文本文件 / URL → 转成 `textNode` 或带图 `imageNode`（含 `urlifyAsset` 失败回退 base64，`H_.jsx:10316`）。
- 音频 → `audioPlayerNode`，图片 → `imageNode`，写入 `label`/`imageUrl`/`thumbnailUrl`。
- 落点用 `screenToFlowPosition`（React Flow API）把鼠标坐标换算成画布坐标再建节点。

### 8.5 复制 / 粘贴 / 克隆

**位置**：`H_.jsx` 的 `Ci`(复制) / `xi`(粘贴) / `Ti`(克隆) + 全局 keydown `H_.jsx:11514-11528`。

- **复制** `Ctrl+C` → `Ci()`：把选中节点序列化成 `{type:'mutiwindow-nodes', nodes, edges, originalIds}`，写 `navigator.clipboard.writeText(JSON)`，toast `已复制 N 个节点`。
- **粘贴** `Ctrl+V`：监听 `window.paste` → `xi()` 读剪贴板文本，解析 `mutiwindow-nodes` JSON，新节点带**偏移防重叠**（复用 `clipboardPasteCount * Zu` 偏移量，见 `shared.js:8058` `tf`）。也兼容 `localStorage` 兜底（`mutiwindow-clipboard`）。
- **克隆** `Ctrl+D` → `Ti()`（`H_.jsx:10026`）：内部 `await Ci()` 复制后走粘贴逻辑，新节点带偏移防重叠，偏移量 = `clipboardPasteCount * Zu`（`Zu=0.6`，`shared.js:7436`），每次粘贴 `clipboardPasteCount` 自增。
- **全选** `Ctrl+A`：跳过输入框时选中所有节点（`H_.jsx:11493`）。
- **图片节点内复制**：`Rg.jsx:410` 用 `navigator.clipboard.write([ClipboardItem image/png])` 复制单张图，可在画布粘贴（跨节点）。

### 8.6 网格吸附（snapToGrid）

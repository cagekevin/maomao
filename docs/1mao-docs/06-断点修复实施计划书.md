### 1.2 P0-2：SSE 流式转发（~50行改动）

**位置**：`handleProxyFormData`（:66-103）、`handleProxyJson`（:106-167）

**改法**：在 `arrayBuffer()` 缓冲之前，加一层判断——当下游 `Content-Type` 含 `text/event-stream` 或请求体含 `stream:true` 时走流式路径：

```typescript
// 在 system.ts 顶部加 import
import { Readable } from 'node:stream';
import { createGunzip, createInflate, createBrotliDecompress } from 'node:zlib';

// 两个 handler 中，在 const elapsed = ... 之前插：
const ct = fetchRes.headers.get('content-type') || '';
const ce = fetchRes.headers.get('content-encoding') || '';

// 判断是否走流式
if (ct.includes('text/event-stream') || ct.includes('application/x-ndjson')) {
  // 流式路径
  const cleanHeaders: Record<string, string> = {};
  fetchRes.headers.forEach((v, k) => {
    if (!skipHeaders.has(k)) cleanHeaders[k] = v;
  });
  // 关键：content-encoding 移除后需本地解压再 pipe
  delete cleanHeaders['content-encoding'];
  delete cleanHeaders['content-length']; // chunked
  
  res.writeHead(fetchRes.status, cleanHeaders);
  
  let bodyStream = Readable.fromWeb(fetchRes.body as any);
  if (ce === 'gzip') bodyStream = bodyStream.pipe(createGunzip());
  else if (ce === 'deflate') bodyStream = bodyStream.pipe(createInflate());
  else if (ce === 'br') bodyStream = bodyStream.pipe(createBrotliDecompress());
  
  bodyStream.pipe(res);
  return; // 流式路径直接 return，不走下方缓冲逻辑
}
// ... 原有 arrayBuffer() 路径保持不变（非流式请求走这里）
```

**验收**：调试面板请求日志中 `chat/completions` 出现持续分块响应（非一次性 200）；压缩响应不乱码。

### 1.3 P0-3：协议翻译层（~20行改动）

**位置**：`handleProxy`（:24-39），在 `handleProxyFormData` / `handleProxyJson` 调用返回后，在 `res.end()` 前加轻量适配。

**改法**：在两个 handler 中，`res.end(resBody)` 之前，解析响应体，识别 `{code, data}` 信封：
```typescript
// 在 res.writeHead / res.end 之间插入：
let finalBody: any = null;
try {
  const parsed = JSON.parse(resBody.toString('utf-8'));
  if (parsed && typeof parsed === 'object' && 'code' in parsed && 'data' in parsed) {
    // 网关 {code:200, data:...} 信封 → 剥信封，返回 data
    finalBody = JSON.stringify(parsed.data);
  } else {
    finalBody = resBody;
  }
} catch {
  finalBody = resBody; // 非 JSON 原样透传
}
```

> **架构决策确认**：网关只透传 Lovart 原生响应，**不拆信封、不做前端形状映射**。所有映射集中在这里。G2 期望 `status==="succeeded"`+`results[0].url`（前端已核-dist：httpClient:561）；draw 期望 `data[0].task_id`（S5 已核形状一致）。

**验收**：生图/对话返回能被前端正常解析。

// 新增：托管 dist 前端页面
function handleFrontendPage(req: http.IncomingMessage, res: http.ServerResponse, urlPath: string): boolean {
  const distDir = path.join(__dirname, '..', '..', 'dist');
  const fileName = urlPath === '/' || urlPath === '/index.html' ? 'index.html' : urlPath.replace(/^\//, '');
  const filePath = path.join(distDir, fileName);
  
  if (!fs.existsSync(filePath)) return false;
  const ext = path.extname(filePath).toLowerCase();
  const mimeMap: Record<string, string> = {
    '.html':'text/html','.js':'application/javascript','.css':'text/css',
    '.png':'image/png','.jpg':'image/jpeg','.svg':'image/svg+xml',
    '.json':'application/json','.woff2':'font/woff2',
  };
  const stat = fs.statSync(filePath);
  res.writeHead(200, {'Content-Type': mimeMap[ext]||'application/octet-stream','Content-Length': stat.size});
  fs.createReadStream(filePath).pipe(res);
  return true;
}

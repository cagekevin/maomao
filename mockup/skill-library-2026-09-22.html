技能库 · 线框（一页平铺卡片 + 分区可折叠）

形态基准 = 同行（WorkBuddy 技能页）
我们唯一多出来的：分组（A 组 / B 组）

三条定稿：① 一页平铺，无"文件夹 / 进入 / 返回"（分区表头只是可折叠的分段，不是层级）； ② 卡片 = 复选框 + 字母头像 + 名字 + 右上开关 + 一句话； ③ 分组最轻：卡上不写分组（表头已表达），把卡拖到某个分区表头 = 归进那组。

04（顶部 ⋯ → 高级）

高级：必须有、但你不必懂

默认折叠；打开也只看到"自动"
高级
让 AI 自动知道有哪些技能开着：每轮多约 500 字清单，AI 能自己挑；关着：只有你手动选中的才会发（默认关）
单个技能最多发多少超了会截断，并在本轮消息上如实标注「已截断」（不静默丢） 自动 ▾

这里只有两项：一个提示词开关（默认关）+ 一个"自动"档的额度。原先把"单个字数 / 合计字数 / 最多带几个" 三个数字摆在用户面前，还配一段"等于没有防线"的警告 —— 那一整块（含警告文案）**删掉**： 需要配警告来解释的旋钮，就不该在用户面前；而"一次最多带几个"在改成**单选**之后压根不存在了。

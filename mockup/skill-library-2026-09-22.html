我重新推的 8 条（不参考旧文档，按"这页要解决什么"推）
  1. 列表，不是卡片：一屏能看 3 倍的行数，名字左对齐扫视快；卡片 3 列会把名字截断，还得"进/退"。
  2. 编辑就地在行下展开：没有右栏、没有详情页、没有"返回"。点谁编辑谁，收起就回到列表。
  3. 每行的常显控件只有一个：开关。复选框与 ⋯ 都是 hover 才出现 —— 常态下这一页只有"名字 + 一句话 + 开关"。
  4. 分组 = 分段表头，可折叠：它是同一页里的一段，不是另一个空间。不提"文件夹/目录"（那是磁盘实现，不是用户模型）。未分组当普通分��显示在最后。
  5. 添加只有一个入口：「＋ 添加」→ 新建空白 / 从 .md 导入 / 从文件夹导入整包；整页也直接接受拖入。不再有"导入""导入目录""新建"三个按钮。
  6. 搜索常驻且跨分组：安静地占 180px，永远搜全部技能，不要求先选分组。
  7. 正常态零状态：只有出问题的行多一句小字 + 一个动作（版本/徽章/计数一律不显示）。
  8. 批量替代"组级全开全关"：一个开关入口管启用，不制造第二个语义相同的入口。

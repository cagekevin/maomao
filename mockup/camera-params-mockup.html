拼接顺序：焦距 → 快门效果 → 光圈 → 曝光时间，英文逗号连接，末尾补句点；缺省项整段跳过。
节点限制：ai-audio 等节点不追加（与参考实现一致）——面板只挂在 imageGenerateNode / 视频节点上。
数据流：面板 onChange → 节点 data.cameraSettings → 生成时 buildGenerationCameraPrompt() → 提示词。三步缺一不可，只做 UI 不会生效。
与现有能力的边界（避免做重）： 本仓库已有 CameraStudioPanel（3D 摄影棚：球面拖拽机位 + 打光，hover 工具条里的太阳图标进入，产出「新建生图节点 + 预填提示词」）。 它和这里是两套独立功能：摄影棚改的是「机位与布光」并生成新节点，本面板改的是「当前节点这一次的成像参数」。 因此按钮不进 hover 工具条（那里已经是摄影棚的地盘），只落在展开面板的参数行。
刻意不做：真实曝光/景深计算（预览只表达趋势）、自定义焦距输入（只给 8 档预设）、把参数写进节点卡片常驻展示（用角标数字表达即可）。
落地口径：预览 SVG 的颜色沿用参考包（它是「画面」，不是 UI chrome，不套 token）；弹层、下拉、按钮全部走 mockup-kit 的 --surface-* / --edge-* / --accent-* token。

「点了没意义」只有两类根因： ① 真冗余 —— 重复入口（两处撤销、三处缩放、走带与浮层）或展示性按钮（「时间轴」标题）→ 直接砍； ② 假禁用 —— 条件不满足就灰掉但不解释（分割、删除、工程 Tab）→ 要么 tooltip 说清为什么灰，要么放宽条件自动就近（播放头不在片段上就吸到最近边界）。 第二类比第一类更伤：用户会判定「这个功能坏了」。
另有一类「隐性无反馈」：轨道 flag（锁/隐/静音）和素材行单击 —— 状态变了但界面看不出来，等同于没点。修法见舞台 3 第 3、4 张卡。

顺手化清单（按优先级：先做 P0，编辑体验立刻变样）
P0 · 1 分割 = 唯一切开路径：先把播放头定位到切点（←→ 帧步进 / 吸附边界），按 S 切开选中片段；配吸附，Alt 临时关吸附。不做刀片工具模式——它与分割做同一件事，只是省了「先定位」这一步；而「先定位」恰好带来所见即所得（切之前就看到那一帧），且能精确到帧。留一条路径，用户不用先想「这次该用哪个」。
P0 · 2 删除二态：⌫ 留洞 / ⇧⌫ 波纹（后面片段整体前移），删完在头部显示「有 1 处空隙 · 闭合」。
P0 · 3 定位三件套：scrub 轨横向拖找大致位置 → 时间码输入 / 帧步进按钮精确卡点 → ⇧←→ 跳片段边界；空格 播放 · Home/End · I/O 设入出点。帧步进必须有真按钮——只写在快捷键文案里等于把最高频动作藏起来。
P0 · 4 缩放跟随指针（⌘滚轮）+ 播放时时间轴自动跟随播放头，别让用户手动追。
P0 · 5 选中即联动：点片段 → 播放头跳到片段起点、预览显示该段首帧；点素材 → 预览显示源素材。
P0 · 6 右栏只读信息折叠：片段详情折成一条摘要行（名称 + 时长 + 分辨率），入点/编码按需展开——选中时把最贵的位置让给「能改什么」。
P1 · 7 三点编辑：素材预览设 I/O → 插入 / 覆盖到播放头，比拖拽精确，长素材尤其明显。
P1 · 8 拖到轨道区空白自动建轨；跨轨拖动给落点指示线 + 目标轨高亮。
P1 · 9 框选 + ⇧/⌘ 多选，多选后给批量（音量 / 转场 / 删除 / 左对齐）；多选时右栏显示「已选 N + 可批量项 + 差异项标—（混合）」，否则多选只删 = 白做。
P1 · 10 抬头动作分组 + 导出收口：取消靠左（离开类），导出收成 主按钮 + 下拉——「导出为新节点」直达不进下拉（主链路不能多点一步），「导出到本地 / 当前帧为图片」挂在箭头下。语义相反的动作不相邻，且 primary 焦点不被三个同宽按钮稀释。
P1 · 11 轨道头右键：重命名 / 复制轨 / 上移下移 / 删除（替代「轨道高度」按钮）。
P2 · 12 导出前自检：分辨率/编码不一致、0 长度片段、无音频 → 导出前一条提示；进度分段可中断。
P2 · 13 自动保存：工程记录持久化（contentStore + STORAGE_KEYS 登记），重开恢复上次播放头与选中。
P2 · 14 预览代理：4K/长素材自动降分辨率预览，导出仍走原素材，防拖动卡顿。
一句话取舍：剪辑器的手感 = 「少一次定位 + 少一次确认」。 所有需要用户「先把播放头挪到正确位置再操作」的设计（分割、插入）都要么给直接操作的替代路径（拖入、框选、双击），要么让定位本身足够顺（吸附 + 帧步进 + 时间码输入）； 所有「点了但界面没变化」的控件（轨道 flag、素材行单击、只读属性）要么补反馈，要么砍掉。 其余锦上添花（降分辨率预览、自动保存）排在 P2，不影响首发可用。
另加一条信息分类规则（本项目追加）：同一个信息只出现在「用户需要它的那一刻」的地方。 只读信息（编码/入点）不进常态可见区（下沉导出对话框或折叠）；同一数值不在两处重复显示 （适配比例只在「适应 ▾」旁）；「离开」与「产出」两类动作必须分列两侧（取消靠左、导出族靠右）。

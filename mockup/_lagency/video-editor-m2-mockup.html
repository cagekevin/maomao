添加入口的语义（抬头「添加 ▾」）： ① 文字 —— 唯一凭空创建的素材：落在播放头、默认 3s、新建即选中（检查器直接打字）；时长在轨道上拖，不在面板里填秒数。 ② 贴图 · 画布图片节点 —— 列出画布上的图片节点，点选落叠加轨（不进主视频轨；M1「图片入主视频轨」的规则不变，叠加是显式动作）。 ③ 新建叠加轨 —— createTrack 是 M2 才暴露的原语（M1 只定义不实现）。
契约对齐 —— 每个新增件落到哪份数据 / 哪条 M1 纪律（M1 的 unknown 字段在 M2 收窄，只改类型、无数据迁移）
新增件 数据落点（core/types.ts） 说明
描边（文字） clip.textStyle.stroke = {width, color}（M2 新增字段；ClipKind 增 'text'） 宽度 0 = 无描边（新建默认就是 0），不设开关 —— 宽度即真相；预览与导出同走 renderFrameAt（C8），所见即所得
字号 / 颜色 / 字间距 / 对齐 clip.textStyle = {content, font, size, color, letterSpacing, align} 画布角柄直接映射字号（框高 = 字号）；行高暂不暴露（未圈定，加一行即可）
大小 / 位置 / 旋转 / 透明度 clip.transform = {scale, x, y, rotation, opacity}（M1 的 unknown 字段收窄） 文字 / 贴图 / 视频共用同一形状；预览 CSS transform 与导出 computeDrawRect 同源换算（C8.1）
取景（黑边） clip.transform.fit = 'contain' | 'cover' | 'stretch' 默认 contain（与 M1 行为一致）；needsCompositing 判据不变
动画（渐隐渐现 / 叠化） clip.transitionIn / transitionOut = {type: 'none' | 'fade', duration}（M1 的 unknown 字段收窄） 淡入 / 淡出作用在片段头尾；叠化 = 与前一段的接缝转场，同一份字段 —— 时间轴接缝圆点与动画 Tab 改的是同一个值，预览经 evaluateTransitionAlpha 同源换算
变速（仅视频） clip.speed = number | {start, mid, end}（M2 新增字段：数字 = 固定倍速；三值 = 曲线，段间线性插值） 只有视频片段有（文字 / 贴图动画 Tab 无此项）。变速改变片段时长（2x = 时长减半），轨道宽度实时变短； 变速片段必然走合成重编码（无法直通）；音调保持，变声不做
叠加轨 / 文字轨 Track.overlay: true（M1 已有的显式标记，M2 开始出现 overlay === true 的视频类轨） routeClipToTrack 判据不变；贴图 / 文字经显式动作进叠加 / 文字轨；自由轨保留自由时间位置（C1.2）
文字轨行高 紧凑行高常量（24px），不写进 ui.rowHeight ui.rowHeight 仍是视频 / 音频轨的单一出处（C7.5 不破）；文字轨是展示型轨道，固定紧凑
播放头 / 选中 project.playhead（M1 已有，单一真相源） 监视器 scrub / 走带 / 基座播放头同一值；选中片段在检查器与轨道光圈间联动
历史栈 整份 tracks 快照（C6 沿用） 拖动变换 = begin() 于 pointerdown、end() 于 pointerup —— 一次拖动一张快照
收起 = 整个工作台关掉（画布与顶栏恢复；工程随改随存，不丢）；M1 的按钮、轨道、状态条在 M2 打开 / 收起两个状态下逐像素一致 —— 这是本图的第一验收项。
本轮不做：文字阴影 / 背景框 / 气泡 · 更多动画预设（弹跳 / 打字机等）· 关键帧 · 音量包络曲线 · 任意控制点的速度曲线（本轮只做固定倍速 / 三点曲线）· 滤镜调色 · 多选批量变换 —— 全是「加字段 / 加面板分区」的填空，不动骨架与渲染管线。

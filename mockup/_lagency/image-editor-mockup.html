③ 扩图 Tab：选目标画幅 → 拉外扩量 → 原图居中内接、四周留白 → 拖原图微调位置 → 应用。 原图始终保持原始分辨率、不拉伸，只放大画布。
★ 补了「原比例」这一项（本仓库现行 5 项里没有）： 外部包 ASPECT_OPTIONS 首项是 original（保持原比例、只往外扩）， 本仓库 OUTPAINT_RATIOS 只有 5 个固定比例—— 想"原样加一圈白边"时选不出。已补为首项并设为默认。
填充色 = 纯白（维持现行 OUTPAINT_FILL）： 外部包用透明留白，因为它的产物要"垫图 → 送 AI 补全"，透明区是给模型的信号。 我们不接 AI、直接出一张图，透明底拿去当素材很容易出问题，所以保持白。
外扩上限维持 2 倍面积（factor ≤ √2）： 外部包 zoom ∈ [0.3, 1]，面积最多能扩到约 11 倍； 本仓库保守得多。滑杆标注「面积最多 2 倍」，超出需求请走裁剪 + 生图节点。
外部包 → 本仓库 差异总表
组织：三个独立编辑器 → 一个壳三 Tab（三者都是一进一出，共用底图/撤销栈）
宫格裁剪：CustomGridEditor → 不做（与 GridSplitNode 重叠，且一进多出不同构）
裁剪模式：矩形 + 钢笔 → 矩形（现行）+ 钢笔（P1 新增）
扩图画幅：6 项含原比例 → 5 项（现）+ 原比例（已补）
扩图填充：透明 → 纯白（不接 AI，直接出图）
扩图倍率：面积 ≤ 11 倍 → 面积 ≤ 2 倍（维持现行）
视口手势：useImageViewportGesture（滚轮缩放 + 空格/中键平移）→ 沿用
结果去向：垫图 + meta 送 AI → 一张 PNG 覆盖本节点（规范 §3.2）
依赖与落地
已有：react-image-crop（矩形裁剪已在用）、原生 canvas（涂鸦/扩图已在用）
新增：钢笔裁剪 PenCropLayer（约 12KB，纯 SVG + canvas，无新依赖）
不需要：framer-motion（外包 FullscreenOverlay 用，本仓库已有 FullscreenModal）
不需要：@iconify/react（本仓库统一 lucide-react）
不需要：模型选择 / prompt / provider（不接 AI，用户自己决定后续）

保留① 涂鸦 Tab：9 个工具（画笔/橡皮/文字/直线/箭头/方框/圆框/编号/吸管），与旧版 1:1。 工具条是 HoverToolbar 那套胶囊风格（rounded-full + bg-surface-1 + border-edge），选中态蓝色实心。 颜色/粗细走规范 §二 的「颜色选择 + 滑块」，不新增控件形态。
本次改动：初始绘制源改为 compressImage(url,{keepOriginalFormat:true}) 的同源 dataURL → 画布永不被污染，toDataURL 永不抛 SecurityError； 吸管 getImageData 补 try/catch（旧实现裸调会崩整个编辑器）。
画布区必须标 nodrag，否则拖笔会误拖节点。

替换② 裁剪 Tab：只做一件事 —— 缩小画面范围。选区框 + 三分线 + 8 手柄 + 比例胶囊 + 实时尺寸。
与扩图分开的理由：裁剪目标是「减画面、提主体」，交互是选区（遮罩压暗外部）； 扩图目标是「留白给 AI」，交互是拖画幅边（外部斜线纹）。二者心智相反，塞进一个 Tab 会让同一组手柄一会儿出遮罩一会儿出白边，容易误操作。
实现要点：裁剪 = 新建游离 canvas + drawImage(源, -x, -y)，禁止 getImageData + 就地改活画布；保存回传 {dataUrl,width,height} → 节点 fitByRatio 跟随。

新增③ 扩图 Tab：画幅往外扩 = 补白边，白区用斜线纹明确「留给 AI 填」。 四边/四角手柄拖动画幅；原图在画幅内自由拖动定位（居中吸附 + 三分线）——原图位置决定 AI 往哪延伸，是核心功能。
统一模型（与裁剪同构、方向相反）：结果画布 tw × th，原图贴入 (dx,dy)； 扩图 dx,dy ≥ 0，裁剪 dx,dy ≤ 0 —— 同一行 ctx.drawImage(img,dx,dy) 覆盖两种情形，原图恒 1:1 自然像素，画质零劣化。
★ fitZoom：画幅一变必须重算缩放并居中，否则白边被顶到视口外看不见、拖不动（旧实现缺这步，是白边“看不见”的主因）。
约束：白边纯白 #ffffff（灰度过噪点会干扰下一步 AI 识别待填区）；输出 PNG 无损，禁止 JPEG；不做扩展滑块（拖边已替代）、不做 shimmer / A-B 对比 / 重新生成。

① 左栏拆掉 Tab，改成上下两段常驻。「场景层级」和「镜头」在线上版是同一个位置的 Tab， 这意味着切镜头时看不见场景里有什么、看场景时不知道有几个镜头——而这两者在导演工作里必须对照着看。 按纪律「导航必须常驻、不随选中变化」，改成上段对象、下段镜头，两段同时可见。
② 视口浮层：四角分工 + 顶中两层。线上版 reference-panel 与 path-panel 同为「顶部居中」，同时出现必然重叠。改后：顶中分两层（工具条在上、条件浮层在下）、 右上「视图面板」、左下监视器、右下轴圈——五个位置互不侵占。 参考图 / 路径 / 镜头角度这类条件浮层落在顶中第二层，垂直堆叠（见舞台 2.5 C）。
③ 视图开关从右栏下沉，与视角切换合成右上角「视图面板」。 「显示网格 / 性能模式 / 无缝背景」是视图开关，线上版放在右栏「全局设置 › 视口」里—— 要先取消选中对象、再滚到视口区才够得着。它们和「编辑视角 / 摄像机视角」同属视图族， 按「同类相邻」合成一个面板：上行切视角、下行切显示。右栏因此少了一整个分区。
④ 右下角是轴圈（ViewCube）的位置，任何浮层都不许占。 线上版 SceneGizmo 用 Hud 渲染在距右 72px / 距底 40px、约 120px 见方， 是「点击轴头跳转标准视角」的导航件。右下是 Blender / Unity / Maya 的通用约定位， 占掉它等于废掉一种不看菜单就能转正视角的方式。 三轴着色沿用线上既有值 X #e5484d / Y #46a758 / Z #3e63dd，右栏变换滑杆的轴标同色—— 轴圈、变换滑杆、监视器三处看到的三轴颜色必须一致。
④ 右栏按频率排：变换置顶，全局设置收起。线上版未选中时右栏被低频的「工程设置」占满， 选中后变换才出现。改后变换恒在最顶（锚点不动），类型专属区其次，全局设置收起为一行摘要 24 FPS · 15 秒 · 16:9。
⑤ 时间轴：「加关键帧」贴回轨道头。线上版三个加关键帧按钮挤在右下角第三列，离它们作用的轨道很远； 改成每条轨道头一个 +，右下只留吸附与缩放（两者都是时间轴自身的视图参数）。
⑥ 删掉的重复入口：监视器头部与「视角工具」里的两处「切换到摄像机视角」（保留视角工具那处，它是视图态； 监视器只留选中 / 最小化 / 放大）；工具条里的「上传背景图」（是文件导入不是工具，随参考图面板走）。
⑦ 「初始化」保留在 topbar，不做下沉。它是工程文件操作，topbar 是这类操作的惯例位置，藏进面板反而更难找、也更危险。 改为用 danger 样式与「打开 / 保存」区分，并强制二次确认后才执行（确认框见舞台 2.5 F）。 全应用只此一处入口，全局设置里不再重复。
⑧ 摄像机没有「锁定 / 复制 / 删除」。线上版 Inspector 的头部按钮对摄像机只渲染「视图聚焦」一项 （其余三项是 仅非摄像机）——这一点容易在实现时被误加成四个按钮，此处明确标注。

监视器最小化态：只剩标题条 + 一个恢复按钮。
人物分支的折叠组重排：线上版 4 个折叠组是「人物（展开）→ 动作库（收起 27 个）→ 完整骨骼（收起 60 关节）→ 我的姿势（展开）」。 问题在于「动作库」和「我的姿势」是同一个东西的两面（预设姿势 vs 自定义姿势），却一前一后夹着一个低频的骨骼组。 合并为单一「姿势」区：常用的「我的」在上、预设库在下；「完整骨骼」降为收起态放到最后，它是高级功能，不该占第二屏。
变换区的 XYZ 三轴着色沿用线上既有值（X #e5484d / Y #46a758 / Z #3e63dd）， 与右下角轴圈、监视器三处保持一致。缩放组补回了线上版的两个细节：「等比」开关和每轴独立锁定。
未选中时右栏只留「工程 + 光照」：「视口」三个开关已挪到视口右上角（见舞台 2 注 ③），这里不再重复； 「初始化」回到 topbar（注 ⑦），全局设置里也不再放一份。
镜头卡片的操作按钮改为 hover / 当前项才出现：三条镜头常驻摆 9 个图标按钮，会把 196px 的左栏挤成一条按钮带。 列表项的操作按需出现是专业软件的常规做法。同时删掉了元信息里的「24 FPS」——FPS 是工程级属性， 每个镜头重复一遍是冗余，改呈现为「15 秒 · 3 关键帧」。
D / E / F 补的是「形态」不是「控件」：物体形态（全形态里最单薄的一种，用来验证骨架不塌）、 资源库级联菜单展开态（topbar 最重的交互）、以及导出进度 / 确认 / Toast / 监视器最小化这四个瞬时浮层—— 它们不常驻，但出现时必须有确定位置，否则实现阶段会临时拍脑袋。

这套"直接用"意味着什么（要一起带走的 4 件东西）：
1. 两个 CSS + 令牌三件套，一个都不能少。它们的 css 全篇只写 var(--af-*)，没有一个字面色值 —— 只搬 css 不搬 themeTokens.ts 的令牌，整块 UI 会变成无色。
2. 令牌只有 dark / light 两套固定值，没有"映射到猫猫 tailwind token"的可能性 —— 要用这套样式，等于在 --mao-* 之外并存第二套主题变量（或做一次全量 1:1 映射表）。这是采用它的主要代价，得你认。
3. 色系确实不同：它的底是 #050505 / 面板 #1a1a1a / 边框 #343434、强调色是 #60a5fa + --af-primary:#f2f2f2（主按钮是白底黑字）；猫猫是 --mao-* + 蓝色主按钮。并排看能看出是两套皮肤。
4. MJ 面板脱壳：它是 1000×680 的独立弹窗，要嵌进 760 卡片必须去掉自身 width/height/border/radius/shadow（.mj-inline 7 条）。
收藏不做：原版有 .af-creative-star（卡片右上）与 ★收藏 分类，本 mockup 都没渲染；连带 POST /api/prompts/creative-library 的 favorites 也不要。

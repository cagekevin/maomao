# 技能变更记录（changelog）

**规则**：任何对技能自身文件（`SKILL.md` / `references/` / `scripts/`）的修改，都要在这里记一笔——**改前记意图，改后补结果**。

**字段**：`版本 / 日期 / 改动 / 依据 / 回滚点`
- **依据**：触发这次改动的 lesson ID，或来源说明。没有依据的改动 = 拍脑袋，先别改。
- **回滚点**：改坏了一键还原的动作（删哪段 / 还原哪个文件）。**禁止删除 `.codebuddy` 目录内容**，回滚只做"撤销本次改动"。

**版本约定**：`major.minor.patch` —— 新增/改机制 = minor；修错别字/补一行 = patch；重构结构 = major。

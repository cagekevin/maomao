# 产出物模板（填充用）

> 本文件只放**可直接套用的填充块**；元数据规则的说明见 `SKILL.md`「产出物元数据规范」。

---

## 一、文档头元数据模板（每个 `0X-*.md` 开头套用）

```markdown
> **目标项目**：<repo 名 / 路径>  |  **commit**：<hash>  |  **逆向日期**：<YYYY-MM-DD>
> **覆盖度**：覆盖 X/Y 个文件（Z%）；跳过：<清单 + 原因>；未覆盖：<清单 + 原因>
> **置信度说明**：文中 `[确证]` = 有源码行号；`[推断]` = 逻辑推理；`[待验证]` = 需运行核对
```

**结论标注格式**：
```
call_llm 默认 timeout=600 [确证 llm_service.py:214]
视频队列并发度约 3 [推断，基于 3 个 worker 启动]
真实 prompt 是否含运行时拼接 [待验证，需抓日志]
```

## 五、采样策略（大项目：> 约 50 个 service 文件）

- **按桶分层抽样**：每个桶至少抽 1 个最大文件精读，其余走"入口函数 + 关键路径"快读
- **子代理并行**：按桶把挖掘任务分派给子代理，主上下文只收结论（避免被撑爆）
- **记录抽样比例**：在覆盖度声明里注明"抽样而非全覆盖"，并列出未精读的文件

# 形状收口手术（执行方）

> **读者：改代码的人。**
> 配套 `架构师改码7步法.md`（全集）。冲突以全集为准。
> 这份只留**方法闭环 + 判据 + 操作骨架 + 验收**。论证与反例已剥离，判据原样保留。
> **只写「要求 AI 做什么」**：仓里有多少个形状、哪些债已还、哪个文件第几行有什么 —— 一律自己从代码数，本文件不复述（复述 = 会过期的副本；本文件已因此删掉一整段旧结论）。

## 这是什么（一句话）

把 **N 份混乱收成 1 份秩序**，而秩序只能按一条链子收：

```
        原语 ──产出──▶ 形状 ──被约束──▶ 契约 ──被验证──▶ 数据流
         ▲                                                    │
         └──────────────── 回环复核（少了这段就是开环）◀──────┘
```

- **原语**：一件事只有一种底层做法（读一次 / 判一次 / 写一次 / 解析一个字段）。
- **形状**：原语交出来的东西长什么样；坏了以后**还能不能取到值**。
- **契约**：形状之间怎么连 —— 谁登记、谁唯一、字段叫什么、构造只许在哪。
- **数据流**：数据**真的**是这么流的吗 —— 从入口追到落点，中间有没有丢字段、旁路、旧路。

七步法管「改对」，这套管「改得完」。**改得完 = 四环闭合**，不是「把形状改整齐了」。

## 为什么必须是闭环（断一环，两周后必退回 N 份）

| 断在哪 | 你会看到的现象 | 真正缺的环 | 只补这一环的后果 |
| --- | --- | --- | --- |
| 有形状、没原语 | 每个调用点自己拼同一个字面量 | 原语 | 工厂建了，底层还是 N 份实现 |
| 有原语、没形状 | 失败靠返回值猜；`catch {}` 遍地 | 形状 | 底层统一了，上层照样吞 |
| 有形状、没契约 | 两种写法都能跑、都过测 | 契约 | 形状对，写法散 |
| 有契约、没数据流 | 层间重包丢字段；旧路没删；死代码 | 数据流 | 接口齐了，链路仍断 |
| 数据流跑完不回环 | 调用点数没降，只是换了个人写 | 回环 | 「收口」后原语数不变 = 没做 |

**闭环判据一句话**：四环里**任何一环**你能给不出 N→1 的数 ⇒ 这轮没收口，别报。

## 四条母判据（跨环，先记这四条）

| # | 判据 | 一句话 |
| --- | --- | --- |
| 1 | **层数 = 形状数 = 入口数** | 三个数对不上 ⇒ 有层在兼职。 |
| 2 | **失败在类型上取不到值** | 坏了就拿不到值；失败那一臂上不许有 `.value` / `.data` / `.groups`。 |
| 3 | **一个函数只干一件事** | 兜底 / 归一化 与 判断好坏 同函数 ⇒ 必拆。 |
| 4 | **合法不是理由** | 两种写法都能跑、都过测照样是债；判据是「**这个概念还能不能写出第二种样子**」。 |

**唯一可以不收的三种情况**（其余「合法 / 历史 / 麻烦」都不算）：

| 可以留 | 判据 |
| --- | --- |
| 不同语义 | 名字相同但答不同问题 ⇒ 必须在文件头写明区别，否则下一个人当成一回事 |
| 外部形状 | DOM / Node / 宿主 / 插件 API 给的签名，改不了 |
| 跨进程边界 | 已发布的序列化格式、前后端字符串契约（`CLAUDE.md §5.7`）不能动 |

# 环 1 · 原语：一件事只有一种底层做法

**判据**：同一语义的**底层实现** ≥ 2 处 ⇒ 该收（`CLAUDE.md §5.4.9` 单一规则原则）。
判据的前置条件：**已经漂移过一次**才算该收；没漂移的先登记，别为整齐而收。

**本仓原语的现成先例**（新增同类能力必须挂上去，禁止再写第二套）：

| 语义 | 唯一实现 | 禁写什么 |
| --- | --- | --- |
| 媒体判型 | `base/utils/media/assetType.ts`（一张 `EXT_KIND` 表派生全部 `isX/detectX`） | 各节点自己 `url.endsWith('.mp4')` |
| node.data 写回 | `useNodeData` / `useNodeField` | 组件里直接 `node.data.x = y` 再 `setNodes` |
| 图像入节点落盘降级 | `filesApi`（`resolveNodeImageUrl` / `showThenPersistInline`，统一降级=落盘失败回退内联） | 再写一套 try/catch 兜底 |
| 存储读写 | `base/core/contentStore.ts` + `contracts.ts` 的 `STORAGE_KEYS` | 裸字符串 key |
| 事件发布 | `base/core/eventBus` + `contracts.ts` 的 `EVENTS` | 裸字符串事件名 |

## P1 · 数原语（不是数调用图）

表：`语义 / 底层实现文件 / 调用点数 / 是否已漂移`。
**硬规矩**：数字现数，只认代码。`daily/架构日志/` 是过程日志（写的时候对、之后必漂），不当依据、不引它的数。用过的口径命令写进本轮轮次文件；不许重画。

## P2 · 拆混装（原刀 5）

兜底 / 归一化 与 判断好坏 同函数 ⇒ 必拆。判据：这个函数能不能被两个不同意图的调用方复用？不能 ⇒ 它在兼职。

## P3 · 净减兜底（原刀 4）

**判据是数量净减（X → Y，Y < X），不是「症状消失」。**

| 破口形态 | 长相 | 处置 |
| --- | --- | --- |
| 静默吞 | `catch {}` · 空 catch | 删；改抛 / 告警 / 带观测字段 |
| 失败归一空值 | 返回 `[]` / `{}` / `null` | 改判别联合的失败臂（带码 + 现场） |
| 占位对象 + 事后补 | 先塞空等回调 | 一次性拿真值再入状态 |
| 默认值兜底 | `?? 默认值` 掩缺失字段 | 缺失要**看得见** |
| UI 层提前宣告成功 | 点了就显「已保存」 | 改「处理中 → 成功 / 失败」两态 |
| 只在一入口补的补偿 | 某页多调一步才看得到 | 补偿收进唯一入口，删调用点补丁 |

- **共同判据**：读可降级但必须标记；写不可降级必须抛。
- **两条例外（必须先裁定，否则 P3 会被执行成一律抛）**：
  - 文件/资源本不存在（`ENOENT` / `notSeen`）⇒ 正常态，给默认，**不抛、不算降级**。
  - 回滚 / 清理路径（导入回滚、回收站、日志 dump、写前读本地）⇒ 允许尽力而为：不抛、跳过、`log` 留痕，但**不许返回业务值**；每处文件头写清为何可不抛。

**本环产出**：原语处数 N → 1、兜底数 X → Y、混装函数数 N → 0。

# 环 2 · 形状：原语交出什么

**判据**：**失败在类型上取不到值**；判别位唯一；`?` 就是第二个形状。

## S1 · 数形状（原刀 0）

三张表，缺一张不许动手：

- **表 A 形状清单**：形状名 / 判别位 / 失败表达 / 生产函数 / 消费点数
- **表 B 入口清单**：入口名 / 谁在用 / 有无守卫 / 能否绕过判据
- **表 C 判别语法**：`grep -rn "\.status\b\|\.ok\b\|\.value\b\|\.data\b" src/` —— 去重后的**种数**，不是行数

**硬判据**：判别语法 > 1 种 ⇒ 一定还有形状没收（`ok` / `status` / `success` / `error` 并存就是 4 种）。

## S2 · 砍可忽略字段 + 砍自由文本（原刀 2、3）

| 形态 | 长相 | 为什么是吞 |
| --- | --- | --- |
| 裸 `ok` + 空值 | `{ ok; stars: {} }` | `{}` 同表「没有」和「读不到」 |
| 裸 `degraded` | `{ value; degraded: string }` | 空串正常非空坏，但 `.value` 永远可取 |
| 裸 `note` | `{ groups: []; note }` | 同上 |
| 自由文本当码 | `{ code: '台账顶层不是对象' }` | 码位写人话 ⇒ 不可穷举、不可测，人话归文案位 |

**中文只有两个合法位置**（本仓注释全中文，这条**只管「会被用户看到的字符串」**，不是禁中文注释）：

| 位置 | 判据 | 例 |
| --- | --- | --- |
| 文案常量 / 登记表 | 最终出现在界面 / toast / 失败提示 | 从常量取，不在数据层造句 |
| **开发者断言**（不上 UI） | 读者是写代码的人：注入缺失、装配顺序、mock 拒绝参数、环境不支持 | `throw new Error('extractImageColors: image 源需要注入 createCanvas')` |

最典型的违规是**数据层自己造句**：`return { status: 'error', code: 'CORRUPT', reason: '字体设置不是对象' }` —— 既不是常量（改文案要动逻辑），也不是断言（用户会看到）。
**判据一句话**：这段中文的**读者是谁**？写代码的人 ⇒ 断言可留；用户 ⇒ 必须来自常量；两者都不是 ⇒ 它在掩盖一个该被分类的失败。

## S3 · `?` 拆两臂（原刀 11）

失败臂 `xxx?:` ⇒ 没分类，下游两种写法都编译。收法：拆两臂用子码当判别位；字段从 `?` 变必填那一刻，编译器列出全部绕过字面量（= 环 3 的 C3 入口）。读可选字段前**必须判子码**。

**本环产出**：形状份数 N → 1、判别位种数 → 1、可忽略字段 N → 0、可选失败字段 N → 0。

# 环 3 · 契约：形状之间怎么连

**判据**：**层数 = 形状数 = 入口数**；一个概念一个名字；构造点唯一。

## C1 · 分四层 + 收路（原刀 1、6）

**按职责分，不按文件分**：

| 层 | 职责 | 知道 | 不知道 |
| --- | --- | --- | --- |
| ① 观测 | 外部 → 三态 | 在不在 / 读得到 / 字节 | 内容对不对 |
| ② 判据 | 折成**结论** | 能不能用 / 坏因 | 用户看什么话 |
| ③ 纯解析 | 不可信 → 可信 | 哪个字段不对 | 文件在不在 |
| ④ 业务结论 | 业务判断 | 域特有三态 | 通用读细节 |

**分层判据**：问「失败说不出原因会不会伤人」。① 可（只报 errno），②③④ 不可。
**处置**：① 只许两个（文本 / 字节）；② 只许一个入口 + 一个形状；③ 只许一个契约，不许 `null`、不许 `throw`；④ 必有判别位、不许可忽略字段。

**本仓分层对齐**（同一件事只在一层落地，别跨层兼职）：

| 本仓位置 | 对应层 | 只许 |
| --- | --- | --- |
| `base/utils/` 纯函数 | ③④ | 纯逻辑 + 单测，不碰 React、不碰 DOM |
| `base/core/`（contracts / contentStore / eventBus） | ①② | 登记表与唯一入口，不放业务判断 |
| hooks（`useNodeData` / `useNodeGeneration`） | ②③ | 状态与写回，不放 UI 文案 |
| `components/<域>/` | ④ | 只消费形状，不自己造形状 |

**收路五手段**：入口数 = 层数；路径守卫方向互斥；原语消费者收窄到底座；必填参数（不给就调不了）；`| null` 从契约删掉（「失败说不出原因」编译不过）。

**做不到** ⇒ 退到 F3 二档（文件头写清用法 + 抄不错），不许宣称做到结构。

## C2 · 一个概念一个名字（原刀 10）

先数字段名去重，按概念分表，**各只一个名字 —— 一个名字只装一种语义**：

| 概念 | 只许 | 里面只放 | 常见错名 |
| --- | --- | --- | --- |
| 判别位（是什么） | 一个 | 字面量联合（`'ok' \| 'error'` / `ErrorKind`） | `kind` · `type` · `status` 并存 |
| 失败码（为什么失败） | 一个 | 可穷举的码（`src/types/errors.ts` 的 `ErrorKind` 是范例） | `code` · `fail` · `issue` · `why` 并存 |
| 用户文案（给人看） | 一个 | 可直接展示的一句话（一律从常量取） | `message` · `text` · `note` · `msg` 并存 |
| 机器现场 / 底层原文 | 一个 | `HTTP 403` / errno / 字段期望实际 / 宿主原话；必填，无观测时为空串 | 塞进文案位；或另起 `cause` / `error` 字段 |

- **判据一句话**：同一名字不许同时装「给人看的话」和「给机器看的原文」（典型：文案位里既放中文又放 `HTTP 403`）。
- 选名取**引用数多数派**；一个名字装两种语义 ⇒ 拆成两个名字，各只一份。
- **登记表优先于约定**：跨模块共享的字符串（存储键 / 事件名 / 模型别名）必须进 `contracts.ts`，由 `npm run check:keys` / `check:events` 静态拦截（`CLAUDE.md §5.4.5/6`）。

## C3 · 构造点唯一 + 工厂四条件（原刀 12）

这个形状的字面量 `{ status:'error', … }` 出现在**几个文件**？1 个（= 唯一构造点/工厂）= 收口；>1 个文件 = 绕过。
> 数**文件**不是数字面量：两臂形状在工厂里必然有两个字面量，那是构造函数的实现，不是绕过。

收法（唯一有效顺序）：先加必填字段（S3）→ 编译器逼出 → 补字段或改调构造函数。**不许用 grep 定范围**（混进别的类型），只用 `npm run type-check` 报错列表。

**工厂要成立，四条必须满足**（缺一条就退化成搬运）：

| # | 判据 | 违反长什么样 |
| --- | --- | --- |
| 1 | 形状只许在工厂里出现，别处一个字面量都没有 | 调用点手搓 `{ status:'error', … }` |
| 2 | 每个参数是一个语义槽，不是 `any` / `unknown` / 整块 payload 透传 | `fail(code, reason, rest)` 里 `rest` 随便塞（等于把形状透传回来了） |
| 3 | 一种语义一个工厂，不许用一个工厂 + 可选参数兼职两种 | `fail(code, reason?, detail?)` —— 两个都可选 ⇒ 两种写法又回来了 |
| 4 | 工厂不吞字段：源形状有 5 个字段，参数就得能表达 5 个 | 工厂只收 3 个，另 2 个在调用点被丢掉 |

**判据一句话**：**把工厂的参数名连起来读，能不能当这个失败的说明书？** 能 ⇒ 是工厂；只能读出「码 + 一堆东西」⇒ 是搬运。
**识别特征**：工厂建好之后，全仓还能 grep 到**同形状**的字面量落在别的文件 ⇒ 绕过还在（工厂有了、调用点没走）。

**本环产出**：层数 = 形状数 = 入口数（三数对上）、字段名种数 → 每概念 1、构造点文件数 → 1。

# 环 4 · 数据流：数据真的这样流吗

**判据**：**每条流能从入口追到落点，中间不丢字段、不旁路、不留旧路。**

本仓标准工具（先用现成的，别手工发明流程）：

| 要回答 | 命令 |
| --- | --- |
| 谁消费这个文件 / 改它会影响谁 | `node scripts/mv-sync-refs.mjs refs <file>` |
| 有没有越层 / 循环依赖 | `npm run check:arch` |
| 这条链路权威记录在哪 | `spec/DATAFLOW.md`（改了链路必须同步） |
| 死的还是活的 | `refs` 0 引用且非入口 ⇒ 死 |

## F1 · 一次替换：删旧实现（原刀 7）

同次改动必须删掉被替代的旧实现。只加不删 ⇒ 旧路还在、新结构是死代码；删了没改调用点 ⇒ 编译红（好事）。
标准：**diff 有删除行**。

**删字段也算删实现。** 字段消失后真正的活是三件：① 编译器列出全部读点（白送）② 读点改成从失败臂 / 现场字段取 ③ 它占着的**文案键与旧概念名参数**一起清（0 使用的死键）。
判据：**grep 那个概念名，还有活着的引用吗？** 有 ⇒ 只删了类型，没删实现。

## F2 · 同步化与错误通道同批换（原刀 8）

只换同步方式不换错误通道 = 用静默吞换锁。一次改动里「怎么写」和「失败怎么上抛」必须同批落地，不许分批。

## F3 · 焊死 + 重包逐字段（原刀 9、14）

**两个档位，都算达标。** 达不到一档就退二档，**不许把二档说成一档**。

- **一档（首选）：结构上不可能** —— 违规**写不出来**。
  手段：不导出内部实现；只给窄接口（字面量联合）；类型层挡住（无 `| null`）；`import` 边界拦（`no-restricted-imports` / `check-arch`）；漏改即编译失败。
  判据：**删掉注释和文档，违规还写得出来吗？** 写不出来 ⇒ 一档。

- **二档（退到这，算达标）：「抄不错」** —— 结构挡不住（TS 表达不了新文件里的字段名 / 要留实现级导出 / 跨进程边界），
  就退到「**仓里只有一种写法可抄**」：字面量收进唯一工厂（C3）+ 文件头四段 + 样板收尾（每域指定唯一范本文件）。
  文件头块注释四段：`// 是什么` / `// 唯一入口` / `// 谁在用` / `// 禁止什么`（少一段 = 没声明；只写现在是什么形状、为什么这样）。
  判据：**删掉样板和注释，仓里同类写法还剩几种可抄？= 1 ⇒ 达标；> 1 ⇒ 没做。**

  | 档 | 门槛 | 能做到吗 |
  | --- | --- | --- |
  | 一档 | **写不出来** | 常常做不到（TS 管不了新文件里的字段名） |
  | 二档 | **抄不到错的** | 总能做到（删到只剩一处就行） |

  ⇒ **「他写不错」做不到，「他抄不错」必须做到。** 只交一档不交二档 = 没做；只交二档不交一档 = 合格，但要写明是哪几条退的。

- **⛔ 禁止用闸替代结构**：一档做不到就拿闸顶上（新 lint 规则 / `check` 步骤 / grep 断言 / 「必须遵守」条目）—— 那只是把「写不出来」换成「有人检查」，下一个人照抄的仍是两种。
  闸只当**证据**用（单测 / `node scripts/probe.mjs` 探针，见七步法 `Step 7.1`），不当收口手段（`ADR-0004` 结构优先于文档）。

**重包形状 = 重新声明全部字段**：从另一个失败重建形状 ⇒ 源字段全带过去。能透传就 `return read`（只换 payload 类型）；不能就逐字段显式列全。
判据：每个重包点能说清「故意丢了哪个字段、为什么」，说不出就是漏。

**本环产出**：入口→落点可追条数 = 全部、重包丢字段数 → 0、旧路残留数 → 0、diff 有删除行。

---

# 回环：F3 之后必须重数 P1

**这是「闭环」和「开环」的唯一区别。**

新拆出的失败臂 / 新建的构造函数 / 新指定的唯一入口，都要回环 1 再数一次：

- 原语实现处数**真的**降了吗？（N → 1，不是「N 处都改成调同一个新包装，而包装里还是 N 份」）
- 兜底数真的净减了吗？（不是从 `catch {}` 换成 `?? ''`）
- 有没有因为这次收口**新长出一个**形状 / 入口？（长出来 ⇒ 回到环 2 重数）

判据一句话：**收口后的数字必须比收口前少，且减少的是「处数」不是「行数」。**

## 开工前置：0 号前提 + 十二个量 + 一件凭据

**0 号前提（域锁定，决定后面的数能不能成立）**

- 同一棵树同时只许一个写入者。
- 开工第一行声明占用：`本次只动：<目录 / 文件清单>`。
- 别人在动的文件不许碰。
- 在途半态禁止：改了形状不跟消费点，哪怕剩 1 处也要当轮跟完。

**十二个量（四环各三个；只报其中一环就开始动手 ⇒ 那一环对、另外三环散）**

| 环 | # | 必须报 | 怎么数 |
| --- | --- | --- | --- |
| 原语 | 1 | 同一语义的实现处数 | 表：语义 / 实现文件 / 调用点数 / 是否已漂移 |
| 原语 | 2 | 兜底处数 | 六种形态逐条数（P3 表），给 X |
| 原语 | 3 | 混装函数数 | 既兜底/归一化 又判好坏的函数 |
| 形状 | 4 | 形状份数 | 表 A：形状名 / 判别位 / 失败表达 / 生产函数 / 消费点数 |
| 形状 | 5 | 判别语法种数 | 表 C：去重后的种数，不是行数 |
| 形状 | 6 | 可忽略字段 + 可选失败字段数 | 失败臂上还能取到的值；带 `?` 的字段数 |
| 契约 | 7 | 层数 / 入口数 | 四层各归谁；对不上点名哪层兼职 |
| 契约 | 8 | 字段名种数 | 每概念一个数字 + 逐名列出 |
| 契约 | 9 | 构造点文件数 | 形状字面量落在几个文件 |
| 数据流 | 10 | 入口→落点可追条数 | 每条流能否 `refs` 追通；断在哪一段 |
| 数据流 | 11 | 重包丢字段数 | 每个重包点丢了哪个字段、为什么 |
| 数据流 | 12 | 旧路残留数 | 被替代实现是否删净；grep 旧概念名还有几个活引用 |

**凭据（第十件不是数）**：哪一处会红 —— 单测 / `node scripts/probe.mjs` 探针 / 临时断言，三选一。
**落点**：十二个量 + 凭据写进轮次文件（`daily/架构日志/<NN>-*.md`）。没落盘 = 没数。

## 收口顺序（不可跳环，也不可乱序）

```
P1 数原语 → P2 拆混装 → P3 净减兜底
   → S1 数形状 → S2 砍字段/砍造句 → S3 `?` 拆两臂
      → C1 分四层+收路 → C2 一个概念一个名字 → C3 构造点唯一
         → F1 删旧路 → F2 同步+通道同批 → F3 焊死/逐字段
            → 回环重数 P1（数字必须更少）
```

**为什么不可乱序**：先做 C 再做 P，会把「N 份实现」包进一个漂亮接口里 —— 形状对了，原语还是 N 份，等于给债刷漆。

---

## 收口验收：四环各给 N → 1 + 五个净减

答不出数 ⇒ 没做。每条贴命令 + 改前改后数字。

```
—— 环 1 原语 ——
同一语义实现处数      N → 1
兜底处数              X → Y（Y < X）
混装函数数            N → 0

—— 环 2 形状 ——
形状份数              N → 1
判别位名字种数        1
可忽略字段            3 → 0
可选失败字段数        N → 0

—— 环 3 契约 ——
层数 = 形状数 = 入口数  三数对上，兼职点名
每概念字段名种数       N → 1
形状字面量构造点      N → 1（只剩构造函数）
登记表外裸字符串        N → 0（check:keys / check:events 绿）

—— 环 4 数据流 ——
入口→落点可追条数      全部可追
重包丢失字段          N → 0
旧路残留              N → 0
diff 里的删除行        有

—— 净减与代价 ——
新增闸数量            0（禁）
约定条数              X → Y（写成注释/文档才算约定）
做不到结构的条目      已退二档（抄不错），逐条点名 + 哪几条退的
回环复检              原语数确实更少（不是只换了包装）
```

**任何一环答不出「N → 1」一律按没收口算。**

**口径自检（先做，再报数）**：每个数字写清「分子 / 分母 / 口径命令」。**判据本身可以是错的**，本仓已证伪三处（改卷可以，但不许为凑 0 把合法的收掉）：

| 被证伪 | 为什么错 |
| --- | --- |
| 「grep 命中 0」 | 失败臂与失败记录**本该**带原因。真目标是「成功臂上 0」 |
| 「字段名种数 1」 | 判别位与失败子码是两回事；并成一个会让子码顶替判别位，两种失败同形 |
| 「处数 = 该迁数」 | 解码实现、判据层、唯一通道也是解析点，**不该迁**。真目标是「每处能说出它属哪一类」 |

## 七种偷懒信号（出现任意一条，本轮作废重来）

1. 只给「做法」不给数（没数就没有 N→1）。
2. 用「我判断 / 我认为」代替证据（判断不是判据）。
3. 拿别处结论当本处理由（别处 0 处 ≠ 本处合理）。
4. **只做一环就报收口**（形状整齐 ≠ 闭环；要交四环数字 + 回环复检）。
5. 「它是合法的」（合法只说明不报错，不说明不会被照抄）。
6. 「先收形状，写法以后再说」（写法不收 ⇒ 两周后又变 N 份）。
7. 用脚本做语义改写（`sed`/`perl` 一次扫全仓 ⇒ 业务载荷 / 字符串 / mock 协议一起改且全绿，错被静默固化）。

   Segoe UI 有真 Semibold ⇒ 任务中心 600 就是 600。
3. **字号/行高**：settings 正文 13px / 1.55（20.2px）；任务中心 11–12px / 1.2–1.4（13–17px）
   （`tailwind.config.ts:143-151` 档位：caption 10px / caption-sm 11px / body-xs 12px / body-sm 13px / base-sm 15px）。
4. **颜色层级**：settings 基准 `--st-text-3`=#aaaaaa、说明 `--st-text-4`=#767676；
   任务中心主力 text-white #fff / text-body #cecece，说明 #676767 ⇒ 任务中心整体更亮。

附带：`-webkit-font-smoothing: antialiased`（settings.css:152）**只在 macOS 生效**，Windows 失效 —— 跨平台观感差异的第二个来源。

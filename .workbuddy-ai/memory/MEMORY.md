## 二·五 · 生成预算真源（143 · 后端持真相）

- **唯一真源 = `localTool/src/budget.ts`**（`DEFAULT_BUDGET_MS` + `budgetMsFor(capability, override?)`）。**前端只读不硬编码**（规划 §2.2：消费者不许替生产者定真相）。
- 三值口径：`chat 180_000`（= `CHAT_TOTAL_TIMEOUT`，**不是** `CHAT_TIMEOUT` 120s 那个段值）· `image 300_000`（实测 **p99**，n=478）· `video 600_000`（⚠️ **无实测支撑**，n=6/max 250s，待补）。
- ⚠️ **`override` 必须过 `Number.isFinite && > 0`**，不能只写 `override ?? default` —— 实证 `0 ?? 5 === 0`、`NaN ?? 5 === NaN`，而 `0` 在本仓 = 不掐点、`NaN` 让 `setTimeout` 立即触发。
- ⚠️ **不预建 `[provider]` 层**（ADR-0053 ①：加层前提 = 先有该 provider 的实测分布）。
- ⚠️ **预算真相归谁，按「任务是否脱离调用方存活」分**（2026-09-22 用户裁定）：
  · **image/video**（异步句柄：后端持有任务、脱离前端仍存活并续跑到终态）⇒ **后端持真相**，前端读响应里的 `budgetMs`。
  · **chat**（同步调用：无句柄、不建任务行、响应即终态）⇒ **前端就是生产者**（它在等、它决定等多久）⇒ **前端声明** `body.timeoutMs`，后端作 **override 原样用**。

- ⚠️ **`ai-relay` 是"连接层 kit"，应用业务策略不许落它**（域外只走门面 · ADR-0044 §①）⇒ 预算落 `localTool/src/` 根。

## 二·五 · 运行时取证入口（**判断"某次实测到底发生没发生"的唯一去处**）

- **localTool 日志**：`localTool/logs/localtool_18080_YYYY-MM-DD.log`，**UTC 时间戳**（`T05:41:07Z` 就是 UTC，别当本地时间换算）。**全盘只有这一处**（用户目录下无第二份）。
- **任务真相表**：`C:\Users\xinye\.maomao-localtool\localtool.db` → `tasks`（788 行）。**只读打开**：`sqlite3.connect('file:...?mode=ro',uri=True)`。时间戳是 **epoch ms**（`created_at`/`submit_ack_at`/`completed_at`）。用托管 python 的 `sqlite3`，别装包。
- ⚠️ **该表有幸存者偏差**：788 行**全部 `status='completed'`**（0 failed / 0 unknown / 0 running）⇒ 从它算出的**任何放弃率/失败率都是下界**，引用必须带此声明。
- ⚠️ **两列从未被写入，不可当证据**：`poll_count` 全 0、`not_found_count` 全 0 ⇒ 不能用它们反证"某形态没发生"。
- ⚠️ **日志只记 HTTP 请求**（`[POST] /api/generate` 等）；服务端轮询器对上游的出站**不在此日志**。故"日志窗口内零请求"只能证明**没经过本实例**，不能证明"没在跑"。
- **一次实测要能对账的最低要求**：`POST /api/generate` 时刻（日志）+ `tasks` 里对应行（`created_at`/`submit_ack_at`/`completed_at`）。**拿不出这两样 = 与传闻同级，不许当决议前提**（2026-09-22 实证：143 号规划 §1.1 的"豆包 8min 实测"在两处都查不到）。

## 三 · 反复踩的坑

1. **「区间差值 ≠ 轮次净减」**：想给某轮出净减，必须在**该轮开工前**跑基线；事后用 `git worktree` 检出改前提交**不可行**（该仓提交常混装，且有整轮域模块化搬迁同区间）。
2. **判据晚于行为的用例不能判违规**：先核 ADR 日期与被审代码日期，晚 ⇒ 判"待清点"交用户。
3. **同形 ≠ 同载体**：判 ADR 毕业前必须**实测载体**（真闸 / 类型层才算；行为单元测试不算），不能看标题归类。
4. **本仓可能同时有另一会话在写**（多个 agent 并行）。动 `git` 前后先看 mtime；发现非本轮的改动**不触碰、不回退**。**报"src/ 零改动"前必须用 mtime 核一遍** —— `git status` 里那一堆 `src/` 改动多半不是你的。
   - ⚠️ **更贵的一层（2026-09-21 实证）**：**审计期间目标会动**。曾出现另一会话按文件顺序逐件施工同一模块（mtime 22:09→23:09 扫完 20 个文件），**一轮读数 6 个文件已过期**。⇒ **下结论前必须再核一遍 mtime；发现漂移，第一件事是逐条复核已有结论，而不是继续往下挖**（否则会把"别人已修好的"当待还报出去）。
   - ⚠️ **取证一律用 Grep 工具（ripgrep），别用 shell `grep`**：本仓 shell 下 `--include=*.ts` 会被 zsh 当 glob 报 `no matches found`、`\|` 交替会**静默返回空**（实测把"README 三处漂移"查成 0 命中，读文件才发现全在）。**静默空结果 = 最危险的假证据**。
5. **审计要自己注入负例**，别复述上一轮的"探针先红后绿"。
5·1. **引 ADR 的"豁免/例外"条款前，先划它的射程**（2026-09-22 实证）。ADR-0049 写「存量 `tests/unit` 一律不动」，我读成"存量测试冻结令"，把"因契约变更同步 5 条断言"误报成**须用户签字的例外**。实际它的射程 = **不许按本条那两条禁令（文档测试／UI 存在性测试）去清点存量**（理由原文：形态口径在存量上失效 + 避免误删）⇒ 契约被改掉后同步断言是**正常施工**。**判据**：豁免条款管的是"**本条的执法范围**"，不是"**资产的冻结**"。
5·2. **报失败形态前先读它的语义标签**（2026-09-22 实证）。`relayProxy.ts:274-286` 前端预算用尽返 `{ok:false, pending:true}` —— **非终态**（"我不再等"），消费方保持 running + 恢复轮询续 attach 到真终态。我把可恢复形态报成"放弃率 0.84%"，等于**造一个不存在的风险**。同类：`unknown` 也是终态但"可能已生成"，不许折成 failed/running。
5·3. **"已有裁定"和"有新数据"不冲突** —— 数据能**支持**一个已定值就是它该有的作用，**别把支持性证据当成重开的理由**（2026-09-22：我把"图片 5min = 实测 p99"误报成待拍板项）。
6. **`debt.mjs add` 之后必须复跑 `debt.mjs audit`**：新债的锚点文件里若没写该债号，立刻制造一条「锚点断链」违规。只看 `add` 的 ✅ 会漏。
7. **`debt.mjs add --summary` 有硬约束**（SOP 未写）：**≤120 字**（超了报「摘要 N 字 > 120」，一行一债、长叙述写区域文件）且**禁裸竖线 `|`**（会撑破表格列，须换「／」）。`--rate` 只有 **高/中/低** 三档（写「中低」会被拒）。写前先按 120 字裁好。
8. **债号可能被并行会话占用**：`TD-<区>-<n>` 是**写入时按主表最大值 +1** 生成的 ⇒ 自己按顺序推的号会串。**一律以 `debt.mjs add` 回显的号为准**，写完再回改轮次文件（实证：2026-09-22 我推 44~48，实际落 45~49）。
9. **复核别人的"已完成"，可机器判定的凭证必须重跑**：批次文件里的 `lint` / `check:*` / 测试凭证**在写下那一刻可能为真，而代码随后又被改过**。实证（2026-09-22）：批次文件两处写「`lint` 0 问题」，重跑 `npm run lint` 得 **1 error**，且该 error 无 `--fix` ⇒ **挡 pre-commit**。⇒ 复核只读结论 = 没复核。
10. **凡写"账实不符"，必须附读数时间戳**：目标在动时，**判词本身会过期**。实证（2026-09-22）：据 01:19 的账本判某债"陈旧"，01:35 复核发现对方刚补完 resolve；反向亦发生过（对方据 23:0x 代码判"已修"，我 23:11 复核发现已变）。⇒ 结论一律标"截至 HH:MM"，并在文末列出"曾据过期读数下过、已被我推翻的结论"。
11. **动别人的账本行前先 `show` 看它有没有凭证**：`resolve` 会**覆盖**原注。实证：我用 `resolve` 覆盖了对方带 3 个探针 sha 的解法注 ⇒ 只能用 `edit --field solution` 手工还原。⇒ 先 `show <TD-ID>`，有凭证就 `edit` 追加、别 `resolve` 重写。

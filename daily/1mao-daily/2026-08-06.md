## 二、剧本盒子「生成资产」图片生成不了 — 根因与修复

**现象**：剧本盒子（`scriptBoxNode`）「生成资产」参考图生成不了。Lovart **已成功生成图、扣了积分**，但前端资产卡不显示。

### 根因（两个叠加 bug）

**① `Mr` 不解析 SSE 流（前端 `src/bundle/H_.jsx`）**
- 资产生成走 `Pr` → `Mr` → `/api/proxy`（命中 `images/generations` → localTool 注入 `wait=1`）→ 网关 wait 模式返回 **SSE 流**（`progress` + `succeeded` + `results[0].url`）。
- 但 `Mr`（L5414）只用 `x.text()` + `JSON.parse` 解析响应，**不处理 SSE** → `JSON.parse(整个SSE字符串)` 失败 → 抛「生图响应不完整」→ 图片 URL 丢半路。
- 普通图片节点 `Sr`（L2786）用 `getReader()` 逐块解析 SSE，所以能正常出图。**`Mr` 没跟进，导致资产生成这一个入口挂掉**。

**② localTool 静态服务不解码中文路径（`localTool/src/index.ts`）**
- 资产图本地化到 `migrated/人物`（中文 subfolder），`ci` 返回 URL 含中文。
- 浏览器请求时编码成 `%E4%BA%BA%E7%89%A9`；localTool `handleStaticFile` 用 `url.pathname`（未解码）拼磁盘路径 → 找不到真实中文目录 → **404** → 前端 `<img>` 加载失败。

### 改动

1. **`src/bundle/httpClient-BknZwXjG_components/H_.jsx`（`Mr`）**：响应解析改为**兼容两种**——`content-type` 含 `text/event-stream` 时用 `getReader()` 逐块解析 `data:` 事件（`succeeded` 取 `results[0].url`、`failed` 抛错）；否则保留原 `JSON.parse`。复用 `Sr`(L2786) 现成逻辑。
2. **`localTool/src/index.ts`（`handleStaticFile`）**：对 `relativePath` 先 `decodeURIComponent`（try/catch）再 `path.join`。

### 验证

- curl 走 localTool `/api/proxy` 发 `images/generations`（模拟 `Mr`）：实测返回 SSE，复现解析失败根因。
- 修复后重启 localTool：`http://127.0.0.1:18080/files/migrated/%E4%BA%BA%E7%89%A9/xxx.png` 从 **404 → 200**（`image/png`，1461247 字节）。
- 日志实证：`[proxy:stream] POST /v1/images/generations` → `[POST] /api/files/upload` → 落盘 `migrated/人物/7f63374cb556b51e_*.png`。

**登记**：`docs/01` 变更登记新增**变更 #13**（前端 `Mr` + localTool 静态服务两处）。

**生效方式**：前端刷新浏览器插件（加载新 dist）+ 重启 localTool（18080）。

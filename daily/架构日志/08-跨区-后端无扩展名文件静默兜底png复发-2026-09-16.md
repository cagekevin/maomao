## 二、命中（TD-08-23）

后端两处本地文件路径扩展名提取，无扩展名时**静默兜底 png**（与前端 `scriptBoxEngine.ts:1186` 同源的 TD-16-11 母亲，只是作用在真实磁盘文件路径而非 URL）：

1. `localTool/src/routes/files.ts:454`
   ```ts
   const srcExt = path.extname(filePath).toLowerCase().replace(/^\./, '') || 'png';
   ```
   缩略图端点：文件已 `existsSync` 确认存在，若磁盘文件**无扩展名**，`path.extname` 返空 → `|| 'png'` 把输出格式强行定成 png（真实无扩展 jpeg 会被重编码为 png，格式/mime 错标）。

2. `localTool/src/utils/resolveLocalImages.ts:50`
   ```ts
   const ext = path.extname(filePath).toLowerCase().replace('.', '') || 'png';
   ```
   `fileToInlineBase64`：同上，无扩展名文件静默当 png 交给 `jimpMimeForExt`。

**证据 / 双证**：
- 非死代码：`files.ts` 缩略图端点、`resolveLocalImages.ts` 内联 base64 均有活跃调用（前者被静态资源路由调用，后者被资源内联逻辑调用）。

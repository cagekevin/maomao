### TD-18-18 · 与上一轮结论冲突（横跳留痕 · 按铁律判债）

- 同日上一轮曾判 ADR-0026 **非债**，理由为「`Date.now()` 均作**临时 id**、非幂等键」。本轮取证给出相反结论 ⇒ 构成**横跳**。
- 按零.3 铁律「首判为债、复核翻非债 = 它仍是债（横跳即证据）」：**横跳本身即判债**，且判定必须能说清差异，不许"感觉不严重"就翻回非债。
- **差异点（可复现，不是感觉）**：`projectStore.genId()` 产出的**不是临时 id** —— 它是
  ① `canvas-state-v1-<projectId>` 的 **KV 落盘槽位键**（`projectStore.ts:331-333`；DB 实况 `kv` 表 6 个键一一对应该 id）；
  ② 后端 `projects` 表按 id **合并去重**的键（`projectStore.ts:263-276`，撞车即视为同一项目）。
  ⇒ 落在 ADR-0026 适用范围「**落盘 / 落库**」之内，判债成立。上一轮的「临时 id」概括不适用于这一处（`App.tsx:1271 ghost-edge`、`useToast.ts:29` 这类**真·临时 UI id** 仍按非债处理，未登记）。

### TD-18-18 · 判据 ↔ 实况对账（第 6 问）

- 判据：`projectStore.genId()` 声称能产出**全局唯一**项目 id（它是 KV 落盘键与后端合并去重键）。
- 实况（只读查库，未改任何数据）：`~/.maomao-localtool/localtool.db` →
  `SELECT id FROM projects` = **5 行，全部形如 `proj-<毫秒时间戳>`**，`COUNT(id) = COUNT(DISTINCT id) = 5`（暂无撞车）；
  `SELECT key FROM kv WHERE key LIKE 'canvas-state%'` = `canvas-state-v1-proj-1786727292715` / `-1788097271985` / `-1787922684426` / `-1787126583792` / `-1786889486202` / `-default`。
- 差集：该判据的碰撞抗性**完全等于**「两次创建不在同一毫秒」这一时序假设 —— 零随机段，连 `generateId` 的 `random36` 都没有。
  ⇒ 结构上失效（ADR-0026：键的来源本身就是判据），债成立。当前无撞车只是**尚未触发**，不是判据有效。

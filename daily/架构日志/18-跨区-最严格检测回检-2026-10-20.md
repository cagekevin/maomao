## 七、清掉最后 7 个 lint warning（`director3d/Viewport.tsx#SceneObject`）

**现象**：全量 `npm run lint` 长期是 `0 error / 7 warning`，7 个全是
`react-hooks/exhaustive-deps`，集中在同一个组件的三个 hook 上：

| hook | 报了什么 |
|---|---|
| 落地吸附 `useEffect` | missing `data` ×1 + 复杂表达式 ×2 |
| `syncTransform` `useCallback` | missing `data` ×1 + 复杂表达式 ×2 |
| `beginObjectInteraction` `useCallback` | missing `data` ×1 + 复杂表达式 ×1 |

**根因（同一条）**：依赖数组里写的是 `data.id` / `data['locked']` / `data['scaleAxisLocks']` /
`data['proportionalScale']` ——
① `data['xxx']` 是**计算成员表达式**，exhaustive-deps 无法静态校验（"Extract it to a separate variable"）；
② 因为依赖项匹配不上，规则同时认为整个 `data` 没进数组（"missing dependency: 'data'"）。
**没有一处是"真的少依赖"**，是写法让它无法核对。

**改法（不加 eslint-disable、不改 hook 结构）**：把 `node.data` 的派生值提为组件内局部常量，
回调体与依赖数组统一改用常量：

```ts
const objectId = data.id;
const objectLocked = Boolean(data['locked']);
const proportionalScale = Boolean(data['proportionalScale']);
const rawScaleAxisLocks = data['scaleAxisLocks'];
const scaleAxisLocks = useMemo(
  () => (Array.isArray(rawScaleAxisLocks) ? rawScaleAxisLocks : [false, false, false]),
  [rawScaleAxisLocks],
);
```

一个容易漏的点：**锁轴数组的缺省值是新建的 `[false,false,false]`**，直接当依赖会让
`syncTransform` 每次渲染都重建（memo 白做）⇒ 用 `useMemo` 以 `rawScaleAxisLocks` 为键固定引用。

**验证**：`npx eslint src/components/director3d/Viewport.tsx` = **0 problem**；全量 `npm run lint`
= **0 error / 0 warning**；`tsc --noEmit` = 0；全量 **278 文件 / 3374 用例通过**。

## 一、溯源（Step 1：债描述有两处失真）

| 面板 | 债描述 | **取证后的真相** |
| --- | --- | --- |
| 贴纸 | 「iconify 直连公网无自建代理」 | ✅ 成立，且是 **3 处各自手拼 URL**：`iconify-api.ts`（自带三家回落链）· `sticker-node.ts:23`（导出渲染取图）· `timeline-element.tsx:382`（时间轴缩略）—— **三套判据** |

| 音乐 | 「数据源未接入」 | ❌ **失真**：`SongsView` 是 `return <div>{'音乐'}</div>` —— **功能从未实现**（空壳），不是"接入问题" |

**根因（比描述更本质）**：cutia 是 **Next 同源**应用，前端写的是相对路径 `/api/sounds/search`；
搬到本仓后前后端**不同源**（vite `:5180` vs localTool `:18080`，且 `vite.config.ts` 无 proxy），
该请求落到 localTool 的 catch-all 透传 → 打向不存在的上游 → **静默空面板**。
`SoundEffect` 的 `username/downloads/rating/bitrate/samplerate` 字段与 Freesound API 完全对应
—— 即原上游是 **Freesound**，本仓从未接过。

**母体**：**外部数据源没有统一入口** —— 每处各自拼 URL / 各自回落 / 各自 fetch，于是既接错端点、也绕过代理。

## 二、定契（Step 3/4）

> 用户裁定「自建」= 数据不来自任何第三方；贴纸走**自建代理**（iconify 是公开 CDN，无需凭证）。

| # | 能力 | 正确形态 |
| --- | --- | --- |
| ① | 贴纸图标 | localTool `GET /api/iconify/*` **原样透传**（唯一出站口 `fetchWithProxy`，上游三家回落收在后端**一份**）；前端只剩**一个 URL 构造函数** |
| ② | 音效 | localTool `GET /api/sounds/library` 扫描 `uploads/sounds/effects/`；音频经既有 `/files/` 静态服务（Range + 长缓存），**不另起文件服务** |
| ③ | 音乐 | 与 ② **同一端点、同一面板组件**，读 `uploads/sounds/music/` |

三条硬约定（写进代码注释）：
- **空库是合法状态，不是错误** —— 返回空清单 + `dir`（后端给的真源），前端据此给"放哪儿"的引导；
- **失败要出声** —— 旧病灶正是"静默空"，用户分不清"没有"与"坏了"；
- **目录/回落链/URL 构造各只有一份**。

## 五、弯路留痕（强制）

**check-api-contract 把正则里的 `\/\//` 当行注释 —— 其后整张路由表被吞（工具债 TD-17-7，当场修）。**

- 现象：新增 `/api/iconify/*`（正则 `pattern: /^\/api\/iconify\//`）后，`check:api` 报 **error 3**，
  且报的是 **`adminStorageHealth` / `adminDeleteFile`** 这些我**根本没碰**的既有端点「白实现（前端有、后端无）」。
- 读闸源码定位：`extractBackendRoutes()` 用括号深度扫描切路由对象，其中
  `if (ch === '/' && nxt === '/') inLineComment = true` —— 我的正则里 `\/` + 正则结束 `/`
  在字面上就是 `//` → **被判成行注释** → 从该点起括号永不配对 → `break` → **后续路由全丢**。
- 修法（最小且治本）：判 `//` / `/*` 前先排除「该斜杠自身属于转义序列」（`body[j-1] !== '\\'`）。
- **先红后绿**：修前同命令 `error 3`；修后 `error 0 / warn 0 / info 157`。
- **教训**：**闸的假阳性会把真实结论盖住** —— 若只盯着"我的新端点报错"，就会去改登记表去迁就闸，
  而真凶是闸自己丢了半张表。**报错指向你没碰过的地方时，先怀疑工具。**

**另一处（早于本轮、同类）**：`probe.mjs` 的 `--expect-out` 未剥离 ANSI（TD-17-6，同日已结清）
—— 两笔工具债同一副面孔：**工具的眼睛被蒙住，结论却由它出**（A11）。

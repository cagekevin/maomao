## 二 · Step 1 证伪

1. **TD-08-36（真债）**：同一 `{debug:0,info:1,log:1,warn:2,error:3}` 在两处各写一遍 —— 典型的 **SSOT 第二份**（改一处忘另一处 ⇒ 阈值判据分叉）。✅
2. **TD-08-37（真债，且**比债描述更重**）**：债描述说"不可达兜底，掩盖接管时序契约"。取证后发现更重的一层 ——
   `write()` 的回落目标是 `console[level]`，而**接管之后 `console[level]` 就是本包装** ⇒ 该兜底一旦可达就是**无限递归**（栈爆）。
   ⇒ 它不只是"掩盖契约"，是**埋了一条自噬路径**。✅

## 三 · Step 3 定位（**为什么不是"加守卫"**）

- 直觉方案是"加一个守卫：`if (!orig) throw`"。但按 7 步法 Step 4 的判据 —— **守卫必须能真触发**；
  而这里"未 init 即 write"按上游不变量**不可达** ⇒ 加守卫就是**假护栏**（要么删、要么改成真判据）。
- **正解 = 把复杂度收敛到正确的物理位置**：原引用在**打补丁那一刻**捕获进闭包
  ⇒ 结构上**不可能缺失** ⇒ **无需兜底、无需守卫**，「接管时序」这条契约不再靠"记得 init"。
- 同时撤掉 `console._orig_*` —— 那是**往全局对象塞私有状态**（真源与实现分离）。

## 四 · Step 4 定契

```ts
// 级别序：唯一真源
const LEVEL_ORDER: Record<string, number> = { debug: 0, info: 1, log: 1, warn: 2, error: 3 };

// 原引用：捕获进闭包（参数传入），不查全局、无兜底
for (const m of methods) {
  const orig = console[m].bind(console);
  console[m] = ((...args: unknown[]) => write(m, args, orig)) as typeof console.log;
}
function write(level: string, args: unknown[], orig: (...a: unknown[]) => void): void { … orig(...args); }
```

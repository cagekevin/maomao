## 二、横向推导候选 + 实证结果

### 候选 1：13 区 eventBus 是否还有"第二套广播"盲区？
- **假设**：22 区 TD-22-23 发现 `window.dispatchEvent` 第二套广播并加 `check:arch` 规则 10 禁 src 内自建广播；13 区是 eventBus 真源区，可能还有绕行点漏网。
- **实证**：
  - `refs eventBus.ts` → 26 fan-in，**全部走 `publish/subscribe`**（合规），无模块裸 `window.dispatchEvent`。
  - 全仓 grep `window.dispatchEvent`：仅 `videoEditor/.../playback-manager.ts:196-197` 一处，且系**已被 TD-22-23 收口的旧遗留**（注释明写"违反红线"，`contracts.ts:128` 记录已改回 eventBus）。
  - `grep new EventTarget` 在 base/localTool 下**零命中**（无自建总线）。
- **结论**：**非债**（已收口 + 机器闸兜底）。13 区"第二套广播"盲区假设**证伪**。

### 候选 2：19 区 UI 基础库是否残留 radix / 第二套弹层协议？
- **假设**：22 区 2026-09-15 移除 radix（-73 包，15 原语自研）；19 区是更早的 UI 基础库，可能漏网 radix 或第二套弹层。
- **实证**：`grep @radix-ui|radix src/components/base/ui` → **零命中**；19 区首轮即纯自研组件，无 radix 史。
- **结论**：**非债**。假设证伪。

### 候选 3：08 后端是否有静默吞错（与 TD-15-3 同母体）？
- **假设**：15 区发现 `importAll` 静默吞 + 恒返 ok:true；08 后端（`:18080`）同母体可能漏登记。
- **实证**：`grep catch|console.error localTool/src` → 仅 `localTool/src/index.ts:388` `console.error('[error] ...', e)` 是**有日志的失败透传**，非静默吞。
- **结论**：**非债**。08 区首轮已深审（5 轮），静默吞假设证伪。

### 候选 4：07 3D/深度视频是否有未登记静默吞？
- **假设**：全仓静默吞密集在 01/02/11/15/22，07 区只有 1 笔死代码债（TD-07-5），3D 异步加载/解码多 → 应有漏网静默吞。
- **实证**：`grep catch src/components/director3d|depthVideo` → **仅 1 处** `App.tsx:632 .catch(() => {})`（已是 TD-07 范畴内，且 07 三轮已裁定）。
- **结论**：假设**证伪**，07 区 catch 链路基本健康，无新增静默吞债。

### 候选 5：taskCompletionBus 是否为"第二套广播"？
- **假设**：名字含 Bus，可能是 eventBus 之外的独立广播机制（与 TD-22-23 同母体）。
- **实证**：`refs taskCompletionBus.ts` + 读实现 → `taskCompletionBus.ts:11` `import { publish } from '../core/eventBus.ts'`，是 eventBus **之上的薄封装**；`eventBus.ts:6` 注释明确"taskCompletionBus / persistFailureBus / resourceStore.onResourceSent 均为本总线之上的薄封装，非第二套"。
- **结论**：**非债**（TD-01-8 已收口设计）。TD-22-23 的"第二套广播"母体**未扩散到 base 层**。

## 三、横向推导结论

1. **已收口母体未回潮**：TD-22-23（第二套广播）、radix 移除、静默吞豁免通道（TD-02-26/27）的修复**未被其他区域重复触发**——机器闸（check:arch 规则 10 / 6 / 7）+ SSOT 收口有效，横向扩散风险低。
2. **真正的盲区不是"已审区的对称债"，而是"低覆盖区本身"**：13（3 债）/ 15（4）/ 16（1）/ 18（2）/ 19（1）/ 23（6）债极少，主因是**审计轮次少（1–2 轮）**，而非干净。但这些区多为横切纯函数/基础设施，经本轮抽样实证（19/08/07/13 的候选均证伪）**当前健康**。
3. **无需新增债**：本轮 5 个横向候选全部证伪/非债，账本 252 条无遗漏补登。

## 一、本轮新增链路快照（对方已建机制，精简取证）

- **ADR 0001 分步调用协议**：`preset_start_run` 只解析/校验/建节点不调模型（属 canvas_write，校验 project+revision）；`preset_run_text_step`/`preset_run_media_step` 逐步骤执行，每次媒体步骤独立审批；失败作为 Observation 回传模型继续规划；**写入与生成均不自动重试**。
- **ADR 0003 按需运行时原子安装**：资源先下到 staging 目录，校验 `index.html`/版本/协议元数据后再切到版本目录；固定清单钉仓库+版本+URL+SHA-256；**校验失败必须中止安装，禁止静默切换版本**；不启动 HTTP 服务（自定义 `director-desk://` 协议 + 规范路径包含校验）；下载限大小/展开大小/文件数/类型/路径；取消或失败删临时文件不破坏已装版。
- **ADR 0005 发现→校验→执行三阶段 + 防替换令牌**：`comfyui_discover`→`comfyui_validate_workflow`→`comfyui_execute_workflow`；校验通过的工flow 只缓存内存 10 分钟，绑定 taskId/projectId/服务地址；执行工具**只收 `validationId`，不能用未校验 JSON 替换缓存内容**（确认对象 == 执行对象）；审批摘要展示真实模型与自定义节点能力；**不自动保存**（助手问、用户同意、file_write effect 再确认）；工作流不进 IndexedDB。
- **ADR 0006 模型选择单一确定性解析序**：`项目 settings.defaultModels.text → 应用 config.assistantModelId`；主窗口/独立窗口/实际请求/上下文预算**复用同一候选序**，禁止各自实现不同优先级；无效/隐藏/不可用时安全回退不阻断旧项目。
- **ADR 0007 视觉上下文指纹化缓存**：对话发送前统一解析 `@图片`；Base64 data URL 限大小/数量；纯文本模型不收字节，改由视觉模型生成描述注入；描述以图片 SHA-256 指纹绑定项目，图片未变复用、替换生新指纹；**只持久化描述/指纹/元数据，不持久化 Base64/本地路径/凭据**。
- **ADR 0009 可信/沙箱双轨**：QuickJS 强沙箱 vs 可信 Python（本机用户权限，非 OS 沙箱）；显式 runtime 区分；安装/启用高风险确认；每次调用独立 CPython 子进程（非 Shell）；错误脱敏、协议隔离；结果仍受 effect/projectId/revision/Store 约束；**不把任意 Shell/Python 能力注册给 Agent 或 MCP**。
- **模块·文件与存储**：schema 版本权威以源码为准（模块说明不固定副本）；持久化媒体引用需抗重启/项目移动/归档，不依赖页面 Blob 或临时签名 URL；凭据只经专用服务进原生存储，不进普通项目持久化。
- **模块·模型与生成**：**生成成功/取消/保存是三态，需分别处理**；模型已生成但保存失败时报告保存状态，**不能把再次生成当作保存重试**；取消贯穿提交/轮询/回填；API Key 由凭据服务管，运行记录不携密钥；工具审批归 Policy 不由 Provider 改写。
- **模块·画布与项目**：异步结果不能写入已切换项目；批量操作只提交一次快照；分镜用稳定镜头 ID；参数改动使在途/排队结果失效。
- **模块·桌面运行时与安全**：外层 Tauri ACL 与命令内部调用方/路径校验**双层保留**；原生凭据不回落普通配置或 IndexedDB；递归操作拒绝私有目录（含祖先）。
- **模块·MCP 控制**：默认关闭，只手动/显式自动开启；**发现结果不代表后续调用已授权**，执行阶段重新校验上下文；令牌只存原生凭据，不进配置/事件/日志；发现内容经瞬时通道返回，不进消息/任务持久化。
- **模块·插件平台**：运行身份同时绑 `sourceDigest`+`revisionDigest`，原生注册表是执行权威，停用/卸载/更新后旧租约不得写回；卸载先停用+撤销授权+删注册+删 IndexedDB，全成功才移除列表，任一步失败保留停用项供重试；注册表 JSON 损坏提供显式修复入口不自动重建；内嵌 UI 隔离 iframe、独立 UI 专用 WebView；**写回失败回收已写文件**。

## 二、定海（我方现状基线，grep 取证）

- `src` 搜 `validationId|校验令牌|防替换|confirmToken|approvalToken` → **0 命中**（可付费生成无"防替换审批令牌"机制）。
- `src` 搜模型解析：`defaultModels|assistantModelId|ModelSelect|resolveModel` 等命中 **13 个文件**（ModelSelect/ApiSettings/AgentChatSettings/VideoGenerate/ImageGenerate/TextGenerate/nodePrefs/useScriptBoxEngine/AgentPanel…）→ 模型选择解析序**散落多文件、无单一确定性序与一致性回退**（对标 ADR 0006）。
- `localTool` 搜 `sha256|staging|原子|钉版本`：仅 `localPatch.ts`/`localPatchOps.ts`（桌面局部修补补丁自身有 SHA-256 指纹与 409 拒绝覆盖契约）→ **按需/运行时资源安装的"暂存-校验-原子切换+钉版本+禁止静默降级"模式尚未体系化**（对标 ADR 0003）。
- `src` 搜生成三态：`保存失败|save.*fail|生成成功.*保存` 仅散见局部重试，**无统一"保存失败≠重生成"纪律**（doc 72 已记静默退化，对标模块·模型与生成）。

## 三、第一类：能提升我们架构（可落地机制，grep 证实我方缺失）

1. **校验-执行防替换令牌（validate-then-execute token）** — ADR 0005。任何可付费生成/外部调用先 produce 不透明令牌（绑 taskId/projectId/参数指纹），审批与执行都以令牌为凭，执行侧不得用新 JSON 替换已确认内容。直击**假护栏 11 / 静默吞 34**（确认对象被偷换）。→ 登记 **TD-01-16（中）**。
2. **生成三态分离 + 保存失败≠重生成** — 模块·模型与生成。统一 `generationRuntime` 把「生成成功 / 取消 / 保存」显式分态；保存失败报保存态并保留远端产物地址，不把重生成当保存重试；取消贯穿提交/轮询/回填。→ 登记 **TD-01-17（中）**。
3. **模型选择单一确定性解析序（SSOT）** — ADR 0006。抽 `resolveModel(上下文)` 唯一入口：`项目默认文本模型 → 应用助手模型`，主窗口/独立窗口/请求/上下文预算全部复用，无效安全回退。消除 13 文件各写各的 → **SSOT 第二份 38 / 口径错位 29**。→ 登记 **TD-01-18（中）**。
   > ⚠️ **【TD-01-18 已改判非债 · 2026-09-16 复检】** 本条**前提不成立**，勿据此施工。取证：① `defaultModels`／`assistantModelId` 是对方 ADR 0006 的符号名，**本仓 grep 0 命中**；② 本仓真源**早已存在** —— `resolveProviderModel`（`providerModels.ts:83`）由 **6 个调用方全部委托**（TextGenerate:192／TemplateNode:266／ImageGenerate:294／VideoGenerate:228／scriptBoxEngine:189,199）；③ 上面所称"13 文件"是**命中 model 相关词的相关性**，不是重复实现 —— 解析序是 **1 份**。详见 `00-跨区-借架构机会16债复检-真债与假需求-2026-09-16.md §二A`。
4. **按需资源原子安装 + 钉版本无静默降级** — ADR 0003。运行时不随包捆绑，首次使用下到 staging，SHA-256 + 元数据校验通过再切版本目录，固定清单钉版本，校验失败中止不静默切版。扩到 localTool 运行时/模型/补丁下载。→ 登记 **TD-08-26（中）**。
   > ⚠️ **【TD-08-26 状态：真债保留 · 2026-09-16 复检】** 取证确认：`localTool` grep `sha256`／`staging`／`原子`／`钉版本` 仅命中 `localPatch.ts`／`localPatchOps.ts`（补丁自身有 SHA-256 与 409 拒绝覆盖），**运行时资源原子安装未体系化属实**。属 localTool 施工，非本轮范围。
5. **scriptbox/插件式执行绑 digest 租约 + 权威注册表 + 失败保留可重试** — ADR 0009/0010 + 模块·插件平台。执行身份绑 `sourceDigest`+`revision`，运行结果不得写回旧版本状态；卸载/停用走"全步骤成功才移除、失败保留可重试"；写回失败回收已写文件；可信/沙箱显式分级、危险能力不向 Agent/MCP 暴露。→ 登记 **TD-14-1（高）**。
   > ⚠️ **【TD-14-1 状态：真债但须问用户 · 2026-09-16 复检】** 取证确认：`src/components/scriptbox` grep `sourceDigest`／`revisionDigest`／`digest` = **0 命中**，执行身份确实无版本绑定 → **缺口属实**。**但不可照搬**：对方是**原生插件注册表（进程级隔离、可停用/卸载/更新）**，我方 scriptbox 是**同进程内存脚本引擎**（无安装/卸载生命周期）—— 「是否真需要 digest 租约」属**业务能力判断**，落地前须 Step 5 交用户。

## 四、第二类：对架构有启发（战略/纪律，不马上搬实现）

- **失败作为 Observation 回传模型、不自动重试**（ADR 0001）：批执行/链式中任何步失败都回传模型由其重规划，写入与生成零自动重试 → 固化进 scriptbox/批执行 SOP（呼应 doc 53/72）。
- **指纹化缓存失效 + 凭据/原字节不落盘**（ADR 0007）：任何"引用解析→缓存"都用 SHA-256 指纹做失效键，且只存派生描述/元数据，**绝不存原字节/路径/密钥** → 加固我们参考媒体治理（与 TD-01-14 同线）。
- **默认否定 + 发现≠授权 + 执行重校验**（模块·MCP）：任何外部/插件入口默认关，发现只给可见性不授执行权，执行时重新校验上下文与 effect → 通用"外部能力最小化暴露"纪律。
- **双层校验（外层 ACL + 命令内调用方/路径校验）**（模块·桌面运行时与安全）：权限声明与运行时校验同时保留，递归操作拒绝私有目录祖先 → 我们 localTool 路由层可加"调用方/路径"二次校验层。
- **暂存-原子切换 + 禁止静默降级** 作为通用安装/升级伦理（ADR 0003）：任何"下载外部资源再启用"都走 staging→校验→切换，永不以"能用就行"静默降级版本。

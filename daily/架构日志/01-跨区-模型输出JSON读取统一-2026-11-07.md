## 二、溯源（症状 vs 病根）

- 症状：同一句模型回复，表格能给出「解析失败，请重新生成」，剧本盒只 `toast` 一句无原因的通用话，
  文本节点与 agent 侧**静默压平成空数组**（用户看到「没拆分」「没有 generations」，零线索）。
- 病根：缺「模型输出读取」统一层。目标形态 `ParseTableJsonResult`（判别联合）**已存在且已被用户裁定**，
  但只落在表格一处 —— 母体 M（同语义一处达标、其余未推广）。

## 三、定海（不变式）

- 「模型回复正文 → JSON」只有一个实现：`base/utils/text/modelJson.ts::parseModelJsonText`。
- 失败在类型上取不到值：`ok:false` 那一臂没有 `value`。
- **schema 不统一**（`shots[]` / `rows[]` / `items[]` / `generations[]` 各异）⇒ 校验由调用方注入；
  **失败契约统一**（`not-string` / `no-json-block` / `parse-error`）。
- 用户文案归**拥有域知识的那层**（域层才生产得出「剧本 JSON 格式有误」这句事实）。

## 四、切割

- 共享：提取算法（围栏优先 → 对象块 → 数组块）+ 失败码。
- 各域保留：schema 校验、用户文案、失败后的业务处置（toast / 降级 / 留痕）。

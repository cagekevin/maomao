## 二、溯源（Phase 1：症状 vs 病根）

### 病根 A：编组显示名「双字段」——TD-04-14 是**末端兼容**，不是**源头收敛**

- 六轮曾宣告 TD-04-14「方案 A 源头收敛：data.name→data.label，复杂度在**数据模型层**死掉」。**复核推翻该措辞**：
- 六轮实际改动点（其文件 §二自列）= `GroupNode.tsx`（读侧 `label ?? name` 兜底）+ `nodeDefaults.ts`（兜底补 label）+ `App.openRenameDialog/commitRename`（改名写 label）。**全部是「读/写消费侧」**，**未含真正的建组写侧源头 `groupNodes.createGroupFromNodes`**。
- 实测：`groupNodes.ts` 建组仍 `data: { name: '编组' }`（唯一建组入口，Ctrl+G / 右键 / Agent `group_nodes` 全走它）；`applyNodeTypeDefaults` 对 group 是 `{ ...data, label: data.label ?? data.name ?? '编组' }` —— **`...data` 把 name 原样保留**，只在其上**追加** label。
- 结果：**新建组 = `{name}`；加载一次 = `{name, label}`（双写，name 永不清理）；改名后 = `{name, label:新名}`（name 变孤儿/误导）**。这正是心法「末端收敛（在消费端兜底）vs 源头收敛（在数据模型层消灭）」的典型反例——六轮给的是前者，却说成了后者。

### 病根 B：整理（Ctrl+L）对 group 的尺寸写回**只写 `style`、不写 `width/height`**

- 尺寸写回不变量（TD-04-16 收口）：`useNodeResize.onMainBoxResize` = `patchNodeById(setNodes, id, { width, height, style })` —— **width+height+style 三写**；`useFitNodeRatio` 亦经此。
- 但 `useArrangeCanvas` 对 group 只写 `style`：`style: { ...node.style, width: pos.width, height: pos.height }`，`width/height` 保留旧值。
- 而 `NodeShell.useNodeWidth = n.width ?? n.style?.width`（**width 优先**，`groupNodes.test.ts` §「编组尺寸刷新保真」已显式守住这条）→ 整理后 group 的 **`node.width`（旧）≠ `node.style.width`（新）** → NodeShell 根 div 与 React Flow wrapper（用 style）尺寸错位 → 端口/连线环绕跑马灯定位偏差（NodeShell 头注释已警告此失配）；落盘快照二者也不一致。同类「改节点尺寸」出现**两个实现 + 两套字段集**，是 TD-04-16 收口**漏网点**。

## 三、定海（Phase 2：不变式 / 唯一真相源）

- **编组显示名 SSOT = `data.label`**（全画布通用，`useNodeRename`/`NodeTitle`/素材匹配同源）。`data.name` 是**孤立遗留字段**，应彻底消亡（非保留兼容）。
- **节点尺寸 SSOT = `node.width/height`**，`style` 是渲染镜像，**必须三字段同写**（`useNodeResize` 已固化）；任何写尺寸的路径不得只写其中一部分。
- 边界 Guard：加载入口 `applyNodeTypeDefaults` 是**唯一迁移点**——把旧 `name` 收敛进 `label` 后删除，脏数据在边界洗净，下游只管读 `label`。

## 四、切割（Phase 3：深模块 / 真缝隙 / 收敛口）

- **建组写侧源头收敛**：`createGroupFromNodes` 直接产出 `data.label`，新数据不再产生 `name`（复杂度在产生前被消灭）。
- **加载迁移收口**：`applyNodeTypeDefaults` 对 group 做 `name→label` 迁移 + 删 `name`（存量收敛）。
- **尺寸写回对齐**：`useArrangeCanvas` 对 group 补 `width/height`，与 `style` 三字段同写，回到 `useNodeResize` 同一不变量。
- 无上帝类 / 无过度抽象：三处改动均为「消除第二真相」，非新增抽象层。

## 四 · 切割（裁定非债，留痕防重审）

本轮对「疑似泄漏」逐条取证，以下**裁定非债**（下一轮 AI 不得当 bug 补）：

- **事件名**（8 个全部登记于 EVENTS，re-grep 实证）→ 非债。
- **端口 18080 / 错误文案 GEN_ERRORS / 端口契约 NODE_HANDLE_CONTRACT / 积分闸字段 / 扩展名表 EXT_KIND / 端点路径 / buildIconSvgUrl**（TD-22-47 已收口）→ 非债仍成立。
- **store 内 `genId()`**：`resourceStore.ts:233`·`taskStore.ts:150` 均 `return generateId('resource'/'task')`——**委托单源**，非绕过 → 非债。
- **`projectStore.ts:313` `proj-${Date.now()}`**：项目 id 须复刻官方 `Vr.jsx L2303` 格式（`proj-<ts>`），注释已固化理由 → 有意设计，**裁定非债**（勿因「禁 Date.now 拼接」改成 generateId，会破坏项目 id 格式兼容）。
- **`groupNodes.ts:54` `crypto.randomUUID()`**：Agent 批量并发建组需碰撞安全 id，`idGen.generateId`（ts+random）并发可能碰撞；已有 `fallback → generateId('group')` 且注释固化 → **裁定非债**；建议 `idGen` 增 `generateUUID()` 后本处改 `group-${generateUUID()}`（未来收口，非当前债）。
- **`cloudSync.ts:156` `CLOUD_META_KEY='__meta'`**：cloudSync 自身 ledger blob 内部子键，单消费方 → 非债。
- **`assistantTable.ts:63` `ROW_INDEX_KEY='_rowIndex'`**：表行内部标记键，非持久化键 → 非债。
- **`conversationState.ts:77/78` `LEGACY_CONV_KEY`/`LEGACY_ACTIVE_KEY`**：旧格式 KV 迁移回读，兼容用途 → 非债。
- **`encoderProbe.ts:62` `memoKey` / `depthVideo/loader.ts:54` `loadedModelKey`**：模块内 memo 缓存，非存储键 → 非债。

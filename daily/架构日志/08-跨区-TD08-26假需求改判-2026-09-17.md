## §二 · TD-08-26 —— 运行时不按需原子安装未钉（改判非债）

### 债的指控（4 条）

1. 运行时资源「按需安装」未体系化
2. 未钉 SHA-256 版本
3. 缺「禁止静默降级」
4. → 债形态 静默吞 34 / 死代码 35

### Step 0 普查 —— 本仓到底有没有「运行时安装」？

| 能力 | 现有实现（取证） | 份数 | 判定 |
| --- | --- | --- | --- |
| 运行时资源还原 | `localTool/scripts/fetch-runtime-models.mjs`（166 行） | **1** | 复用 |
| 资源清单 + 校验 | `localTool/runtime-models/depth-video/MANIFEST.json`（22 文件带 `size`+`sha256`） | **1** | 复用 |
| 规范 | `docs/95-本机推理模型资源-GitHub规范.md` | 1 | 复用 |
| 运行时**联网下载** | **不存在**（`allowRemoteModels=false` + `local_files_only:true`） | **0** | — |

⇒ **本仓根本没有「运行时按需安装」这件事** —— 还原发生在**构建 / 换机期**，不是运行时。
债指控的「按需原子安装」在**我方根本不存在的架构面上**。

### Step 1 证伪 —— 逐条打掉

| 指控 | 取证真相（文件:行） | 裁定 |
| --- | --- | --- |
| 未钉 SHA-256 | `MANIFEST.json` **22/22** 文件全带 `sha256`+`size`；`fetch-runtime-models.mjs:99` 校验一致才跳过 | **不实** |
| 校验失败会静默切版 | `:143-147` sha 不符 → **`continue`（不写盘）**，并打印「版本漂移？请钉 `TRANSFORMERS_VERSION`」 | **不实** |
| 缺「禁止静默降级」 | `MANIFEST.vendor.*.versionEnv` **就是钉版本入口**；**无静默切版路径** | **不实** |
| 静默吞 / 死代码 | 实跑 `--check` → 如实报「共 22，就绪 0，失败 22」（**不静默**）；loader `local_files_only:true` ⇒ 运行时零联网 | **不实** |

**实跑命令**（可复现）：

```bash
node localTool/scripts/fetch-runtime-models.mjs depth-video --check
# → 汇总：共 22，已就绪 0，新拉取 0，失败/缺失 22   （如实报告，非静默）
```

### 裁定

**TD-08-26 → 改判非债。** 对方 ADR 0003 是 **Tauri 桌面端**「运行时按需安装 Python/QuickJS 插件」；
我方（Web SPA + Node localTool）的运行时资源是**构建期物化**（约 470MB 大二进制不入库，靠 MANIFEST 还原）
—— **两个架构面不同，机制不可照搬**（A5：外部仓库是参考实现，不是「仓库里没有」的证据）。

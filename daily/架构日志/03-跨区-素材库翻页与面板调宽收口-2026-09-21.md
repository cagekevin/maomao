## 二、溯源（症状 vs 病根）

**症状**：素材库永远 20 条，且新素材把最旧一条挤出首页。

**病根（结构死锁，不是某个 CSS 写错）**：

```
第 1 页 = 20 条（PAGE_SIZE=20）
20 条高 ≈ 734px < 容器高（330px 面板在 1080p 下约 900px）⇒ 无滚动条（用户实测：完全不会动）
而「加载更多」的**唯一触发**是 onScroll（ResourceLibrary.tsx:308-312）
⇒ 要加载第 2 页必须先滚动；要能滚动必须先加载更多 → 互为前提，永不发生
```

⇒ **改 CSS 治不了**：唯一的"让滚动发生"的办法是把 20 条拉高（换屏幕/缩放即再犯），
或"不满视口就自动续拉"（那是新增兜底）。**正解是让触发不依赖滚动** ⇒ 点击翻页。

## 三、定海（不变式）

- 分页读取的真相在**后端**（`total` / `totalPages`）→ `base/api/pagedList.ts` 已收口（TD-02-56），本轮**一行未写**。
- "还有没有下一页"的呈现判据归**翻页控件**（`page < totalPages`），不在各面板各算一份。
- 面板宽度的**合法区间**归各宿主面板（`min`/`max` 值单源）；**拖拽运算**归唯一原语。

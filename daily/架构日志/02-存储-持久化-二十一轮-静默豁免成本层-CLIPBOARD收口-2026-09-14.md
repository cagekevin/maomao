## 三、改动清单

1. **`VideoExtractNode.tsx`**：下载按钮 `onClick` 改 `async`，走 `downloadUrl` 信封 `{ok,msg}`，`!res.ok` → `showToast(res.msg, {type:'error'})`；移除原死 try/catch（未 await async fn，实为死代码）。
2. **`ImageBoxNode.tsx`**：`import { loadImageWithTimeout, attemptQuietly }`；`onDragStart` 中 `e.dataTransfer.setData(...)` 改 `attemptQuietly(() => ...)`（复用 NON_BLOCKING 主实现，零新增标记）。
3. **`PromptLibrary.tsx`**：`import { copyText }`；`handleNewNode` 改 `async`，走 `copyText` 信封 → `showToast(res.ok ? '已复制到剪贴板' : res.msg, {type: res.ok?'success':'error'})`（修复"先报成功"误报）。
4. **`TaskCenter.tsx`**：`import { downloadUrl, copyText }`；`copyPrompt` 改 `async`，走 `copyText` 信封 → 同上正确 toast（修复误报）。
5. **测试配套**（行为契约对齐）：
   - `TaskCenter.test.tsx`：`clipboard.ts` mock **补 `copyText` 桩**（原只桩 `downloadUrl`，导致组件侧 `copyText` 为 `undefined` 抛错）；复制断言前 `flush` 微任务。

## 〇 · 一句话

> **`useMemo` 是纯派生 —— 同输入必须同输出。在里面生成随机 id，等于让同一份数据每次重算都换一批身份。**
> 受害的是所有"按 id 记住某个实体"的地方（选中态 / React key）：
> `:628` 的「选中片段」effect 认不出 `selectedClipId` ⇒ `setSelectedClipId` ⇒ 渲染 ⇒ 重算 ⇒ …… 无限循环。

## 一 · 弯路留痕（强制 · 与结论同等对待）

### 弯路 1（**假绿**）：抖动开关只换了外层对象，用例"通过"是假的

为锁"引用抖动下不收敛"这条不变量，我给 mock 加了开关：
```js
useReactFlow: () => (unstableReactFlow ? { ...xyflowMethods } : xyflowMethods)
```
然后跑 → **通过** → 我据此准备收工。**但这是假绿**：

组件是 `const { setNodes, getNodes } = useReactFlow()` —— **解构以后**，抖动的是**外层对象**，
而 `setNodes` / `getNodes` 两个**函数引用根本没变** ⇒ 组件侧毫无感知，`useMemo` 依赖没变，压根没抖动。

**怎么发现的**：做"能否变红"的反向验证时，把组件改回随机 id，用例**仍然通过**（172ms）——
按推理它必须挂死。⇒ 不是"我的修复生效了"，而是"**我的用例没测到东西**"（7.1 的教科书形态）。

**教训**：**"用例通过"必须先用"注入违规 → 应变红"反向验证过，才算数**；
尤其当用例断言的是**间接可观测值**（计数、收敛）时，先问一句「**我的触发条件真的传导到被测代码了吗？**」
（本例：消息在**解构**那一刻就断了。）

### 弯路 2：断言选错（"恰好 6 次"在抖动下不成立）

不变量用例最初复用了普通用例的断言 `toHaveBeenCalledTimes(6)`。
但抖动场景下 `sources` 每渲染都变 ⇒ 抽帧 effect **每渲染都重跑**，上一轮会被清理函数置 `cancelled`
而**中途退出**（抽到第 1~2 帧就 `return`）⇒ 调用次数**不定且 > 6**。
⇒ 后绿一步直接红（`waitFor` 超时）。

**教训**：断言要跟着**场景**走 —— "恰好 N 次"只在"依赖稳定"的场景成立；
换到"依赖抖动"的场景，判据必须换成**收敛性**（静置后不再增长）而不是**精确次数**。

## 三 · Step 1 证伪

| 三问 | 结论 |
| --- | --- |
| ① 根因证据 | ✅ 硬证据：**本轮实测**（组件注入随机 id + 引用抖动 ⇒ vitest 挂死，日志停在 `RUN`、worker 烧 CPU）；且"`useMemo` 同输入产不同输出"是**确定性的语义违反**，不依赖复现 |
| ② 替代方案 | 现状（随机 id）**没有任何**替代价值 —— 它不服务任何需求，只是"顺手拿了个 id 生成器" |
| ③ 业务性 | 否 —— id 生成规则是**结构** ⇒ **架构师直接定**（Step 5 左栏） |

**真实环境可达性（诚实标注）**：**低**。三条依赖当前都稳（`useConnectedInputs` 用
`useStore(selector, upstreamEqual)` 保证 `upstream` 引用稳定，是 P0-B 专门做的；`timelineTracks` /
`sourceMetadata` 都是 state）⇒ **当前不会坏**。性质是**脆性缺陷**：任何人往这条链加一个不稳引用即复现，
且**复现形态是"整个剪辑器卡死"**，排查成本极高（本轮就绕了一大圈）。

## 四 · Step 3/5 定位与定权

**id 该由谁产生**（Step 3 六问）：
- 职责归属：clip 是**从 source 派生的** ⇒ 身份应由**来源标识**决定，而不是随机；
- 真源：`sources[].sourceId`（去重后的 URL）是唯一且稳定的标识；
- 变化速率：source 不变则身份不变 ⇒ **同输入同输出** ✅。

| 位置 | 改为 | 理由 |
| --- | --- | --- |
| `:437` 自动补片段 | `clip-auto-${s.sourceId}` | 同一源 → 恒等 id（`usedSourceIds` 已保证每个源最多补一次，无碰撞） |
| `:401` 持久片段缺 id 的回退 | `clip-${idx}-${ci}` | 纯旧数据兜底；按"轨道序号 + 片段序号"派生即可确定 |

**定权**：结构 ⇒ 架构师直接定（用户能做的事不变）。

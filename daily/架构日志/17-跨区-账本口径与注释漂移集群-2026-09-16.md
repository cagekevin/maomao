## 三 · 工具债（真债 · A10 当场修）

**缺陷**：`debt.mjs` 的 `loadAll()` 只并 `债务.md` + `债务-归档.md`，未并 `债务-全文归档-*.md`。

**修法（三件）**：
1. `loadAll()` 并入全文归档，优先级 **主表 > 活归档 > 全文归档**（同 ID 先入者胜）；
2. 快照行打 `src:'full'`，**只用于存在性 + `add` 取号**；`list`/`search` 排除、`show` 降级输出（见弯路 3）；
3. **顺带修**同类写入口缺陷：`resolve --note` 此前无人拦**裸管道符**（`validate` 只拦 `add` 的 summary）
   ⇒ 这正是 `audit` 报的「状态含裸 `|`」错位行（14 处）的成因；现于写盘前拦掉。

**先红后绿**：
```
红（修前）: node scripts/debt.mjs show TD-02-19  → ❌ 主表与归档中均无 TD-02-19
绿（修后）: node --check scripts/debt.mjs       → 语法通过
           node scripts/debt.mjs show TD-02-19  → ── TD-02-19（仅存于「全文归档」…）+ 原文去处
           node scripts/debt.mjs resolve TD-17-12 --note "probe|pipe"
                                               → ❌ note 含竖线…（被拒，账本未改：TD-17-12 仍 [已解决]）
```

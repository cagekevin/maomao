# 架构日志 · 22 视频（剪辑器 · 移除 Radix 依赖 / 编辑器原语自研）· 2026-09-15

> **触发**：用户报「左上角各 tab 互相遮挡 / 参差 / 内容前空一截」→ 根因不是某个视图写错了类，
> 而是 **Radix Tabs 用 `hidden` 属性隐藏非激活面板**（依赖 UA 样式 `[hidden]{display:none}`，
> 而任何作者 `display` 类都能压掉它）⇒ 空容器与激活面板**平分高度**。
> 上一轮（`22-视频-剪辑器-面板分区契约重写-2026-09-15.md`）已用 `data-[state=inactive]:hidden` 收口为过渡护栏，
> 并留下施工规格 `docs/135-radix-ui依赖移除计划-2026-09-15.md`（**本轮的施工依据**）。
> **目标**：`src/` 内 0 处 `radix-ui` / `@radix-ui/*`，`package.json` 删这两个依赖；
> 编辑器 UI 全部由本仓自己的「新语言」原语承担，**调用点尽量零改动**。
> **债**：本轮**无新增债**（工具侧两处按"工具债当场修"处理，见 §五）。

## 一、为什么必须删（三条都有实证，不是审美偏好）

| # | 事实 | 后果 |
| --- | --- | --- |
| 1 | `@radix-ui/react-tabs`：`hidden: !present`（`node_modules/…/react-tabs/dist/index.mjs:170`） | 依赖 UA 样式表 ⇒ 被作者 `display` 类压掉 ⇒ **空容器占位**（本轮事故真身） |
| 2 | Radix 弹层 Portal 到 `document.body`，而 `.ve-scope` 在编辑器根上 | 弹层拿不到 `--ve-*`；当时的补丁是 `document.body.classList.add('ve-scope','dark')`（用附随复杂度补，而非源头收敛） |
| 3 | Radix 用 `data-state="active\|open\|…"`，`ve-theme.css` 用 `data-active` | 同一 UI 两套状态属性 ⇒ 样式作者每次要先查"这是谁的" |

**不做**的替代方案：换 `floating-ui` / `headlessui` / `ark-ui`（那是换一个黑盒，判据不变）。

## 二、施工（6 步，一步一验）

**① A 级 8 个 → 原生元素**（`aspect-ratio` / `label` / `separator` / `progress` / `checkbox` / `switch` / `radio-group` / `slider`）

- 前 5 个直接降级为原生元素 + ARIA（`aspectRatio` 属性、`<label>`、`role=separator`、`role=progressbar`、`button[role=checkbox]`）。
- `switch`：`button[role=switch]`，状态属性 `data-state` → **自有 `data-active`**（`ve-theme.css` 三条规则同步改写）。
  顺带补 `display:inline-flex; align-items:center` —— 19 − 15 = 4，拇指必须上下各 2px 居中，否则 2px/17px 两个位移量对不上。
- `radio-group`：自研 context + roving tabindex + 方向键移动**并立即选中** + 端点环绕。
- `slider`：**原生 `<input type="range">`** + `.ve-slider`（`::-webkit-slider-*` / `::-moz-range-*`）。
  保留 Radix 的**数组形态 API**（`value: number[]` / `onValueChange` / `onValueCommit`）⇒ 13 个调用点零改动。
  键盘/step/触摸/a11y 全归浏览器；手写指针拖拽是重新实现浏览器已做对的事。

**② B 级 `tabs.tsx` 自研** —— 本原语最重要的一条：**非激活 = 不渲染**

```tsx
if (ctx === null || ctx.value !== value) return null;   // TabsContent 实现体第一句
```

不渲染就不存在布局，**无需与 CSS 优先级搏斗**，调用点也不必"记得别写 display 类"（母体 M2：靠人记得 ⇒ 换成机器可判定）。
键盘：方向键移动**并切换**（automatic activation）+ Home/End + `aria-controls`/`aria-labelledby` 成对。

**③ 层根基座（新增 4 文件 `ui/ui/layer/`）**

| 文件 | 职责 | 关键坑（都是实测踩出来的） |
| --- | --- | --- |
| `layer-root.tsx` | 层根 `#ve-layer-root`（`fixed inset-0 pointer-events-none z-modal-raise`）+ `LayerPortal` | 层根解析必须**在 render 期**（`useState` 惰性初始化）。放 effect 里 ⇒ 首帧 Portal 返回 `null` ⇒ 弹层自己的测量 layout effect 跑在"没有 DOM"时 ⇒ 早退后再也不重跑 ⇒ **永远 `visibility:hidden`**（只在 resize/scroll 时自愈） |
| `use-anchored-position.ts` | 锚点 rect → fixed 坐标 + 视口翻转/夹取 | ① 锚点收 **ref**（收元素 ⇒ `defaultOpen` 时首帧拿到 `null` 且依赖锁死）；② `contentRef` 必须**真的挂到节点**（漏挂 = 同样永远 hidden）；③ `pointerup` 也重算（`react-resizable-panels` 拖面板不触发 `resize`） |
| `use-dismissable.ts` | Escape + 点击外部（**唯一实现**）+ 层级仲裁 | ① capture 阶段 `pointerdown`；② 排除触发器自身（否则"点了先关再开"）；③ **在任意已打开层里也不算外面**（子菜单与父层是**兄弟**）；④ Escape 只给**栈顶**（否则对话框里的下拉按 Esc 会两层一起关） |
| `compose-refs.ts` | `forwardedRef` + 内部测量 ref 合挂同一节点 | Radix 那 15 行没有黑盒价值，自研免掉一个依赖 |

**④ 弹层原语**（顺序：popover → tooltip → menu 内核 → select → dialog）

- `popover`：`LayerPortal` + 定位 + dismissable；触发器 `onClick` **切换**；Escape 归还焦点、点外面**不抢**焦点。
- `tooltip`：hover/focus + `delayDuration`（Provider 缺省 700，Root 可覆盖）+ **跳过延迟**（刚关掉 300ms 内移到下一个立即显示，工具条扫描不重等）；
  气泡本体 `pointer-events-none`（**绝不能吞掉子元素事件** —— 8 个消费方全是"图标按钮 + 气泡"）。
- `ui/ui/menu/menu.tsx`：**`dropdown-menu` 与 `context-menu` 的同一份列表实现**（两者只差"怎么开"：点触发器 vs `contextmenu` 的鼠标坐标）。
  焦点留在容器、高亮写 `data-highlighted`；↑/↓/Home/End/Enter/Space/Esc/←/→ 全覆盖；子菜单是独立 `MenuRoot`（锚点 = 子菜单触发器）。
  **子菜单与父层共用同一份 `closeAll`** ⇒ 子项选中收起整棵树。
- `select`：`role=listbox/option` + 方向键 + 展开**定位到当前值** + 关闭归还焦点到触发器（下拉与菜单不同：菜单有手势栈顾虑，见下）。
- `dialog`：层根 + 遮罩 + **焦点陷阱**（Tab/Shift+Tab 在内容内循环，判据用 `hidden`/`aria-hidden` 而不是 `offsetParent`
  —— jsdom 里 `offsetParent` 恒 `null`，过滤后只剩"当前已聚焦那一个"，焦点陷阱会**静默退化**）。
- `slot.tsx`：`asChild` 唯一实现（`button.tsx` 与各触发器共用）。合并规则与 Radix 逐条对齐，**唯一有意差异**：`className` 用 `cn()`（tailwind-merge），
  让"调用点显式写的类赢"而不是"样式表先后决定"。

**⑤ 两处 `createPortal(document.body)` 跟着迁**（否则"body 补丁"一删它们就掉出 `.ve-scope`）：
`ui/ui/color-picker.tsx`（色轮弹窗）· `assets/draggable-item.tsx`（拖拽预览，用 `ve-card-thumb` 等作用域类）。

**⑥ 收尾**：`npm uninstall radix-ui @radix-ui/react-separator`（-73 包）· 删 `EditorShell` 的 body 补丁 ·
删 `ve-theme.css` 里两个引用 `var(--radix-accordion-content-height)` 的关键帧（0 使用 + 变量只在 Radix Accordion 里存在）·
`tabs.tsx` 的 `data-[state=inactive]:hidden` 由"不渲染"取代。

## 四、与图纸的偏差（诚实登记）

1. **闸加了又删**：按 `docs/135` §六 新增 `scripts/check-radix-free.mjs`（含扫描基数自检），跑了**两条先红后绿探针**
   （① 源码 import 注入 → 精确报 `spinner.tsx`；② `package.json` 依赖注入 → 精确报 `package.json`）。
   随后**用户裁定删除**：「依赖已经删干净、以后不可能再加回来 —— 永远都绿的门禁不需要，多个门禁没有意义」⇒ 已删（script + manifest 条目 + npm script），
   先红后绿证据留在此处（`docs/135` §六 那条"强制先红后绿"已完成，只是闸本身不再保留）。
2. **视觉差异（有意，往唯一真源收）**：
   `bg-popover` / `bg-popover-hover` → `bg-background` / `bg-secondary` —— 前者对应的 `--ve-popover*` 在 `ve-theme.css` **从未定义**，
   静默回落宿主画布色（`docs/135` §三.1 明令禁止）。受影响：导出 popover、转场选择 popover、提示气泡、菜单高亮。
3. **右键菜单高亮从 `focus:` 改为 `data-[highlighted]:`**：Radix 靠"把焦点放到每一项"实现高亮，自研把焦点留在容器上 ⇒ 不改则**悬停/键盘移动毫无反馈**（静默失效）。
4. **select 关闭时留一份 `hidden` 的选项副本**（只为"值 → 文本"登记）：否则 `<SelectValue placeholder>` 在关闭态只能显示占位符 = **选了但显示没选**（功能回归）。
   原 Radix 用 `SelectContentFragment`（Portal 进触发器的 value node）解决同一问题。
5. **`aspect-ratio` 用原生属性**：Radix 是 padding-bottom + 内层绝对定位（外层 `data-radix-aspect-ratio-wrapper`、`className`/`ref` 落**内层**）；
   自研单 div + `aspectRatio`，可见盒等价。

**当场修：`check:api` 的 `info 157` 里 123 条是闸自身 bug**（用户问「info 157 怎么这么多了」→ 逐条聚合取证）

| 项 | 事实 |
| --- | --- |
| 症状 | `info 157`，人根本不会去读；其中真问题（反向差集）被埋掉 |
| 聚合 | `consumer 模块未映射` **118** · `后端有、前端未登记` 29 · `consumer 形态非法` **5** · 信封不可静态判定 3 · 调用点变量化 1 · `fn 模块未映射` 1 |
| 根因 | `consumer` 是**字符串**（`contracts.ts`：`consumer?: string`，一个字段可用 `|` 列多条链），而脚本写 `for (const c of entry.consumer \|\| [])` → 对字符串即**逐字符遍历** ⇒ 每个字母 / `.` / `\|` 都当一条门面链解析（`consumer='r'`、`consumer='.'`、`consumer='\|'` 即铁证） |
| 真正的害 | 不只是"吵"：**门面存在性一次都没被校验过**（全进 info = 假守卫），即 R5 4.4 那半条判据是空转 |
| 修法 | 按 `\|` 拆分 + trim；非字符串脏数据显式报形态非法（不静默跳过）—— 工具债当场修 |
| 修后 | `info 157 → 33`（29 未登记 + 3 信封不可判定 + 1 调用点变量化） |
| 先红后绿 | 把 `consumer: 'relayProxy.relayGenerate'` 改成 `…TYPO` → `consumer 缺失` + exit 1（**修之前这条永远不红**） |
| 同族顺带 | `contracts.ts` 的 `iconifyProxy.fn: 'iconifyApi.buildIconSvgUrl'` 指向**不存在的模块名**（真身 `videoEditor/engine/lib/iconify-api.ts`）→ 改裸导出符号 `buildIconSvgUrl`（自动发现支持"全仓导出符号"形态）；探针证明改后 exit 0 且 `fn 模块未映射` 消失 |

**剩下的 29 条"后端有、前端未登记"是方向良性**（前端不静态可见地调用）：`/api/admin/*`(6) · `/api/providers/*`(5) · `/api/files/*`(3) · `/api/local-patch/*`(3) · `/api/logs`(2) · `/api/public/*`(2) 等。
⚠️ 唯一要留意的情形：其中若有**前端其实在调**（走变量化路径、反向差集 D 看不见）的端点，那才是真缺口 —— 按需补登记，本轮不列债。

## 六、手工实测清单（jsdom 测不出来的，必须人眼过）

> jsdom 无布局、无合成层、无浏览器手势栈 ⇒ 下面这些**不写自动断言**（写了就是假覆盖）。请按此单实测：

1. **面板 tab**：各 tab 切换后内容占满、无空白条 / 无参差（本轮核心验收）。
2. **属性面板**：滑杆拖动 + 松手落定（`onValueCommit` 快照）· 开关/复选框/单选（含禁用态）· 数字输入。

4. **排序菜单**（素材面板）与**右键菜单**（时间轴片段 / 轨道）：点开 / ↑↓ / Enter / Esc / 点外面；右键菜单出现在鼠标点；「基础编辑」子菜单悬停展开、← 收回。
5. **下拉选择**（设置 · 字幕 · 音色）：展开定位到当前值、列表可滚、选完焦点回触发器。
6. **导出弹出层**：能开、导出成功与取消、关闭后焦点去向。
7. **对话框**：删除 / 重命名 / 快捷键三个（Esc、Tab 循环、点遮罩、右上角关闭、`aria` 关联）。
8. **层根新位置**：拖动面板改宽后再开弹层 → 位置仍贴合触发器（`pointerup` 重算）。
9. **拖拽素材**到时间轴时的缩略图预览位置/外观；**色轮弹窗**定位与配色。
10. **「导入」按钮的文件选择器**：必须是直连 `openFilePicker`（**不得**回到"挂在菜单项 onClick 上"——菜单关层会打断浏览器手势栈，文件选择器被静默丢弃）。

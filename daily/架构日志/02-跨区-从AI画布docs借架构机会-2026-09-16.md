## 一、链路快照（对方架构地图，精简取证）

对方 `doc/架构说明.md`（v0.9.0, 2026-08-30）给出完整边界：

- Store 是状态入口不是协议实现层；services 持有厂商协议／持久化（§12.1）。
- 统一生成入口：`aiService` → 按媒体类型拆 `generateImage/Video/Audio`；`mediaProviderRegistry` 把参考媒体统一分发到厂商适配器（§6.1）。
- 异步派生结果回写前经 `canvasDerivationGuard` 复核项目／源节点／revision（§5.8, §9.1）。
- 插件执行身份由 `sourceDigest`（入口源码 SHA-256）约束，运行 IPC 只传不透明身份＋输入；旧版本结果不能写进新版本状态（§6.5, ADR 0010）。
- 失败关闭纪律：Plan 模式只放行只读；「宁可拒绝也不覆盖用户修改」（ADR 0002:26）；声明式 `inputConstraints` 元数据缺失即失败关闭（ADR 0008）。
- 凭据不进 Store 持久化／Event／日志／导出归档，只进 Rust `secret_store`（§12.13, §8）。
- 生成结果 `generationService` 先落盘本地文件再回写节点，刷新不丢图（§9.1, doc 56 §14.4）。
- 外部协议（MCP）只复用已注册工具＋Policy＋审计，不新增 Shell／任意路径／通用 HTTP（ADR 0004）。

- `src` 搜 `derivationGuard|sourceDigest|revision.*复核|写回前.*revision` → **0 命中**（无前端写回前 revision 复核）。
- `src` 搜 `mediaProviderRegistry|connectedReferenceMedia|参考媒体.*统一` → 仅命中我们复制的对方文档，**实际代码无此注册表**。
- `src` 搜 `inputConstraints|失败关闭|failClosed` → 仅 `scriptbox` 子系统有局部 constraints，**媒体生成无统一声明式校验＋失败关闭层**。
- `src` 搜 `generationService|先落盘.*再回写|downloadUrlAndSave` → 无统一「先落盘再回写」service（doc 56 §18.4 已记）。
- 参考图靠 `resolveLocalImages` 内联 base64（架构总览 §3），超大图／视频有体积上限风险（架构总览 §7.10 图床缺失）。

## 四、切割（借什么／不借什么）

- **借（机制可迁移，与 Tauri 解耦）**：canvasDerivationGuard、mediaProviderRegistry、声明式 inputConstraints＋失败关闭、generationService 落盘收口、Store=状态入口边界、凭据不进可观测通道、画布语义单一、外部协议不扩权、版本租约防回潮。
- **不借（强绑 Tauri/Rust 原生）**：native plugin trust registry 的 Rust 私有快照、secret_store 文件系统实现、MCP 的 Rust bridge——只借其**设计纪律**，不搬实现。
- **已借（doc 56 覆盖，不重列）**：policyEngine effect 矩阵、ghost 节点、revision 锁、双重授权、子 agent 只读。

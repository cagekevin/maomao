## 〇 · 铁律重申（裁定，2026-09-17）

> 「一段代码失败了、却没任何人知道，那就是债。」→ 失败必须可见；`catch { return [] }` 把读取失败伪装成"空结果"，用户账户/提示/历史静默消失，零痕迹 = 债。

## 二 · 溯源（母体）

**母体 = 兜底闸的盲区 + 本仓"存储失败必日志"约定被局部偏离。**
`check-silent-catch.mjs:104-118` 的 `INLINE_PATTERNS` 与跨行扫描**只识别"空 catch 块"**（`catch {}` / `.catch(()=>{})` / `.catch(()=>null)`）。
但 `catch { return []; }` 是**有内容体**的 catch，闸的正则（`catch\s*\{\s*\}` 要求块内仅注释/空白）**匹配不到** → 放行。
于是"读取失败→返回默认空值→不日志"的静默吞，既不触发闸，又偏离本仓对话/记忆/偏好存储早已建立的 `logger` 留痕约定，成为漏网债。

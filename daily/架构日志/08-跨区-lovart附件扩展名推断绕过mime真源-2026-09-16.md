## 三 · 探债（逐条结论 + 证据）

### 1 · lovart_attachments 四套内联 ext 推断绕过 mime.ts 唯一真源（新发现，未登记）
`localTool/src/ai-relay/providers/lovart/lovart_attachments.ts`：
- `extFromDataHeader(header)`（:59-71）与 `extFromContentType(ct)`（:73-86）：用 `h.includes('jpeg')||h.includes('jpg')` / `h.includes('png')` / `h.includes('mp4')` / `h.includes('webm')` / `h.includes('mpeg')||h.includes('mp3')||h.includes('audio')` 子串匹配 → ext。
- `B64_MEDIA_MAGIC`（:23-36）+ `extFromB64Magic`（:51-57）：魔数前缀 → ext（值不带点：`jpg`/`png`/…）。
- 三处未知型均 `return 'png'`（:56 / :70 / :85）= **静默兜底**。

**证据（逐条可复现）**：
1. **绕过 SSOT**：`mime.ts` 文件头明写「唯一实现（2026-09-11 收口）」，且 `mime.ts` 已导出 `mimeToExt(mime)`（`files.ts:328` `mimeToExt(mime) || …` 实证可用）与 `extToKind(ext)`（`resources.ts:22` `import { extToKind } from '../utils/mime.js'` 实证可用）。本文件未 import 二者，自持四套 → 与 TD-08-17/18 同母的第二份。
2. **口径错位 / 假收窄（`includes` 子串匹配漏判）**：
   - `h.includes('audio')` → `audio/aac`·`audio/ogg`·`audio/flac`·`audio/wma`·`audio/opus`·`audio/x-ms-wma` **全部错归 `'mp3'`**（应为 aac/ogg/flac/wma/opus）；
   - `h.includes('mpeg')` → `video/mpeg` 也归 `'mp3'`（视频误归音频扩展名）；
   - 整条链**不认** `avif`/`svg`/`tiff`/`m4v`/`mkv`/`avi`/`mov`/`oga`/`opus`/`wma`/`aiff`/`flv`/`wmv` → 这些类型（无论 data-header 还是 content-type 还是裸 base64）一律落默认 `'png'`。
3. **静默吞 / 失败伪装成功**：未知/不支持媒体不上报，直接当 `.png` 上传 Lovart CDN → Lovart 按 png 解析非 png 字节，生成结果偏差或失败，但调用方无感知（与文件头「真实上传失败才 throw」的可见性红线矛盾）。

**根因**：TD-08-17/18 收口轮只改了 `resources.ts` / `admin.ts`，未把 `lovart_attachments.ts` 纳入；且后端无机器闸禁止新增 inline ext 推断（前端有 `check:arch` 规则 10 类守卫，后端缺对等闸）→ 同母复发。
**归类/归属**：增债 / 结构债（委托 mime.ts，纯重构，不改对外 Lovart 契约；修正后非 mp4 音频/视频/avif 等参考素材将带正确扩展名上传，属正确性修复非契约变更）。
**利息率**：中（核心图片路径不受影响；主要影响图生图/图生视频里非 mp4 的音频与 avif/mkv 等参考素材，错扩展名可触发 Lovart 解析失败或结果偏差）。
**偿还计划**：`extFromDataHeader`/`extFromContentType` 改为委托 `mime.ts mimeToExt`（先去参数再查，如 `mimeToExt(ct.split(';')[0].trim())`）；`extFromB64Magic` 输出 ext 与 `mime.ts` 规范扩展名对齐（补 `.` 或调用方 `.slice(1)`）；删除 `includes` 子串链与静默 `'png'` 兜底，未知型走 `mime.ts` 的 fallback 语义（resources dataURL=.bin / base64 外置=mime subtype）；若 `mime.ts` 缺 `aac`/`ogg`/`flac`/`opus`/`wma` 等映射则补入唯一表。

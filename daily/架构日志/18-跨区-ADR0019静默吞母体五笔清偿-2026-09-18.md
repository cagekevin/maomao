## 一 · 正确形态（施工前先写下来）

1. **三态必须可区分**：`真空`（无内容体，合法静默）／`非法`（有体但解析不出，真失败）／
   `读失败`（响应流中断，真失败）。原实现用同一个 `{}`（或 `''`）承载三者 ⇒ 后两者被伪装成第一种。
2. **失败由产生它的那层暴露**：生产者给**判别联合 + 可展示文案**，消费者**只转发**（禁自造文案、禁重新归类）。
3. **留痕属于产生失败的那层或拥有 UI 的那层**：中转层不重复记（重复留痕 = 噪声 + 制造第二份真相）。
4. **兜底净减**：删兜底，不新增兜底。**保留的降级必须带判据**（"为什么可以吞"），否则就是兜底。

**零炸三问**：

1. **哪些行为被改了？**
   - ① `httpRequest` 2xx 且体**非空但非法 JSON** → 由静默 `{}` 改为**抛错**；
   - ② `httpRequest` 2xx 且**读体失败** → 由静默 `{}` 改为**抛错**（AbortError 原样上抛，类别不变）；
   - ③ 非 2xx 且错误体**非 JSON** → `HttpError.message` 由空串改为**错误体原文**（TD-03-11 本意首次生效）；
   - ④ `agentRuntime` 非流式读体失败 → 由**空回复**改为**抛错**；
   - ⑤ `director3d/App` 参考图导出失败 → 行为**不变**（仍清空背景），**新增留痕**；
   - ⑥ `localTool` 上传登记失败 → 由"泛化上传失败"改为 **500 + 明确 message + 专用留痕**；
   - ⑦ `accountsStore.readTabLocalStorage` 的 `chrome.tabs.query` 异常 → 由**直穿**改为**降级返 null**（与其 JSDoc 一致）；
   - ⑧ 2xx **真空**（空体/204）→ **未改**，仍静默返回 `{}`。
2. **改前能走的路径，改后仍能走吗？** → 是。`npx vitest run` → **3031 passed / 242 files**（改前基线同为 3031/242）；
   `npm run test:localtool` → **350 pass / 0 fail**。
3. **改前会失败的，改后仍失败吗？** → 是。2xx 空体仍返回 `{}`；非 2xx 仍抛 `HttpError`；
   `filesApi` 的"200 但后端未回 url"仍 `ok:false`；`persistUrlToUploads` 的 `unsupported`/`empty` 判词未动。

**用户可感知的行为变化（显式声明，哪怕是有意的）**：
- ① 后端/AI 返回**被截断的响应**时，用户从「看到空白 / 空回复」变为「看到可重试的错误文案」——
  这是本债的**目的**（一诚实闸的应有结果），非副作用；
- ② 上传**登记失败**时接口从 200 泛化失败变为 500 + 明确原因，且原因经 `UploadOutcome.message` 上浮到 UI。

# 22 · 视频剪辑器 · 时间轴缺失素材显示（用户报障触发）

> 触发：用户报「Video editor 里缺少丢失素材的显示。一个素材没有或者消失了，它在时间轴里应该有一个显示，但现在没有，就是一片空白」。
> 定位：区域 22（视频 / 剪辑器）。本轮只审时间轴素材缺失这一表面，自下而上取证。
> 结论唯一落点 = 本文件；index.md 只放状态 + 链接；DATAFLOW 只打灯。

## §一 · 链路快照（refs 实证）

时间轴片段渲染读取媒体资产：

```
editor.media.getAssets()            ← MediaManager.getAssets（videoEditor/engine/core/managers/media-manager.ts:136）
  → timeline-element.tsx ElementContent  按 element.mediaId 查找 MediaAsset（:98-103）
      ├ 找不到 mediaAsset            → <span>{element.name}</span>（:426-429）
      ├ video 且 mediaAsset.file 缺失 → 跳过 VideoThumbnailStrip，落到末尾 name 文本（:431）
      ├ image 且 mediaAsset.url 缺失  → 跳过背景图，落到末尾 name 文本（:454）
      └ 其余 → 末尾 return <span>{element.name}</span>（:469）   ← 全部"源不可用"坍缩成同一空白态
video-thumbnail-strip.tsx            ← VideoThumbnailStrip：以 mediaAsset.file 抽帧，file/url 缺失时画布留白、无失败指示（:217-235）
```

`refs` 实证：
- `timeline-element.tsx` ← `timeline-track.tsx`（1 处模块 import，叶子渲染组件）；字符串残留 3 处（脚本/ lint 批处理，非消费方）。
- `types/assets.ts` 0 处模块 import（`import type` 不被 refs 计入；真实消费者经类型 import：timeline-element / media-manager / types/timeline 等）。
- `media-manager.ts` 由 `editor.media` 单例持有，无独立 fan-in 计数意义。

## §二 · 溯源（谁产生 → 谁消费 → 落哪）

- **产生**：`MediaManager.addMediaAsset` / `loadProjectMedia` / `setAssets` 维护 `assets: MediaAsset[]`（`media-manager.ts:11/29/89/140`）。
- **消费**：`timeline-element.tsx` `ElementContent` 按 `element.mediaId` 查 `mediaAssets`（:98-103）决定片段视觉。
- **落哪**：`MediaAsset` 形状 = `file: File` + `url?`（`types/assets.ts:5-8`）；持久化形 `MediaAssetData`（`engine/services/storage/types.ts:15-29`）只有 `url?`/`thumbnailUrl?` 可选，**无任何 availability/status 字段**。
- **失败路径**：`loadProjectMedia` catch 仅 `logger.error`（:91-92），`this.assets` 保持为空或旧值 → 时间轴元素仍带旧 `mediaId` 引用 → 渲染成 `!mediaAsset` 空白（与 TD-22-43 同根，但 TD-22-43 范围是"加载层静默空面板"，本债是"时间轴渲染层空白"，表面不同）。

## §三 · 定海（不变式 / 红线）

- **期望不变式**：时间轴片段引用的素材"找不到 / 源不可用"时，应渲染明确的"缺失 / 断链"指示（红框 + 图标 + 名称），让用户能区分"缺失素材片段"与"正常空片段"。
- **现状**：该不变式被违反——所有"源不可用"分支坍缩为仅显示 `element.name` 的小字或留白画布，视觉上即"一片空白"。
- **红线冲突**：无。不涉及端口 `18080` / `{code,data}` 契约 / 存储键登记表等 CLAUDE 级红线。

## §四 · 切割（边界）

- **本轮回审范围**：时间轴片段渲染 `timeline-element.tsx` `ElementContent` + 缩略图条 `video-thumbnail-strip.tsx` + 底层 `MediaAsset`/`MediaAssetData` 类型 + `MediaManager` 加载失败路径。
- **不在范围（@见其他债）**：
  - 素材面板加载失败可见性 = TD-22-43（loadProjectMedia 双缺口，已待还）。
  - 预览面板 / 导出管线缺失素材处理 = 下轮（本轮未审，覆盖度表列 `未审`）。
  - 切项目单例重置遗漏 = TD-22-46（素材"消失"的另一诱因，已待还）。

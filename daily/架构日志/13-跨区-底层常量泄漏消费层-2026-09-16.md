## 一 · 链路快照（真实现状，refs/grep 实证）

`contracts.ts` 是横切契约**唯一登记表**：`EVENTS` / `STORAGE_KEYS` / `GEN_ERRORS` / `NODE_TYPES` / `NODE_HANDLE_CONTRACT` / `API_ENDPOINTS` / `apiRegistry` 各自「单一事实来源」，文件头明文「新增键→先在此登记，禁止散落字符串字面量」（contracts.ts:154-160、:797-799、:627）。

但 `STORAGE_KEYS` 已登记的**固定键**里，有一批没有导出命名 const，于是各自消费/抽象层**本地再声明一份同名字面量**：

## 二 · 溯源（为什么会产生）

- `contracts.ts` 文件头 + TD-13-4 已立规则：「登记表导出命名 const，模块 import 引用，键名全仓唯一定义」（contracts.ts:215-224）。
- TD-13-4 实际只导出了 7 把 `yimao_*` 键（`KEY_YIMAO_*`）+ M7 裸写键（`KEY_DIRECTOR3D_*` / `KEY_EDITOR_CAPTION_*` / `KEY_VIDEO_EDITOR_SAVED_SOUNDS`）。
- `agent_*` / `active_api_endpoint` / `mutiwindow-clipboard` / `agent_split_width` / `agent_panel_width` / `scriptbox_playbooks` 这批**登记了却没导出 const** → 各消费层只能自己再声明 → 第二份。
- **缺机器守卫**：TD-13-4 只「人补 7 把」，没加 `check-arch` 规则拦「`contentGet/Set/sGet/sSet` 的键字面量必须引用 contracts 导出 const」→ 同母（M7 SSOT 第二份）必然复发（TD-13-4 自身注释就写「M7 复发」）。

## 三 · 定海（红线 / 真源，不影响登记）

- 真源 = `contracts.ts STORAGE_KEYS`（已含这些键）。
- `getLocalKeys()`（contracts.ts:605）读 STORAGE_KEYS 派生**备份/云同步清单**；若某键在「登记表」与「消费层本地 const」两处不一致，清单即漂移 → 漏备/误还原（数据完整性风险）。这正是 TD-13-4 原文描述的爆炸半径。
- 本债只登记，不动代码（readonly 流程）。

## 四 · 切割（哪些不在本债范围 / 已裁定非债）

本轮同时扫了其余「本该在底层」的契约，结论均为**已收口，非债**，列入覆盖度表防重审：

- **事件名**：`EVENTS` 全表登记；grep `publish('`/`subscribe('` 全部命中已登记事件（resource:sent / agent:task-completed / upstream:updated / persist:failed / presets-changed / project:import / project:export / videoeditor:seek），无裸事件泄漏。
- **端口 18080**：`config.ts:12` `LOCAL_TOOL_PORT` + `API_BASE` 单一来源；`depthUrls.ts` 用根相对 `/depth-video` + API_BASE（非字面量），其余 `18080` 多为注释/UI 展示文本。
- **错误文案**：`GEN_ERRORS`（contracts.ts:635）单一分类入口；`genErrors.ts` 实现，节点侧无 `if(/网络错误/)` 裸判（scriptBoxEngine.ts:210 反而依赖 classifyError）。
- **端口契约**：`NODE_HANDLE_CONTRACT`（contracts.ts:768）单源；`lazyNode.tsx:40` `LAZY_NODE_HANDLE_CONTRACT = NODE_HANDLE_CONTRACT` 已收口；`App.tsx` 旧内联表无残留（grep 无 `TARGET_/SOURCE_HANDLE_BY_NODE_TYPE` 定义）。
- **积分闸字段**：`CREDIT_SWITCH_KEY` / `CREDIT_GATE_FIELD` / `CREDIT_GATE_EVENT` 均导出 const 且被消费方 import（conversationState/conversationInvariants/conversationSkillState/useCanvasAgentTools）。
- **扩展名表**：`EXT_KIND`（assetType.ts:29）是扩展名→类别唯一真值源，`EXT_MAP` 由其派生；`filesApi.ts:178` 的 `EXT_BY_TYPE` 是「每类首选输出扩展名」**独立关注点**（4 项闭集、显式选值），非第二份 → 非债。
- **端点路径**：`API_BASE` + `apiRegistry` 收口；`GeneratedView/ResourceLibrary/pollTask` 仅注释含 `/api/...`，真实调用走 filesApi/relayProxy/localToolApi。
- **`shot-` 前缀**：`scriptBoxEngine.ts:696` 的 `` `shot-${shot.id}` `` 是 `runAbortable` 的**中止 map key**，非 React Flow 端口 id（端口走 `shotHandleId`，见 :1384/1523）→ 非 SHOT_HANDLE_PREFIX 泄漏，误报剔除。

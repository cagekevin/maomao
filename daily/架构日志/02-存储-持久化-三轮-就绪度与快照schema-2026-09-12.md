## 二、本轮消除的复杂度错位

### 2.1 M4 → TD-02-2：把「就绪度」从隐式时序契约升为一等状态

- **错位复述**：`storageAdapter` 的预填是**异步**的，导出的读写是**同步**的 → 天然存在「未就绪窗口」；窗口的**唯一表达方式**曾是「模块求值顺序 + main.tsx 第 12 行」这句注释。同时 `contentStore.loadFromLocal` 把「未就绪（还不知道）」与「确实不存在」都写成 `cache.set(key, undefined)`，且 cache 无失效机制 → 该键被粘成不存在直到整会话结束；`projectStore`/`resourceStore` 还在未就绪时**回写种子**（等于用默认值覆盖真实存档）。
- **三层修法（复杂度归位，不搬家）**
  - **L1**：`storageAdapter` 增 `isStorageReady()`（非扩展环境恒就绪——那里本就没有「异步预填」这一步）与 `onStorageReady(cb)`（已就绪则立即执行）；`initStorage` 统一走 `markReady()` 唤醒等待者。
  - **L2**：`contentStore.loadFromLocal` 未就绪时**返回 undefined 但不写缓存** —— 这是「不制造假真相」的最小动作（不再需要「就绪后清缓存」这种会让已渲染组件快照抖动的末端补丁）。
  - **L3**：三个模块级 eager 读（`projectStore` / `resourceStore` / `appSettings`）未就绪**不回写种子**，并注册 `onStorageReady` 在就绪后**重读一次**（`projectStore` 另加「已从后端加载过则不覆盖」守卫）。
- **度量**：认知单元数「读一个键」4→2（后端路由 / 策略族；不再需要同时记住「adapter 是否 ready」与「启动顺序」）；隐式契约数 1→0。
- **验证**：`contentStore.test` 65 例（+2 就绪度用例）、`storageAdapter.test` 17 例（+4）；**全量单测 190 文件 / 2429 例全绿**；`check:arch`（无循环）+ `type-check` 0 错。
  - 连带发现（同一根因的传染面）：`tests/unit/assetTools.test.ts` 的 storageAdapter 桩未声明 `isStorageReady` → 该桩下「未就绪」恒真 → `nodePrefs` 读不到 seed 而退化默认值（**1 例失败**）。属「替身未随契约更新」的典型；已补 `isStorageReady: () => true` 并注明原因 —— 也说明本改造让「就绪度」成为**显式契约**（替身必须表态），不再能靠默认行为蒙混。
- **状态**：**已解决 2026-09-12**。

### 2.3 M6 → TD-02-9：修掉一个「瞎了却一直报绿」的对账工具（假护栏）

- **现象**：`npm run check:node-data` 长期输出 `palette (0)` 与 `读侧声明式产出 NODE_OUTPUTS: (未解析到)`，却仍报「**字段缺口 0 处**」并通过 `check:health`。
- **两个技术根因（均因 `.ts` 化而静默失效）**
  1. 正则写死「名 = [」字面形态，而源码是 `export const paletteNodes: PaletteNodeDef[] = [`（类型标注插在中间）→ 匹配失败。
  2. 修完 (1) 仍为 0：`src.indexOf('[', m.index)` 被类型注解里的 `[]` **抢先命中**，`open` 落在注解上 → 配对到注解的 `]` → 整段解析为空。
  3. 另有 `blankComments` 把**字符串内容**抹成空格，而 `type: 'assetNode'` 的 type 值正是字符串字面量 → 取 type 必须从**原始源**同偏移读回。
- **修法**：三处一并修（容忍类型标注 / 用 `m.index + m[0].length - 1` 定位真正的 `[` / 新增 `readRaw` 供取字符串字面量）。修复后 palette 侧解析出真实字段（如 `imageBoxNode: images activeIndex expanded`、`gridMergeNode: 13 键`），NODE_OUTPUTS 解析出 `scriptBoxNode / imageBoxNode / videoExtractNode / gridSplitNode / gridMergeNode`。
- **加固（防再次假绿）**：脚本新增**解析器自检** —— 任一解析源为空即视为「工具瞎了」，输出显式告警并在 `--strict` 下 `exit 1`（「0 缺口」从此只有在工具证明自己看得见时才可信）。
- **负例探针验证**：临时打断 `paletteRawSrc` 后运行 → `⚠ 解析器自检失败 …: NodePalette paletteNodes/HIDDEN_TOP_LEVEL_NODES` 且 `PROBE_EXIT=1`；探针脚本已删除。
- **状态**：**已解决 2026-09-12**。

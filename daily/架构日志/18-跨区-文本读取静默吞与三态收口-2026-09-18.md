## 一 · 正确形态（施工前先写下来）

**不变式**（与 `16-跨区-读失败伪装成空拆兜底-2026-09-17` 同源，本轮只是让 HTTP 读取侧不再违背它）：

1. **读取函数只负责分清三态**：读到内容 / 读到空 / 读失败。
2. **「失败怎么呈现」是调用方判据** —— 读取层无权替所有调用方决定失败长什么样。
3. **失败不得入缓存** —— 否则失败被固化，此后永远不再重试。

**链路（改后）**：

```
httpRequest ──非2xx/网络/超时→ throw（httpClient.ts:228/244）
      │
fetchText ──不吞──→ {ok:false,error}（源头 reportDegrade 留痕，不弹 toast）
      │                     └ 成功才 textCache.set
      ├── useTextAsset（三态 hook · 唯一实现）──→ loading / ok / failed
      │        ├── ResourceLibrary.TextAssetCell   → 单元格显示内容或失败判词
      │        ├── GeneratedView.TextResourceCell  → 同上
      │        └── ResourcePreview.TextPreview     → 内容 / 「（空文件）」/ 「（失败判词）」
      └── makeAssetDragProps.onDragStart ──失败→ reportDegrade + toast（发起端知道用户正在拖）
```

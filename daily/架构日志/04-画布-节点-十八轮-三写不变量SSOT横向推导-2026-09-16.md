## 二、溯源（横向推导主线）

母体 **M7（SSOT 第二份 / 同语义两处写点）** 在区域 02/05/12/22 反复出现。本轮验证该母体在**区域 04 的尺寸写回层**也有漏网实例：

节点尺寸 `width` / `height` / `style.width` / `style.height` 必须**四值同写**，否则刷新/落盘后尺寸塌缩（NodeShell 读 `n.width ?? n.style?.width`，width 优先）。该不变量当前被 **3 处手抄**，每处都用注释自证"必须同时写"——正说明它该是 1 个共享纯函数而非 3 份手抄：

| # | 写点 | 实证行 | 手抄内容 |
| - | ---- | ------ | -------- |
| ① | `base/core/uiHooks.ts` · `onMainBoxResize` | :231-232 | `style={...(getNode(id)?.style\|\|{}),width:w,height:h}` + `patchNodeById(setNodes,id,{width:w,height:h,style})` |
| ② | `hooks/useArrangeCanvas.ts` · group 写回 | :265-271 | `width:pos.width,height:pos.height,style:{...node.style,width:pos.width,height:pos.height}` |
| ③ | `base/canvas/groupNodes.ts` · 建组 | :64-69 | `style:{width:gw,height:gh}` + `width:gw` + `height:gh` |

注释对照（同源自证）：
- ② `useArrangeCanvas.ts:261-264`：「必须同时写 width/height（与 style 一致）……与 `useNodeResize.onMainBoxResize` 的「width+height+style 三写」不变量**保持一致**（TD-04-16）」→ 直认"手抄 + 手动同步"。
- ③ `groupNodes.ts:65-67`：「⚠️ 必须同时写 width/height 字段（与 style 一致）……仅写 style 时，落盘/刷新后若 width 未同步，尺寸会塌成默认」。

**根因**：TD-04-16「尺寸写回唯一化」只把**手柄拖拽**收敛到 `onMainBoxResize` 单入口，却未把「三写不变量」抽成共享纯函数；批量写点（② 排版、③ 建组）无法走 per-node hook，于是各自手抄 + 注释兜底。**同一真相 3 份，靠"约定"同步** = 典型 M7。

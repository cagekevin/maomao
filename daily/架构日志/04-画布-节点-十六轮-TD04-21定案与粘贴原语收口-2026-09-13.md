# 04 区 · 十六轮 — TD-04-21 定案（粘贴识别原语收口）

> 日期：2026-09-13 ｜ 方法：**按 `架构师改码7步法.md`**（Step 1 证伪 → 2 归因 → 3 定位 → 施工 → 7 验证落账）。
> 触发：**用户澄清业务语义** —— 「网页富文本要建文本节点啊…不管来的是什么文本，直接给它清洗成我们自己简单的文字」。
> 范围：`hooks/useAssetDropPaste.ts`（A: useGlobalPaste / B: onPaste）+ 既有测试锚定。

## Step 1 · 证伪（用户澄清 → 推翻十四轮的两项认定）

**取证三条（实测）**：

| # | 事实 | 证据 |
| - | - | - |
| 1 | **画布上**粘任何文本 → 清洗成纯文本 → 建文本节点 | `onPaste` → `handleTextPaste` → `sanitizePastedText`（`clipboard.ts:37`：压缩连续空格/空行、去不可见字符、统一换行）→ `addNode('textGenerateNode', …)` |
| 2 | **输入框（CE）内**粘任何文本 → 只取 `text/plain` 插入 → 天然纯文本化 | `PromptInput.handlePaste`（`PromptInput.tsx:616-646`）无条件 `preventDefault` + `getData('text/plain')` + 插入光标处；**不保留 html/样式** |
| 3 | **只有 1 个粘贴入口** | `App.tsx:1003 useGlobalPaste(onPaste)`；ReactFlow **无** `onPaste` prop（grep 全 App 仅此一处） |

**→ 用户正确：代码已经是「任何文本都清洗成纯文字」**。十四轮的两项认定均不实：
- ❌「B 会把网页富文本建成 textGenerateNode（用户没想要）」——**用户想要**（且这正是设计：清洗后建节点）；
- ❌「调用链有**两条入口** → 存在重复触发可能」——实际**只有 window 一个入口**（取证错误）。

---

## Step 2 · 归因（真债是什么）

不是「判据不一致要统一」，而是 **A/B 各自重复实现 4 个探测原语 × 2 份**（CE 判定 / 图片判定 / 组 JSON 判定 / 读剪贴板文本）→ **改一处易漏另一处**。

---

## Step 3 · 定位（**不合并判据** —— 本轮关键）

A 与 B 的判据**必须不同**，这是**分层职责**而非漂移：

| | A（window 层） | B（onPaste 内） |
| - | - | - |
| 职责 | 「事件是否交给 onPaste」的粗判 | 「建节点前的编辑器放行」 |
| 数据面 | **只看同步** `clipboardData.items`（window handler 不便异步读） | 必须允许 **`items` 为空时继续往下**走 `navigator.clipboard.read()` **异步兜底** |
| 判据 | 放行 ⟺ 图片 **或** 组 JSON | 拦截 ⟺ **只有纯文本**（⇒ `items` 空 → 非纯文本 → 不拦截 → 交给 read() 兜底） |

**锚定证据**：`useAssetDropPaste.test.tsx` 用例 219 / 262 明确用 `clipboardData: { items: [] }` + `navigator.clipboard.read()` 返回内容 → **若判据统一成 A 的（items 空即不放行），read() 兜底立即失效**。

→ **收口「探测」，保留「判据」。**

## Step 6 · 施工

1. 抽出 5 个**模块级私有原语**（单一实现）：
   `isContentEditableEvent` · `readClipboardText` · `isCanvasGroupJson` · `hasImageClipboardItem` · `isOnlyPlainTextClipboard`（内部复用 `hasImageClipboardItem`）。
2. A / B 各自**组合原语**：A 保留「放行 ⟺ 图片或组 JSON」，B 保留「拦截 ⟺ 只有纯文本」。
3. 两处判据差异以注释**显式留痕**（「属分层职责、非漂移，故不共用同一判据函数」）。

## ⚠️ 教训（本轮最重要的产出）

- **「重复」须先分辨是「探测重复」还是「判据重复」**：探测原语应**收口**；判据重复可能是**有意的分层**（收口会让某层失去必要的灵活性/兜底）。
- 本轮第一版我**想当然统一判据**（抽 `shouldPassContentEditablePaste` 两处共用）→ `useAssetDropPaste.test.tsx` 的「CE 内 `items:[]` + `read()` 返回图片」用例**当场变红**（B 提前 return → `read()` 兜底失效）。
  **十四轮「正解不是抽一个函数两处共用」的结论是对的**，我一度违背 → **被既有测试锚住**。
- 印证心法：**动手前先取证（尤其看测试锚定的语义）**；既有测试是**行为契约**，不是可随手改的。→ 已回退判据统一，仅保留探测收口。

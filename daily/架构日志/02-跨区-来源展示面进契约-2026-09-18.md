## 二 · Step 1 证伪（母体成立：三症状 = 同一条规则失败）

**规则失败**：「这是**来源的**展示属性，却不在来源契约里」。

1. **① 硬证据**：`TAB_LABEL` 的 3 项与 3 个 `provider.label` **逐字相同**（真 M3 第二份）；
   `TAB_ORDER` 硬编码 ⇒ 新增来源必须**同时改消费方**，否则 tab 不出现 —— 而 `mediaRefRegistry` 的契约原文写着
   「新增来源 = 写一个 provider 文件 + 加一行 import；**消费方改 0 行**」⇒ **承诺与实现相反，且失败是静默的**。
2. **② 替代方案对比**：`order?: number`（来源声明）＜ 消费方维护清单（又一条"来源的知识不在来源里"）；
   ＜＜ **依赖 `providers/index.ts` 的 import 顺序**（更隐蔽：顺序会随 import 重排静默改变）。
   ⇒ 选显式 `order`，并**专门写一条测试**锁住「内置三来源都必须显式声明 order 且互不相同」，防它退化成 import 序。
3. **③ 致命拷问**：用户不"多做"事；变的是**新增来源 = 消费方改 0 行**（从契约承诺变成**机制保证**）。

## 三 · Step 3 定位

- **判据归属**：三样都是「**来源的**展示属性」⇒ 归 `MediaRefProvider` 契约（来源自己声明）。
- **排序归注册表**：`listMediaRefSources()` 是来源集合的所有方，且**每个消费方都必须拿到同一份顺序** ——
  让消费方各排一次 = 又一份规则（M3）；硬编码更糟（见 §二）。
- **谁是本弹窗自己的**：`local`（本地导入）是**写动作**、不是来源 ⇒ **不进契约**，由弹窗保留一处声明
  （`LOCAL_TAB` + `LOCAL_TAB_LABEL`）—— 契约管不到的就不塞进契约。
- **范围判定（真假接缝）**：tab 展示面 = **同一语义的多份声明** ⇒ 强制收口；
  各 provider 的 `list` 实现 = 判据/宿主不同 ⇒ 保留分层。

## 四 · Step 4 定契

```ts
// mediaRefTypes —— 契约补**展示面**（数据面原有：label / categories / list）
export interface MediaRefProvider {
  source: MediaRefSource;
  label: string;          // Tab 显示名（消费方直接用，不写映射）
  order?: number;         // 展示顺序：越小越靠前；缺省 = 排所有显式声明者之后（同缺省者保持注册序）
  categories?: () => MediaRefCategory[];
  //   ⚠️ 契约条款：**首个分类 = 该来源的默认分类**（进入即套用）—— 此前只是消费方的"猜"
  list: (query?: MediaRefQuery) => Promise<MediaRefEntry[]>;
}

// mediaRefRegistry —— 排序唯一入口
listMediaRefSources()  →  按 provider.order 升序（Array.sort 稳定 ⇒ 同值不乱序）

// ImportMediaModal —— tab 序列唯一派生处（禁止再写硬编码清单）
tabs = [{ key: LOCAL_TAB, label: '本地导入' }, ...providerSources.map(p => ({ key: p.source, label: p.label }))]
```

## 六 · 弯路留痕

1. **差点只删 `TAB_LABEL` 而留着 `TAB_ORDER`**：第一直觉是"label 明显是重复，顺序是产品裁定、放哪都一样"。
   回读契约原文（`mediaRefRegistry` 的「新增来源消费方改 0 行」）才意识到**顺序才是致命那个**：
   label 重复最多写错字，而顺序硬编码会让**新来源静默不出现** ⇒ 契约承诺当场失效。**三样一起收**。
   （教训：判"哪一份更该删"要看**它坏掉时的可见性**，不是看谁更像重复。）
2. **"顺序该住哪"的三选一（留痕，防后人重纠结）**：① 消费方硬编码（现状，新来源不出现）；② 依赖
   `providers/index.ts` 的 import 顺序（最隐蔽：重排 import 就静默改顺序）；③ **来源显式声明 `order`**（选定）。
   ⇒ 并专门写测试锁住「内置来源必须都声明且互不相同」，因为 ② 的诱惑力在于"少写一个字段"。

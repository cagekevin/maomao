## 一、背景：现在数据存在哪

localTool 的数据（SQLite 库 + 上传的图片/视频素材）默认落在**系统用户目录**：

- **Win**：`C:\Users\<用户名>\.maomao-localtool\`
- **Mac**：`/Users/<用户名>/.maomao-localtool/`（即 `os.homedir()` 下）

目录结构：

```
.maomao-localtool/
├── localtool.db      # SQLite 主库（sql.js 落盘）
├── uploads/          # 用户上传的所有图片/视频（按 subfolder 分）
└── backups/          # 每日自动备份
```

决定路径的代码在 `localTool/src/db/database.ts:11`：

```ts
export function getDataDir(): string {
  const envDir = process.env['MAOMAO_DATA_DIR'];
  if (envDir) return envDir;                 // ← 方案 A：环境变量优先
  return path.join(os.homedir(), '.maomao-localtool');  // ← 现状：系统用户目录
}
```

> 跨平台提示：`os.homedir()` 在 Win/Mac 都返回用户主目录，所以现状两平台都"不在项目里"。改成项目根目录后，两平台行为一致（路径写相对 `__dirname`，无需区分 OS）。

## 二、目标目录约定（双平台统一）

建议存到**项目根目录下的 `.maomao-data/`**（仓库根 `g:/01画布项目/maomao/.maomao-data` 或 `/Users/xxx/.../maomao/.maomao-data`）：

- 优点：随项目走、备份方便、不占系统盘。
- 注意：`database.ts` 编译后位于 `localTool/dist/db/database.js`，`import.meta.url` 上两级到 `localTool/`，再上一级到仓库根。

| 想要的"根" | 相对 `localTool/dist/db/` 的层级 |
|---|---|
| `localTool/.maomao-data/` | `../../.maomao-data` |
| **仓库根 `maomao/.maomao-data/`（推荐）** | `../../../.maomao-data` |

## 三、方案 A：环境变量（不改代码，推荐，双平台零差异）

代码已预留 `MAOMAO_DATA_DIR` 读取，只需在启动前注入：

**Win（PowerShell，写进 `launch-all.ps1` 启动 localTool 之前）：**
```powershell
$env:MAOMAO_DATA_DIR = "G:\01画布项目\maomao\.maomao-data"
```

**Mac（在启动命令前 export，可写进 `mac-启动服务.sh` / `.command`）：**
```bash
export MAOMAO_DATA_DIR="/Users/xxx/01画布项目/maomao/.maomao-data"
```

> 也可在 `localTool/.env` 里加一行 `MAOMAO_DATA_DIR=...`（代码 `loadDotEnv()` 会注入 process.env，但注意 `.env` 是相对 localTool 根的，路径里写绝对路径即可，Win/Mac 各自一份 `.env` 不冲突）。

## 四、方案 B：改 `getDataDir` 默认值（写死到项目根）

适合"任何人都无需设环境变量就存项目根"。把 `database.ts:11` 改为：

```ts
import { fileURLToPath } from 'node:url';
import { dirname } from 'node:path';

export function getDataDir(): string {
  const envDir = process.env['MAOMAO_DATA_DIR'];
  if (envDir) return envDir;
  // 仓库根目录下的 .maomao-data（dist/db → 上三级到仓库根）
  const repoRoot = dirname(dirname(dirname(fileURLToPath(import.meta.url))));
  return path.join(repoRoot, '.maomao-data');
}
```

> 跨平台提示：`path.join` 在 Win 用 `\`、Mac 用 `/`，自动处理；`fileURLToPath` 两平台均可用。无需 `os.homedir()`。

## 六、数据迁移（旧 C 盘数据搬到新目录）

改路径后旧数据**不会自动跟随**，需手动搬，否则等于全新空库。

**Win（PowerShell）：**
```powershell
$src = "$env:USERPROFILE\.maomao-localtool"
$dst = "G:\01画布项目\maomao\.maomao-data"
if (Test-Path $dst) { Write-Host "目标已存在，先确认是否覆盖"; exit }
Copy-Item $src $dst -Recurse
# 旧目录确认新目录无误后可删：Remove-Item $src -Recurse -Force
```

**Mac（bash）：**
```bash
SRC="$HOME/.maomao-localtool"
DST="/Users/xxx/01画布项目/maomao/.maomao-data"
[ -e "$DST" ] && { echo "目标已存在，先确认"; exit 1; }
cp -R "$SRC" "$DST"
# 确认无误后旧目录可删：rm -rf "$SRC"
```

> 中文路径两平台均支持（PowerShell UTF-8、Mac HFS+ 原生 UTF-8），无需额外处理。

## 七、首启让用户指定路径（进阶，可选）

若想做成"正规软件首次弹窗选路径"体验：
1. 新增 `localTool/config.json`，首次无则生成，存 `{ "dataDir": "绝对路径" }`。
2. `getDataDir()` 优先级改为：`config.json` > `MAOMAO_DATA_DIR` 环境变量 > 默认。
3. 前端首次启动检测无 `dataDir` → 跳引导页（**手填绝对路径**最稳；Web 端 `<input webkitdirectory>` 拿不到绝对路径，不靠谱）。
4. 设置页留"更改存储位置"（后台复制目录迁移）。
5. `config.json` 同样加进 `.gitignore`。

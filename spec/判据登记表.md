# spec/判据登记表.md · 收口判据与唯一真源登记

> **它是什么**：本仓每一条「答案只有一个、却可能被写在多处」的真相，登记在这里 ——
> **判据是什么 · 真源在谁手里（文件:行）· 同一个答案还写在哪些地方 · 载体数 N**。
>
> **本文件只写「当前真相」**：一行只回答**「这条判据的真源在哪、全仓还有几份载体」**。**不写过程**
> （TD 编号 / 日期 / 轮次 / 「原登记…已过期」/ 收口前后对比 / 证据链）。历史叙事见 `daily/架构日志/<NN>-*.md`。
>
> **为什么要有它**：`ADR-0057` 规定收口的验收是**载体数净减**。没有这张表，执行者只能靠搜索找副本，
> 而搜索只能搜到他想到的那一种 —— 143 那次按数值搜，类型层与配置层的副本整层漏掉，载体数 **7→8**。
>
> **怎么用**：开工前先在这张表里数 N，收口后再数一次 M —— **M < N 才算完成**。

## ⛔ 维护规矩（改本文件前必读 · 全文只有这一份）

> 本表越写越长的根因 = 把「收口日志」写进了「登记表」。**同一件事只在这里说一遍。**

**允许写（每行只有这 6 列的内容）**：

| 列 | 填什么 | 禁止 |
|---|---|---|
| **判据** | 一句话：「什么的答案由谁定」。**不是**常量名、**不是**类型名 | 写实现细节、写解决方案 |
| **真源** | 唯一说了算的地方。**优先写 `文件#符号`**——符号名稳定、不随代码漂移；**仅当真源是一个区块 / 无法命名的实现**时才写 `文件:行`（此类行号是**定位手段**，代码变动后须随改）。同文件续写锚写 `#符号`。**填不出唯一一个 ⇒ 填 `—`**（即"本板块未收口"） | 填多个、填"多处"、填 TBD；**给区块锚硬编一个 grep 不到的"符号名"**（假锚） |
| **N** | 载体总数（**含真源**），**只数本板块内**，最小 1 | 写"不计／约／0" |
| **型别** | 数值／类型／配置／文档（多选用「·」连） | 留空 |
| **跨板块** | **只写板块名**（多个用「／」连）。别的板块也持有这条判据的载体 | 写说明、写理由、写"疑似" |
| **备注** | **一句话的当前状态**：真源唯一 / 未收口（+ 为什么）/ 已裁定非债（+ 为什么） | 写过程 |

**变更时怎么做**：

| 情况 | 动作 |
|---|---|
| 收口完成（M < N） | **就地改**该行的 真源／N／备注，让行重新等于现状（**改，不是追加**） |
| 新判据 | 追加在所属板块小节内（小节顺序固定为下面 9 个） |
| 已裁定非债 | 真源照填（或填 `—`），备注写「已裁定非债：<理由>」，**不写裁定过程** |
| 有理由 / 日期 / TD 号 / 轮次 / 证据要留 | 写进 `daily/架构日志/<NN>-*.md`，**不写在这里** |

**禁写清单**（出现即违规，须当场回退）：

- ❌ TD 编号、日期、轮次号、「原登记…已过期」、收口前后对比、证据链、谁在何时做了什么
- ❌ 同一结论在「备注」与别处（核实列 / 小结 / 汇总）重复表述（要复用就写指针）
- ❌ 单元格内裸 `|` —— 字面量联合一律写 `a／b／c`（裸 `|` 会把表格列撑破，整行错位）
- ❌ 加列、改列序、打乱小节顺序

### 附表：本表不装的资讯去哪（AI 想写日志时看这里）

| 想写的信息 | 去哪 | 说明 |
